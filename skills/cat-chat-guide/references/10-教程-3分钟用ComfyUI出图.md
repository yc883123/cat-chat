# 教程：3 分钟用 Cat Chat 调 ComfyUI 出图

> 来源：仓库图文教程（图文版带截图；本文件是文本版，供教程助手引用）。
> 这是「3 分钟」系列的第 1 篇现有教程；后续篇目随版本追加到本目录。

---

> 目标：不动一行代码，让 AI 帮你把 ComfyUI 跑起来出图。
> 你只需要会三件事：**填一次 API**、**启动 ComfyUI**、**用大白话打字**。

---

## 第 0 步：配置在线 API（第一次使用必做，约 1 分钟）

naiba-chat 本身不带模型——AI 要思考、要调工具，都得先接一个模型服务。第一次打开先配一个在线 API：

1. 点右上角 **⚙ 设置** → 左侧 **「API 供应商」**（默认就在「在线 API」页）。
2. 点最后一张 **「添加 API」** 卡 → 顶部点一个**平台预设模板**（DeepSeek、Kimi、智谱、OpenAI、Claude、Gemini……），名称、URL、请求格式会**自动填好，只剩粘贴 API Key**：

3. 点「检查模型」拉列表选一个模型 → 「测试连接」通过后点 **「保存设置」**。
4. 回到主界面，**在顶栏模型下拉里选中刚加的模型**（不选中发不出消息）。

> Key 到对应平台官网申请（模板卡里一般有「打开注册页」直达链接）。
> 模板里没有你的平台？选「自定义（OpenAI 兼容）」手动填——硅基流动、OpenRouter 等只要文档写着
> 「兼容 OpenAI」，把它们的 Base URL 填进来即可。
> 想让 AI 看图（本教程不涉及，但常用），记得选支持视觉的模型。

## 第 1 步：先把 ComfyUI 启动起来（约 1 分钟）

naiba-chat 是"指挥官"，真正画图的是 ComfyUI，所以它必须在运行：

1. 打开你的 ComfyUI（和平时一样启动它）。
2. 看到网页能打开 `http://127.0.0.1:8188` 就说明它在跑了。**保持它开着**。

> 没有 ComfyUI？先去 ComfyUI 官网装一个，这步不在本教程范围。

## 第 2 步：一键让 AI 接管 ComfyUI（约 30 秒）

打开 naiba-chat，点开一个**新会话**，开始页上就有现成的卡片：

点 **①「通过 HTTP 调用 ComfyUI」** 这张卡——预设指令会**立即自动发送**，不用打字、也不用回车：

**② AI 随即开始探测** ComfyUI 是否在线、接管后续出图操作；想打断随时点输入框右侧的红色停止键。

## 第 3 步：用大白话出图（约 1 分钟）

直接在输入框说你要什么，例如：

```text
用 D:\workflows\cover_api.json 出 6 张封面，seed 1-6
```

> 这个 `.json` 是 ComfyUI 的 **API 格式工作流**：在 ComfyUI 网页里搭好图后，
> 菜单 → 工作流 → **导出（API）**（旧版界面需先在设置里开启 Dev 模式，再点 "Save (API Format)"），保存成一个 json 文件即可。

AI 会自动调用 `comfyui_batch` 把任务提交给 ComfyUI，**图片直接挂回消息里**，点开看大图；真实文件落盘在 `data\generated` 目录：

批量出图在后台跑，**不耽误你继续聊天**。点顶栏的「任务」可以看到进度、随时停止：

## 常见问题

**Q：AI 说连不上 ComfyUI？**
A：九成是 ComfyUI 没启动，或地址不是 `http://127.0.0.1:8188`。先启动 ComfyUI；地址不同时直接告诉 AI："ComfyUI 在 http://127.0.0.1:你的端口"。

**Q：提示没有出图工具？**
A：当前 Agent 的工具集没包含 ComfyUI 工具。打开 设置 → Agent → 选中你的 Agent → 工具集，点 **「ComfyUI 联动」** 卡套用并保存（默认"通用 Agent"已包含，一般不用动）：

**Q：图出到哪里了？**
A：消息里直接能看；文件在 naiba-chat 工作目录的 `data\generated` 下。

## 进阶（可选）：走 MCP 通道

除了上面的 HTTP 直连，也可以让 AI 通过 MCP 调用 ComfyUI。**不用手填任何表单**——点开始页的 **「设置本地 Comfy MCP」** 卡，回车发送，AI 会按 ComfyUI 官方指南自己干完所有事：探测本机 ComfyUI 的 Python 环境 → 安装 comfy-mcp → 注册进 naiba-chat：

- 前提：第 0 步的 API 已配好（AI 得有模型才能干活）；ComfyUI 最好在运行中——AI 会优先挑正在运行的那个环境，本地有多个 ComfyUI 且都没启动时，它会停下来问你用哪个。
- 装完后按 AI 的提醒，到 **设置 → Agent → 工具集** 里勾选启用 MCP 引入的 comfy 工具（MCP 工具不会自动开启）。
- 已注册的服务器在 **设置 → 连接状态 → MCP 服务** 里查看和管理；那里也留着手动添加的表单，但一般用不着。

> 新手用前面的 HTTP 直连就够了，MCP 属于可选项。
