# 验收、返修与事实交接

## 提示词验收

检查原事件、人物关系、对白含义与揭示顺序保留；每格一个瞬间；必要行为、接收与反应之间能衔接；没有把情绪形容词代替可见表演；身份、视线、手部、道具、地标和光源连续。

格数、布局与顺序须一致，关键证据有可读空间。模式转换只改变呈现，不改事实。结尾显示规定结果或明确的开放状态。逐句核对源文字与代码块中的实际入图文字：所选范围的对白、内心、旁白和必要线索无漏句、改写、错归属或重复，栏位与字号足以阅读。仅有图外台词表不满足默认交付；用户明确选择无字时才采用完整图外记录。有目标时长则检查完整行为及对白容量。

提示词自检仅说明设计已检查，不能据此宣称图片合格、模型成功率或视频节奏已经验证。

## 实际成图验收

必须读取实际返回图，对照原事实与提示词。看不清的地方说明无法确认，没有图不声称验收。

| 检查方面 | 实际可见证据 |
| --- | --- |
| 剧情与信息 | 关键事件存在，台词反应顺序相符，线索未提前泄露，关系与结局未改 |
| 表演 | 视线确实指向对象，姿态表达指定行为，迟疑／未回应没有被画成已经接受 |
| 连续性 | 相邻格位置可推断，道具转移有依据，持有手与身体归属正确，场景未复位 |
| 布局 | 格数与阅读顺序可辨，关键脸、手、物件未被裁切遮挡 |
| 视觉模式 | 动漫设计或真人演员保持一致，画风、材质与光影符合所选模式 |
| 文字策略 | 全部应保留文字准确可读，无缺句、错字、漏字、重复、错归属或类型混淆；没有无关文字与伪文字 |

影响事实与可读性的错误不能标记通过；漏台词、关键错字或文字过小同样影响交接，不能因画面正确而忽略。不影响事实的衣纹、装饰或细微调色不要求无限返工。实际比例与提示不同但证据仍清楚可接受并记录，不能只按比例或精美程度判定通过。

## 返修

先判断原因：设计缺必要状态则补连接；已有状态但画错则定点纠正；裁切／景深／遮挡问题则改构图；单格身份或道具错误则局部编辑；文字缺失、错误或过小则重排文字区并给出完整正确原文；多处关键事实或格序错误则重构相关页。不以图外补一张表代替默认图中的文字返修。

一条编辑词应包含本次实际上传映射，用“下排左格”等版面位置与地标定位，给出正确的当前可见瞬间，并保留其余格、身份、场景、格缝、完整正确文字和未指定区域。不能只写“情绪更自然”或“修好手”。

示例：仅修改下排左格，乙的左手停在伞柄前尚未握住，甲的右手仍握柄；两人的袖口清楚区分，乙看向伞柄，保持脸、衣服、背景和其他格不变。

返修后复查整页与相邻格，局部编辑不保证其他区域不变。同一关键问题两轮局部返修仍存在时改用简化构图或相关页重构，不原样循环；用户更低的预算优先。本技能不自动调用生图工具。

## 默认以分镜图交接

默认让已验收分镜图携带本段画面、完整台词、文字类型、角色归属、必要事实与顺序。图中已有完整信息时，用户向下游提供该页／这些页即可，不例行要求同时上传原漫画和另附台词表。原素材在本阶段用于核对，不自动成为用户后续每次必交的材料。

隐藏事实或不能由画面／台词表达但下游确实需要的前提，可用页底简短“剧情备注”随图保留；只写已有事实，避免提前泄露，标明是交接备注、无需出现在视频或配音中。已有足够信息则不添加备注。

下游使用文字栏读取台词、类型与归属；对白转成角色发声，内心独白与旁白转为画外音，角色与类型标签不朗读。实拍画面之外的文字栏不改变真人模式，文字栏、气泡与格框不作为成片元素。

单图交接须以实际图中文字准确可读、剧情完整为前提，不根据提示词承诺已完成。用户需要专门人物／场景／声音参考时仍可提供；不宣称任何任务都只需一张图。

## 需要时的图外补充

只有用户选择无字版、图中尚有明确局限且用户接受继续，或确需补充无法随图携带的信息时，才在代码块外附相应记录；若这时缺少关键原文或事实，应指出所需补充，不假装单图足够：

> 事实与对白交接（不渲染）
> 来源与原阅读顺序：素材／用户描述。
> 不可改事实：关系阶段、事件先后、线索与结局。
> 对白／独白：说话者｜确切原文｜对应格或事件｜类型。
> 文字线索：载体｜确切原文｜首次可见节点｜谁知道／观众可知范围。
> 参考职责：新图控制已验收构图与表演；专门资产控制外观；源素材和记录控制剧情事实。
> 镜头关系／时长（适用时）：连续状态格组、允许的机位变化、用户目标或未指定。
> 尚未确认的事实与已接受局限（如有）。

没有对白就不加空白对白表；只记录所选范围的必要事实与完整文字，不输出内部推理。抽象独白不能悄悄变为实体事件。默认信息已经随图完整保留时不要求用户重复携带原素材与记录；无字版等例外的补充必须覆盖缺失内容。

后续进入视频任务时按用户所选画风与视频工作流处理，不自动进入打戏流程，不提前输出 H3 字段或时间码。成图违反事实则先修图；用户明确接受局限并要求继续时如实交接，不称其已通过验收。
