## 4. 关键实现细节（避免下轮踩坑）

- `messageElement()` 的 `id` 必须置空，否则会带出编辑/分支/删除/重新生成/新会话按钮；这些按钮也没有辅助窗的服务端语义。
- 流式工具卡的「结构签名」要带 pending 位：`tool_result` 是**就地替换同一条 run**（数量不变），只看数量会让「执行中」一直挂着。
- 回填真实消息时只在 `serverMessages.length >= tab.messages.length` 时替换；冒烟里 `/api/chat` 是拦截的假流，后端没有落库，否则会把本地已渲染内容抹掉。
- `restoreAuxChats()` 在启动链里早于 bootstrap 完成，所有 `state.bootstrap.*` 读取必须可选链。
- 辅助对话的供应商**不读** `#modelSelect`（除新建时继承一次），也不监听主对话下拉 change——这是用户明确要求的「主对话换供应商不影响辅助对话」。
