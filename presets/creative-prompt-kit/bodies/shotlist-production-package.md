# Part 2 · 镜头级拆解

## §1 完整视听签名表 (8 字段锁定 · 所有镜头卡的底层约束)

> 必填全部 8 字段 · 大师基因 ≤ 3 位 (公式 A × B 或 A × B × C, A=骨架 60% / B=调色 30% / C=节奏 10%)。
> 自检: 大师不互斥 / 类型 = 配方一致 / 介质 vs 类型匹配 / 核心主题可视化 / 色彩 ID 覆盖完整 (≤ 6 个) / 不超过"什么都想要"。


| 字段 | 锁定值 |
|---|---|
| 介质 (Medium) | [16mm / Super 16 / 35mm / 65mm / IMAX / Arri Alexa LF / Sony Venice / Red Komodo / 数字 + 胶片模拟 LUT] |
| 长宽比 (Aspect Ratio) | [1.33:1 / 1.85:1 / 2.39:1 / 2.76:1 / 1:1 / 9:16 / 可变比例] |
| 调色基调 (Color Grading) | [Teal-Orange / Bleach Bypass / Day for Night / Kodak Gold / Ektachrome / 高对比 B&W / 单色统治 / 黑白局部色 / 怀旧暖橙 / 赛博朋克霓虹 / 北欧冷灰 (选1–2种)] |
| 色彩 ID (Color ID) | [角色 1 = 色相 / 角色 2 = 色相 / 势力 = 色相, ≤ 6 个总数] |
| 介质质感 (Texture) | [颗粒程度 + 光晕 + 反射 + 大气元素 + 噪点, 选 3-5 个标签组合] |
| 核心主题 (Core Theme) | [一句话, 主语 + 比喻动词 + 宾语, 必须可视化] |
| 大师基因 (Master DNA) | [1-3 位导演, e.g. 吉尔莫·德尔·托罗 × 迈克尔·贝] |
| 类型片配方 (Genre Formula) | 开场: [一行] / 转折: [一行] / 高潮: [一行] / 落幕: [一行] |

**8 字段自检清单**:
- [ ] 8 字段全部填写完整
- [ ] 大师基因 ≤ 3 位 (超过会互相打架)
- [ ] 色彩 ID ≤ 6 个 (角色/势力均覆盖, 没有漏色或重色)
- [ ] 类型 = 配方一致 (科幻怪兽不能用文艺片配方)
- [ ] 核心主题可视化 (能拍出来, 不是抽象概念)
- [ ] 大师组合不互斥 (e.g. 小津 + 迈克尔·贝 = 矛盾)
- [ ] 介质 vs 类型匹配 (e.g. 16mm 配文艺 / 65mm 配史诗)
- [ ] 没有"什么都想要" (一份签名锁 1-2 种风格, 不贪多)
