# 打标器任务删除与一键清理已完成任务计划

日期：2026-10-26
背景：用户反馈「打标器完成的任务不能删除，也没有一键清理已完成任务」。交接调研结论见 `2026-10-26-会话进度交接报告.md` §二.1，本计划据此实施。

## 1. 删除范围（拍板口径）

- **删**：任务 JSON（`data/labeler/tasks/<id>.json`）、事件文件（`<id>.events.jsonl`）、
  SQLite 里的 `task_items` 逐图运行行（按 `task_id`）。
- **不删**：`annotations` 标注库。标注按「图片内容 + 配置指纹」全局复用、归属第一个
  产出它的任务，可能被多个任务引用；删除任务后标注继续可查询、可导出，原图留存
  保护由剩余标注行承担（`referenced_original_digests` 会随任务项减少而收紧，这是
  预期行为：不再被任何标注/任务引用且过保护窗口的原图才会被清理）。
- **活动任务（queued / running）拒绝删除**，跳过并在响应里回报；用户先取消、等它
  进入终态后再删。不做「删除时自动取消」——打标按图计费，取消语义必须显式。

## 2. 接口契约（对齐造梦机 `DELETE /api/comfyui/tasks`）

`DELETE /api/labeler/tasks`，body `{ "task_ids": ["tg-…", …] }`：

- 非空 `task_ids`：只删列表里的**已结束**任务；执行中的进 `skipped` 回报。
- 不带 `task_ids` / 空数组：清理**全部已结束**任务（「清理已完成」语义）。
- 响应 `{ ok, deleted, skipped: [id…] }`，HTTP 200；标注库异常 503、文件异常 500。

## 3. 后端改动

- `naiba/labeler/store.py`：`LabelerStore.delete_task(task_id)`——锁内删 JSON 与事件
  文件，Windows 共享冲突短退避重试；只认 `tg-` 前缀 id。
- `naiba/labeler/db.py`：`LabelerDB.delete_items(task_id)`——删 `task_items` 行，
  不动 `annotations`。
- `naiba/labeler/jobs.py`：`LabelerJobManager.delete_tasks(task_ids)`——终态判定用
  `LABELER_ACTIVE_STATUSES`（与取消/恢复同一口径）；逐条「先删记录后删逐图行」，
  单条失败如实抛错，前端刷新后以实际状态为准。
- `naiba/labeler/service.py`：`api_tasks_delete(body)`。
- `naiba/http.py`：`do_DELETE` 里 `/api/labeler/tasks` 分支（GET/POST 已有该 path）。

## 4. 前端改动（public/index.html + 23-labeler.js + styles.css）

- 批次行从单个 `<button>` 改为「主按钮 + 删除按钮」结构（`div.labeler-batch` 包
  `button.labeler-batch-main` 与 `button.labeler-batch-delete`），仅终态批次显示删除。
- 批次头加「清理已完成」（刷新旁）：确认后发空 body 的 DELETE，回报删除条数与跳过数。
- 删除当前正在查看的批次时：停止轮询、清空 `labeler.taskId` 与结果三档缓存、隐藏
  进度条区（`clearSelectedBatch()`），再刷新批次列表。
- 确认文案用户视角：说明「已生成的标注仍保留在标注库，可继续查询和导出」。

## 5. 测试

- 单测（tests/test_labeler.py 新增 `LabelerTaskDeleteTests`）：
  - store 删除任务 JSON + 事件文件；不存在 / 非 `tg-` id 返回 False。
  - db 删逐图行、标注行保留；`counts` 归零。
  - jobs：终态删除成功（store+db 都清）、活动任务 skipped、未知 id 忽略、
    不传 id 清理全部已结束。
  - service：正常响应形状、空 body = 清理已完成、异常映射 503。
  - 前端接线静态断言（删除按钮、清理入口、当前批次清空逻辑在源码中存在）。
- 浏览器冒烟（可选后续）：删除终态批次行、清理已完成、活动批次无删除按钮。

## 6. 验收

- 全量 `tests/` 通过；`node --check public/js/23-labeler.js` 通过。
- 删除后：批次列表即时少了该行；标注库/导出不受影响；正在看的批次被删后界面回空态。
