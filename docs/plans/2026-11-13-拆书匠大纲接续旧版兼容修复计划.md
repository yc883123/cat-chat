**拆书匠「接续已有大纲」旧版兼容修复计划**

日期：2026-11-13。状态：源码兼容修复、针对性回归、专用真实接口 Playwright 及当前完整前端冒烟已完成；全量守门由本轮主任务统一收口。

目标：旧作品只有一份大纲正文、没有版本记录时，用户选择界面提供的「第 1 版」后，可以正常预检、生成，并保存为新版本。

本计划处理已复现的版本号不一致问题，并补齐对应回归验收。已有的接续规则、4000 字截断提示和默认不接续行为沿用现状。横屏三栏与工作台分档冲突另行处理；真实模型逐字保留旧幕的能力也不在本次兼容修复的验收承诺内。

1. **复现与根因**

   受支持的旧作品清单可以包含非空 `outline`，同时缺少 `outline_versions` 和 `outline_version`。

   `NovelStore._sync_current_versions()` 保留这类单份成果；`NovelStore._public_manifest()` 向前端返回大纲版号 1；`public/js/25-novel.js::renderStagePanel()` 也提供「第 1 版」选项。

   `NovelService._build_stage()` 校验 `continue_outline_version` 时，却从原始清单取得默认版号 0。因此选择 1 后，预检和提交都返回 400「指定的版本不存在」，任务未排队。普通 `outline_version` 的校验也使用同一错误默认值：请求同时携带两个字段时，必须保证前一道校验也能通过。

2. **统一只读版本号解析**

   在 `naiba/novel/service.py` 内提取一个只读的大纲有效版号解析函数，供公共清单输出，以及 `_build_stage()` 的 `outline_version`、`continue_outline_version` 两处校验共用。函数名在实施时按文件现有命名风格确定。

   规则如下：

   | 清单状态 | 有效版号与行为 |
   | --- | --- |
   | 缺少 `outline_versions`，正文非空，版号缺失或为 0 | 按旧版单份大纲处理，有效版号为 1 |
   | 缺少 `outline_versions`，正文非空，已有有效正整数版号 | 保留已有版号 |
   | 存在有效版本数组 | 以 `_sync_current_versions()` 同步后的真实版号为准；版号有缺口时也不能用数组长度代替 |
   | `outline_versions` 键存在，但为 `[]` 或 `null` | 沿用当前同步逻辑，按没有有效大纲处理，不从残留缓存恢复旧稿 |
   | 没有可用正文 | 不提供可接续成果；显式请求仍拒绝 |

   保持 `_selected_version()` 的通用校验职责。兼容回退不能让任意不存在的版号通过，也不应扩展到人物设定、剧本等无关字段。

   正文读取仍优先使用选中的版本记录；只有受支持的单份旧稿才回退到清单里的 `outline`。选中版本为空时继续拒绝，不能悄悄换用另一版。

   解析不写入清单、不制造持久版本记录。`sources.continues_outline` 和 `sources.continue_outline_version` 应准确反映所选旧稿；旧稿没有版本标签时，前端现有「第 1 版」回退文案继续可用。沿用已有 API 字段。

3. **保留现有保存与重试语义**

   生成输入继续冻结旧稿正文及来源信息；任务重试使用原始输入快照。用户显式保存结果时，仍由 `NovelStore.apply_outline()` 将没有版本数组的旧正文补为第 1 版，再追加生成结果为第 2 版。

   验收时对比保存前后的旧正文，确认它没有被改写，且新版本引用正确的任务。预检本身不新增版本；提交仍可按现有逻辑更新摘要和作品 revision，不将这些正常副作用误判为兼容修复失败。

4. **补齐后端回归测试**

   优先扩展 `tests/test_novel_records_api.py`，复用现有隔离作品与任务替身；解析函数的边界测试可放在 `tests/test_novel_stage.py`。先让旧版场景在当前代码上失败，再实施修复。

   构造旧格式时使用当前章节 schema，仅移除大纲版本字段，避免把章节迁移混入本次测试。需要验证只读行为时，对预检前后的 `book.json` 做内容比较。

   | 用例 | 必须断言 |
   | --- | --- |
   | 单份旧稿，版号缺失或为 0，接续第 1 版 | 预检 200、提交 201；冻结输入含旧正文与接续规则，来源版号为 1 |
   | 同时传 `outline_version=1` 和 `continue_outline_version=1` | 两处校验都通过 |
   | 单份旧稿已有显式版号 | 公共视图和两处校验保持一致，不重置成 1 |
   | 已有版本数组，存在版号缺口，选择较旧版本 | 引用准确版本，不按数组长度或最新版本替代 |
   | 请求不存在的版号 | 预检、提交均 400，任务提交次数不增加 |
   | 无正文，或选中的版本正文为空 | 明确拒绝，不排队，不改用其他版本 |
   | 空数组或 `null`，同时残留旧正文缓存 | 接续被拒绝，已清空的成果不会恢复 |
   | 默认不接续、非大纲阶段 | 保留现有行为，不增加旧大纲接续槽 |
   | 旧稿生成后保存 | 新增第 2 版，旧第 1 版逐字不变，任务和新正文关联正确 |
   | 预检与重试 | 预检不新增版本；重试不因作品后续变化而更换旧稿快照 |
