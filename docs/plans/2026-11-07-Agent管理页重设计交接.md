## 二、方案定案口径（用户逐轮拍板，别推翻）

1. **控件白名单 = 5 张截图里出现过的控件**，不发明新功能按钮；**唯一新增**是用户批准的「复制为新 Agent」。
2. **按钮位置可以随便移动**，目标是「好看 + 用起来简单」；三层压成一层。
3. **砍掉「恢复默认」**（现状无此功能，且要新后端接口）。
4. **模板区不做卡片，做下拉框**：下拉是动作入口，收起时永远显示占位「套用工具集模板…」，选完立即复位，**不保留选中态 / 不跟着亮**。理由见上表最后一行。
5. 「当前是什么」交给摘要行文字，不靠高亮。
6. 两个保存按钮（「保存 Agent」/「保存工具集」）**保留原名、不合并**：前者存 Agent 配置，后者存可复用模板到 `/api/tool_sets`，目的不同；只挪位置 + 补说明。

设计原型：`_agent_manager_mockup_v2.html`（v2 定案，含完整交互核对表）；`_agent_manager_mockup.html` 是已废弃的 v1，保留作对照。两者都**不是**产品代码。

## 六、必须记住的约束

1. **不要推 master / 不要打 tag / 不要改版本号**。本项目推 master 即触发发版，且发版期间再推会掐掉 CI。本次全部改动都**还在工作树，未提交**。
2. **提交时显式列文件，禁用 `git add -A`**；本机 git 无作者身份，需内联 `-c user.name=... -c user.email=...`。
3. **「内置」标签文案保持原文「内置」不要改**：`verify/agent_cards_smoke.cjs:270-271` 对 badges 做精确匹配，改成「内置 · 可编辑」会破。新角标也**不要**用 `agent-card-badge` / `data-agent-edit` 类名（这两个是负向断言）。
4. **`matchToolScope()` 不能删**：还要服务 `confirmToolScopeOverwrite()` 防误触和 `toolTemplateUsedByAgents()` 删除引用判定，只是不再驱动 `is-active`。
5. **下拉太容易顺手一选，防误触确认更不能省**：出厂全能 Agent 是「预设 + show_media」，按精确匹配口径算「未保存的自定义组合」，所以初始状态选任意模板也会弹一次确认 —— 这是现状保护行为，不是 bug。
6. `confirmToolScopeOverwrite()` 的文案「还没有保存成工具集卡片」被测试断言钉住，别顺手改成「模板」。
