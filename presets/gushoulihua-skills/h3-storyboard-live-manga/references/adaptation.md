# 真人改编与参考分工

## 读图与编号

先看完整材料，辨认分格、人物、台词、旁白、内心文字、拟声字、回忆、想象和时空跳转。阅读方向依据页面布局、作品约定和动作/对白语义链共同判定，不因“漫画”而一律右→左，也不因排列方便一律左→右。仍会改变剧情、说话者或动作结果的歧义需要询问。

按用户提供顺序建立一次全局 `Picture N = 来源` 映射。长图如需裁切、拼接或因输入上限缩减，先确定可辨认的最终集合并确认映射；之后所有 P 上传相同集合与顺序。角色多视图表只提供一个人的不同视角，不能生成多位人物、分屏或展示台。

## 五项改编记录

在确认方案中把下面五项分开列出，已确认项沿用，不重新询问。

### 1. 角色替换

逐项绑定“源角色/叙事职责 → 成片人物 → 身份参考”。例如“源进攻方 → 紫发女性 → Picture 1”。不要只写“使用图 1 图 2”，必须明确谁发炮、谁受击、谁说话。

真人人物图控制脸、年龄段、发型、肤色、身体外形、常规服装与已知颜色。漫画的原人物身份与服装只在用户明确保留时继承。角色性别替换后，未指定的声音锚点适配成片人物；对白原意与说话者叙事职责不变。

没有真人人物图时，可根据漫画可核验的外观事实提出真人对应设计。不要把夸张漫画比例、符号眼睛或绘制线条照搬成人体；也不要凭空加演员姓名、种族或不同年龄设定。

### 2. 装备与道具

区分：

- **剧情驱动装备**：机械臂、炮口、剑、盾、能力装置、用于开门的钥匙等。角色替换不能让必要动作失去执行条件。用户未说明时，提出保留、改装或功能替换的具体方案；会改变攻击方式或剧情时必须确认。
- **身份服装**：帽子、裙子、披风、鞋、饰品。默认服从成片人物参考，不把漫画原角色的整套服装带回。剧情依赖某件服装时单列冲突。
- **非剧情附带物**：摄影表中的手袋、道具摆台或灰色背景。并非全部都应自动丢弃：按动作需求提出保留、收起或排除，进入确认方案。不要因是战斗就擅自去鞋、脱衣或换装。

每个装备覆盖记录清楚：哪个人物、哪个部位、来源、保留功能、何时展开/收回、与原服装怎样兼容。机械臂替换人臂，不生成额外手臂；折叠炮与拳击形态必须能在动作顺序中合理转换。保留功能不等于照搬旧角色脸或服装。

### 3. 环境转换

实景参考控制环境材质、颜色和客观外观；漫画控制叙事必需的方位、距离、遮挡、出入口、运动路径与碰撞目标。若参考是一间室内房间而漫画依赖大型峡谷，不自行平均混合；确认能执行剧情的场景改编。

无实景图时，由漫画空间事实构建真人环境：岩壁变成可见裂隙与断面的实体岩石；尘土、碎石、水和烟有可见运动；建筑保留结构与动线。明确这是媒介转换，不是另有实景身份参考。不擅自新增城镇、天气灾害、车辆或观众。

### 4. 表演与视效转换

转换表现手段，保留叙事功能与能量尺度：

| 漫画信息 | 真人表达 |
|---|---|
| 汗滴、惊讶符号 | 细小汗珠、眼神变化、呼吸或表情；不生成图形符号 |
| 速度线 | 位移、运动模糊、尘土、摄影机跟随；不把线画在画面上 |
| 重复手臂/残像 | 连续动作轨迹或快速切镜；不生成额外肢体 |
| 相邻格重复同次打击 | 接触近景与结果全景合成一次完整打击；不凭空增加连击 |
| 超常击飞、能量炮 | 真人表演结合整合视效，保留路径、命中/掠过、冲击与结果 |
| 飘动披风 | 未保留披风时用现有头发/衣物表达运动，不补回旧服装 |

真人目标不要求放弃超自然动作。能量特效应照亮人物、地面与尘雾；攻击具有起势、方向、接触或明确掠过、位移和落点。地面破坏、飞行与撞壁依照源格，不把掠过写成命中，不把烟尘遮挡写成消失或死亡。

文字只用于提取对白、语义或物理声音；不要在提示词描述原文字的颜色、位置和字形，以免诱导复刻。

### 5. 色彩与媒介

媒介固定为真人影像，允许 `live-action footage`、`natural skin detail`、`tangible rock surfaces`、`integrated visual effects` 等有职责的描述。不是要求堆砌 `cinematic`、`8K`、`masterpiece` 等标签。不能正向要求 anime/manga/cartoon/cel-shaded 成片，也不能让“外观服从漫画”把人物和背景拉回绘制形式。

可靠彩色人物或环境参考支持整段彩色；没有颜色依据时提出一致方案，未知颜色保守推断并标明。用户指定黑白则保持黑白真人片。不要把颜色选择与媒介选择混为一谈。

## 全局视觉职责

每个 Picture 都列出职责和排除项，可按人物外观、装备覆盖、环境外观/空间、分镜、动作、构图、镜头顺序组合。

人物图和实景图不应夺走漫画的动作时序；漫画不应夺回被人物图覆盖的身份和服装。职责冲突在方案阶段解决，所有 P 使用同一职责文本。
