将用户提供的剧本、镜头表或实际图片分析转为一个子单元的一份图像故事板提示词。只输出文字，不调用生图工具。范围≤15秒，长段按戏剧自然断点切分，本次仅写指定单元，不同时写视频版。
先输出简短【素材视觉清单】逐镜列真实主体/姿态/方向/场景，再按单一推拉摇移能否完成决定合并；明确不同主体/场景或剪辑切换才拆。已有镜表不擅自增删重排，确需合并说明映射。
参考图使用@图片N作为具体角色名或场景名，编号与实际素材对应；没有图则不造引用。故事板不要自称其输入就是故事板，也不列未给的道具图。标题、段头和风格行用以下契约。K个有内容镜≤8，随后8−K格黑屏，黑屏只是拼版占位，不代表视频也要黑场；K>8应另分子单元，不挤格或漏镜。

## 4.1 故事板 prompt 整体结构

```
@图片1作为{角色A}
@图片2作为{角色B}
@图片3作为{场景A}
@图片4作为{场景B}

白色故事板。2×4 网格 8 帧黑白线条分镜，黑边框、红墨方向箭头、蓝色中文运镜批注。文字只需要运镜描述，不需要其他内容。

八帧 —— {短片标题} (总时长 X 秒)

镜头1 | {景别+角度+运动} — {画面描述}
镜头2 | {景别+角度+运动} — {画面描述}
...
镜头N | {景别+角度+运动} — {画面描述}

风格： 分镜故事板 —— 黑白线条、红墨方向箭头、蓝色中文运镜批注
```

## 4.2 故事板 8 条硬约束

1. **有内容镜头数灵活, 视题材定**: 不死磕 8 镜, 按 §4.5 推/拉/横移摇能一次完成的合并为一帧, 实战有内容镜头常用 3-8 镜
2. **批注文字只放运镜术语** (蓝色中文)
3. **风格行固定为**: `风格： 分镜故事板 —— 黑白线条、红墨方向箭头、蓝色中文运镜批注`
4. **段头固定为**: `白色故事板。2×4 网格 8 帧黑白线条分镜，黑边框、红墨方向箭头、蓝色中文运镜批注。文字只需要运镜描述，不需要其他内容。`
5. **标题行格式**: `八帧 —— {短片标题} (总时长 X 秒)` (中文破折号). **标题永远写"八帧"**, 不改成"五帧" (网格固定 8 格)
6. **严禁 @故事板 自指**: 故事板 prompt 第一行**严禁**写 `@图片1作为故事板`. 参考图只列**角色**和**场景**, 道具也省
7. **故事板是"静止画面"原则, 允许"动作高潮瞬间" frozen frame** (见 §4.3)
8. **镜头不足 8 时用"黑屏" 补足 ** — 故事板网格固定 8 格, 实际有内容镜头 < 8 时, 用 `镜头N | 黑屏` 补足到 8. **不是"第 8 镜永远是黑屏"**, 是"不足 8 镜时把后面缺的补成黑屏"

   **规则**:
   - 实际 8 镜内容 → 8 镜全写内容, 不补黑屏
   - 实际 < 8 镜内容 → 后面缺的镜头都写"黑屏" 补到 8

   **例 1 (实际 5 镜)**:
   ```
   镜头1-5 全写内容
   镜头6 | 黑屏
   镜头7 | 黑屏
   镜头8 | 黑屏
   ```

   **例 2 (实际 3 镜)**:
   ```
   镜头1-3 全写内容
   镜头4 | 黑屏
   镜头5 | 黑屏
   镜头6 | 黑屏
   镜头7 | 黑屏
   镜头8 | 黑屏
   ```

   **例 3 (实际 8 镜)**: 8 镜全写内容, 不补黑屏

   **Why**: GPT Image 看到段头"8 帧" 必须画 8 格. 不补 8 → 模型自己脑补补镜头 → 经常自加海报帧. "黑屏" 是最干净的"占位"。

   **配合 v1.22-B 1:1 对应**: 视频 prompt **不需要补黑屏**, 只写故事板**有内容**的镜头数

## 4.3 frozen frame 原则

故事板每一帧是**一个静止画面 = 一张照片**, 但这个画面**可以是动作的高潮瞬间** (frozen frame), 不必规避动词。

### 判断标准

GPT Image 能不能从描述里画出**一张明确的画面**?

** 禁用: 连续过程描述** (描述"从 A 到 B 的运动过程"):
- "戟从天空朝屋顶飞行直到接触" (过程)
- "鬼影从远处朝镜头逐渐飞来" (过程)
- "童年主角朝镜头深处奔跑过去" (过程)

** 允许: 动作高潮瞬间 frozen frame**:
- "神戟戟头**砸入**屋顶, 屋顶瓦片**飞溅**, 烟尘弥漫" (砸入瞬间画面)
- "鬼影**扑面**, 嘴几乎贴住镜头, 黑舌**伸出**" (扑面瞬间画面)
- "童年主角**奔跑**, 半身倾斜, 双腿半空跨步, 灰布飘动" (奔跑高潮姿态画面)

**思维**: 把每个镜头描述当成"摄影师按快门那一瞬抓到的画面"。

## 4.4 故事板动词允许 / 禁用对照

### 允许 (5 类)

| 类型 | 例 |
|---|---|
| **位置** | 在画面顶部 / 中央 / 右上 / 深处 |
| **朝向** | 凝视 / 面朝 / 背对 / 侧对 / 仰面 / 俯首 |
| **姿态 (静止)** | 悬挂 / 站立 / 跪坐 / 持刀 / 张口 / 闭眼 / 仰头 |
| **姿态 (动作高潮)** | 奔跑 / 扑面 / 砸入 / 撞击 / 飞溅 / 崩裂 / 塌陷 / 迸发 |
| **关系** | 围绕 / 包围 / 散落 / 堆积 / 紧贴 |

### 禁用 (过程动词)

朝镜头飞来 / 从远处坠下 / 缓缓走来 / 逐渐显形 / 朝 X 运动过去

### 区分"过程动词" 和"瞬间动词"

- **过程动词** (描述持续运动): 飞来 / 坠下 / 走来 / 推开 / 显形 / 渗出 → **禁用**
- **瞬间动词** (描述某一刻的状态/动作): 砸入 / 飞溅 / 扑面 / 撞击 / 崩裂 / 跨步 / 张开 → **允许**

### 实战对照表

| 场景 | 故事板 (frozen frame 瞬间) | 视频 prompt (动态过程) |
|---|---|---|
| 鬼影扑镜头 | "鬼影**扑面**, 嘴几乎贴住镜头, 黑舌伸出" | "鬼影【朝镜头袭来】, 张大口扑面" |
| 火星坠落 | "火星**砸入**屋顶, 火花迸发, 瓦片飞溅" | "火星【从画面顶部坠下】砸入街市" |
| 主角奔跑 | "童年主角**奔跑**, 半身倾斜跨步" | "童年主角【朝画面深处奔跑】, 灰布飘动" |

## 4.5 镜头演变 ≠ 拆多帧 

故事板每帧 = 一个**视觉锚点**。如果两个"镜头" 是**同一个镜头的镜头运动演变** (推/拉/横移/摇), 那它们是**视频阶段的一个镜头**, 故事板**只画一个锚点**。

### 错 ↔ 对 对照

 **错** (镜头运动演变拆成 2 帧):
```
镜头3 | 中近景 仰拍·静止 — 反派本体, 嘴张开露上下两排尖牙
镜头4 | 极端特写 平视·静止 — 镜头深入嘴内, 上下尖牙占满画面
```
→ 镜头4 = 镜头3 推镜头进嘴的演变, 视频阶段会自然处理。

 **对** (一帧故事板 + 视频 prompt 推镜头):
```
故事板镜头3 (唯一帧): 中近景 仰拍 — 反派本体, 嘴张开露尖牙

视频 prompt 镜头3 (对应): 中近景 仰拍·慢推 — 镜头从反派本体推进至嘴内深处, 上下尖牙渐近占满画面
```

## 4.6 严禁自加"收尾/海报帧" 镜头 

故事板/视频 prompt 必须严格忠于:
1. **原 frame 范围** (用户给的逐帧分析)
2. **原 shotlist 范围** (用户给的镜头表)

**严禁自加**:
- "大远景拉远定格" 收束镜
- "多元素同框" 海报帧
- "鸟瞰全景" 收尾镜
- 任何**原素材没出现过的镜头**

**判断流程** (写每个子单元最后一镜时):
1. 这一镜在**原 frame / 原 shotlist** 里吗?
2. 不在 → **删除**, 不要自加
3. 在 → 保留, 但要忠实于原视觉

**Why**: 死板教科书思维 ("每段必须海报帧收尾") 让 prompt 跟原素材脱节, 视频模型生成"自创收尾" 时可能跑偏。子单元之间**自然连接到下一段** 就够。

## 4.7 故事板状态渐变需要新视觉锚点 

状态渐变要分多镜, **但每镜必须有新视觉锚点 (景别/角度/主体/构图 至少一个不一样)**。

### 边界对照

 **错** (同景别+同角度+同主体, 只改细节状态):
```
镜头1 | 大远景 仰拍 — 古城屋顶 + 天空平整阴云
镜头2 | 大远景 仰拍 — 古城屋顶 + 天空翻卷浓云
```
→ 黑白线条故事板里, 两帧画出来 80% 像, 浪费格子。

 **对 - 方案 A** (合并为一镜):
```
镜头1 | 大远景 仰拍 — 古城屋顶 + 天空翻卷浓云
```

 **对 - 方案 B** (每镜真有新视觉锚点的渐变):
```
镜头4 | 全景 平视 — 主角入院, 天空月色          (新主体)
镜头5 | 近景 仰拍 — 主角面部, 月光打脸           (新景别 + 新角度)
镜头6 | 近景 仰拍慢推 — 主角面部, 蓝光→红光      (新光线状态 + 拐点)
```

### 3 问检查

1. 跟前一镜对比, 景别/角度/主体/构图至少一个不一样吗?
2. 黑白线条画出来, 跟前一镜能一眼区分吗?
3. 这一镜带来的新信息, 能不能在视频 prompt 阶段通过运动描述实现, 而非占用故事板格子?

**3 个全"否" → 合并**。
