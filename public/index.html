Agent 是什么？

把 Agent 理解成一个「岗位角色」：它有自己的人设（提示词）、自己的工具箱（工具集）和技能包（Skill）。 切换 Agent 就像换了一个不同岗位的助手——它能干什么、不能干什么，完全由工具箱决定： 没勾选的工具，它一律用不了。工具箱在会话开始时就锁定，中途不能换（要改去「设置 → Agent」）。

三种预设 Agent 怎么选？
  • 通用 Agent：没有特定人设，日常问答、写作、整理资料都用它。
  • 编程 Agent：程序员人设，写代码、改文件找它；动手改文件前会先告诉你改哪里。
  • 短剧 Agent：编剧人设，配合短剧类 Skill 一步步确认主题、角色、分镜后再产出内容。
想用 ComfyUI 出图？两条路任选其一

路线一 · HTTP 直连（推荐，最省事）

  1. 启动本机 ComfyUI（默认 http://127.0.0.1:8188）。
  2. 「设置 → Agent」编辑 Agent → 工具页，一键套用「ComfyUI 联动」预设 （含 comfyui_prepare_workflow、comfyui_batch 和任务查询工具 job_output / job_status / job_wait）。
  3. 不需要配置 MCP。

路线二 · MCP 连接

  1. 在「设置 → MCP」配置并连接 ComfyUI MCP 服务（可用「设置本地 Comfy MCP」预设指令让 AI 帮你装）。
  2. 连接成功后，MCP 引入的 comfy 工具会出现在 Agent 工具页，手动勾选启用。
两条路任选其一即可，一般不需要同时开。Agent 的每个工具在设置页都有说明，不确定就先只读模式试试。
