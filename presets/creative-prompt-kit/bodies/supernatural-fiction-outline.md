## 三、功能结构母题（FSM）

### 十大功能簇

角色在叙事中采取的31种核心行动，归纳为十大功能簇，聚焦微观层面的情节动力学。

### 链式触发原则

```
前一功能输出状态 → 后一功能输入条件 → 因果驱动的叙事流
```

**链式展开四要素：**
- 激活条件（何种状态触发）
- 执行过程（具体叙事展开）
- 状态变更（世界+角色变化）
- 后续选项（基于状态变更的合法后续功能集合）

### 主线-支线耦合规则

| 规则 | 说明 |
|------|------|
| 容量规则 | "磨难"阶段容量最大5-7个，"平凡世界"最小1-2个 |
| 类型规则 | "深入洞穴"优先空间探索；"终极恩赐"优先能力获取 |
| 顺序规则 | "遇见导师"引入的物品必须在后续发挥作用 |

### 母题密度控制

| 阶段 | 密度（次/千字） | 说明 |
|------|---------------|------|
| 开篇 | 0.3-0.5 | 建立世界观 |
| 高潮 | 2.0-3.0 | 制造紧张感 |
| 结尾 | 1.0-1.5 | 情绪缓冲 |

## 四、三级纲要生成法

### Macro：小说大纲（英雄之旅 × ATU映射矩阵）

**阶段-类型映射矩阵（STMM）：**
- 纵向：英雄之旅八阶段
- 横向：ATU功能类别
- 单元格：该交叉点的推荐编码+叙事权重

**超自然元素调用频率（斐波那契间隔）：**
- 核心元素（主角神器）：每章出现
- 重要辅助（关键援助者）：每2-3章
- 次要元素（一次性道具）：每5-8章
- 稀有元素（世界规则揭示）：每13-21章

**波浪式分布：** 每10-15章 = 上升期(3-5章) + 高潮期(2-3章) + 下降期(3-5章) + 蓄力期(2-4章)

---

### Meso：细纲展开

**功能母题链式展开：**
```
头母题（关键节点）→ 后续链节（N个）→ 叙事钩子（悬念）
```

**钩子四类型：**
- 信息缺口（新发现需解读）
- 情感危机（关系待修复）
- 生存威胁（敌人即将反扑）
- 道德困境（两难选择待决）

**冲突升级曲线：**
- 可选数值模型（实际为指数增长） S(t) = S₀ × (1+r)^t
- 战力跃迁：获取关键元素后提升50%-200%

---

### Micro：章纲细化

**场景-功能单元（SFU）：**
- 每个SFU = 微型叙事弧：触发→反应→决策→结果
- 标准节奏："张-弛-张"（高冲突后接过渡）

**悬念钩子植入：**
- 检查未解决张力：本章是否留下可追踪的问题，不输出未定义的数值指数
- 每章至少1个章节内钩子
- 每2-3章至少1个跨章节钩子
- 每10章设1个"超级钩子"（核心谜题/终极威胁）

**情感节拍三控制点：**
- 起始点（承接上章）
- 转折点（情感方向改变）
- 结束点（与钩子类型匹配）

---

### ATU锚定提示模板（AAPT）

```
【元数据层】 ALMEF编码（英雄之旅阶段+ATU类型+功能母题序列）
【情境层】 时间/地点/角色状态/前情提要
【任务层】 本章需完成的叙事功能
【约束层】 禁止的设定冲突/角色偏差/文风要求
【输出层】 格式规定（场景标题/正文/对话标注/情感节拍）
```

### 三层上下文窗口管理（HCC）

| 层级 | 内容 | 权重 |
|------|------|------|
| 全局层GC | 英雄之旅阶段概要（~200 tokens） | 0.3 |
| 中观层MC | 功能母题链（~1000-2000 tokens） | 0.5 |
| 微观层MiC | 前2000-4000字正文 | 0.8 |

## 十大核心原则

1. **类型是骨架，ATU是肌肉，FSM是血液**
2. **功能母题链式触发，因果驱动而非事件堆砌**
3. **母题密度控制节奏：高潮密集，铺垫稀疏**
4. **契约系统 = 条款 + 代价 + 违约三元结构**
5. **冲突升级 = 持续加压 + 有铺垫的能力跃迁**
6. **每章必须有钩子，超级钩子贯穿半部作品**
7. **超自然元素渐进揭示：前期单一，中期组合，后期联动**
8. **平凡世界压缩，冲突前置，倒叙式启程**
9. **主角成长 = 功能整合，不等于类型转换**
10. **女性英雄之旅需要主动赋予完整的行动空间**
