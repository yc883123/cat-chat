## 二、总结论

1. **3469 项单元/契约测试全部通过**（217 秒，OK），与 README 声称的数字一致。
2. **静态检查全部通过**；esm_graph_check 的 11 条告警逐条核实**全部为误报**（同名局部变量/字符串字面量/已存在的导出），浏览器加载零 pageerror 佐证。
3. **浏览器与脚本冒烟**：官方浏览器冒烟在干净实例通过；80 项冒烟初轮 37 过 43 败，复跑与逐项归因后——**未发现需要修改代码的产品缺陷**。失败项归为五类（详见报告 04）：
   - 首启向导拦截（4）——脚本早于向导功能，缺一行标准关闭调用；
   - 报错噪音计数（11）——favicon 404 与播种死供应商 400 被旧脚本的「零 console.error」口径误判；
   - UI/API 演进断言漂移（8）——操作区按钮、预设工具数扩容、即时保存、模型门禁等**有意的功能演进**，当前行为均已在 GUI 实测为正常；
   - 环境与配套缺失（11）——已被清理的一次性配套脚本、缺失的 seeder、无 ComfyUI 服务、fake-ip DNS 等；
   - 待人工复核（4）——folder_drop 重拖是否应记住拒绝、tool_peek 是否漏列 `extract_video_frames_exact`、quick_msg 富文本插入路径、_comfyui_opt 默认参数显示集。**这 4 项是全轮测试唯一值得人工看一眼的点。**
4. **GUI 黑盒实测 16 个测试点全部通过**（1 项部分）：从首启向导 → 添加供应商 → 检测模型 → 流式对话 → Markdown（标题/列表/代码高亮+复制/表格）→ 工具调用确认与文件真实落盘 → 停止/插话/重新生成/编辑/分支/删除+撤销 → 外观字体滑杆 → 设置 12 页 → 工作台五模块 → 手机 375px，全链路零 pageerror。
5. 侧栏活跃状态图标（最新提交 06a4dc3）在有会话实例上复跑冒烟**全部通过**，且 GUI 中肉眼可见旋转图标正常工作。

## 三、给维护者的三句话

1. 旧冒烟脚本大面积停更于 9 月上旬～10 月初，而 3.6→3.9.10 期间 UI 演进很快；建议按报告 04 的归类分三步收口：给 A/B 类脚本补「关向导 + favicon/400 白名单」两行口径、按 C 类逐条更新断言、为 D 类补回配套脚本或改用 `_serve_tmp`。
2. E 类 4 项建议人工复核，其中 tool_peek 的 `extract_video_frames_exact` 缺列是唯一「UI 可能真的少列了一个工具」的疑点。
3. 本轮在开发库 `data\chat.db` 播种的冒烟会话（媒体/用量/收藏/Agent 卡）沿用了仓库既定冒烟流程，未清理，可随时用界面删除或忽略。
