# 发版前改动汇总（2026-10-25）

对应版本：**3.7.5-beta**  
实施计划：[2026-10-25-造梦机完整节点映射与动态端口提示计划.md](plans/2026-10-25-造梦机完整节点映射与动态端口提示计划.md)

## 本次改动

### 造梦机完整节点/端口映射

- 媒体槽标签恢复为「节点号 · 节点名 · 字段 → 目标输入端口」，例如 `43 · 載入圖片 · image → ref_images.ref_image_3`；不再用「参考图 4」这类短名称代替映射。
- 同一来源的全部下游连接逐一列出，不再只报第一个端口或「等 N 处」；多输出节点标出 API 输出索引；不同目标节点端口重名时补目标节点号消歧。
- 非媒体参数节点同样保留来源与全部下游端口。
- 主表单与「编辑参数」清单都显示完整映射；长映射与多行输出允许换行，375px 窄屏不截断。

### 未选媒体提示

- 按 ComfyUI 节点声明判断未选媒体能否安全跳过，提示与实际执行一致：
  - 全部相关输入可省略：`未选即跳过`
  - 已选文件：`已选：文件名`
  - 无法确认可跳过、工作流原值为空：`请选择文件`
  - 无法确认可跳过、工作流保留原文件：`未选沿用原文件`
- 「清除」按钮说明同步（确认可跳过时提示清除后跳过，其余说明回到原文件/空值）。
- Autogrow 动态输入校验 `prefix`/`names`、编号范围与 `min`；混有必需输入或声明不明时不承诺跳过。
- 执行端移除未选媒体连接与界面提示共用 `input_is_optional()`，避免提示与执行判断分叉。

### 参数缓存升级

- `PARAMS_SCHEMA_VERSION` 从 5 升至 6；旧工作流详情读取时重扫一次，恢复完整映射。
- 升级时 ComfyUI 离线的工作流，下次打开详情只补未确认的媒体可选性并落盘；不重置用户参数勾选、工作流内容或任务快照。

### 任务卡片标题闪烁修复

- 现象：造梦机任务列表第一张卡片的标题在 `任务` 与工作流名之间来回切换。
- 原因：任务列表接口返回带 `workflow_name` 的精简行，任务详情轮询接口返回原始任务，没有 `workflow_name`；前端回退显示 `任务`，两条刷新链交替覆盖同一张卡片。
- 修复：详情接口与列表接口统一返回精简字段（`workflow_name` 等），并给前端卡片指纹补上 `workflow_name`；标题稳定显示工作流名。
