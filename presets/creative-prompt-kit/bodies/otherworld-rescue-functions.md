根据用户设定写一份营救冒险大纲，或用同一表分析已有故事。输出【角色功能】【A–G功能链】【三重试炼】【道具铺垫与兑现】【归来验证】【检查与缺项】。每节点给激活条件、行动、状态变化、后续后果；分析模式引用原文，不补造事实。
本模板借鉴异界营救民间故事，A–G为本地设计标签，不是官方ATU或Propp功能编号。来源Propp F1–F27对应及ATU近邻表多处错误，均不使用；龙穴故事与地下营救不能只凭有龙归为同一官方类型。
七簇完整定义：A破局=目标失踪/任务发布/出发；B试炼=导师或赠礼者/获得有条件帮助/三种不同考验；C探入=下降至异界/发现被困者/获知守卫弱点/取得识别信物；D对决=面对守卫/用能力或智谋/解除囚禁；E归途=撤离/追击/障碍/援助兑现；F确认=不被认出/假英雄领功/信物与证词/最终考验/真伪揭露；G新秩序=奖励、关系或身份变化/责任清算/和平恢复。
被救者可以提供情报、保管信物、协助逃离、作证并自己作决定，不能把婚姻当营救自动奖赏；结尾可用伙伴结盟、家园复原或公开认可。三重是可选重复变奏，三关分别检验力量、智力与道德，不是打同一怪三次。

## 七、三重结构（The Rule of Three）

异界营救模式 中最核心的叙事规律：**三重法则**

### 三重试炼（Three Trials）

```
第一试炼：身体力量型
├─ 例：穿过火焰
├─ 例：跨过刀桥
└─ 例：击败守卫

第二试炼：智力解谜型
├─ 例：猜出谜语
├─ 例：完成不可能的任务
└─ 例：分类物品

第三试炼：道德抉择型
├─ 例：抵抗诱惑
├─ 例：帮助弱者
└─ 例：遵守诺言
```

### 三重逃脱（Three Escapes）

```
逃出龙穴后：
├─ 第一次逃脱：越过火海
├─ 第二次逃脱：跨过尖刺桥
└─ 第三次逃脱：水上奔跑
```

### 三重证明（Three Proofs）

```
证明英雄身份：
├─ 第一证明：信物（公主给的头巾）
├─ 第二证明：怪物的一部分（龙的舌头/牙齿）
└─ 第三证明：公主的证词
```

## 十、叙事功能簇分析检查清单

*用于分析或创作异界营救模式类型故事*

### 建置阶段检查

- [ ] 公主/少女处于正常状态
- [ ] 破局事件发生（被偷走/失踪）
- [ ] 国王发布悬赏或英雄自发出发
- [ ] 英雄获得某种形式的帮助或物品

### 发展阶段检查

- [ ] 英雄经历第一重试炼
- [ ] 英雄经历第二重试炼
- [ ] 英雄经历第三重试炼
- [ ] 下降到"另一个世界"

### 高潮阶段检查

- [ ] 英雄发现被囚禁的公主
- [ ] 获知怪物的弱点或打败方法
- [ ] 英雄与怪物进行最终战斗
- [ ] 公主被成功解救

### 结局阶段检查

- [ ] 英雄带着公主踏上归途
- [ ] 遭遇追兵或设置障碍
- [ ] 成功逃脱返回王国
- [ ] 面临假冒者的挑战
- [ ] 最终考验验证身份
- [ ] 英雄与公主结婚
- [ ] 王国恢复和平
