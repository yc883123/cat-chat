# 分镜图提示词输出契约

## 默认交付

简短注明视觉模式与参考图上传顺序，然后交付一个 `text` 代码块中的完整提示词；多页时每页一条可独立复制的提示词。没有参考写“参考图：无”。本次参考映射必须在各代码块内也写全，不能只引用聊天上文。Picture 是自然语言标识，不是 API 参数。

默认生成带完整台词的分镜图：生图代码块内逐格写全需渲染的原文、角色与类型标签、文字位置和阅读顺序。用户复制一个代码块即可保留本页画面与文字，不依赖额外台词表。

不先提供确认方案，不另附未经请求的备选版本或 negative prompt，不输出内部状态表与推理。代码块外只放必要的补充事实、镜头关系及实际调用设置；不得把默认应入图的台词只放在代码块外。建议比例或设置不能声称已经在模型界面生效。

## 提示词结构

1. **任务与风格**：动漫或现实世界模式及用户已确认的具体风格。
2. **版式**：整页方向／比例、确切格数、各行格数、跨行／跨列位置、清楚格缝与唯一阅读顺序。默认左到右、上到下；源素材先按其原阅读顺序理解，再按目标顺序重排。
3. **参考与全局状态**：人物／场景／道具／剧情／构图职责，身份锚点、关系阶段、场景地标、道具归属与光源。
4. **逐格瞬间**：当前可见行为、表演、位置、视线、景别／机位、焦点及必要入画部位。每格只有一个时刻。
5. **视觉层级与相关防错**：按当前事件写少量必要约束，例如没有重复实体、道具未换手、线索不提前露出。平静段落不强套视觉爆点。
6. **文字策略**：默认有字分镜，写全所选范围的对白、内心独白、旁白与必要文字线索，按下面规则安排到对应格中。

逐格可采用：

> 第 N 格（版面位置；景别与机位）：人物当前位置、朝向和正在保持的姿态；视线或手部目标；这一瞬间的主要可见变化；必须入画的证据及视觉焦点。

> 本格文字栏（实际渲染，按列出顺序）：角色名·对白：「完整原文」；角色名·内心：「完整原文」；旁白：「完整原文」。

本格没有文字就不加空栏。角色名和类型是分镜标注，不是待配音台词。旁白归属不明不得强行写成某角色内心。跨多个格的一段文字只完整标注一次，并注明对应格组；不能复制成重复发言。

字段按需选择。人物不在场的线索格不强塞表情；反应近景不强塞全身。身份与空间由相邻格支撑。

“把伞递出去、对方接过后一起走”必须拆成不同瞬间；“伞柄仍由甲握住，乙的手停在柄前”可以同格。互斥的持有状态、打开／关闭状态不靠“随后”塞进同一格。

## 布局与容量

先展开必要状态，合并无信息重复，再决定版式。写具体布局，例如“上排两格、中排一格通栏、下排两格”，而不是只有“自由排版”。格号用于提示词定位，不印在画面。

重要脸部反应、手部交接、屏幕内容或细小线索给足面积与合适裁切；不把所有格都压成极窄画框。画面区与文字区分别预留面积，用清晰高对比字体和自然换行，不覆盖脸、手和线索。已知尺寸时结合格缝及文字栏估计单格可读空间，不规定通用最低像素或格数。

拥挤时先删装饰、重复机位与无关细节，再调画面／文字面积。仍不够可按完整叙事段拆页，每页重述资产和即时状态，不在中途割断完整问答。不得删台词、把文字缩到无法辨认或用省略号代替原文来凑单页；有用户单页、尺寸、格数或时长硬限制时不静默违背，指出具体容量冲突与可放宽项。

分页不是视频分段，连续姿态不是必须切镜。必要时在代码块外简短注明哪些格属于同一行为／镜头关系，不平均分配每格时长或输出视频时间码。

## 对白与剧情文字

默认在图中保留台词，不新增无关标题、Logo、水印、装饰 UI 或伪文字。固有服装图案与已确认标识保留。

- **对白／内心独白／旁白**：逐字保留所选剧情范围内的全部原文、归属、类型与先后，包括短回应、重复呼喊及原有停顿。不得删减、概括成“惊呼”、改写或翻译。换行可调整，文字与标点不擅自更改；模糊字或关键归属无法判定时询问，不猜测通过。
- **默认载体**：每格下方的独立文字栏，按“角色名·对白／角色名·内心／旁白”标明类型。两种画风都适用。现实世界模式的栏位于实拍画面之外，人物与场景仍为真人摄影，不因有字而漫画化。
- **其他载体**：用户要求气泡漫画、原素材排版或明确字幕形式时按其选择。无论载体都保持阅读顺序、说话者归属与关键动作可读。不必同时重复使用气泡和文字栏。
- **剧情必要文字**：短信、便条、信件、门牌或证据文本按确切原文、载体与首次揭示位置安排。必须由观众读到的内容要在道具上可读；文字栏可以辅助交接，但不能把原应在较晚节点揭晓的内容提前写出。真实道具界面不算任意装饰 UI。
- **原有拟声／呼喊**：具有声音意义的源文字保留原字串，可标为“声音·拟声”或“角色名·喊声”，供下游转成声音；无关扫描网站标识与页外出版信息不保留。
- **无台词原创**：没有源台词且用户未要求创作对白时，不编造台词、不添空栏。用户要求原创台词时在授权范围内创作并完整入图。
- **明确排除的内容**：用户删去的剧情段及其文字一并排除，其他保留段的文字仍完整保留。
- **无字例外**：只有用户明确要求严格无字／纯画面时才移出文字，代码块外完整附台词记录并说明这时下游需要额外文字材料。不得把“真人版”“电影画面”或“准备交给 H3”解释为无字授权。

下游 H3 把图中的对白作为人物发声，把内心与旁白作为画外音，把拟声转成对应声音；角色／类型标签只是说明，不朗读。文字栏、气泡和格框不属于成片画面。这里是交接约定，不输出 H3 正式字段。
