Agent 是什么？

把 Agent 理解成一个「岗位角色」：它有自己的人设（提示词）、自己的工具箱（工具集）和技能包（Skill）。 切换 Agent 就像换了一个不同岗位的助手——它能干什么、不能干什么，完全由工具箱决定： 没勾选的工具，它一律用不了。工具箱在会话开始时就锁定，中途不能换（要改去「设置 → Agent」）。

内置 6 个 Agent，按用途挑一个就行
  • 教程助手 Agent（下拉里排第一位）：不会用 Cat Chat 就问它。它只读、不改你的文件， 回答一律是「一句话结论 + 编号点击步骤 + 这个功能在哪个页面」。
  • 全能 Agent（新会话默认）：日常都找它——问答、写作、整理资料、读写文件、跑命令，工具箱最全。
  • 导演 Agent：出图和拍片找它。聊创意 → 定剧本/分镜 → 写提示词 → 批量出图； 本地 ComfyUI 与云端 RunningHub 两条路都归它管。
  • 提示词优化 Agent：一句大白话或一张参考图，帮你改成能直接用的结构化提示词； 动笔前先问你给哪个模型、要不要英文、出图还是出视频。
  • 编程助手 Agent：写代码、改脚本、看报错找它；动手改文件前会先说要改哪几个。
  • Skill 助手 Agent：帮你发现、安装、用好 Skill——你说想做什么，它去已装清单里找对口的。
这 6 个是内置的：能改能复制，但删不掉（卡片上没有 ×）。 早期版本预置的「通用 Agent / 编程 Agent / 短剧 Agent」已退役：升级时 会自动清掉你没改过的那几个；改过的原样留着，去留由你决定。 想用 ComfyUI 出图？两条路任选其一

路线一 · HTTP 直连（推荐，最省事）：导演 Agent 开箱就带这套工具，切到它直接用即可。 换成别的 Agent 才需要去「设置 → Agent」编辑它 → 工具集页，一键套用「ComfyUI 联动」预设 （含 comfyui_prepare_workflow、comfyui_batch 和任务查询工具 job_output / job_status / job_wait）。

路线二 · MCP 连接：在「设置 → MCP 连接器」里配置并连接 ComfyUI MCP 服务 （可用开始页「设置本地 Comfy MCP」预设指令让 AI 帮你装）；连上后 MCP 引入的 comfy 工具 会出现在「设置 → Agent → 工具集」里，手动勾选启用。

两条路任选其一即可，一般不需要同时开。Agent 的每个工具在设置页都有说明，不确定就先只读模式试试。

    • 
                  
  • 训练人物 LoRA：选「忽略人物」，描述会略过长相、发型、体型与年龄，整个人物留给模型学。
    • 
                  
  • 训练服装 LoRA：选「忽略服装」，描述会略过衣服的品类、面料、图案与配饰。
    • 
                  
  • 训练画风 LoRA：选「忽略画风」，描述会略过媒介、笔触、色调与光影。
    • 
                  
  • 训练场景 LoRA：选「忽略场景」，描述会略过地点、天气与背景环境。
    • 
                  
  • 训练动作 LoRA：选「忽略动作」，描述会略过人物在做什么、动作方向与姿态变化。
    • 
                  
  • 要忽略别的东西：在「高级设置 → 补充要求」里点名，例如「忽略红色手提包」。
    • 
                

                
核心原则：描述里不写什么，模型就学什么。只想完整描述画面，选「通用描述」。
