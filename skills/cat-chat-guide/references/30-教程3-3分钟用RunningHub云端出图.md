# 3 分钟上手：用 RunningHub 云端出图出片（不用本地显卡）

> 目标：家里没装 ComfyUI、或者显卡不够用，也能出图出视频——**算力在云上**。
> 前提：**已经按教程 1 配好一个在线 API**（没配先看 教程 1 · 第一次对话）。
> 你只需要：**切到导演 Agent**、**打 `/` 引用技能**、**说清要什么**。

---

## 第 1 步：切到导演 Agent，再用 `/` 引用 RunningHub（约 30 秒）

1. 在顶栏 Agent 下拉里选 **「导演 Agent」🎬**。
2. 在输入框打一个 **`/`**，会弹出已装 Skill 的列表——选 **`runninghub`**：

打 `/` 是「**本轮临时借用某个技能**」的标准做法，任何已装技能都能这样呼出来（教程 7 会细讲）。

> RunningHub 这套技能是**出厂自带**的，不用你先去装。`/` 只是告诉 AI「这一轮按这个技能的说明来干活」。

## 第 2 步：拿到 Key，交给 AI 保管（约 1 分钟）

RunningHub 是云端服务，得先有一个自己的 Key。**有两件事先说清楚，能省掉一半返工**：

**① 先选站。** RunningHub 有两个**互相独立**的站点，账号与 Key **不通用**：

| 站点 | 网址 | 界面 |
|---|---|---|
| **AI 站**（国际站） | [runninghub.ai](https://www.runninghub.ai) | 英文 |
| **CN 站**（中文站） | [runninghub.cn](https://www.runninghub.cn) | 中文 |

第一次用它时会先问你走哪个站（你也可以告诉她「我用的 AI 站」）。**在哪个站注册，就用哪个站的 Key。**

**② 再选 Key 的类型。** 站里能建好几种 Key，而**标准模型接口（文生图 / 图生视频…）只认「企业级-共享 API Key」**；
个人版 Key 调模型会被直接拒掉（错误码 `1014`，原文是「标准模型API仅限企业级-共享API Key调用」）。

> 也就是说：**个人版 Key 能验通、能存下来，但一出图就被拒**。这是最容易白忙一场的地方，
> 遇到时看文末常见问题，那里有诊断截图和三条出路。

拿到能用的 Key 之后，**直接把 Key 发给 AI**，让它自己验证并保存：

```text
这是我的 RunningHub API Key：xxxxxxxxxxxxxxxx，帮我测试能不能用，然后存下来。
```

发出去之后你会看到它**先去调一次接口验 Key**（几个「已执行」的工具块），通了才写进本机配置。
如果 Key 不对，它会把接口返回的原文贴给你，不会假装成功。

> 注意：这一步**只验「Key 通不通」**。能不能真出图还取决于 Key 的类型（见上面 ②）。
>
> 你也可以自己设系统环境变量 `RUNNINGHUB_API_KEY`，效果一样。
> Key 存在你本机的配置里；除了调用 RunningHub 自己，不会发给别处。

## 第 3 步：说清楚你要什么（约 30 秒）

云端按次计费，所以**先说清楚再提交**最省钱。至少说三件事：

| 要素 | 例子 |
|---|---|
| **要什么** | 一张古风人物立绘 / 一段 5 秒的产品展示视频 |
| **规格** | 竖版 1024×1536 / 横版 / 视频 5 秒 |
| **参考**（可选） | 直接拖一张图进输入框当参考 |

例如：

```text
用 RunningHub 出一张古风人物立绘，竖版 1024×1536，参考我拖进去的这张图。
```

它不会闷头就提交。出图之前它会**先给你一张模型菜单**，让你挑一个再动手：

**说个数字就行**（不选它就默认用第一个）。觉得贵就说「用最快最便宜的」——菜单里每一项都标了「默认推荐 / 最快最便宜 / 写实照片感」这类特点，照着说就行。

挑完之后它才整理参数、提交到云端，**在云端排队**。

## 第 4 步：等云端跑完，产物自动回来（时间看排队）

提交之后是在**云端排队 + 生成**，不在你电脑上跑，所以你可以去干别的（Cat Chat 窗口留着就行）。

- 产物**直接挂回消息里**，点开看大图 / 播放；
- 真实文件落盘在 `data\generated` 目录；
- 长任务挂后台跑，点顶栏的 **「任务」** 看进度、也能停——面板里能看到「运行中 N / 已完成 N」和每批的耗时，不想等就停掉。

> 排队时长取决于云端负载，高峰期可能从几分钟到十几分钟。

## 常见问题

**Q：提示「标准模型API仅限企业级-共享API Key调用」（错误码 1014）？**
A：你用的是**个人版 Key**。所有标准模型接口（文生图、图生视频……）都只认站里的**「企业级-共享 API Key」**，
个人版 Key 只能跑「AI 应用」那一条路。助手会当场把这件事诊断出来并给你几条出路：

三条出路，按省事程度排：

1. **换一条路子**——让它找有没有**支持个人 Key 的 AI 应用**（别人做好的工作流挂到云端跑，同样不需要本地显卡）；
2. **去站内申请「企业级共享 Key」**——想直接用标准模型接口就走这条；
3. **改用本地 ComfyUI**——见 教程 2。

**Q：提示没有 Key / 认证失败？**
A：先去站里拿 Key（**注意 AI 站和 CN 站的账号与 Key 不通用**），然后把 Key 发给 AI 让它存下来（第 2 步）。Key 失效了就重新生成一个。

**Q：提示余额不足？**
A：RunningHub 按量计费，去站内充值即可。注意**「余额」和「coins」是两个口袋**——验 Key 时会同时报出来。

**Q：排队很久？**
A：云端负载决定的，高峰期慢。建议先用一张小图把参数试对，满意了再批量出。

**Q：我自己的 ComfyUI 工作流能用吗？**
A：能。RunningHub 支持把你自己的工作流挂到云端跑，需要先在站内拿到它的 **webappId**，再告诉 AI。技能说明里有这条路径，让 AI 带你走一遍就行。

**Q：本地 ComfyUI 和这个怎么选？**
A：有显卡、想省钱的用 **教程 2**（本地 ComfyUI）；没显卡、想省事的用这篇。
