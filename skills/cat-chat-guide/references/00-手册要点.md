# Cat Chat 手册要点（教程助手知识库）

> 来源：应用说明书（精简重写，术语已统一为 Cat Chat）。表格式给出「入口 → 说明」，需要完整叙述时以软件当前界面为准。

## 一、第一次打开要做的四件事

本机访问免口令；手机 / 局域网访问要口令（**设置 → 连接状态** 页可查）。

1. **添加一个 API**：左下角侧栏底部的 **⚙ 设置 → API 供应商 → 「添加 API」卡片** → 选平台模板 / 填地址与 Key → 点「检查模型」拉列表 → 「测试连接」→ **保存设置**。
2. **选一个 Agent**：顶栏中间的 **Agent** 下拉（Agent = 人设 + 系统提示词 + 工具集）。
3. **选这个会话要用的模型**：底部状态栏最左的 **模型** 下拉（列表来自该 API 的模型目录），**必须显式选一次才能发送**。
4. **发第一句话**：输入框打字 → `Enter` 或点发送。空态里还放了常用指令卡片，点一下就直接发。

> 「API」和「模型」是两个独立开关：**API 供应商**页配的是「去哪儿」（连接），**模型**下拉选的是「用哪个」（按会话记忆）。

## 二、界面分区

| 区域 | 能干什么 |
|---|---|
| 顶栏左 | 展开 / 收起侧栏（状态记住） |
| 顶栏中 | 切 **API**（连接配置）、切 **Agent** 两个下拉 |
| 顶栏右 | 文件 / N 任务 / N Skill / MCP 状态 / 刷新 |
| 左侧栏 | 工作区分组、会话列表、底部「已收藏」 |
| 中间聊天区 | 对话、思考块、工具块、产物、本轮修改文件、**新会话分割线**；右侧还有**对话刻度轨**（一轮一条横条，点一下跳过去） |
| 右侧文件面板 | AI 改过的文件，多标签预览 / 编辑 |
| 底部输入区 | 附件列表 / 添加文件 / 思考强度 / 上下文圆环 / 发送 |
| 底部状态栏 | 模型下拉、工作区下拉、**审批**按钮、快捷消息；右侧：思考强度、上下文百分比、就绪状态 |

## 三、三个必知开关

### ① 审批档位（底部左侧「审批」按钮，点一下弹上拉三档）

| 档位 | 行为 |
|---|---|
| **确认**（默认） | 每次工具调用都弹「需要确认」卡片，点「允许执行」才跑 |
| **自动** | 工作区内自动放行；**工作区外（连读也算）** 仍会停下弹确认卡 |
| **完全** | 不再询问，可访问工作区外。最省事，但写错可能毁文件 |

切换会话 / 打开别的浮层 / 按 `Esc` / 点外面都会收起。

> 已经没有「轻量 / 富文本」开关了——**AI 能用哪些工具完全由 Agent 的工具集决定**。想收窄能力，去 **设置 → Agent** 改工具集。

### ② 深度思考（输入区右侧球形按钮，5 档）

跟随 API（自动）/ 关闭 / 低 / 中 / 高。当前档位常显在输入框下方（如「思考 自动」）。需要模型本身支持（DeepSeek-R1、Claude、o 系列），否则忽略。

### ③ 上下文提醒（输入框右侧彩色圆环 + 「上下文 x.x%」）

- 每次模型请求后刷新；**70% 转黄、90% 转红**；悬停看「已用 / 上限」。
- 超过阈值（默认 80%，**设置 → 运行设置** 可改，填 0 关闭）会弹窗，建议让 AI 写交接文档后开新会话。
- 隔 5 个百分点才提醒第二次，不会一直弹。

## 四、一次对话能干什么

| 能力 | 怎么做 |
|---|---|
| 读 / 写 / 搜文件 | 直接说；受当前 Agent 工具集限制 |
| 发附件 | 拖进输入区（图片、PDF 等） |
| 引用工作区文件 | 输入框打 `@` 弹列表，`Tab` 进目录、`Shift+Tab` 返回 |
| 看图、看 PDF | 附上文件；对话中也能让它调视觉工具（**设置 → 视觉** 可配供应商，留空走免费兜底链） |
| 执行命令 | 直接说；受审批档位约束 |
| 发 HTTP 请求 / 联网搜 | 需要会话工具集里有对应工具；搜索在 **设置 → 联网搜索** 配 |
| 长任务放后台 | 让它放后台跑；顶栏 **N 任务** 看进度、可停止 |
| 中途插话 / 暂停 / 取消 | 直接在输入框继续发；停就点输入框右侧停止键 |
| 本轮改了哪些文件 | 聊天区「本轮修改文件」+ 右侧文件面板 |

### 三个「重开」入口（在消息上悬停出现）

| 位置 | 按钮 | 作用 |
|---|---|---|
| 自己的消息 | **编辑** | 在原处改字后重发（引用与附件都带着走）；`Ctrl+Enter` 确认 |
| 自己的消息 | **分支** | 从这条分叉到新会话（继承同一 API 与模型） |
| AI 回复 | **复制** | 复制整条回复 |
| AI 回复 | **重新生成** | 用那条提问原样再答一次（前面上下文一字不动） |
| AI 回复 | **新会话** | 在此划线，线以上不再进模型上下文（聊天记录仍保留） |

## 五、特色功能

### 5.1 每个会话单独选模型

API 与模型分离：**API 供应商**页配连接，底部 **模型** 下拉选模型，按会话记忆。列表末尾有「↻ 重新检测模型」可当场重拉目录。

### 5.2 长会话模式

工具集预设里选「**长会话模式**」= 标准模式 + `find_conversations` / `recall_history` / `read_conversation` / `reset_context`。配合「新会话分割线」可以把聊很久的会话切段用。

### 5.3 Skill：给 AI 装行业操作手册

- 输入框打 `/` 弹已装 Skill 列表，选中即在**本轮**引用；
- 在 **设置 → Agent → Skill 分区** 可给某个 Agent 绑**固定 Skill**（每次都用）；
- 管理在 **设置 → Skills 管理**（启用 / 隐藏 / 恢复已隐藏 / 安装 zip 或 md / RunningHub 站点切换）。

### 5.4 MCP：给 AI 插外设

**设置 → 连接状态 → MCP 服务**。默认不注册，**只有显式配置并授权才会连接**；连接状态用顶栏 **MCP** 圆点看（绿 / 红 / 黄 / 灰）。

### 5.5 ComfyUI 自动流水线 / RunningHub 云端生成

本地出图走 ComfyUI（HTTP 直连，工作区里的工作流 json + 批量参数）；云端走 RunningHub（420 个接口 + AI 应用）。两条路都归「导演 Agent」管。

### 5.6 权限与安全

工作区 = AI 可读写的根目录，是**安全边界**。底部 **工作区** 下拉切换（绑定会话，重启不丢）。工作区外操作按审批档位拦。

## 六、设置页速查（每个 tab 一句话）

| Tab | 关键项 |
|---|---|
| **API 供应商** | 卡片网格 + 「添加 API」；请求格式（OpenAI 兼容 / Anthropic / Gemini / Ollama / LM Studio / llama.cpp 等）；「检查」测连通+图片能力+工具调用；温度 / 上下文 / 最大输出按供应商独立；**Key 留空 = 保留原值** |
| **Agent** | 卡片网格 + 「新增 Agent」；点卡片进编辑（ID 自动生成、自定义头像、系统提示词、工具集两态、Skill 绑定） |
| **运行设置** | 命令超时、上下文提醒阈值、新会话种子模板（`{handoff_path}` / `{task_count}` / `{task_list}`）、原图上传与压缩、缓存清理阈值 |
| **连接状态** | 上：MCP 列表；下：手机访问地址 + 访问口令 + 局域网 URL |
| **视觉** | 视觉供应商（留空走免费兜底）、单次超时（毫秒）、最大图片数（默认 4） |
| **联网搜索** | 搜索 API profile（可配多个）；搜索结果当素材，别当真理 |
| **Skills** | 已装列表 + 启用/隐藏 + 恢复已隐藏 + 安装 Skill + RunningHub 站点 |
| **数据与迁移** | 数据库版本 / 数据目录 / Skills 目录 / 健康状态 / 备份位置；历史数据一键压缩；「备份」压缩到 `backups/`（**升级前必做**） |
| **软件更新** | EXE 模式：自动检查 → 下载 → SHA-256 校验 → 提示重启；**源码模式不支持一键更新**（要 `git pull` 后重启）；目标版本下拉支持回退 |
| **工作区** | 添加 / 浏览 / 上级跳转；**切换分组即切换目录**，「移至未分组」只改分类不换目录 |

## 七、Agent 与工具集（最容易踩的三条）

1. **工具集在首条消息固化，之后不可改**——要换工具集就开新会话。
2. 工具集有 5 张只读预设卡：**只读 / 标准 / 长会话 / ComfyUI 联动 / 全能**；另有「我的工具集」（存在 `config.json`，重启不丢，可删）。
3. **内置 Agent 不可删除**，但可以点开编辑生成个人覆盖版（「内置」徽标保留）。

## 八、常见问题

| 现象 | 先查什么 |
|---|---|
| 模型连不上 / 报 500 / 代理冲突 | **设置 → API 供应商** 点「检查」；确认底部**模型**下拉已选中一个模型 |
| 换了模型却不生效 | 模型是**按会话**选的；切会话不会跟着变，需在新会话重新选 |
| 图片发不出去 | 当前模型可能不支持图片输入；「检查」里有图片能力检测结果 |
| ComfyUI 工作流报错 | 先确认 ComfyUI 在跑（`http://127.0.0.1:8188`）；再确认工作流 json 是**API 格式**导出 |
| MCP 工具调不到 | 顶栏 **MCP** 圆点看状态；未注册 / 未授权的服务不会连接 |
| 权限一直弹窗 | 底部 **审批** 档位改成「自动」（工作区内放行）或「完全」（慎用） |
| 上下文快满了 | 按弹窗提示让 AI 写交接文档 → 开新会话；或者用「新会话分割线」切段 |
| 卡住了 | 顶栏 **N 任务** 里停止后台 Job；仍不行点顶栏**刷新**整页 reload（内嵌窗口按不了 F5 时用它） |
| 没配过模型 | 主界面空态的指令卡片点一下就能发；先按顺序点「列出可用工具」试水 |
