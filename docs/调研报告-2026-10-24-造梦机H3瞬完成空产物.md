## 3. 已排除的分支（别再查了）

- **媒体缺失理论**（8 个槽位值是 "None"、ref_audio 全空）：用户已否定——H3 无媒体可采样（t2v）。
  快照里 12 个媒体槽 8 个 "None"、3 个上个视频遗留图，只影响内容不影响「是否执行」。
- **「忽略多组孤海」标记节点本身**：`goohaitools-comfyui/nodes/忽略多组.py`——无输入、无输出
  （`RETURN_TYPES=()`、`OUTPUT_NODE=True`、`execute` 返回空元组）的纯 OUTPUT_NODE 占位，
  是 goohai 前端「分组忽略」配置的挂钩；微探针证明它们存在与否**不影响** VHS 是否被执行。
  （但注意它们的存在说明：**goohai 的分组忽略状态不进 API 导出**——Cat Chat 拿到的图与 ComfyUI UI
  里被前端 bypass 后的状态可能不同，这是另一个待确认的语义问题，不是本次瞬完的原因。）
- **VHS 注册表被覆盖**：全库搜 `"VHS_VideoCombine"` 的 py 重注册，只有 VHS 自己
  （`ComfyUI-VideoHelperSuite/videohelpersuite/nodes.py:1040`，类 `VideoCombine` 第 277 行 `OUTPUT_NODE = True`）。
- **核心节点替换（node_replace_manager）**：`comfy_extras/nodes_replacements.py` 注册的替换表
  （longeredge/batchimages/…）不含 VHS。
- **loop_boundary**：validate_prompt 会按 v3 节点的 `loop_boundary` 重排执行，全 custom_nodes 无此声明。

## 4. 当前最大嫌疑（下一步从这里打）

`validate_prompt`（`ComfyUI/execution.py:1147`）判定输出节点就是一句
`class_.OUTPUT_NODE is True`（execution.py:1182），其中 `class_ = nodes.NODE_CLASS_MAPPINGS[class_type]`。
 therefore 剩下两种可能：

1. **运行进程内的 `NODE_CLASS_MAPPINGS["VHS_VideoCombine"]` 不是磁盘上那个类**——某个包在 import
   阶段动态改了这一项或 monkeypatch 了 `VideoCombine.OUTPUT_NODE`。嫌疑对象：ComfyUI-DD-Translation、
   ComfyUI-Custom-Scripts、te/man 系（te_prompt_text.js 提到过 ReferenceToVideo）、
   TE-Fusion-NB-Speedup-MiniMaxH3 / te-speed-minimaxh3（专为这条管线做的加速/融合包）。 grep 源码没搜到明面补丁，
   但运行期（import 后）改属性的查不到——需要运行期探针。
2. **进程内存里的代码与磁盘不一致**：ComfyUI 进程（PID 32384，60GB 宿主、启动命令见
   `--fast fp16_accumulation` 等）可能在某次 ComfyUI/VHS 更新后没重启过。查
   `powershell (Get-CimInstance Win32_Process -Filter "ProcessId=32384").CreationDate` 对比
   VHS/execution.py/`comfy_extras\nodes_minimax_h3.py` 的 mtime。

**最便宜的决定性实验：请用户重启 ComfyUI，然后把同一条执行图重新提交**（第 5 节脚本一键可跑）。
若重启后整条链正常执行 → 进程内注册状态问题定案；若依旧 → 需要在运行期 dump
`NODE_CLASS_MAPPINGS["VHS_VideoCombine"].OUTPUT_NODE`（可临时给 ComfyUI 挂一个小 custom node 或
用现有测试通道）。

- **WS 事件追踪 + 复现脚本**（照抄即可）：

```python
# 复现：从历史取 357a2abf 的执行图重提交；换 prompt_id 0943e771 看我已跑的复现
import json, time, uuid, urllib.request, websocket
hist = json.load(urllib.request.urlopen("http://127.0.0.1:8188/history/357a2abf-892b-4f0f-b746-3105a65dc9e3", timeout=10))
graph = list(hist.values())[0]['prompt'][2]           # 执行图（397.seed 可改）
cid = uuid.uuid4().hex
ws = websocket.create_connection(f"ws://127.0.0.1:8188/ws?clientId={cid}", timeout=5)
req = urllib.request.Request("http://127.0.0.1:8188/prompt",
    data=json.dumps({"prompt": graph, "client_id": cid}).encode(),
    headers={"Content-Type": "application/json"}, method="POST")
pid = json.loads(urllib.request.urlopen(req, timeout=30).read())["prompt_id"]
ws.settimeout(300)
while True:
    msg = json.loads(ws.recv()); d = msg.get("data") or {}
    if msg["type"] == "executing" and d.get("node") is not None:
        print("executing", d["node"]);                 # 看采样链是否入列
    if msg["type"] in ("execution_success", "execution_error"):
        print(msg["type"]); break
```
