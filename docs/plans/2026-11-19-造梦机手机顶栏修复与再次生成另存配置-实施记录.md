# 造梦机手机顶栏修复 + 再次生成支持另存配置（2026-11-19 实施记录）

日期：2026-11-19。两条来源同一批手机反馈截图（8765 正式版，4.5.0-beta）。

## 一、手机顶栏排版乱（进度条跑到省略号下面）

### 根因

11-11 `a808dac1`（工作台布局重构）把 `#comfyuiStepMeter` 从共享顶栏搬进各功能页页头，
设计是「独占尾行贴右」（`grid-column: 1/-1`）。手机 ≤760px 时页头主列（标题 + 分档折行）
变成两行高：

1. `.wb-header-actions`（状态栏 + ⋯）在两行高的网格行里**垂直居中** → 悬在标题与分档之间的半空；
2. 进度胶囊独占尾行 → 落在 ⋯ 正下方（反馈原话「进度条跑到省略号下面去了」）。

### 改法（`public/styles.css`，≤760px 块）

- `.wb-resource-header > .wb-header-actions { align-self: start }`：状态列顶到标题行
  （对贴签匠等所有页头同样生效，它们此前也一样悬空）；
- `#studioView [data-wb-page-header] > .comfyui-step-meter { grid-column: 1; grid-row: 1;
  justify-self: end; align-self: start }`：进度胶囊上到标题行右侧、贴着状态栏；
- `:has(> .comfyui-step-meter:not([hidden]))` 时隐藏 `.comfyui-status-text`：生成中让出
  「已连接…」文字只留连接点与 ⋯，320px 窄屏才放得下（进度条隐没时自动恢复显示）；
- 选择器限定 `[data-wb-page-header]`：提词库共享顶栏是 flex + `margin-left:auto` 贴右，
  不受影响（特意验过 rect 仍贴右）。

桌面（>760px）不变：仍是尾行贴右（实测 y=94 在页头线下）。实测几何：390px 下
meter y=8 与标题同行、x=222..310 不与标题（右缘 120）或状态栏（x≥320）重叠；
360/320 无重叠。

顺手修了工作区里一处 CSS 拼接事故（`.kvmem-config-actions` 两条规则挤在一行，隔壁会话遗留）。

## 二、再次生成不能另存配置

### 背景

再次生成实现时按当时计划拍板「不改/不新增工作流库条目」：进入再次生成即
`setRerunSaveAsHidden(true)` 藏掉提交行 ⋯ 菜单里的「用当前配置另存工作流」，
`openSaveAsDialog/confirmSaveAs` 双重拦截。手机上 ⋯ 菜单只剩「批量生成」。
本次用户明确要求放开。

### 难点

后端 `api_workflow_save_as` 要求 64 位 `workflow_fingerprint` 且**按库内当前工作流图**落副本；
任务快照里没有指纹，且快照 prompt 已把原任务覆盖值烤进去——拿它当对比基准会把
覆盖值全部误判成「未改」，另存会得到空副本。

### 改法（`public/js/24-comfyui.js`）

- `loadRerunWorkflowBase()`：进入再次生成后**后台补读**库内原工作流
  （`GET /api/comfyui/workflows/{id}`），存进 `comfyui.rerun.workflowBase =
  {fingerprint, prompt}`，成功才放开另存按钮；失败（原工作流已删除等）保持隐藏，
  `workflowBaseError` 记原因。不阻塞再次生成表单本身；期间取消/切档用
  `rerun.sourceTaskId` 校验丢弃。
- `saveAsRows()`：对比基准改为 `rerun.workflowBase.prompt`（普通模式仍用
  `detail.prompt`）；另存「当前值」取值 `saveAsValueFor` 在再次生成下无草稿时回退
  `slot.default`（快照值，含原任务覆盖），普通模式维持 undefined=未改。
- 原工作流后来编辑过、槽位已不存在：标「这个参数已不在原工作流的当前版本里，不能另存」，
  不再发给后端吃 400。
- `confirmSaveAs`：指纹取 `rerun.workflowBase.fingerprint`；另存成功后照常
  `selectWorkflow(副本)` → 自动退出再次生成态（横幅消失、按钮复位）。

### 验证

- 真机流程（8901 源码版 + 金鱼 H3 任务 cf-20261105）：再次生成横幅正常、
  ⋯ 菜单两项齐、核对清单「共 76 参数 · 2 项已改动（1 写进副本，1 提示词不能另存）· 74 未改」
  与原任务 2 条覆盖完全对应——证明基准确实是库内值而非快照值；取消后草稿保留、库仍是 6 条。
- `test_comfyui_frontend_assets.py`：改 2 处断言（拦截文案 assertNotIn + 补读/基准新断言），
  vm 测试新增 `liveWorkflow`（steps=99 故意 ≠ 快照 6）证明基准切换；18 例全绿。
- 全量 `unittest discover` exit 0；补跑资产三模块 57 例全绿。

## 三、边界（本版不做）

- 再次生成下另存成功的语义 = 切到副本（工作流库多一条），再次生成草稿随切换丢弃；
  「另存后继续留在快照草稿」没人要求，不做。
- 提词库页手机端进度条仍是独占行贴右（flex 布局，没人反馈，不动）。
- 快照与库内工作流版本差异不可知（快照不带任务时指纹），清单按库内现状如实显示差异。
