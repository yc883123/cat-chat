# 现实世界模式

默认生成像真人实拍电影剧照组成的多格分镜页：真实人物、可信空间与材质、自然表演、符合场景的光影。这里的“分镜”指有明确构图和叙事顺序的画面，不默认手绘草图。用户明确要求写实铅笔／导演分镜草图时可以改变呈现媒介，仍保留以下真人空间和表演规则。

真人版同样默认保留完整台词。每格上方是真人实拍画面，下方是独立文字栏，按 [output-contract.md](output-contract.md) 标明角色、对白／内心／旁白及完整原文。文字栏属于分镜说明层，不是现实场景中悬浮的字，也不要求人物看到它；不因追求电影感而移除文字。下游视频读取文字生成声音，成片不显示文字栏与格框。

## 世界与资产转换

- 现实世界模式不等于现代都市。保留既定时代、地域、季节、建筑、职业、道具及服装；架空场景按可理解的实景、服装与实体道具呈现。
- 真人人物参考优先维持可识别的面部结构、发型、肤色、体态与服装，不每格另换演员，不用磨皮改变年龄。
- 动漫人物转换成真人时，将可识别设计映射为可信演员面部、发型、服装材质与配饰，不机械复制巨眼或不可能的身体比例，不自行绑定某位明星。
- 非自然发色可按染发或既定造型处理。明显非人结构、不可实现服装／道具或超自然事实不得静默删除；根据用户已选改编约定做可信实体／特效表达。若“完全现实无超自然”与必须保留的事实冲突，询问该事实的转换办法。
- 缺真人场景参考时，根据已知空间布局与时代保守构建实景。漫画里的门、桌、走廊与重要物件位置仍是连续性依据，不因真人化随意换场。

## 自然表演

使用具体但克制的眼神、嘴部、手指、肩部、呼吸姿态与人与人距离。姿态须能由真实身体完成，靠坐、递物、拥抱与起身需要合理支撑和接触。

不默认添加动漫汗滴、心形、速度线、Q版脸或情绪光环。脸红、眼泪与大幅表情只在事实允许时出现；浪漫场景不自动变成广告摆拍，惊悚场景不要求人人惊叫。

双人互动可以一人主动、一人迟疑或未回应，不把演员同时看向镜头当成互相交流。前后格维持对话视线，反应与收到的信息对应。

## 拍摄感与物理空间

- 按叙事选景别、机位与透视，不为每格强加焦段、器材品牌或摄影参数。
- 适度景深可引导视线，但必须读到的证据、双人手部关系或门外位置要保持清楚。自然焦外不能掩盖线索。
- 窗、灯具、屏幕、路灯等提供对应光源，脸、衣物、玻璃反射及阴影方向跨格一致。风格化布光仍需可信来源。
- 雨水、皮肤、织物、金属、玻璃和纸张使用对应材质。镜面反射不得凭空多出人或提前泄露应隐藏的角色。
- 门口、桌边、座位与路线保持可拍摄的地理关系。近景可裁切身体，但不能裁掉本格必需的手、接触点或线索。

## 模式验收

检查人物像同一演员、身体可实现、材质与光照可信、没有动漫符号混入；同时核对剧情、视线、物品归属和揭示顺序，并检查全部应保留文字准确可读、角色与类型标签清楚。文字栏不算动漫符号。写实质感不等于叙事通过。
