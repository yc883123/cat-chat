## 本次改动

### 造梦机：媒体输入分组卡片 + 拖拽 + 手机点选

- 中间栏媒体输入不再每槽一行碎按钮，按 `field_type` 归堆成「图片 / 音频 / 视频」各一张分组卡：卡片头（图标、类型名、N 个输入、x/N 已选、折叠箭头）+ 槽位块网格；没有该类型节点就不出该卡。归堆只认媒体类型，与节点号、节点名、端口名解耦，任意工作流节点命名都兼容。
- 槽位块：空块为虚线格（点它即唤起系统选择器）；工作流原值有文件的槽按实块显示「沿用原文件 + 原文件名」；已选块显示缩略图（视频为首帧海报＋播放按钮＋时长角标，点块放大播放）。节点号、节点名、目标端口收进块底 9.5px 小字，完整映射保留在悬停 title 与「编辑参数」清单里。四态提示（已选 / 未选即跳过 / 请选择文件 / 沿用原文件）判定与文案一字未改。
- 桌面拖拽：拖到具体块＝进那个槽（已选即替换）；拖到卡片空白处或卡片头＝按槽位顺序依次填空位，空位不够时多出的拒绝并提示；类型不符拒绝并提示应拖到哪张卡；目录拖放一律拒绝。多文件串行上传，全部完成后只重绘一次。
- 手机：点选是主路径，替换/清除按钮在触屏常驻显示（`@media (hover: none)`），网格自适应窄屏排布，卡片头可折叠。
- 修复：「编辑参数」取消勾选媒体槽现在真的会隐藏对应块——旧代码对已保存显示集无条件合并媒体 key；现在保存过的显示集带 v2 标记（按工作流 id 存 localStorage），按用户实际勾选执行，旧工作流首次打开仍自动并入媒体输入。另修复分组卡在表单超高时被 flex 压缩成一条线的布局问题。
- 提交数据结构、上传接口、执行端转传与未选移除逻辑一律未动；`PARAMS_SCHEMA_VERSION` 仍为 6，已有工作流无需重新导入。媒体节点识别覆盖率未变（仍以现有 `_MEDIA_NODE_FIELDS` 白名单为准）。

### 打标器：可选触发词前缀

- 任务配置区新增「添加触发词」开关与输入框（输出语言行下方、模型配置行上方），默认关闭；启用但未填写时不允许开始任务。
- 启用后触发词加在每张图标注结果的最前：标签类结果放进标签列表首位（不受置信度阈值和预设过滤影响，首标签已是触发词时不重复加）；文本类结果放描述最前并用与输出语言相符的分隔符。`both` 模式两者都加。触发词不进发给模型的提示词。
- captions / LoRA 训练包的逐图 `.txt` 经标签/描述序列化自动携带前缀；图片与文本配对、原图字节和 manifest 语义不变。
- 触发词参与配置校验与结果复用指纹：不同触发词配置不会错误复用旧标注；关闭状态下指纹与旧任务一致，已有标注照常复用、不重复计费。暂停、继续和恢复沿用原任务值。

### 打标器：输出形式与输出语言联动

- 「输出语言」只显示当前「输出形式」下有明确含义的选项：标签 / 词组短语 / 自然语言 → 中文、英文；标签 + 自然语言 → 全中文、全英文、英文标签 + 中文描述。「中英混合」这个含混简称退役。
- 切换输出形式时语言值始终映射到可见选项：从「英文标签 + 中文描述」切到「标签」选英文，切到「词组短语 / 自然语言」选中文；中文/英文在单一形式之间保持。隐藏值不保留生效，提交前组合必合法。
- 新任务不能提交与输出形式不匹配的语言组合（服务端 400）；历史任务与继续/恢复按创建时保存的配置原样执行，兼容既有 `mixed` 配置。配置目录接口同步提供按形式区分的语言选项。
- 新任务默认组合为「标签 + 英文」（旧默认 mixed 在标签模式下本就等效英文标签，默认行为无实际变化）。

### 冒烟基线修正

- `verify/studio_ui_smoke.cjs` 顶层页签基线从「模块库」（唯一页签）更新为「提词库」（可扩展多页签，3.7.4 起由「模块库」更名），否则 3.7.4 之后每次跑该冒烟都会误报；`tests/test_studio.py` 同步修正注释。
