# Super-agent V1 竣工验收

日期：2026-11-02。

## 目标与发布约束

用户要求补齐多步骤创建页面，接齐聊天、后台任务、子 Agent，使用真实模型验证暂停、重试和重启；完整 V1 竣工后才发布稳定版 `4.0.0`、推送 master。当前限定范围 Beta 不作为竣工依据。

原计划依据：`docs/plans/2026-11-01-Super-agent工作台总计划.md` §5、§12。实现优先复用现有执行器与权限边界，不重写聊天和工作台。

## 实施方案

1. 保留已存在的静态门禁及循环初始化修复，复核后显式提交；不混入无关工作树文件。
2. 用户创建页面按名称选作品、选择单阶段或完整固定阶段链、提供实际章节参数、共享全局供应商模型。聊天和子 Agent 关联已有会话，后台任务仅安全关联已有 Job，不开放任意 shell/参数创建入口。
3. 新增服务端有界调度，生产接入 Chat Run、Job、子 Agent、Writer、Novel。显式开启 autostart/auto_advance 才自动执行，审批阻断；旧入口保持手动语义。
4. 持久启动 claim、执行器关联与 attempt 围栏；暂停停止后续派发，不声称冻结供应商请求或立即停止计费。重启先对账，不盲目重放未知副作用。
5. 完成本地回归、桌面移动交互、真实最小样本与独立数据目录进程重启，再开展稳定版打包发布。

## 真实验证授权与隔离

用户经确认工具选择 `tedschat / deepseek-v4.1-flash`，授权模型目录核对及原创短文本真实推理，首轮最多 20 次模型请求，串行执行；达到上限仍有缺项就停止汇报，不自动追加。目录核对已执行：精确模型匹配，返回 2 个模型；尚未执行推理。

- 使用独立测试数据/工作区及非正式端口，不改现有作品、正式配置或运行实例。
- 仅选取批准的供应商，凭据不打印、不提交；不复制整份真实配置。
- 统计内部重试在内的真实出站推理，跨重启保留计数；故障优先在本地生产边界注入。
- 不把本地模型替身、真实 HTTP 创建或绿色测试数当作真实模型生成闭环。
