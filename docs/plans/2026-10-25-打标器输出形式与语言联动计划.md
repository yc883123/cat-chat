# 打标器输出形式与语言联动计划

## 目标

让「输出语言」只显示当前「输出形式」下有明确含义的选项，避免用户选择「自然语言 + 中英混合」后误以为描述会同时包含中英文。

## 当前问题

`provider.py` 将语言规则和输出形式规则分别拼进模型提示词。`mixed` 定义为标签英文、描述中文；但 `phrases` 明确要求输出短语且 `tags` 为空，`description` 明确要求 `tags` 为空。因此在这两种形式中，mixed 没有英文标签可用，效果与中文重复。

## 交互规则

| 输出形式 | 输出语言选项 | 语义 |
|---|---|---|
| 标签 | 中文 / 英文 | 标签全部使用所选语言 |
| 词组短语 | 中文 / 英文 | 短语全部使用所选语言 |
| 自然语言 | 中文 / 英文 | 描述全部使用所选语言 |
| 标签 + 自然语言 | 全中文 / 全英文 / 英文标签 + 中文描述 | 分别控制标签和描述的语言 |

- 「中英混合」只在「标签 + 自然语言」下显示，文案改为「英文标签 + 中文描述」，去掉含义含混的简称。
- 切换输出形式时，语言值必须始终映射到当前可见选项，不能保留隐藏但仍生效的值。
- 从「标签 + 自然语言 / 英文标签 + 中文描述」切到「标签」时选择英文；切到「词组短语」或「自然语言」时选择中文。
- 从单一形式切到「标签 + 自然语言」时，中文映射到「全中文」、英文映射到「全英文」。
- 用户手动选择某个语言选项后，仅影响本次新任务；不得静默改写历史任务或已保存的标注。

## 实施范围

- `public/index.html`：为语言选项提供明确的界面语义；「英文标签 + 中文描述」只作为 `both` 模式的语言选项。
- `public/js/23-labeler.js`：监听 `#labelerOutputMode`，更新 `#labelerLanguage` 的可见选项和有效值；提交任务前保证组合合法。
- `naiba/labeler/service.py`：若选项目录仍由接口提供，则按输出形式返回对应语言选项，避免前端和接口定义分叉。
- `naiba/labeler/engines/provider.py`：按有效组合生成一致、不互相矛盾的语言与输出形式提示词。
- `naiba/labeler/jobs.py`：校验新任务的输出形式/语言组合；历史任务和恢复任务继续按创建时保存的配置执行，兼容既有 `mixed` 配置。
- `tests/test_labeler.py`、`verify/*labeler*smoke*`：覆盖组合规范化、提示词内容、配置校验和浏览器联动。

## 验收

- 四种输出形式只显示表格中对应的语言选项；单一形式不显示「英文标签 + 中文描述」。
- 每种输出形式切换后，当前选中值均可见且语义明确；无隐藏值被提交。
- 4 种输出形式 × 所有可见语言选项的后端提示词要求互相一致。
- 旧任务中的 `mixed` 配置可读取、恢复和查看；新建任务不能提交与输出形式不匹配的组合。
- Playwright 覆盖桌面和窄屏上的选项变化、模式往返切换、实际提交配置及无前端错误。

### 实施结果

- 改动文件：`public/index.html`（语言选项改为 中文/英文/英文标签 + 中文描述，默认「标签＋英文」对齐旧默认 mixed 在标签模式下的实际效果；mixed 选项仅在 both 下可见，由 JS 控制）、`public/js/23-labeler.js`（`syncLanguageOptions`：按输出形式切换可见性与文案（both 下为 全中文/全英文/英文标签 + 中文描述）；离开 mixed 的映射规则（标签→英文、词组短语/自然语言→中文）；zh/en 在单一形式间保持）、`naiba/labeler/jobs.py`（新任务拒绝 `mixed + 非both` 组合；`allow_legacy_language` 供继续/恢复放行历史配置）、`naiba/labeler/service.py`（`languages` 目录换新文案并新增 `languages_by_mode`，防前端与接口分叉）、`tests/test_labeler.py`（组合校验、合法组合提示词一致性 9 组、旧 mixed 可组提示词、前端接线源码断言；`_base_config` 默认语言改 `en`）、`verify/_labeler_mode_smoke.cjs`（桌面＋375px 选项变化、往返切换、真实提交配置拦截校验、无前端错误）。
- `naiba/labeler/engines/provider.py` 未改：现有提示词对全部合法组合已经一致（语言规则与形式规则不矛盾），新增测试锁住；历史 `mixed + keywords` 仍可组出提示词。
- 与计划的偏差：无实质偏差；「实际提交配置」在冒烟中经拦截 `/api/labeler/tasks` 校验请求体完成（不真连模型）。
