# 贴签匠进度/切页签修复 + 工作台刷新 + KVMem 路径选择器（2026-11-18 实施记录）

日期：2026-11-18。三条来源：远端用户反馈（进度不实时、切回按图空白）、本人体感（模型路径手填太容易错）、
以及「刷新要能刷整个工作台，不止贴签匠」。

## 一、修了什么

### ① 批次卡进度不跟轮询走（远端反馈）

根因：`pollTask` 打标中只 `renderTask(task)`（底部进度条），从不动 `labeler.batches`；
批次卡文字由 `renderBatches()` 从 `labeler.batches` 读，而它只在 `refreshBatches()` 时重拉，
`refreshBatches()` 只在切页/切批次/任务终态被调用。所以打标期间卡片永远停在开局那个数，
底部条却在动——手机上尤其扎眼，因为人不切页。

改法（`public/js/23-labeler.js`）：
- 抽出 `batchMetaText(task)`，`renderBatches` 与就地同步共用一份文案拼装；
- 新增 `syncBatchCard(task)`：把服务端 task 合并回 `labeler.batches`，只改那张卡的
  `.labeler-batch-state` 与 `.labeler-batch-meta` 文本（差异才写 DOM，不重建行、不闪）；
- `pollTask` 的 active 分支与 `reconcileTask` 的 active 分支各调一次。

### ② 切回「按图」要等一会才出列表（远端反馈）

根因：`renderImageResults` 的懒加载签名里没有「当前是哪个页签」。切到标签云/句子库时 body 被替换，
`lastImageSignature` 仍是上次按图的值；切回来时数据没变 ⇒ 签名相同 ⇒ 早退，一块 DOM 都不画，
要等下一轮 1.2s 轮询改到数据才补出来。

改法：`setResultTab()` 切页签时清 `labeler.lastImageSignature`；签名数组首位补 `labeler.resultTab` 兜底。

### ③ 工作台级「刷新」（新需求：不止贴签匠）

- `public/js/22-studio.js` 新增 `refreshWorkbench()`：当前页是提词库走 `refreshStudio()`，
  其余页发 `emitStudioPage(page, {refresh:true})` 走各页自己的进入即重读逻辑（不在这里按页写分支）；
- `bindStudioEvents()` 里加一处委托 `[data-studio-refresh]`，顺手收起 `<details>` / popover 菜单；
- 五个功能页右上 ⋯ 各加一颗「刷新工作台」，与「资源监控」并排：
  提词库（`index.html` 的 `libraryMoreTrigger`）、贴签匠（`labelerMoreTrigger`）、
  造梦机（`comfyuiMoreTrigger`）、拆书匠（`novelMoreMenu`）、织书台（`writerMoreMenu`）。
- 批次栏 ⋯ 里原有那颗「刷新」保留，它只管批次列表。

### ④ KVMem 安装目录 / 模型路径选择器

- 后端新增 `NaibaChatApp.pick_filesystem_path(mode, initial, title)`（`naiba/app.py`），
  复用工作区选择器那套 tkinter：`dir` 走 `askdirectory(mustexist=True)`，
  `file` 走 `askopenfilename(filetypes=[("所有文件","*.*")])` —— **不按扩展名过滤**，
  `.gguf` / `.ninfer` / `.safetensors` 分片都能选；返回 Windows 原生反斜杠路径；
- 路由 `POST /api/fs/pick`（`naiba/http.py`，紧跟 `/api/workspace/pick`）；
- 前端：两个输入框改成「输入框 + 选择…」（`index.html` + `.kvmem-path-field` 样式），
  `09-settings.js` 的 `pickKvmemPath()` 填值，`15-bind-events.js` 绑两个按钮；
- 手机/局域网访问时隐藏按钮：`hideLocalPickers()` 按 `location.hostname` 判定，
  非 127.0.0.1 / localhost 一律藏。原生对话框只会开在跑服务的那台电脑上，手机上点了等于没反应。

## 三、边界（本版不做）

- 模型路径只给「选择文件」；分片 `.safetensors` 若需要整目录，等真碰到再加「选择文件夹」。
- 手机端没有选择器替代方案，仍手填；填正斜杠也能存（安装目录保存时会被 `Path()` 规整成反斜杠）。
- 「刷新工作台」不跨页刷新隐藏页：只重读当前可见页。
