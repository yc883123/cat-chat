## 十三、爱情、悬疑、超级英雄与恐怖的类型骨架

### 1. 爱情片模板 (Romance)

```
① 邂逅（The Meet）
   → 欢喜冤家 / 一见钟情 / 迫近接触

② 阻碍（The Obstacle）
   → 已有伴侣 / 社会差距 / 误解心结

③ 分离（The Separation）
   → 外部事件 / 内部动摇

④ 顿悟（The Realization）
   → 发现真心

⑤ 归来/追求（The Return/The Pursuit）
   → 主动追回 / 跨越阻碍

⑥ 结局（The Resolution）
   → 大团圆 / 开放式结局
```

### 2. 悬疑片模板 (Mystery/Thriller)

```
① 罪案发生（The Crime）
   → 开场即展示或暗示犯罪

② 调查开始（Investigation Begins）
   → 侦探登场，建立规则

③ 线索铺设（Clues Scattered）
   → 误导线索 + 真实线索交替

④ 误导高峰（The Red Herring Peak）
   → 指向错误嫌疑人

⑤ 真相揭露（The Revelation）
   → 所有线索指向真凶

⑥ 终局（Final Confrontation）
   → 真相与和解
```

### 3. 超级英雄片模板 (Superhero)

```
① 起源（Origin）
   → 特殊能力获得 + 道德选择

② 试炼（Testing）
   → 能力成长，承担责任

③ 世界危机（World Threat）
   → 强大反派现身

④ 绝境（The Abyss）
   → 英雄被彻底击败/道德困境

⑤ 蜕变（Transformation）
   → 接受使命，突破极限

⑥ 终局对决（Final Battle）
   → 标志性场景 + 最终战斗

⑦ 战后余韵（Aftermath）
   → 世界改变，传承延续
```

### 4. 惊悚/恐怖片模板 (Thriller/Horror)

```
① 日常打破（The Breach）
   → 恐怖元素登场

② 规则建立（The Rules）
   → 恐怖世界的逻辑

③ 第一次攻击（First Strike）
   → 非主要角色死亡

④ 真相追寻（Investigation）
   → 主角接近真相

⑤ 陷阱（The Trap）
   → 陷入绝境

⑥ 逃亡（The Escape）
   → 短暂脱险

⑦ 最终对峙（Final Confrontation）
   → 与恐惧根源的正面对决

⑧ 开放式结局（Open Ending）
   → 恐怖未消，余韵
```

---

【输出】
先给一句话故事，再按本结构逐节点列出目标、行动、阻碍、结果与前后因果；标出人物选择如何改变下一步条件，最后给3项以内结构薄弱处及具体改法。页码、比例和时长均为规划参照。

只选与材料相符的一套，混合类型时说明主类型和辅类型。爱情中的误解需有真实信息差；悬疑的误导要来自可复核事实且不隐瞒人物已经知道的信息；超级英雄的力量解法需先给限制与代价；恐怖中的伤亡或开放结局可按题材调整，不机械要求配角先死。
