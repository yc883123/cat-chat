**作用：** 用3行锁死全片方向，防止后续分镜跑偏。

**原文案例：**

## 1.3 Step 0.8｜分镜数量规划

**作用：** 目录+检查清单。

**格式：** `编号 + 一句话（动作/空间/核心事件）`

**原文案例（前6镜）：**
```
01 建立自由城上空—云海俯冲到断桥与时空门同轴
02 贴地切入车阵—锁定芭比粉肌肉车杀出重围
03 断桥腾空—盲区燃烧战车撞偏肌肉车

06 失败者摘头显—玩家A崩溃怒吼
```

**拆镜原则：**
- 一镜一事，不塞两件事
- 按原剧情决定入场顺序，适合群像开场时可配角先行、主角延迟出场
- 每6-8镜插一个静谷
- 终镜允许多段叙事压缩

### 内容密度装填规则（15秒容器判断）

**密度分级：**

| 密度等级 | 剧本特征 | 15秒容器装填策略 |
|---------|---------|----------------|
| 过密 | 3轮以上对话/对峙、2个以上独立动作事件 | 必须拆分。切点选在情绪峰值或动作完成点。每镜只保留1个核心信息点 |
| 标准 | 1个完整动作闭环 或 1轮对话+1个伴随动作 | 正好1镜。正文3段=起势/高潮/收束 |
| 偏疏 | 纯行走/等待/环境交代 | 允许1镜，但必须用视觉密度补偿叙事密度：增加环境细节层、光影变化、镜头运动感 |
| 极疏 | 纯空间展示、纯情绪铺垫 | 合并入相邻镜的起幅或落幅，不独立成镜 |

**切点选择决策树：**
1. 有明确的动作完成点（枪响/门关/车停/落座）？→ 在完成点切
2. 有情绪峰值（怒吼/沉默/对视/转身）？→ 在峰值切
3. 有空间转换（室内→室外/车内→车外）？→ 在转换点切
4. 以上都没有？→ 在信息交接点切（一句话说完=切点）
5. 绝对禁止：把一句台词切成两半分到两镜

**对话密度特殊处理：**
- 1-2句台词：台词内嵌在动作中，1镜完成
- 3-4句台词（约2轮对话）：1镜，但台词间必须有动作间隔（走位/表情变化/道具互动），不可拍成纯对话
- 5句以上台词：强制拆镜，每镜最多承载2-3句，切点在话题转向处或情绪转折处

**古装宫廷案例（凤谋天下·场次三）：**
```
剧本原文：赵嬷嬷叫出沈昭宁 → 拿戒尺点肩 → 威胁"三天后你病了" → 走开 → 青禾害怕 → 沈昭宁说"先不急"
密度判断：过密（2轮对话 + 2个角色情绪变化 + 1个威胁事件）
拆法：
  镜A（嬷嬷威胁）：嬷嬷叫她出列 → 戒尺点肩 → "三天后你病了" → 落幅停在嬷嬷转身走开
  镜B（沈昭宁消化）：青禾发抖问话 → 沈昭宁"先不急" → 食指在腿侧敲三下
  切点选择：嬷嬷走开=动作完成点，情绪从压迫切向隐忍
```

**现实都市案例：**
```
剧本原文：女主在电梯里接到离婚律师电话，说了三句话，出电梯时撞见前夫
密度判断：标准偏密（2句对话 + 1个空间转换 + 1个意外相遇）
```

起幅和落幅不只是画面描写——它们是相邻两镜的物理焊接点。AI视频工具逐镜独立生成，**如果接力物只写在过门字段而不在起幅/落幅的描写中，视觉连续性不会被生成出来。**

```
落幅：[视觉描写]
```

## 字段⑧：提示词正文

### ⑧a. S+质量描述（正文第一句）

**格式：** `【本分镜S+质量描述】[画质定性]，[题材质感]，[品质方向]。`

**三要素分工（V3厘清）：**
- **画质定性**：技术标准（REAL_CG / 实拍质感 / 动画渲染 等）
- **题材质感**：全片统一的影像气质（如"赛博末日电影质感"、"南宋宫墙质感"），各镜应基本一致
- **品质方向**：本镜的品质基调（如"冷峻华丽"、"沉郁克制"），是品质形容词，不是拍法

**关键区分：S+回答"这镜应该像什么级别的东西"，不写"怎么拍"。"怎么拍"归字段⑫成像个性。**
> 判断方法：如果这句话换到同片另一镜还基本成立 → 属于S+；如果只对本镜成立 → 属于⑫成像个性。

## 字段⑫：成像个性

**格式：** `【成像个性】[本镜独有的镜头手法/运动策略/节奏控制，1-2句]`

**与S+的分工（V3厘清）：**
- **S+** 回答"像什么级别的东西"（品质标杆、题材质感）——全片各镜基本一致
- **成像个性** 回答"这一镜怎么拍"（镜头行为、运动策略、节奏控制）——每镜独有
- **画质路线（⑪）** 回答"用什么调色"（色温/光线/材质）——技术参数层

> 三者形成清晰层级：S+ = 品质定调 → 画质路线 = 色光配方 → 成像个性 = 拍法策略

**边界辨析案例：**

| 这句话 | 归属 | 理由 |
|--------|------|------|
| "REAL_CG，赛博末日电影质感" | S+ | 全片通用的品质标杆 |
| "冷峻华丽、危险压迫" | S+ | 品质方向形容词，不是拍法 |
| "暖调车内，皮革、金属、玻璃层次明确" | 画质路线⑪ | 色温+材质技术参数 |
| "先让山路和夜色吞掉速度，再把真正的戏钉进后视镜" | 成像个性⑫ | 只对本镜成立的节奏策略 |
| "贴地广角前导，速度来自前景擦过" | 成像个性⑫ | 具体的镜头运动手法 |
| "拒绝手持、拒绝加速" | 成像个性⑫ | 本镜独有的运动约束 |

**写法模式与案例：**

| 模式 | 赛博科幻案例 |
|------|-------------|
| "先X再Y"式 | 先让山路和夜色吞掉速度，再把真正的戏钉进后视镜 |
| "不靠X靠Y"式 | 贴地广角前导，速度来自前景擦过与车辆结果位移，不靠镜头乱甩 |
| "像XX一样"式 | 不急着看角色，先让体量和制度感吃人；移动缓慢克制，像审判现场的冷静巡视 |
| "拒绝X"式 | 拒绝手持、拒绝加速，整镜保持稳定悬浮，靠镜面、光线、实物抛接做关系推进 |

## 4.2 字段互锁关系

```
构图锚点 ──→ Must-Show ──→ 稳帧点
    │                          ↑
    └── 正文钉子画面 ──────────┘

起幅【接力承接】←── 上一镜「过门」接力物 ──→ 正文P1自然描写
落幅【接力传出】──→ 下一镜「承接」接力物 ──→ 正文P3自然描写

挂载区@音频台词 ──→ 正文铁律7时间锚点
挂载区@角色 ──→ ID卡1.4（跨镜外观锁定）
```
