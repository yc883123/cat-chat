## 一、通用基础框架（填空公式）

```
\[①前缀标签] \[②风格/美学定调] \[③人物基础] \[④面部/妆容] \[⑤发型发色] \[⑥服装穿搭] \[⑦配饰道具] \[⑧姿态/表情/动作] \[⑨场景/环境] \[⑩光线/色调] \[⑪构图/镜头] \[⑫质感/画质] \[⑬氛围/情绪收束]
```

|序号|字段名|必填/选填|说明|填写示例|
|-|-|-|-|-|
|①|前缀标签|选填|族裔/媒介声明|`亚洲，真人，` / 留空|
|②|风格/美学定调|**必填**|一句话定义整体风格|`超写实摄影` / `日常快照风格`|
|③|人物基础|**必填**|性别、年龄感、气质、肤质|`一位气质清冷的东亚美女`|
|④|面部/妆容|选填|脸型、眼型、妆容|`鹅蛋脸，韩式妆容`|
|⑤|发型发色|**必填**|颜色+长度+质感|`乌黑长发柔顺垂坠`|
|⑥|服装穿搭|**必填**|款式+颜色+材质|`黑色西装外套内搭丝绒吊带`|
|⑦|配饰道具|选填|首饰、包袋、环境道具|`佩戴金色手镯和项链`|
|⑧|姿态/表情/动作|**必填**|姿态+表情+手部|`左手搭在头顶，姿态慵懒又干练`|
|⑨|场景/环境|**必填**|地点+环境细节|`豪华轿车后排，酒红色真皮座椅`|
|⑩|光线/色调|**必填**|光源+色温+色调|`暖光与冷光交织，高曝低饱和`|
|⑪|构图/镜头|选填|景别、视角、参数、画幅|`高清特写，50mm f/1.4` / `竖屏9:16`|
|⑫|质感/画质|选填|分辨率、胶片模拟|`8K，皮肤通透，发丝分明`|
|⑬|氛围/情绪收束|选填|氛围总结词，尾部规则见规则9|`氛围感十足`|

### 开头句式可选表（按分支对号使用，禁止跨分支乱用）

|句式|结构|作者范例出处|适用分支|
|-|-|-|-|
|**电报式**|`\[风格声明]，\[人物]…`|人像摄影，日常快照风格，非精心构图或打光，…|A/C|
|**呈现画面式**|`以X风格艺术美学呈现画面。画面中的\[人物]…`|以墨明风格艺术美学呈现画面。画面中的离尘师妹…|C|
|**具备式**|`具备X风格，\[色调/颗粒描述完整句]。\[人物细节完整句]…`|具备胶片风格，暗调复古的色调中带着自然的胶片颗粒感，…|A|
|**营造式**|`营造出充满X氛围的画面。…` / `打造出氛围感强烈且神秘的画面。`|亚洲，真人，营造出充满故事感和治愈清爽氛围的画面。…|B|

注意：

* 选"呈现画面式/具备式/营造式"开头时，人物描述允许用完整句（`有着…，有着…` / `她拥有…` / `模样极为…`），不必压缩成电报短句。
* **C类开头只能二选一**：电报式或呈现画面式（见C类激活层），禁止具备式/营造式。
* **A类**开头用电报式或具备式，也允许画质声明前置（见A类差异化）；**B类**开头用营造式或以 `亚洲，真人，` 直接起头。

## 二、三种风格分支模板

### A. 摄影写真类

适用：影棚人像、街拍写真、杂志封面、商业摄影

**公式：**

```
\[摄影类型声明]，\[镜头参数(可选)]，\[人物基础：气质+族裔+年龄感+肤质]，\[面部：脸型+五官+妆容]，\[发型发色：颜色+长度+质感+造型细节]，\[服装：款式+颜色+材质+层次]，\[配饰+道具]，\[姿态+表情+手部动作]，\[场景：具体地点+环境物件+前景小物件]，\[光线：光源+落点+环境反射]，\[构图：景别+视角+虚化+对焦锚点]，\[画质：分辨率+皮肤/发丝质感+细节锚点]，\[色调/胶片模拟]，\[氛围收束语]。
```

**示例填空：**

```
\[8K超高清，RAW格式，专业人像摄影]，\[50mm f/1.4大光圈定焦镜头，浅景深，背景虚化]，\[一位绝美东方年轻女性，冷白皮，气质清冷]，\[鹅蛋脸，五官精致，直视镜头，妆容清透]，\[乌黑浓密超长黑长直，发丝根根分明，发间点缀珍珠碎钻发饰]，\[身穿米白色抹胸缎面拖尾长裙，同色系宽松缎面披肩]，\[佩戴珍珠耳钉]，\[姿态优雅慵懒，双手交叠于腰腹]，\[极简室内影棚，米灰色哑光水泥墙，前景矮几上斜插一枝枯枝，深灰色水泥地]，\[专业影棚柔光从侧前方打在面部与发丝上，水泥墙映出柔和漫反射]，\[对焦精准落在面部，近实远虚]，\[皮肤质感通透真实，发丝分明，超高清]，\[胶片质感，柯达Portra 400，低饱和莫兰迪色调]，\[杂志封面级质感]。
```

**摄影类差异化：**

* ②风格定调 → 必须包含摄影类型声明（`专业人像摄影` / `超写实摄影`）
* **画质/拍摄声明允许前置**：`8K超高清，RAW格式，专业人像摄影` 或 `高清画质，真人摄像，专业拍摄` 可直接作为句首，这是作者高频写法
* **锐度锚点必带（规则6）**：对焦锚点（`对焦精准落在面部`）+细节锚点（`发丝根根分明`）至少各一个，已并入上方公式的构图/画质字段
* ⑪构图/镜头 → 强调镜头参数（焦距、光圈、景深）
* ⑫质感/画质 → 必须写分辨率+皮肤/发丝质感+胶片模拟
* ⑩光线 → 具体光源名称（`伦勃朗光` / `影棚柔光` / `侧光`）+ 落点 + 环境反射（规则7）

**A类子模式 —— 叙事长句型（400\~500字）：**

当用户给出"一个人物+一个明确场景"且要求画面有故事感时启用。此子模式**用流畅完整的叙事句**（规则5的完整句写法），按固定段落推进：

```
\[景别+镜头+构图法完整句（如：中景镜头，平视拍摄，画面构图采用三分法，人物位于右侧，…形成视觉平衡）]。\[背景环境完整句：墙面/装饰物/细节物件及其与人物的呼应关系]。\[灯光效果完整句：光源+落点+在人物身上形成的明暗/高光]。\[拍摄角度补充句]。\[主角完整句：服装逐件描述（领口/腰线/裙摆/材质）]。\[发型+姿态+表情+神态完整句]。\[场景道具与人物色调呼应句]。\[整体风格收束句（如：整体风格写实而富有艺术感，通过光影与构图，强调…氛围）]。
```

参考句式指纹（摘自作者原词）：

* `画面构图采用三分法，人物位于右侧，X占据左侧三分之二空间，形成视觉平衡`
* `灯光效果柔和且富有层次：X光勾勒出…边缘，同时在人物腰部与裙摆处形成自然高光，凸显曲线`
* `吧台边缘形成自然的引导线，将视线引向主体`
* `整体采用三分法构图，营造出舒展而富有呼吸感的画面节奏`
* `整体风格写实而富有艺术感，通过光影与构图，强调人物优雅的轮廓与环境的静谧氛围`

规则1复沓、规则2赞美词穿插仍需执行，但以自然方式融进句子，不做关键词堆叠。

### B. 艺术创作类

适用：国风水墨、厚涂伪厚涂、梦核幻境、怪诞美学、东方神秘

**公式：**

```
亚洲，真人，\[艺术技法/美学流派声明]，\[材质/肌理描述]，\[色彩体系：主色+辅色+点缀色]，\[人物基础：气质+年龄感]，\[发型发色：颜色+造型+动态感]，\[面部（简写或省略）]，\[服装：风格+材质组合+装饰层次]，\[华丽配饰/头饰/装饰元素堆叠]，\[姿态/情绪/叙事动作]，\[场景/意境空间]，\[光线：艺术光效+弥散/朦胧/曝光]，\[构图：动态角度/留白/极端构图]，\[质感叠加：颗粒感+肌理感+虚化感]，\[氛围情绪收束：多个情绪词叠加]。
```

**示例填空：**

```
亚洲，真人，\[重彩，叠涂，厚涂，磨砂肌理和岩彩的表现手法，弥散渐变]，\[背景：深色雕花大窗外朦胧淡橘渐变枫树，山间雾蒙蒙]，\[一个穿着素雅深蓝汉服的少女，肌肤白皙透亮]，\[大师级别构图]，\[色彩搭配，静谧美好，绝色容颜，清冷]。
```

**艺术创作类差异化：**

* ①前缀 → 几乎必带 `亚洲，真人，`
* **★ 混搭特征（本 LoRA 标志性用法）**：保留 `亚洲，真人，` 真人前缀的同时，叠加水墨/厚涂/岩彩/水彩/伪厚涂等**插画技法词**，形成"真人底+画意"的混合质感。不要写成纯插画向，真人声明必须保留
* ②风格定调 → 必须包含艺术技法名称（`水墨晕染` / `伪厚涂` / `重彩叠涂`）
* 新增"材质/肌理"字段 → `宣纸质感` / `磨砂颗粒` / `岩彩`
* ⑥服装 → 强调材质组合（`纱质+丝绸`）和装饰层次
* ⑦配饰 → 可大量堆叠华丽元素（`流苏、冰晶、丝带、羽毛、宝石`）
* ⑩光线 → 偏艺术光效（`雾感光源` / `动态柔光投影` / `朦胧发光层`），B类允许突破光链要求，以意境优先
* **锐度锚点豁免（规则6）**：B类以意境优先，朦胧、虚化、弥散是合法审美，不强制对焦锚点与细节锚点；肤质锚点仍建议保留
* ⑬氛围 → 多个情绪/美学词密集叠加（`空灵，朦胧，迷幻，浪漫，梦幻`）
* 整体写法更松散、诗意，允许逗号/空格分隔的关键词堆叠（规则5糙感许可适用于B类全部写法）
* **内嵌列表许可**：服装/古装描述允许用 `古装：- 汉服类型：唐制齐胸襦裙，大袖款式，- 配色：整体以明黄色为主…` 这种带冒号破折号的内嵌列表，作者原词有此写法

**B类子模式 —— 华丽堆叠型（重型词，350\~500字）：**

当用户要"华丽/仙/神性/盛世/怪诞/梦核"时启用，在B类基础上追加以下操作：

* **装饰元素成串堆叠**：`流苏、冰晶、丝带、羽毛、宝石、魔法、冠冕、泼金点缀、流光溢彩` 一口气列出，不做完整句子
* **画质词首尾双放**：开头写 `超清画质`，结尾再压一个 `超高清64k画质` / `大师级作品`
* **构图用极端词**：`大张力构图` / `极端构图` / `错纵复杂的细节` / `对比度强烈`
* **允许意识流断句**：语义可以跳跃，靠词与词的碰撞推进，不追求因果连贯

参考骨架：

```
亚洲，真人，\[艺术技法堆叠3\~5个]，\[发丝/面部极致刻画词堆叠]，\[人物+发色+气质]，\[服装色+装饰元素成串堆叠]，\[动态角度+构图极端词]，\[主色彩声明]，\[颗粒感/肌理感/虚化感]，\[情绪词+美学标签堆叠]，\[大师级作品，画质词收尾]。
```

### C. 日常快照类

适用：生活随拍、CCD风格、手机自拍、非精心构图的真实感

**一句话原理：** 快照词 = **激活层**让LoRA发力 + **骨架层**让画面成立 + **氛围层**让它像随手拍。糊从来不是运气问题，永远是三层中某一层的缺失——按下文排障表对号入座即可。

#### 排障速查表（先看症状，再补对应层）

|出图症状|缺失层|缺的具体件|
|-|-|-|
|整体发软、像底模直出、LoRA没存在感|①激活层|没写肤质词 / 没用墨明开瓶器或角色锚|
|像素清晰但观感"肉"、平、灰|②骨架层-光/对比度|光链没写全（模型默认平光）；或踩了禁忌组合"浅色全身+亮背景+无落点平光"|
|人物像抠图贴在背景上|②骨架层-光/景|光链缺第三段（环境反射）；场景缺前景小物件|
|真的没对上焦、糊|③氛围层超配|柔化指令>2个（按封闭清单计数），把锐度锚点淹没了|
|首尾出现两个场景、设定打架|②骨架层-自洽|全词只允许一个场景（如中段书店+尾部"暗调房间"=废词）|
|又亮又暗、明暗混乱|③氛围层|写了"高曝低饱和+暗调"但光链没有"亮主体"，组合前提不成立|

#### ① 激活层（必带，缺一件出图即底座软图）

瑶光是质感提升型LoRA，这一层是它的开关，其余词汇只是输入。

* **风格开瓶器**（严格二选一，**禁止具备式/营造式开头**）：

  * `以墨明风格艺术美学呈现画面。画面中的…`（呈现画面式，首选，少女/师妹系尤其有效）
  * `人像摄影，日常快照风格，非精心构图或打光，…`（电报式）——注意："非精心构图或打光"只是genre声明，**不代表不写光**，光链落点仍是骨架层必带
* **角色锚**（如有，优先级高于开瓶器）：具名角色（`离尘师妹` / `湛佳琳`）直接替换泛称人物。角色锚是训练集标签，一个字顶一句风格声明——有角色锚时甚至可以不用墨明开头
* **肤质点火器**：`白净` / `瓷感白肌肤` / `皮肤白皙透亮` / `冷白皮` 至少一个，可出现两次（复沓加权）。**妆容可省，肤质不可省**
* **赞美词**：`模样极为可爱` / `绝色容颜` 撒在前段，不准攒在结尾

#### ② 骨架层（按此顺序组装，每件都可渲染）

1. **人物**：`有着X脸蛋，有着X眼睛` 完整句（呈现画面式）或短句（电报式），眼睛优先用作者训练词`可爱无辜且眼睑下至的眼睛`
2. **发型**：颜色+造型+`发丝垂坠且轻抚泛光`（发丝是细节锚点主战场）；亮背景场景优先深发色（`乌黑`），深色发是最强衬脸对比
3. **服装**：写颗粒度——吊带写粗细（`细吊带`）、裙写廓形（`A字短裙`）、料写织法（`棉麻`），颜色必写
4. **姿态**：candid + 与环境互动（`指尖轻捻书页` / `双手微微张开迎着海风`），禁止影楼式摆拍动作与快照风格打架
5. **光链三段**：`光源（方向+性质）→ 人物落点（脸/发丝/书页）→ 环境反射（波光/地板反光/光斑）`，三站写全。示例：`侧方窗光落在书页与发丝上，木地板映出柔和反光`
6. **场景三层**：`前景小物件（贝壳/散落的书/半杯咖啡）→ 中景人物 → 远景具体景物（木质书架/浅海天迹线）`。**全词只允许一个场景设定**，首尾出现两个不同场景=自相矛盾，禁止
7. **锐度锚点**：`画面聚焦面部` + `发丝根根分明` / `睫毛根根分明`（建议两个都带）
8. **对比度**（三选二，光链成立则第三项自动满足）：深色发色或深色单品衬脸 / 睫毛根根分明 / 光链自带明暗过渡。**禁忌组合：浅色全身+亮背景+无落点平光**——三无组合必灰必平，禁止

**信息配比原则**：面部相关描述（脸型/眼睛/肤质/发丝/表情）的token占比应保持40%以上。场景可以丰富，但不能喧宾夺主——这个LoRA卖的是脸和质感，token分布就是出图精度分布。

#### ③ 氛围层（限量，宁少勿多）

* **柔化指令配额：全词最多2个，按封闭清单计数**

  * **计入配额（封闭清单，只有这些算柔化指令）**：`构图随意` / `构图平庸` / `高曝低饱和+暗调`（两者合算1个组合指令，且仅在光链成立的"亮主体+暗环境"下合法） / `昏暗` / `朦胧` / `整体虚化、全部虚化` / `运动模糊、快门模糊`
  * **不计入配额**：`浅景深` / `背景虚化` / `近实远虚` / `50mm f/1.4` 等镜头参数——它们描述景深层次，不是柔化指令，写了不占配额；但C类一般不需要写参数，参数也不能替代场景三层的前景小物件
  * genre由激活层的开瓶器和骨架层的candid姿态建立，柔化指令只是调味——**快照感是演出来的，不是喊出来的，禁止写"随手一拍抓拍风格"这类genre复读**（电报式开瓶器里的"日常快照风格"是开瓶器本体，不算复读）
* **表情反差许可**：表情词按用户需求的气质方向自由配比，允许跨族反差——`清纯又妩媚` / `纯欲` / `可爱又冷酷` 是作者词汇分布里的原生组合（词库"纯欲"本身即跨族概念），不作限制
* **尾部落点**：全词最后必须是质量词/氛围词（`清纯元气感十足` / `甜美治愈` / `大师级作品`），禁止柔化指令收尾（与规则9同口径）

## 四、风格还原核心规则（通用层，所有分支执行；C类另有强化规格见其模块）

**规则1 · 复沓（关键词重复）**
核心氛围词、质感词允许并鼓励重复出现 2\~3 次。可原词重复（`雾感光源……雾感光源`），也可近义复沓（`皮肤白皙……冷白皮……皮肤白皙透亮`）。禁止"每个词只出现一次"的洁癖式写法——重复即加权，这是该 LoRA 训练词的强化手法。

**规则2 · 赞美词穿插**
`大师级构图 / 绝色容颜 / 明星气质 / 高级感 / 倾国倾城 / 模样极为可爱` 等溢价词**不准集中在结尾**，要随机撒在人物段、服装段、画质段之间，形成"从头夸到尾"的节奏。结尾仍需 1\~2 个氛围词收束（见规则9）。

**规则3 · 真人+插画技法混搭**
艺术创作类和华丽堆叠类必须保留 `亚洲，真人，` 前缀，同时叠加水墨/厚涂/岩彩/水彩/伪厚涂等插画技法词。真人声明与画意技法并存是本 LoRA 的标志性用法，缺一不可。

**规则4 · 画质+风格声明位置双灵活**

* 画质声明：摄影类允许把 `8K超高清，RAW格式，专业人像摄影` / `高清画质，真人摄像，专业拍摄` 放在句首；华丽堆叠类要求画质词首尾双放。不要永远把画质词固定在尾部。
* 风格声明：快照/胶片/CCD等风格声明可前可后。但无论放哪，全词最后几个字必须是氛围/质量词（规则9）。
* **例外：C类开瓶器固定句首**（呈现画面式/电报式都必须是全词第一句，见C类激活层），不适用本条的位置灵活。

**规则5 · 糙感许可（仅B类、C类电报式）**
B类艺术创作和C类电报式允许关键词松散堆叠、语义跳跃、碎片化断句，不追求语法完整和因果连贯。写出来的词应该像"堆出来的创作笔记"，而不是"改出来的通顺文案"。过度流畅、过度规整 = 不像。
**不适用本条、必须写流畅完整句的**：A类全部写法（含叙事长句型）、C类呈现画面式——这两类碎片化反而不像。

**规则6 · 锐度锚点（A/C类必带，B类豁免）**

* **A/C类每条至少包含**：

  * **对焦锚点**：`画面聚焦面部` / `对焦精准落在面部` / `对焦清晰`
  * **细节锚点**：`发丝根根分明` / `发丝根根分明且轻拂泛光` / `皮肤纹理清晰` / `睫毛根根分明`
* **肤质锚点**：C类必带，A/B类强烈建议——`白净` / `瓷感白肌肤` / `皮肤白皙透亮` / `冷白皮`
* **B类豁免对焦/细节锚点**：B类以意境优先，朦胧、虚化、弥散是合法审美，不强制锐度锚点

机制：瑶光是质感提升型 LoRA，靠质感词激活——肤质词是点火器，没有它 LoRA 不发力，出图就是底座原生软图。柔化指令没有锚点对冲时，模型会把"随手一拍"执行成"没对上焦"。**C类的完整锚点规格（含对比度三选二）见其模块②，比本通用版更严，以模块为准。**

**规则7 · 光与景（A/C类执行，B类以意境优先可突破）**

* 光必须有**明确落点**（脸/发丝/肩头等），禁止笼统的"自然光""光线明亮"；有条件时补**环境反射**（波光/地板反光/光斑），人物和场景的光照才是一体的
* 场景要有**前景小物件**（贝壳/散落的书/咖啡杯），禁止只有"人物+虚化背景"两层——`背景虚化`是抽象描述，喂不出纵深感
* **C类的三段光链+三层场景为强制规格，见其模块②**

**规则8 · 具体事实优先
写成因，不写结论。** 模型渲染的是画面不是概念——抽象技术标签只能当辅料，不能当主菜：

|❌ 抽象标签（结论）|✅ 具体事实（成因）|
|-|-|
|形成明暗过渡|午后阳光从侧上方洒落，在海面形成粼粼波光|
|背景虚化|背景是蔚蓝浅海与天际线，沙滩上有零星贝壳脚印|
|空间层次丰富|吧台边缘形成引导线，玻璃柜里陈列着烘焙点心|
|对比强烈|乌黑发丝垂落在浅色裙摆上|

判断方法：对每个描述句问一遍——"模型能拿这句话画出具体东西吗？"画不出的就是标签，要么删掉，要么改写成可渲染的事实。

**规则9 · 尾部落点**
提示词尾部是黄金位置，决定模型的"最终审美目标"。**全词最后必须是质量词/氛围词**（`清纯元气感十足` / `氛围感十足` / `大师级作品`），**禁止让柔化指令成为结尾**（`…抓拍风格` / `…运动模糊` / `…虚化` / `…构图随意` / `…昏暗`）。风格声明后置时同样遵守：声明后面必须再压一个氛围词。

## 五、使用说明

**AI根据本模板生成提示词的操作流程：**

1. **判断风格分支**：根据用户需求语境选择模板

   * 提到"摄影/写真/杂志/商业/影棚/8K/镜头" → **摄影写真模板（A）**
   * 摄影类 + 单一明确场景 + 要故事感/完整画面叙事 → **摄影写真·叙事长句子模式**
   * 提到"国风/水墨/厚涂/梦幻/仙/神秘/艺术" → **艺术创作模板（B）**
   * 提到"华丽/盛世/神性/怪诞/极致堆叠" → **艺术创作·华丽堆叠子模式**
   * 提到"日常/随拍/快照/自拍/CCD/生活感/随手拍" → **日常快照模板（C类模块，三层架构）**
   * **两可词（街拍/胶片/复古）看搭配语义**：搭配"写真/精致/商业/影棚" → A；搭配"随拍/CCD/生活感" → C
   * 仍不明确 → 默认摄影写真模板（A）
2. **选开头句式**（按分支对号，禁止跨用）：

   * **A类** → 电报式或具备式；胶片/复古/街头感优先具备式；也可用画质声明前置开头
   * **B类** → 营造式，或 `亚洲，真人，` 直接起头
   * **C类** → 开瓶器严格二选一：师妹/少女/洛丽塔系快照优先"呈现画面式+墨明风格"；短词用电报式；有具名角色直接用角色锚（可不写开瓶器）。**禁止具备式/营造式开头**
3. **按分支模板组装**：A/B类按各自公式填空；**C类直接按"激活层→骨架层→氛围层"三层架构组装**，无需对照通用字段表。
4. **从词库取词+自由发挥**：词库提供高频参考词，优先选取以保持风格一致性；超出词库范围时自由创造。拿不准的服装/材质直接用"随机款/随机组合"，比硬编更像作者。
5. **执行自检**：

   * A/B类：对照第四节通用规则逐条检查（复沓/赞美词撒开/混搭/声明位置/糙感范围/锚点/光与景/具体事实/尾部落点）
   * C类：用模块末尾的"生成后五问"，不必再过通用规则（C类模块是超集）
6. **风格语感匹配：**

   * 摄影写真类 → 语句完整流畅，像专业摄影师的拍摄brief
   * 摄影写真·叙事长句型 → 完整叙事段落，像美术指导的画面阐述文档
   * 艺术创作类 → 允许关键词堆叠、诗意碎片化表达，像艺术家的创作笔记
   * 日常快照类 → 呈现画面式用完整句演candid，电报式用短句堆单品，像朋友圈配文
7. **长度控制**：

   * 摄影写真类：150-350字
   * 摄影写真·叙事长句型：400-500字
   * 艺术创作类：150-350字
   * 艺术创作·华丽堆叠型：350-500字
   * 日常快照·电报式：50-150字
   * 日常快照·呈现画面式（满配）：180-230字
8. **收束原则**：每条提示词末尾用1-2个质量词/氛围词收束（详见规则9尾部落点）。
9. **禁忌**：

   * 禁止英文tag式质量词结构（如 `masterpiece, best quality, 8k` 这类纯堆标签写法）；
   * **放行**：艺术家英文名（如 `William Morris`）、与画面内容相关的英文短句插入、品牌型号名（`IPHONE16`、`Prada`、`LOVE`字样道具）——这些是作者原词真实用法，不属于tag式写法；
   * 保持全中文自然语言描述为主体；不要加编号或分段标题——输出的是一整段连贯文本；
   * **禁止抽象标签当主菜**（规则8）：`形成明暗过渡` / `空间层次丰富` / `对比强烈` 这类结论式词汇只允许在已有具体事实打底后作为补充出现；
   * **禁止场景矛盾**（C类）：全词只允许一个场景设定，首尾出现两个场景=废词；
   * **禁止C类用具备式/营造式开头**：C类开瓶器严格二选一（呈现画面式/电报式）；
   * **禁止对比度三无组合**（C类）：`浅色全身+亮背景+无落点平光`，必灰必平。
