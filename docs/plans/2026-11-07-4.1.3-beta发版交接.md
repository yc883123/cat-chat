## 三、调查代理已回的两份结论（要点）

### 1. 批量转换图片链路（已完成对应改造）
- 前端 `buildBatchConvertRequest` 收集已勾选图片口已上传原图（≤6 张，超限抛错拒绝）→ 后端 `naiba/studio/images.py` 校验（uploads 受管树 + Pillow 解码 + 20MB/张、60MB/总）→ `naiba/studio/runner.py:283-312` 逐张 `encode_image_file` base64 内嵌（`图N（文件名）：`文本 + 图片交替），provider wire 全覆盖（OpenAI image_url / Responses input_image / Claude image / Gemini inlineData / Ollama images / LM Studio data_url）。
- **模型看不到图的三种边角**：请求体超 8MB 预算或 413 时最旧图被占位文本替换（runtime.py:1602-1624）；模型显式标纯文本则整条失败；执行期文件被清报错失败。都不是静默丢。
- 「未提供关键帧（无图）」原本只写进 user_request，UI 不可见 → 已落「带图小字提醒」。
