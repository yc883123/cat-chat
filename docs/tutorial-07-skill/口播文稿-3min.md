# 口播文稿：3 分钟给 Cat Chat 装个新技能（小白版）

- 时长设定：**3 分钟**，中速 **240 字/分钟**
- 正文约 **690 字**（纯念约 2 分 52 秒，加停顿与画面切换刚好 3 分钟）
- 素材：**01-agent ~ 05-pin-skill 共 5 张截图**
- 读法提示：`Skill` 念英文或「技能」都行，同一段里保持一致；`/` 念「斜杠」；`zip` 念「zip 包」

---

## 分镜 1｜0:00–0:17 开场：先搞清 Skill 是什么

**画面**：05-pin-skill.png（固定 Skill 面板），大字幕「Agent 是岗位，Skill 是手册」

> 先说清楚一个概念：Agent 是岗位，Skill 是岗位手册。Agent 决定它手里有哪些工具，Skill 是一份行为指导，告诉它做某类事该按什么流程走。记住一句话——Skill 不是新工具，它教的是怎么用好已有的工具。

（约 105 字）

---

## 分镜 2｜0:17–0:37 第 1 步：换 Agent，说人话

**画面**：01-agent.png 与 02-ask.png 切换

> 第一步，顶栏的 Agent 下拉里选「Skill 助手 Agent」。然后别管术语，说人话就行。比如直接说：我想按小红书的风格写文案。你不用知道 Skill 叫什么名字，也不用知道它在哪。

（约 90 字）

---

## 分镜 3｜0:37–1:02 第 2 步：它会翻已装清单

**画面**：04-slash.png（`/` 弹出的 Skill 列表）

> 第二步，它会先去你自己的清单里翻一遍。有对口的，就直接教你怎么用，不用装。清单在哪不用记——在输入框打一个斜杠，当前所有可用的 Skill 会直接弹出来。顶栏那个写着数字的 Skill 按钮，点开是同一份清单，还带搜索框。

（约 110 字）

---

## 分镜 4｜1:02–1:30 第 3 步：没有就装

**画面**：03-install.png（导入 Skill 面板）

> 第三步，如果没有合适的，就让它装。开箱已经带了几个常用的，比如「Cat Chat 使用指南」和「文案写作」，多数需求直接能用。真缺了再装，三种喂法都行：给链接、给压缩包、给一个单独的 md 文件。装完它会主动给你演示一句触发语——装完不会用，等于没装。

（约 122 字）

---

## 分镜 5｜1:30–1:52 第 4 步：打斜杠，选它，说一句

**画面**：04-slash.png（选中 Skill 后插入的 `/技能名` 引用）

> 第四步，怎么用。在输入框打斜杠，在弹出的列表里选中那个 Skill，然后正常说你的需求，一句话就够。它会往输入框里插一个斜杠加技能名的引用，长得像链接，别手动删掉。发送后首轮注入、之后追加到对话末尾，这样对缓存最友好。

（约 106 字）

---

## 分镜 6｜1:52–2:22 第 5 步：让它常驻

**画面**：05-pin-skill.png（固定 Skill 标签页，勾选并保存）

> 第五步，让它常驻。如果某个 Agent 你每次都配同一个 Skill，就把它固定下来。左下角的设置进 Agent，选中那个 Agent，点编辑，切到「固定 Skill」这一页，勾上，保存。之后这个 Agent 每次开口就自带这份手册，不用再打斜杠。内置的导演 Agent 出厂就钉了三个，所以它开箱就会拍片。

（约 136 字）

---

## 分镜 7｜2:22–2:44 三个提醒

**画面**：黑底三条字幕逐条浮现

> 三个提醒。第一，Skill 在哪看？输入框打斜杠最快，顶栏的 Skill 按钮和设置里的 Skills 管理都行。第二，能删，设置里的 Skills 管理有两条路，建议选「移到回收目录」，能恢复。第三，装的 Skill 不好用可以让 AI 改，它会先告诉你要改哪几个文件。

（约 112 字）

---

## 分镜 8｜2:44–3:00 收尾

**画面**：黑底字卡「换 Agent → 说需求 → 装或直接用 → 打斜杠 → 固定」+ 项目名

> 记住这条链：说需求、看清单、装或直接用、打斜杠引用、常用就固定。技能装对了，同一个 Agent 能干的事就完全不一样了。

（约 52 字）

## 制作备注

1. 全片 8 个镜头，静态截图 + 分块高亮即可，不必做复杂动效。
2. **本片不需要任何外部账号**，但「装一个新 Skill」这一镜最好做实拍（真的导入一次），
   否则观众对「装」这件事没有实感。若手边没有现成的 zip，可现场演示「让 AI 从链接装」。
3. 分镜 6 是全片最长的一段（约 30 秒）。若超时，可把「内置的导演 Agent 出厂就钉了三个」
   压成字幕，立省 5 秒。
4. 分镜 1 的概念区分是全片的认知锚点，**建议配一张对比图**（左边 Agent＝工具箱，右边
   Skill＝手册），比纯口播有效得多。
