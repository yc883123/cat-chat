# 口播文稿：3 分钟第一次对话（小白版）

- 时长设定：**3 分钟**，中速 **240 字/分钟**
- 正文约 **680 字**（纯念约 2 分 50 秒，加停顿与画面切换刚好 3 分钟）
- 素材：**01-api ~ 05-tutor 共 5 张截图**
- 读法提示：`API` 念「A-P-I」；`Agent` 用英文原音或念「智能体」；`ComfyUI` 念「康菲 UI」；`Key` 念「密钥」

---

## 分镜 1｜0:00–0:14 开场钩子

**画面**：03-first-chat.png（对话成品），压暗背景 + 大字幕「装好之后，第一句话怎么说」

> 装好了软件，点开却不知道从哪下手？其实只要三件事：接一个模型、确认用哪个 Agent、然后打字回车。接下来三分钟，跟着点一遍，你就能跑通第一次对话。

（约 68 字）

---

## 分镜 2｜0:14–0:52 第 1 步：接一个模型

**画面**：01-api.png（添加 API 表单；地址、格式、Key 三项画红框）

> 第一步，接一个模型。Cat Chat 自己不带大脑，得先接一个模型服务。点左下角侧栏底部的设置，左边选「API 供应商」，再点最后那张「添加 API」卡片。上面挑一个平台模板——DeepSeek、Kimi、智谱、OpenAI 都能选——名称和地址会自动填好，你只要把申请来的 Key 粘进去。点「检查模型」拉出列表选一个，「测试连接」通了就保存。

（约 148 字）

---

## 分镜 3｜0:52–1:10 两个必踩的坑

**画面**：底部「模型」下拉特写（05-model-pick.png，或用 01-api.png 加箭头标注）

> 这里有两个新手必踩的坑。第一，顶栏那个下拉是「API」，底部的才是「模型」——一个 API 底下可能挂着好几个模型，选哪个在底部选。第二，不选模型就发不出去消息，发送键会一直是灰的。每个新会话都要选一次。

（约 100 字）

---

## 分镜 4｜1:10–1:34 第 2 步：认识顶栏

**画面**：02-agent-help.png（点开 `?` 的说明弹层，6 个内置 Agent 高亮）

> 第二步，认识顶栏三件事：左边是走哪个 API，中间是「这一轮谁当家」，右边是后台任务。中间那个就是 Agent，你可以把它当成员工岗位——导演会出图，编程助手会写代码。它右边有个问号，点开能看到内置的六个 Agent 分别是谁。排第一位的是教程助手，这个系列每一篇都会用到它。

（约 122 字）

---

## 分镜 5｜1:34–2:02 第 3、4 步：发出第一句、看懂确认框

**画面**：03-first-chat.png（对话进行中）→ 2:00 左右切 04-approve.png（确认框）

> 第三步，说第一句话。新建会话默认就是「全能 Agent」，日常杂事都找它，不用先切换。确认底部模型选好了，打字回车就行。第四步，它要动你电脑上的东西时，会先弹一个框问你同不同意——点允许它才动手。嫌烦可以点底部的「审批」，切到自动或完全档。只是聊天问答，不会弹这个框。

（约 130 字）

---

## 分镜 6｜2:02–2:22 第 5 步：不会就问教程助手

**画面**：05-tutor.png（对教程助手提问与回答）

> 最后一步最省事：不会就问。Agent 下拉里排第一位的「教程助手」，就是专门教你用这个软件的。它回答很固定——先给结论，再给编号的点击步骤，按钮名精确到字，最后告诉你这个功能在哪个页面。拿不准的按钮名，它宁可说去查一下，也不会编一个给你。

（约 112 字）

---

## 分镜 7｜2:22–2:46 排错提示

**画面**：底部模型下拉特写 + 设置里 Agent 卡片特写（可分成左右两半）

> 两个排错提示。发送键是灰的，八成是没选模型，去底部下拉选一个。它说「我没有这个工具」，是当前 Agent 的工具集里没有——换个更合适的 Agent，或者到设置、Agent、工具集里勾上。

（约 82 字）

---

## 分镜 8｜2:46–3:00 收尾

**画面**：黑底字卡「接模型 → 选 Agent → 打字回车」+ 项目名

> 记住这三件事就够了：接一个模型、选一个 Agent、打字回车。下一集，让导演 Agent 帮你出图。

（约 42 字）
