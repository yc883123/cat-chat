# 工作台与任务总管前端实施

基线：`3e5e810`（包含 `4.2.6-beta` 与本地贴签匠修复）。设计依据为用户提供的 2026-11-11 交接 Markdown 和独立 HTML 预览；压缩包无法正常读取，未运行包内脚本。

## 范围与默认选择

- 实施 P0 基础修复、P1 共享展示工具、P2 五个工作台页及 P3 任务总管。
- 接线信息默认折叠但完整保留；新建、导入、续写收进书名菜单；低频操作进入更多菜单。
- 任务总管复用应用侧栏，按真实步骤与能力展示主操作；状态色使用统一语义。
- 保留元素 ID、原有事件、数据和执行权限；不改后端接口，不混入贴签匠待修逻辑。
- P4 只抽取本次实际复用的展示工具；HTTP 缓存/压缩、大规模事件重构另行处理。本轮不发版、不推送。

## 实施与验收

1. 共享语义色、字号、按钮高度和局部 `[hidden]` 兜底；不得全局覆盖贴签匠有意保留的 hidden 布局。
2. 复用真实导航节点合并页头，切页后桌面/手机仍能打开应用导航；尺寸按实际容器判定。
3. 逐页保持操作可达、表单草稿不丢、原有列表/预览/导出行为不变。
4. 总管未变化区域不重建；验证焦点/选区、待开始/恢复/审批状态及终态轮询。
5. 测试覆盖共享展示函数、各模块行为，执行静态检查与隔离浏览器桌面/窄桌面/手机、亮暗主题验收。

测试必须使用隔离数据及模型替身，不触碰正式实例。截图、日志、一次性夹具目录不入库。

## 已落地与保留边界

- P0：修正书页 hidden 覆盖、局部缺失变量、次要文字及状态色；不更改对话配色。
- P1：共享菜单定位/关闭/回焦、容器观察、状态显示和导航节点迁移；供应商请求缓存与各域表单仍由原模块管理，不在视觉改版中重写。
- P2：五页完成紧凑页头、扁平分组、低频操作菜单与窄屏适配；书页/贴签匠动作栏固定，造梦机完整接线默认折叠、手机批量条目转字段卡。
- P3：任务列表复用侧栏、主卡按真实状态与能力渲染、概况右栏/窄屏抽屉、活动折叠、列表按任务 ID 复用、未变详情分区不重建；终态详情以成功读取的线程与时间为准，间隔至少 30 秒复核晚到产物，失败自动重试；Job 镜像所有状态的主卡均只读。
- 复审修正：菜单 Escape 不再冒泡关闭应用侧栏；二级导出菜单锚定可见按钮；书页弹窗关闭后仅在焦点丢失时回到可见菜单入口；空态清理旧任务标题/状态；手机、桌面与映射区共用按素材类别分别编号，文件和事件仍按整体口索引绑定。
- P4 的 HTTP 缓存/压缩、供应商下拉整合和大规模事件拆分未纳入；旧贴签匠逻辑复查问题保持独立待修。

可复用浏览器入口：

- `verify/workbench_visual_smoke.cjs`：六档宽度、亮暗主题、几何/字号/触控区/可测对比度、草稿与导航、聊天输入区。
- `verify/novel_writer_mobile_smoke.cjs`、`verify/workbench_books_smoke.cjs`：长文本与真实书库阶段、菜单、导出、动作栏及续写入口。
- `verify/workbench_super_smoke.cjs`：刷新时焦点/选区/节点身份、终态详情低频补查晚到产物、失败 Job 镜像只读与手机抽屉。
- `verify/workbench_media_smoke.cjs`：有内容工作流映射、更多菜单、手机批量字段完整性与混排素材编号一致；只读 API 替身，不提交生成。

上述浏览器脚本均针对隔离实例。正式供应商、真实 ComfyUI 生成、EXE 打包和发布不在本轮验收内。

## 复查修复的验证备注

四项修复的定向测试、真实页面浏览器回归及静态检查通过。全量首轮在未改动的 `test_continue_requires_current_supervisor_version` 与 `test_authorization_and_path_are_enforced` 失败；相关两个模块单独复测通过，基线上的同两个用例也通过。前者直接改写快照与后台线程有竞争，后者失败在清理临时 `qq.db` 文件占用阶段；保留为既有测试时序风险，不将本轮全量报告标为全绿，也不混入这批前端修复。
