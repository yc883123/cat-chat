## 2. esm_graph_check 告警逐条核实（全部误报）

检查器按「标识符名出现在模块里 = 引用了其他模块的导出」做保守匹配，以下告警经源码核对均为同名局部变量/属性/字符串字面量，不是跨模块引用：

| 告警 | 核实结论 |
| --- | --- |
| `05-bootstrap.js: import startUpdatePoll as startFastUpdatePoll 未在 07-models-agents.js 中定义（无处定义）` | 误报。`startUpdatePoll` 在 `07-models-agents.js:499` 定义且 `export`，别名导入合法 |
| `07-models-agents.js / 08-conversations.js / 09-settings.js / 16-file-refs.js / 22-studio.js / 23-labeler.js / 24-comfyui.js / 25-novel.js 引用 note（20-sound.js）但未 import` | 误报。以上文件里的 `note` 全部是局部变量、箭头函数参数、DOM 查询结果或对象属性（如 `release_notes.map((note) => …)`、`const note = menu.querySelector('[data-manual-note]')`），无一调用 20-sound 的提示音函数 |
| `09-settings.js 引用 statusText（24-comfyui.js）但未 import` | 误报。`09-settings.js:4888` 的 `let statusText` 是连接状态文案局部变量 |
| `25-novel.js 引用 markdown（02-markdown.js）但未 import` | 误报。出现处为字符串字面量 `"text/markdown;charset=utf-8"`（25-novel.js:2923） |

判定依据：全部 27 个模块在真实浏览器加载中**零 pageerror**（报告 03），若存在真实缺失绑定，ESM 在加载期即抛 `SyntaxError`。
