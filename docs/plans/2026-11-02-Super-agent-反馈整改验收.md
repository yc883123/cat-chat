## 已实现

1. 详情节点只写入 `superAgentNodeList`，空态不销毁容器；只保留一次节点操作委托。
2. F1：Store 字典/列表字段归一，兼容旧 JSON null 且读取不批量改库；关联写回故障后按当前 attempt 的持久关联接回同一 Chat/Job/子助手，不重新提交未知结果。补齐 claim 结算、错误清除和恢复/取消转换。
3. F2：活 Run 确认锁内快照、安全 `thread.chat_confirmations`、pending/processing 状态展示；回到原聊天允许或拒绝，不新增授权接口。首次/重复回放处理中的确认卡不显示按钮；异步受理显示正在执行，不误称已完成。
4. F3：单一目标输入，Chat/子助手分别映射 message/instruction；名称可选，作品/会话按类型选取；模型和串联步骤折叠，默认不启动。
5. F4：桌面横向三栏，总管态隐藏聊天侧栏并释放其布局轨道；保留对话/工作台切换，返回恢复侧栏收起偏好；手机单列。概览、步骤、时间线和本地筛选只展示真实数据。
