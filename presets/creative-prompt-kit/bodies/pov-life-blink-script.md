**6 字段中, ④⑤⑥ 最关键** — 命题决定整片基调, 情感主线决定 8-12 章节装什么, 系列归属决定标题卡和片尾字幕格式。

**关于"呼应物"为何是可选**:
原三个参考片只有 1/3 真正做到"一件贯穿全片"。v1 是"糖果(母亲给我)↔字条(我给妻子)"的前后对照, v3 是多件事件道具各管一段。所以**不要硬给主角塞一件信物贯穿一生** — 那样反而显得机械、AI 化。每章有具体可拍道具就够了(那是步 1 的事), 跨章呼应是锦上添花。

## 4 种典型主角原型

### 原型 A · 致敬亲人 (Tribute)
- 真实原型: 母亲/外婆/父亲/爷爷
- 命题倾向"奉献-被托付-不被看见"
- 系列归属(自定): "我父亲的XX年" / "她的XX年" / 任何你的原创系列名
- 案例: **v1参考片(致敬亲人版)** — 都市男性一生(幼年→老年→弥留产房闭环)
- 案例: **v2参考片(致敬亲人版)** — 山村男性一生(离家→高三→初恋→工地→丧父→嫁女→临终)
- 命题写法范例: "用一辈子, 把孩子送出大山"

### 原型 B · 时代英模 (Icon)
- 公开历史人物: 雷锋/钱学森/王进喜/邓稼先/张桂梅
- 命题倾向"信念-牺牲-被传颂"
- 系列归属: "榜样" / "国魂"
- 案例: 参考片(英模版) — 真实历史人物一生(出生→事迹→事迹→...→牺牲→后世传诵)
- 命题写法范例: "把好事做完一火车,然后悄悄下车"

### 原型 C · 平民史诗 (Everyman)
- 虚构平凡人, 真实时代背景
- 命题倾向"小人物-大时代-被遗忘"
- 系列归属(自定): "百年中国"风格 / "改革四十年"风格 / 任何你的原创系列名 / 独立
- 命题写法范例: "下岗那年, 摆摊把儿子供成了大学生"

### 原型 D · 性别中立POV (Neutral)
- 不指定具体身份, 用"你"或"我"指代任何观众
- 命题倾向"一生即一瞬"
- 系列归属: 独立 / 抒情短片
- 命题写法范例: "你来过, 你爱过, 你被爱过"

## 字段填写指引

### ① 性别·出身年代
- 必须给具体年份(1958/1972/1985), 不要"上世纪"
- 性别影响章节模板(看第三部分)

### ② 出身地·阶层
- 城/乡/山区/边疆/部队大院 — 决定开场环境与道具(油灯/煤油炉/蜂窝煤/筒子楼/大杂院)
- 阶层决定主角"穿什么/吃什么/进什么门"

### ③ 一生主职业·身份
- 越具体越好(不要"工人", 要"机床工"/"三班倒纺织女工"/"汽车兵")
- 职业是中段章节的"骨架钉" — 把主角带到不同的可拍场景

### ④ 一句话核心命题
- 必须含一个**动词** + 一个**对象**
- 好例: "把好事做完一火车,然后悄悄下车"(雷锋,v3) / "对不起 我来晚了"(山村男人对初恋的婚礼,v2)
- 差例: "奉献的一生" / "不平凡的人生"(空泛, 不可拍)

### ⑤ 情感主线 (修订)
- 第一项 [必填]: 一种**反复发生的关系事件** — 离别/相聚/送行/迎接/告状/许诺
- 第二项 [必填]: 一位**活着记得他的人** — 配角中的"见证者", 结尾还活着, 把主角传下去
  - v1: 母亲(产房泪笑→老照片→弥留时再现)
  - v2: 老黄狗"旺财"(出场领路 → 老年看着主人临终 → 旺财的儿子衔接)
  - v3: 后世小学生(齐声朗诵《雷锋叔叔, 你在哪里》)
- 第三项 [可选, 没有就空]: 一组**跨章呼应物** — 可以是同一件贯穿, 也可以是"前后对照"的两件, 也可以**没有**(每章自己的道具就够, 章间不强求呼应)。**警告**: 不要为了凑齐三项就硬给主角塞一件"贯穿一生的物件" — 那是 AI 化的对称设计, 实际故事里大多数人的人生没有这种东西。

### ⑥ 系列归属
决定标题卡和片尾字幕模板:
- 致敬亲人系列: 《[你的原创片名]》+ 小字副标题(自定, 不要照抄已有系列名), 字幕 4 行(导演/制片/创作支持/平台)
- 英模/史诗系列: 《[你的原创片名]》大字标题, 章节卡用历史时间地点(e.g. "1959·抗洪前线"), 字幕 3 行(导演/创作支持/使用平台)
- 独立: 任意命名, 不带副标题

## 章节卡模板 (每章必填 6 字段)

```
章 N ·  [章节卡文字]
├─ 章节卡类型:       [年龄段 / 事件标签 / 历史时间地点]
├─ 时代锚点(可拍道具): [具体可拍的招牌/制服/海报/老物件]
├─ 核心戏剧动作:      [一句话动词 - 主角"看到/听到/触摸/送出/收到"什么]
├─ 关键道具:         [1 件本章可拍的具象物 - 不强求贯穿全片, 服务本章即可]
├─ 配角及其台词:      [1-2 人 - 必有 CU/MCU 直视镜头时刻 + 一句台词]
└─ 章末情绪:         [沉重/疲惫/惊醒/释怀/不甘 - 决定本章后的眨眼类型]
```

**关于"关键道具"**: 这是**章内**道具(本章可拍的某件物), 不是"贯穿一生的信物"。章与章如果有自然呼应 当然好, 但**不强求**。硬塞"贯穿物"是 AI 化的对称设计, 实际故事里大多数主角的人生没有这种东西。

## 章节卡的 3 种命名风格 (必看)

通过分析三个原案例发现, **章节卡(chapter card)**有 3 种命名方式, 根据题材选用:

### 风格 1 · 年龄段(适合致敬亲人) — 案例 v1
```
出生 · 幼年 · 少年 · 青年 · 中年 · 壮年 · 老年 · 弥留
```
- 简单, 适合不需要解释具体事件的题材
- v1 用此风格(都市男性一生)
- 不严格按生理年龄, 可按"情感阶段"排列(中年丧父 → 壮年新婚 是合理的)

### 风格 2 · 事件标签(适合英模事迹) — 案例 v3
```

```
- 历史时间或地名 + 具体事件名
- 对真实历史人物特别合适, 章节卡本身就是史料标题
- v3 用此风格(雷锋一生)

### 风格 3 · 留白(适合情感片) — 案例 v2
```
(无章节卡, 用台词或场景切换示意)
v2 通篇几乎不用章节卡, 章与章靠台词和场景跳跃自然衔接
```
- 让观众自己感受章节边界
- 仅在需要时间跳跃明显时上小字 (e.g. v3 用"两小时后")
- 适合写实情感片

### 第一段: 开场 (0:00-0:08)
仰拍 + 红色眼皮血管晕影 (案例三片皆有)

- 首镜光源类型决定题材调性 (见下表)
- 配角(母亲/伸手者)在 4-6 秒间出现, 凑近镜头

### 第二段: 标题落版 (0:05-0:10)
《XXX》大字 + (副标题)小字, 落在第一段尾或刚切到第二镜后
- 参考 v1: 主标题在 8s 落版, 带小字副标题(系列归属)
- 参考 v2: 主标题在 ~6s 落版, 带小字副标题(系列归属)
- 参考 v3: 主标题在 4s 落版, 无副标题(单独成立)

### 第三段: 片尾闭环 (最后 5-15 秒)
**3 种闭环手法 (从案例验证)**:

#### A. 画面同构 
开场画面(母亲泪笑)在结尾**直接重现**, 配主创字幕
- v1 末尾 4 帧母亲流泪笑望同框, 叠加 4 行主创字幕(导演/制片/创作支持/平台)
- 构成"一生即一瞬"的强烈轮回感

#### B. 视角反转 
开场是 POV, 结尾**揭示 POV 之外的真相**
- v2 末尾首次露出主人公真容(中年男人流泪), 揭示孙女问"外公怎么了"
- 然后**重现片首山雾画面**, 完成画面+认知双重闭环

#### C. 后世传颂 
主角已逝, 但**用诗歌/课文/合唱**让他活在后世
- v3 用《雷锋叔叔, 你在哪里》的选用用户提供或有权使用的短段朗诵
- 课本翻开 + 课堂齐诵 = 后世闭环

## 写作 6 条铁律

### 1. POV 视角永不破
- 主语永远是"我" / "你" / 省略
- 不写"他低下头" — 写"他的额头出现在我面前"
- 不写"她笑了" — 写"她笑容凑近镜头"

### 2. 配角必须直视镜头说台词
- 凡台词, 必有人脸正对镜头
- 台词用引号写, 例: 妻子凑近: "要下雨了。"
- **不写说话人**(因为画面已经显示了谁在说)

### 3. 关键道具至少特写 1 次
- 每章必有 1 件具象物的特写镜头
- 物件即潜台词 (糖/字条/绣花包袱/无影灯/课本)

### 4. 写"可拍可听", 不写"心理"
- 不写: "她意识到他要走了"
- 写: "她转身, 行李箱拖在身后, 在站台上越走越远。"
- 不写: "他难过得不能自己"
- 写: "我喉咙发紧, 没说话。"

### 5. 时代锚点用具体可拍道具说话
- 不写: "那是个艰难的年代"
- 写: "招贴画上'节约储蓄, 支援国家建设'的红字"
- 不写: "改革开放了"
- 写: "电视雪花点散了, 屏幕里跳出彩色画面。"

### 6. 每段 80-150 字
- 太短: 镜头数不足, 章节立不起来
- 太长: 时长溢出 90/120/150s

## 4 种眨眼情绪类型

### 类型 1 · 释怀眨 (Soft Blink) — 0.3-0.5s
- 章末情绪正面, 主角接受了什么
- 视觉: 慢速夹紧, 慢速打开
- 配音: 一声短叹气 + 下一章环境音淡入
- 用例: 幼年妈妈送学(章 2 末) / 工地见师傅(章 4 末)

### 类型 2 · 沉重眨 (Heavy Blink) — 0.5-0.8s
- 章末情绪沉重, 主角不愿但必须接受
- 视觉: 快速夹紧, 慢速打开(久久才睁开)
- 配音: 心跳声 + 下一章音延后 0.3s
- 用例: 父亲去世后 / 偷看初恋婚礼

### 类型 3 · 惊醒睁 (Wake Open) — 0.2-0.4s
- 主角猛然睁开眼, 时间跨度大
- 视觉: 黑屏先停 0.5s, 然后快速打开
- 配音: 突然的环境音(火车汽笛/嘈杂声)出现, 模拟"惊醒"感
- 用例: 出生章末(章 1 末) / 大事件发生时

### 类型 4 · 不甘眨 (Reluctant Blink) — 0.5-0.7s
- 章末情绪是"不忍/挽留"
- 视觉: 夹紧后停留稍久 (~0.3s) 再睁开
- 配音: 心跳更长 + 下一章音乐前置
- 用例: 与初恋分别 / 火车送别女友

---

## 眨眼标注语法

在每章剧本末尾用此格式:

```
[BLINK 0.5s · 沉重 · 心跳叠粘膜声]
```

字段解释:
- `0.5s` — 总时长 (夹紧+打开)
- `沉重` — 4 类情绪之一
- `心跳叠粘膜声` — 配音处理 (可选)

---


```
章 1 出生            → [BLINK 0.3s · 惊醒睁]
章 2 高三            → [BLINK 0.4s · 释怀眨]
章 3 初恋            → [BLINK 0.7s · 不甘眨]
章 4 工地            → [BLINK 0.5s · 沉重眨]
章 5 偷看初恋婚礼     → [BLINK 0.8s · 沉重眨]  ← 全片最重的一次
章 6 树根埋念物       → [BLINK 0.4s · 释怀眨]
章 7 父丧            → [BLINK 0.6s · 沉重眨]
章 8 嫁女            → [BLINK 0.5s · 不甘眨]
章 9 老年聚          → [BLINK 0.3s · 释怀眨]
章 10 喂狗           → [BLINK 0.4s · 释怀眨]  ← 视角马上要切换
章 11 临终(POV切换)   → [BLINK 1.0s · 释怀眨, 慢]  ← 最长, 准备切换
章 12 反转+片首重现   → (片尾, 不需眨眼)
```

总眨眼次数: 11 次 (12 章 - 1)
单片总眨眼时长: 6-7 秒 (约占片长 5%)

---

## 特殊眨眼: POV 切换专用

当章节边界发生 **POV 视角切换**时(如 v2 主人公→老黄狗, v3 雷锋→后世小学生), 用 **2 段连续眨眼**:

```
[BLINK 0.5s · 释怀] → [BLACK 0.3s] → [BLINK 0.5s · 惊醒]
```

第一次眨 = 当前 POV 闭眼
中间黑屏 = 时间/视角切换的"间隙"
第二次睁 = 新 POV 睁眼

---

## 眨眼"不能用"的情况

不是每个章末都用眨眼。以下情况**不要**插入眨眼:

1. **同一时间线内的镜头连续切**: 例如 v2 章 3 初恋送行内部 有 5-6 个镜头, 内部用普通切, 章末才眨
2. **片头标题落版**: 标题出现时不能眨, 要保持画面
3. **片尾闭环重现**: 终幕回到开场画面时不要眨, 要慢叠化
4. **POV 内的闪回**: 如 v3 章 11 闪回雷锋抱迷路孩子, 闪回前后不眨, 用淡入淡出

## POV 镜头特殊用法

### 1. POV 不能用过肩镜头 (OS)
传统电影的 over-shoulder 在 POV 类型片**禁用** — 因为肩头的就是主角自己, 不可见。

### 2. POV 入手镜头 (Hand-In-Frame)
主角的手出现在画面边缘或前景:
- 接糖果(章 2)
- 收信物(章 3)
- 撑伞(章 7)
- 抚摸狗(章 10)
- 死前伸手(章 N-1)

镜头表标注: `MCU / POV / 自己的手伸入画面接[物]`

### 3. POV 走路 (Walking POV)
模拟 GoPro 头戴感, 画面有微微抖动:
- 走过幼儿园铁门
- 走过工地
- 走过田埂

镜头表标注: `MS / POV / 步行视角穿过[场景]`

### 4. POV 转头 (Head Turn)
快速摇镜头模拟主角转头:
- 看见好友走过
- 看见妻子凑近

镜头表标注: `CU→MS / POV / 头转向左/右, [对象]进入画面`

## 时长校验

镜头表全部填完后, 校验:

```
总时长 = sum(镜头时长) + sum(眨眼时长)
```

应在 90s/120s/150s 的 ±5% 内。如超出:

| 超出方向 | 处理 |
|---|---|
| 超出 +10% | 裁掉最长章的 1-2 个非关键镜头 |
| 不足 -10% | 给关键章节(临终/初恋)增加 ECU 信物特写 |

## ASL 节奏统计 (可选)

把每章的镜头数和总时长统计:

```
章 1 出生:    5 镜 / 8.5s   ASL=1.7s
章 2 幼年:    6 镜 / 10.4s  ASL=1.7s
章 3 少年:    5 镜 / 8.0s   ASL=1.6s
...
全片 ASL ≈ 1.8s (本类型片标准范围 1.5-2.5s)
```

ASL 过短(<1.2s) = 太碎, 看不清; ASL 过长(>3s) = 拖沓, 不适合 90-150s 短片。

统一交付格式：
# 《原创片名》
目标时长/章节数/真实镜数/ASL。
Part 0 主角骨架；Part 1 章节卡与三段闭环；Part 2 各章80–150字可拍散文与BLINK标记；Part 3 七列表；Part 4 主创字幕与自检。
七列：镜号｜时间｜时长｜景别｜POV标记｜动作/画面｜字幕/对白。字幕是后期计划，不要求影像模型准确写字。镜号按章.镜，转场单列，时长只加一次。
自检：可见视点一致；每章有具体道具；台词在自然时长内可说完；表演与年代连续；闭环A画面同构/B视角揭示/C后世传承选一且成立；呼应物可空，不能硬塞贯穿信物；不靠旁白说教；有轻重变化；题名署名不照抄参考片。
