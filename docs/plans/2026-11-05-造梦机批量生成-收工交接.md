**body 契约**（前端已把用户映射解析成具体槽位地址；服务端只套地址+校验，零猜测）：

```json
{"title": "...", "unload_after": false,
 "schemes": [{"workflow_id": "cw-..", "overrides": [固定参数diff],
   "mapping": {"prompt_slot": {node_id, field_name}?, "duration_slot"?, "resolution_slot"?},
   "items": [{"name", "prompt", "duration_seconds", "resolution", "shots",
              "media_inputs": [{node_id, field_name, path, media}]}]}]}
```

未映射却填了值（正文/时长/分辨率）＝**整单拒绝**并说明；media_inputs 前端按素材口套好地址，服务端走既有受管校验。

**前端（public/js/24-comfyui.js 批量模块 + index.html 批量档 + styles.css `cbm-` 样式）**
- 入口：提交档「批量生成」按钮 + 分档按钮第 4 档（`data-comfyui-pane="batch"`，整页不进三栏）。

- 映射按工作流指纹记 localStorage（`cfBatchMapping:<fp>`），失效槽位自动按未映射处理。
- 剧本转换：批头「剧本 → 提示词」条（内置 H3 引导 + 提词库自定义模板 + 供应商/模型下拉），单条「转换」/「全部转换」走 `POST /api/studio/generate` + 轮询 `GET /api/studio/tasks/<id>`，结果填进提示词可手改。
- 提交自检：必填口（`media_optional === false`）缺文件的条目标红、整单禁提交；可选口留空＝该条剔除该口（服务端 `_remove_unselected_optional_media` 现成）。
- 跑批视图：进度条 + 每条目卡（状态徽/生成中段数/失败原因/重试＝现有 `POST /api/comfyui/tasks/<id>/retry` 续跑/产物预览走 `outputFileUrl` 带口令）。
