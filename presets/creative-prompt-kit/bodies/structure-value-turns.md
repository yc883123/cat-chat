请依据用户的题材、人物、核心冲突、结局与目标篇幅，采用“场景价值反转”输出可执行故事大纲；若提供原稿并要求分析，则逐节点引用原文，不补造已有事实。只进行文本规划，不调用任何工具或其他模板。
先列一句话故事、主角外在目标/内在需求、对手、风险和结局；再按下列节点出表：节点名称｜预计位置/篇幅｜具体事件｜人物选择｜状态或价值变化｜铺垫/兑现｜连接下一节点的因果。节点名称不能当内容，每行写可发生的具体事。最后检查前后因果、人物知识、能力代价、支线作用、高潮选择与开场回应。
价值轴应具体，例如信任/怀疑、安全/危险、自由/受控；变化可正转负、负转正或更深恶化，不只限情绪正负。

#### 核心逻辑

> **故事的本质是价值反转**
> 每一个场景都必须完成一次价值正负反转

#### 五层结构

```
┌─────────────────────────────────────────┐
│  终极故事（Complete Story）              │ ← 主角从头到尾的根本性价值改变
│    ├─ 多幕（Acts）                      │
│    │     ├─ 序列（Sequences）           │
│    │     │     ├─ 场景（Scenes）        │
│    │     │     │     └─ 节拍（Beats）   │ ← 最小单元：动作+反应
│    │     │     └─ ...                   │
│    │     └─ ...                         │
│    └─ ...                               │
└─────────────────────────────────────────┘
```

#### 场景价值反转示例

| 场景类型 | 反转方向 | 情绪效果 |
|----------|----------|----------|
| 希望建立 | 希望→绝望 | 悲伤/震惊 |
| 信任建立 | 信任→背叛 | 愤怒/心碎 |
| 爱情升温 | 爱→恨/失去 | 心碎/恐惧 |
| 胜利在望 | 信心→失败 | 沮丧/绝望 |

使用边界：比例仅辅助定位，人物与因果优先；原作缺项标未提供，不强造高潮。已有结构适合时不再同时套其他八套。若需组合，仅另加一种局部检查（人物/价值/悬疑），不能把多套百分比强叠成一张机械任务表。
