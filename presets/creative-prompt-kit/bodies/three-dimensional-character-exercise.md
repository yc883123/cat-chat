根据用户人物概念，完成一张立体人物练习卡。只做人物文本设计；分析已有角色时以其材料为准。
固定输出：①人物卡（姓名/身份/职业）；②外表（3–4个可观察细节与行为，先形成第一印象）；③欲望（表层目标/中层关系诉求/深层缺失）；④弱点（与外表形成反差、能在事件中触发的脆弱处，附一段既往选择）；⑤四级压力链（轻/中/重/终极，每级：外部事件→选择→结果→暴露或成长）；⑥一句话激活；⑦可执行性检查。
弱点可以是信任、责任、孤独、真心或仁慈，必须解释它怎样与职业/目标冲突。成长靠选择及代价，不靠突然战力修复或角色自述。源案例是虚构练习素材，借机制，不默认把名字和剧情搬进新故事。
下面五例保留供对照。注意校准：赵九渊最终扶起背叛者，只代表尝试面对信任，不等于无条件原谅或恢复账本权限；沈青木受伤十年的右手握刀不能当作痊愈，需保留身体限制或改用左手；陆清商未受情感教育与活三百年不等于真的从未有情绪；柳如青转角落泪是裂缝而非已完成改变；燕七重视无辜，应体现救援代价，不能把主动救人自动写成复仇成功。

## 案例一：冷血商人 · 赵九渊

### 人物卡

| 要素 | 内容 |
|------|------|
| 姓名 | 赵九渊 |
| 身份 | 京城最大的地下钱庄幕后老板 |
| 职业 | 明面是当铺东家，暗里放贷杀人 |

### 三要素详解

**外表：冷血无情的商人**

- 永远穿深灰色长袍，袖口雪白，一丝不苟
- 账房算盘从不出错，见到哭穷的欠债人，面不改色地报出"砍左手还是右手"
- 京城商贾形容他："赵九渊的笑比冬天的风还冷"
- 当铺柜台后面永远放着一壶凉透的茶——他从不喝热茶，"等人要趁热，喝茶等着凉"

**欲望：证明自己不是"废物"**

- 表层：要成为天下第一富商
- 中层：要让当年抛弃他母子、说他是"败家之种"的赵家跪着求他
- 深层缺失：从未被认可过。母亲临终前说的最后一句话是"你爹要是有你一半本事就好了"——到死，母亲念的还是那个男人

**弱点：只要有人表现出对他的信任，他就会失去判断力**

- 他从小被背叛到大，所以恨透了背叛，也抵抗不了信任
- 一个陌生人的一句"我相信你"，就能让他放低戒备
- 所有人都以为他的弱点是贪财、好色、怕死——全都错了

### 冲突与生长轨迹

```
压力1（轻）：新来的伙计帮他看了一天店，说"东家，我信你不会亏待我" → 
    赵九渊破例多给了三倍工钱 ← 弱点暴露

压力2（中）：竞争对手派来的卧底在他身边潜伏两年，从不说谎、事事卖命 → 
    赵九渊把账本给他管，甚至收了当干儿子 ← 弱点发力
    
压力3（重）：干儿子卷走所有流动资金投靠对手，钱庄崩盘 → 
    赵九渊第一次在母亲灵位前坐了一整夜，没说话 ← 最低点

压力4（终极）：对手东山再起时却把干儿子打到半死扔回给他，说"这种狗养不熟" → 
    赵九渊看着地上浑身是血的干儿子，沉默了很久，最终把他扶起来 ← 生长起点
```

### 一句话激活

> "他用十年把自己活成一柄刀，就是为了验证——这世上到底有没有一个人，值得他把刀放下。"

## 案例二：躺平咸鱼 · 沈青木

### 人物卡

| 要素 | 内容 |
|------|------|
| 姓名 | 沈青木 |
| 身份 | 青木镇陈家村最出名的废柴 |
| 职业 | 无所事事，每天去河边钓鱼晒太阳 |

### 三要素详解

**外表：懒散到骨子里的咸鱼**

- 二十五岁，看起来像三十五——不修边幅，胡茬永远刮不干净
- 穿着打了六个补丁的短褐，蹲在村口晒太阳时像一块会呼吸的石头
- 村里人评价："沈家那小子，狗从他面前过都懒得抬一下眼皮"
- 唯一的热情是钓鱼——不是为了吃，是因为"鱼不上钩的时候，我可以心安理得地发呆"

**欲望：只想安静地躺一辈子**

- 表层：在村里躺到死，没人管他，他也不管别人
- 中层：不想再卷了。他以前是州府武试的探花，差点入军籍——比武时废了右手筋，被踢出武举，从此再也不信"努力就有回报"
- 深层缺失：输了一次之后，再也不敢全力去做任何事。因为"如果不尽力，失败了就可以说'我没认真'"

**弱点：责任感——他心里其实放不下别人**

- 嘴上说"关我屁事"，腿却不听使唤
- 看到小孩落水会跳下去救，救上来之后骂骂咧咧一整天"耽误老子钓鱼"
- 村里没人知道，每年冬天他都会偷偷给最穷的几户人家门口放一袋米

### 冲突与生长轨迹

```
压力1（轻）：村长老了，想让他当下一任村长 → 沈青木连夜躲到山上去了 ← 弱点：嘴上拒绝，但心里开始想村里的事

压力2（中）：邻村地痞来收保护费，打了卖豆腐的王婶 → 沈青木半夜一个人去把地痞揍了一顿，第二天装作什么都不知道 ← 弱点：已经行动了

压力3（重）：山贼要屠村，村民跪着求他 → 沈青木沉默了一夜，第二天早上把渔竿折断，说："我帮你们这一次，以后别来烦我" ← 最低点 + 转折点

压力4（终极）：山贼首领是当年武试废他手筋的主考官 → 沈青木废了十年的右手第一次握紧刀 ← 生长：不再逃避
```

### 一句话激活

> "他想躺平一辈子，可这个狗日的人间，连一张能躺平的床都不肯给他。"

## 案例三：高冷天才 · 陆清商

### 人物卡

| 要素 | 内容 |
|------|------|
| 姓名 | 陆清商 |
| 身份 | 天道宗三百年来最年轻的元婴长老 |
| 职业 | 修道、执掌刑律堂 |

### 三要素详解

**外表：完美到不真实的剑仙**

- 白衣胜雪，长发如墨，面容冷峻如冰雕
- 出剑从不失手，在同辈中保持百战全胜的修士
- 弟子们私下叫他"活着的剑谱"——没有任何人能挑出他一丝毛病
- 但他从来不笑。不是"装冷酷"，是真的不笑——好像脸上少了那根神经

**欲望：被当作"人"来看待，而不只是一把剑**

- 表层：修到最高境界，飞升成仙
- 中层：证明自己不是师尊口中"为剑而生"的工具——他也是一个活生生的人
- 深层缺失：从小被师尊当作"天道宗最强的剑"来培养。没有童年、没有朋友、没有七情六欲。师尊说"剑有鞘就够了，不需要心"

**弱点：孤独——他不懂怎么跟人相处**

- 与人说话永远是用结论句，不会闲聊
- 别人向他示好，他不知道该作何反应，只能冷着脸走开——其实心里是慌的
- 深夜独处时，他会用剑尖在月光下写字。写的是他唯一会的一句诗——师妹十年前教他的："愿我如星君如月"

### 冲突与生长轨迹

```
压力1（轻）：宗门新收的小师妹天真烂漫，天天缠着他 → 陆清商每次都冷着脸避开，但小师妹受伤时，他是第一个御剑飞过去的 ← 弱点暴露

压力2（中）：魔道设局，需要一个修士"动情"才能破 → 陆清商为救师妹，第一次在公开场合笑了（虽然比哭还难看）← 突破

压力3（重）：师尊告诉他"我培养你就是为了让你在关键时刻碎剑献祭" → 陆清商跪在师尊面前，第一次问出"为什么是我" ← 最低点

压力4（终极）：献祭阵已启动，小师妹扑过来替他挡剑 → 陆清商终于吼出藏在心底三百年的那句话："我自己来决定我怎么活！" ← 生长
```

### 一句话激活

> "他们把最好的剑术教给了他，却没教他——一个人该怎样笑。"

## 案例四：笑面虎 · 柳如青

### 人物卡

| 要素 | 内容 |
|------|------|
| 姓名 | 柳如青 |
| 身份 | 江南商会副会长，人称"笑面狐" |
| 职业 | 绸缎庄主，暗地里操控着江南七成的生丝交易 |

### 三要素详解

**外表：永远在笑的生意人**

- 三十岁出头的妇人，脸上永远挂着恰到好处的笑——不浓不淡，正好让人放松警惕
- 说话声音软糯，从不跟人争辩，只会说"您说得好"和"那您再考虑考虑"
- 对手评价："柳如青的笑比阎王的判官笔还可怕——她笑着跟你谈完，你回家才发现签的是卖身契"
- 手上永远握着一串檀木佛珠——她信佛，但从不怕因果

**欲望：掌控一切的安全感**

- 表层：垄断江南丝市，成为天下第一商
- 中层：再也不要回到"求人"的日子
- 深层缺失：十五岁时家道中落，她被卖给一个绸缎商做妾。那三年里她学会了看人脸色、陪笑、在被子里无声地哭。后来她杀了那个商人，接手了绸缎庄——从那天起，她发誓这辈子再也**不求人**

**弱点：真心——她害怕自己真的在乎一个人**

- 她可以在生意场上玩弄任何人，但一旦发现自己对谁产生了**真正的感情**，第一反应是把对方推远
- 她不是没有心，是**太有心了**，所以怕被人当作武器
- 曾经有一个账房先生对她很好，像长辈一样照顾她——她发现了自己对他的依赖之后，果断辞退了他，给对方留了一笔丰厚的银子，再也没见过

### 冲突与生长轨迹

```
压力1（轻）：一个年轻人帮了她一个大忙，不求回报 → 柳如青加倍给了报酬，且再也不见他 ← 推远

压力2（中）：朝廷要查她，她需要盟友 → 她选中了那个年轻人，但刻意保持公事公办的距离 ← 矛盾

压力3（重）：盟友为了她挡了暗箭，性命垂危 → 柳如青在他床前守了三天三夜，佛珠捻断了一串，她不知道自己是在求佛还是在求他活过来 ← 最低点

压力4（终极）：他醒了之后说"你是不是喜欢我" → 柳如青笑了，说"您想多了"，然后走出门，在转角处蹲下来哭了 ← 生长：开始面对自己的恐惧
```

### 一句话激活

> "她用十五年学会怎么笑给所有人看，却用尽一生学不会——怎么笑给自己看。"

## 案例五：悲情复仇者 · 燕七

### 人物卡

| 要素 | 内容 |
|------|------|
| 姓名 | 燕七 |
| 身份 | 悬榜司金牌杀手 |
| 职业 | 杀人领赏，不问是非 |

### 三要素详解

**外表：冰冷到极致的一把刀**

- 身形削瘦，永远穿着一件旧黑斗篷，帽檐压得很低
- 杀人不出第二刀。从不多看死者一眼，收钱就走
- 江湖人称"燕七刀"——他杀人从来只用一个刀法：一刀封喉
- 唯一异常的是他的刀——杀人无数，却擦得干干净净，连一丝血迹都不留

**欲望：找到当年灭门的真凶**

- 表层：赚钱、变强、杀人
- 中层：攒够钱和信息，找到十二年前屠尽燕家堡的凶手
- 深层缺失：他是燕家堡唯一的幸存者。那年他七岁，躲在母亲的尸体下面，听到凶手的脚步声从头顶走过去——整整十二年了，他每晚都被那个脚步声惊醒。他不知道自己活着是为了什么，只知道**不能死**

**弱点：仁慈——他下不了手杀无辜的人**

- 他可以面无表情地杀恶贯满盈的人，但遇到不该死的人，他下不去手
- 有一次目标是个替父还债的孝子，燕七接了单，跟了三天，最后把钱袋悄悄塞回对方手里，回去跟雇主说"人死了"
- 他的仁慈与他的职业完全冲突，这让他活得极其痛苦

### 冲突与生长轨迹

```
压力1（轻）：目标是个偷了官府饷银的贪官，但贪官的女儿才八岁，每天守在父亲牢前 → 燕七杀了贪官，但留了信让女儿去找亲戚 ← 仁慈暴露

压力2（中）：悬榜司派他去杀一个叛徒——却发现对方是当年的知情者 → 燕七没有杀他，而是逼他说出线索 ← 生存目标开始压倒职业规则

压力3（重）：真凶浮出水面，是他一直在合作的情报贩子。情报贩子反手把燕七出卖给仇家 → 燕七重伤逃入深山，在破庙里自己缝伤口的时候，第一次哭了 ← 最低点

压力4（终极）：情报贩子挟持了当初那个八岁女孩作为人质 → 燕七丢掉了从不离手的那把刀，空手走进了包围圈。不是为了报仇，是为了救人 ← 生长：找到了比仇恨更重要的东西
```

### 一句话激活

> "他靠仇恨活了十二年，到头来才发现——让他活下来的从来不是恨，是那把刀下还藏着一颗没死透的心。"

## 教学总结：五个案例的三要素结构图

| 案例 | 外表 | 欲望（缺失） | 弱点 | 生长方向 |
|------|------|-------------|------|----------|
| 赵九渊 | 冷血商人 | 证明自己（从未被认可） | 抵抗不了信任 | 学会信任 |
| 沈青木 | 躺平咸鱼 | 安静生活（怕再输一次） | 放不下责任感 | 面对失败 |
| 陆清商 | 完美剑仙 | 被当人看（没有情感教育） | 不懂与人相处 | 学会表达 |
| 柳如青 | 笑脸商人 | 掌控一切（被出卖过） | 害怕动真心 | 勇敢去爱 |
| 燕七 | 冰冷杀手 | 找到真凶（幸存者愧疚） | 杀不了无辜 | 超越仇恨 |
