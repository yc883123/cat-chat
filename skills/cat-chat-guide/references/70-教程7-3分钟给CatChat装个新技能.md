# 3 分钟给 Cat Chat 装个新技能：Skill 是什么、怎么装、装完怎么用

> 目标：搞清 Skill 是什么，会自己装、会用、会固定。
> 前提：**教程 1 的 API 已配好**（教程 1 · 第一次对话）。

---

## 先记住一句话

**Agent 是岗位，Skill 是岗位手册。**

Agent 决定「它手里有哪些工具」（工具箱在会话开始时就锁定）；
Skill 是一份**行为指导文档**，告诉它做某类事该按什么流程走。同一个 Agent 换上不同 Skill，
干活的方式就变了。所以：**Skill 不是新工具，它教的是怎么用已有的工具。**

## 第 1 步：切到「Skill 助手 Agent」，直接说想干什么（约 20 秒）

顶栏 Agent 下拉里选 **「Skill 助手 Agent」🧩**，然后**别管术语，说人话就行**：

```text
我想按小红书的风格写文案。
```

## 第 2 步：它会先翻「已装清单」，告诉你有没有对口的（约 20 秒）

它会去你自己的 Skill 列表里找。**有对口的，就直接教你怎么用**——不用装。

> 不用记清单在哪：输入框里打一个 **`/`**，当前所有可用的 Skill 会直接弹出来。
> 顶栏那个 **「N Skill」** 按钮点开是同一份清单，还带搜索框。

## 第 3 步：没有就装一个（约 30 秒）

**开箱已经带了几个常用的**（比如「Cat Chat 使用指南」和「文案写作」），多数需求直接能用。
真的缺，再让 Skill 助手装——下面三种喂法都行：

| 你手里有什么 | 怎么做 |
|---|---|
| 一个链接 | 直接把链接发给它 |
| 一个 `.zip` 压缩包 | 拖进对话，或者用 **设置 → Skills 管理 → 导入 Skill** |
| 一个单独的 `.md` | 同上，选 **「选择 .zip / .md」** |

装完它会**主动给你演示一句触发语**（装完不会用，等于没装）。

## 第 4 步：怎么用——打 `/`，选它，说一句触发语

1. 在输入框打 **`/`**；
2. 在弹出的列表里**选中**那个 Skill（也可以在上面搜索框里打字过滤）；
3. 正常说你的需求——**一句话就够**。

它会在你输入的位置插入一个 `/技能名` 引用（长得像链接，别手动删）。

> 引用是**首轮注入、之后追加**到对话末尾的——这样对前缀缓存最友好，聊得越久越省。

## 第 5 步：让它常驻，以后不用每次打 `/`（约 20 秒）

如果某个 Agent 你**每次都配同一个 Skill**（比如导演 Agent 总是用短剧那套），把它固定下来：

**设置（左下角 ⚙）→ Agent → 选中那个 Agent → 编辑 → 「固定 Skill」标签页 → 勾上 → 保存。**

固定之后，这个 Agent **每次开口就自带这份手册**，不用再打 `/`。

> 「固定 Skill」标签页上的数字就是当前钉住的个数。内置的导演 Agent 出厂就钉了 3 个
> （短剧本地版 / 云端版 / RunningHub），所以它开箱就会拍片——就是这个机制在起作用。

## 常见问题

**Q：装好的 Skill 在哪看？**
A：三个地方：**输入框打 `/`**（最快）、**顶栏「N Skill」按钮**（带搜索）、**设置 → Skills 管理 → 已加载 Skill**（能导入和删除）。

**Q：能删吗？**
A：能。**设置 → Skills 管理**里删除，有两条路：**删除（移到回收目录，可恢复）** 和 **彻底删除（不可恢复）**。不确定就选前者。

**Q：每次都要打 `/` 吗？**
A：不用。参照第 5 步把它**固定**到某个 Agent 上，之后自动带上。

**Q：装的 Skill 不好用，能改吗？**
A：能。直接跟 **Skill 助手 Agent** 说「把 XX Skill 的某段改成……」，它会先告诉你**要改哪几个文件、改什么**，你同意再动手。
