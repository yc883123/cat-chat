# 织书台设定单步重跑计划（2026-11-21）

状态：**已拍板方向，待实施**。本文档只写计划，代码未动。

## 1. 背景

讨论结论（2026-11-21）：

- 设定五步（题材→书名→简介→世界观→角色）每步落一版，五版是**累积快照**——旧版内容全部包含在最终版里，纯过程记录，回退真正靠的是"本次生成之前"的基线版。大纲每部一版同理。
- 正文每稿一版是必要的（整段换血，旧稿不存就真丢），与设定不同。
- 改某一步只能整套重跑（`setup_all` 五步全跑），多花四步请求、又冒 5 版。

**用户拍板（方向二）**：表单分组不重排，在「生成整套设定」组里加一排单步按钮；点按钮先弹**输入预览**；世界观/角色被覆盖的风险靠**左侧设定版本列表兜底**（不建新确认链）。

## 2. 现状事实（已核实，带行号）

### 后端两条链路已全通，本次预计零后端改动

1. **发起单步流水线**：`POST /api/writer/books/{id}/pipelines` 已透传 `body.step`（`naiba/writer/service.py:421`）；`start_pipeline` 接受 `kind="setup_step"` + `step∈{genre,title,blurb,world,chars}`（`naiba/writer/pipeline.py:179-182`）。单步快照/重试/失败恢复与 `setup_all` 同机制。
2. **单步输入预览**：`POST /api/writer/generate/preview` 里 `step = kind if kind in prompts.SETUP_STEPS`（`naiba/writer/service.py:381`）——`kind` 直接传五步之一即可拿到该步的提示词正文、system、预算（content/budget/slots）。

### 前端现有机制（复用）

- `submitPipeline(kind, opts)`（`public/js/27-writer.js:2466`）：完整发起链路——busy/并发闸门、`writer.setupDirty` 时先自动存一版（:2507）、`gateByBudget` 预算门槛、body 组装。本次 body 需加 `step` 字段（service 层已认）。
- `refreshPlan()`（`27-writer.js:1726`）：已在调 `/api/writer/generate/preview`，setup 阶段固定 `kind="genre"` 只预览第一步。单步预览直接把 kind 换成目标步。
- 各步提示词素材（`naiba/writer/prompts.py:468-500`）：所有步都带【创作提示词】（idea 文本）；world/chars 额外带世界观摘要；chars 额外带角色清单；`extra_note`（补充要求）**所有步都追加**。
- 五步写回行为（`naiba/writer/pipeline.py:1414-1442`）：每步只替换自己的字段、其余保留（genre 替换题材四项+基调+标签；title 写 `title_candidates` 且仅在手动或当前书名为空时改书名本身；blurb 同理；world 替换世界观；chars 替换角色列表）。
- 跑完刷新：现有 pipeline 轮询已有，完成后设定表单自动刷新——单步复用。

## 3. 改动清单

### 3.1 `public/index.html`——入口（「生成整套设定」组内）

在 `#writerSetupGenerate` 按钮所在 action-bar 上方（或同一行内）加一排五个小按钮：

```
单步重跑：[题材] [书名] [简介] [世界观] [角色]
```

- 样式沿用 `control-button tiny`；窄屏允许换行（不横滚——素材格横滚改法在造梦机被否过，口径一致）。
- 组标题 small 文案补一句"也可以只重跑其中一步"。

### 3.2 `public/js/27-writer.js`——弹层 + 发起 + 滚动

1. **弹层**（点单步按钮后、发起前）：
   - 内容（大白话，不露 JSON/内部词）：
     - 标题：`重跑「世界观设定」`（步名用 `STEP_LABELS`，`27-writer.js:114-118` 已有中文映射）；
     - 「会带上」：创作提示词（X 字）+ 该步的附加素材行（世界观摘要/角色清单，按 `prompts` 实际拼接显示与否）+ 补充要求（若填了）；
     - 「会改动」：只替换 X，其他不动（替换字段表见 §4）；
     - 覆盖提醒（world/chars 步）：`跑完会顶掉现在的世界观。想留底的话先看一眼左侧「设定版本」——现在的内容已经在里面存着，不满意随时切回。`
     - 模型行：当前选中的供应商/模型；
     - 按钮：取消 / 开始重跑。
   - **挂载必须进 dialog/top layer**（弹窗挂 body 会被 `showModal` 盖住——造梦机弹窗的教训）。实施时先看织书台现有确认弹窗（拆章确认链）怎么挂，照抄同构。
2. **发起**：确认后走 `submitPipeline("setup_step", { step, ... })`，body 加 `step` 字段；模型取 setup 阶段字段（`setupProviderKey/setupModelName`），预算门槛 `gateByBudget` 照走。
3. **预览数据**：弹层里的字数/素材来自 `/api/writer/generate/preview`（kind=该步，模型先按当前选择取，取消则不发起）。
4. **跑完滚动**：单步链终态后滚到对应字段（title→`#writerTitle`，blurb→`#writerBlurb`，world→`#writerWorldview`，chars→`#writerCharList`，genre→`#writerGenrePicker`）。

### 3.3 样式（`public/css` 相应文件）

单步按钮排的间距/换行样式；弹层复用现有 dialog 结构则零新增。
