## 一、目标与验收

从已拆好的作品出发，生成两类成果：

1. **要素**：人物 / 场景 / 道具（影视化拆解用）。
2. **改编大纲**：三幕结构（建置 / 对抗 / 结局）。

### 验收标准

| # | 标准 |
|---|---|
| 1 | 阶段一作品的任意章节可勾选后生成要素与大纲，结果可编辑并写回作品 |
| 2 | **创作场任务不混进模块库历史**，模块库历史也看不到创作场任务（各管各的） |
| 3 | 历史列表「来源」列显示「创作场」，不再恒为「来源未记录」 |
| 4 | 长素材按分章节 + 分槽上限送入，超限**明示提示**，不静默截断 |
| 5 | 多章生成时带**近 3 章摘要链**，跨章一致性可人工判读 |
| 6 | 任务可取消 / 可重试；重进工作台按服务端状态校准，无重复定时器 |
| 7 | 回归绿：全量单测、`verify/studio_ui_smoke.cjs`、`verify/topbar_smoke.cjs` |

## 三、必须先修的既有 bug（P0）

`module` / `origin_label` 只写在任务 `input` 里，runner 从不提升到顶层，而列表接口 slim 从顶层取 ⇒ 历史列表「来源」恒为「来源未记录」。

| 事实 | 位置 |
|---|---|
| 字段只落在 input | `naiba/studio/service.py:197-212`（input_data） |
| 落库记录顶层没有这两字段 | `naiba/studio/store.py:69-95` |
| runner 只更新 status/result 等 | `naiba/studio/runner.py:159`、`:279-283` |
| 列表 slim 从顶层取 → 恒空 | `naiba/studio/service.py:315-325` |
| 前端 `taskOrigin()` 因此落到「来源未记录」 | `public/js/22-studio.js:1683-1691` |

修法：`api_tasks()` 的 slim 从 `row["input"]` 提升 `module` / `origin_label` 到顶层输出。**不往 `MODULE_TABS`（`22-studio.js:15`）加 `novel`**——它是分类导航数据源，加进去会在模块库多一个空分类。

## 四、任务复用与分区

### 4.1 提交契约（沿用现有结构，不新建任务表）

调 `StudioJobManager.submit(input_data)`（`naiba/studio/jobs.py:70`），字段沿用 `service.py:197-212`：

| 字段 | 小说侧取值 |
|---|---|
| `content` | 阶段内置 prompt + 选中章节正文（经分槽截断）+ 摘要链 + 用户补充 |
| `model_key` / `model_name` | 复用模型配置与模型选择 |
| `title` | `《书名》· 要素` / `《书名》· 改编大纲` |
| `module` | `"novel"` |
| `origin_label` | `"创作场"`（必填，否则历史来源显示不出来） |
| `novel`（新增） | `{book_id, stage, chapter_ids}`；input 是自由 dict，Store 不强校验，retry 原样带回 |

### 4.2 分区（各模块管各模块的）

| 层 | 改动 |
|---|---|
| `StudioStore.list_tasks()`（`:223`） | 新增 `module` / `exclude_module`，读 `input.module`；**先过滤后 limit** ⇒ 每模块各 60 条，互不挤占 |
| `StudioJobManager.tasks()`（`:54`） | 透传两个参数 |
| `StudioService.api_tasks()`（`:315`） | 接受参数 + 提升字段（§三） |
| HTTP `naiba/http.py:573` | `?module=novel` 或 `?exclude_module=novel`；不传参保持现有全量行为 |
| 前端模块库 | 请求 `?exclude_module=novel` |
| 前端创作场页 | 请求 `?module=novel` |
| 侧栏「历史产出」 | 按当前分页取对应分区，不混排 |

## 五、长文策略（照启元实证）

取证自 `nv_main.js`（启元小说项目前端）：

| 做法 | 取证位置 | 本侧取值 |
|---|---|---|
| 章节级调用，全书永不进 prompt | 1548-1568 | 一次只带勾选章节，默认 1 章 |
| 参考素材硬上限 | 1551 `text.slice(0,3000)` | 正文槽 3000 字 |
| 分槽限额 | 2412-2417（「≤4000 token」，worldview 1200 / chars 800） | 要素槽 800、大纲槽 1200 |
| **滚动摘要链** | 2569-2589（近 3 章「首 120 字 + 尾 220 字」，零额外推理） | 每章产出后落 `summaries[章号]`，后续调用带前 3 章 |
| 截断绝不静默 | 3458 / 3476 / 3510 | 超限时提示超了多少、建议减到几章，**不静默截断** |

阈值集中在 `naiba/novel/prompts.py` 一处定义，不散落。
