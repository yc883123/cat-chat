# 任务总管配方预设实施与验收

日期：2026-11-02
状态：实施中；下列清单不是完成声明。

## 本轮执行口径

用户已要求执行《任务总管配方预设与造梦机执行计划》，并指定固定工作流先采用 ComfyUI 官方 MiniMax H3 图生视频、参考生视频两类；提示词参考 shortdrama 与 H3 prompt writing。

- 两个固定配方共用有界清单和原生执行适配；一个素材项目对应一次反推和一个造梦机任务，默认串行。
- 图片/片段内容由用户准备，不自动新增剧情创作、分镜拆分或聊天规划轮次。
- 图生视频首帧与参考生视频身份/场景参考是不同角色；参考图片连续编号，首期最多六张，不假装支持未接入的音频/视频参考。
- 先确认反推，保存并审核提示词，再确认准确的生成快照。修改未执行输入需重新确认；仅保存不执行。
- 自定义配方从造梦机当前工作流显式选择文本和媒体槽位，保存受校验的快照，不覆盖原稿或库内原件。
- 不新增总管长期默认模型设置；本任务显式选择且固定反推供应商/模型，凭据仍全局维护。
- 自动化仅使用本地假模型、假 ComfyUI、临时数据；真实供应商/付费生成、提交、推送、发布均未授权且不执行。
- 不启动 Super Agent V2，不增加任意 DAG、无限画布、持续监听或定时触发。

### 已取得证据（不包含真实 H3 推理）

- 官方目录：实际源文件哈希、MIT 许可、子图父值覆盖、连线与连续引用裁剪测试通过；转换器可离线复现，固定资产与提示词哈希在 `recipe_assets/provenance.json`。
- 配方核心：`tests/test_super_agent_recipes.py` 覆盖 owner、并发确认、同键重放、跨存储响应丢失、重启等待继续、迟到结果、源文件变化/快照损坏、配置漂移、精确绑定、自定义结果歧义、真实派生图确认及补收集；审计后 29 项通过。
- 原生执行：`tests/test_native_recipe_submission.py` 覆盖原生持久防重、未知提交不重提、远端取消失败保持 pending_remote、取消作用域、下载描述符恢复、多次生成的待生成剩余项、损坏产物、精确种子和原文来源；审计后 27 项通过。
- 原文回调：`tests/test_recipe_raw_content.py` 覆盖实际 ModelRuntime 的流式/非流式请求格式、失败重试 reset、空正文、原始空白与 `</think>` 前缀、排除独立 reasoning。使用可选 `raw_content_sink`，无此选项的既有路径保持原行为。
- 隔离真实原生 HTTP：`tests/test_recipe_ui_fixture.py` 保留真实 Studio/ModelRuntime/ComfyUI runner，仅把外部服务替换为 loopback；9 项通过。默认使用本地 ffmpeg 合成 1 秒、160×120 H.264/AAC MP4，真实 HTTP 收集并解码；另保留 PNG 模式。
- 浏览器桌面：确认 R2V 两道确认、逐项派生图/实际媒体绑定、原生执行关联、结果和刷新保持；发现的重复项目卡与错误下一步提示已修复并重新观察。
- 浏览器 375px：创建表单 clientWidth/scrollWidth 均为 365，无横向溢出；反推与生成审核可打开，编辑在轮询后仍保留，并通过 HTTP 读回验证保存。R2V 注入第一项下载失败，页面显示部分失败且只提供该项补收集；补收集后全部完成。

### 仍未通过或未覆盖的验收项

1. 当前可用浏览器后端不支持系统文件选择上传。没有绕过或伪造上传成功；实际桌面/手机“选择本地文件/目录 → 导入 → 创建批次”的完整 GUI 路径仍缺验证。HTTP 夹具种子和清单测试不能替代此项。
2. 没有做真实供应商反推或真实 ComfyUI H3 GPU 推理，官方图已离线验证，执行前有 live object_info 门禁；本地根据图构造的假 schema 不是实际安装兼容证据。
3. 音视频产物在生产收集器中做容器基本结构检查，图片做完整解码；没有承诺对每个生产视频全量解码或质量审查。
4. 自定义配方只开放数值/布尔额外覆盖；改过但不支持的字符串/枚举字段明确拒绝，不静默恢复原值。需要先保存为新工作流再交接。生成后改稿要求新建批次，不覆盖已执行事实。
5. 尚未运行 PyInstaller 打包；spec 已登记固定模板/提示词/许可资产，但源码验证不等于打包运行验收。

因此本轮不能仅凭单测或此表宣称原计划全部验收完成。
