# 瑶光（Z-image）提示词引擎

基于 `references/瑶光提示词模板_v5.0.md`（约 440 行）生成全中文人像提示词，供 Kook_Zimage_瑶光 工作流出图。

## 与 anima/K2 引擎的区别

- **全中文自然语言**输出，禁止英文 tag 式质量词（masterpiece/best quality/8k 堆标签写法）
- 无外部质量词/画师拼接：模板自带氛围词收尾（规则 9）
- 瑶光是质感提升型 LoRA，**肤质词是点火器**（冷白皮 / 瓷感白肌肤 / 皮肤白皙透亮），缺了出图即底座软图

## 三分支选择

| 用户语境 | 分支 | 长度 |
|---|---|---|
| 摄影/写真/杂志/商业/影棚/8K/镜头 | A 摄影写真 | 150-350 字 |
| 摄影 + 单一场景 + 故事感 | A 叙事长句型 | 400-500 字 |
| 国风/水墨/厚涂/梦幻/仙/艺术 | B 艺术创作 | 150-350 字 |
| 华丽/盛世/神性/怪诞/堆叠 | B 华丽堆叠 | 350-500 字 |
| 日常/随拍/快照/自拍/CCD/生活感 | C 日常快照（电报式 50-150 / 呈现画面式 180-230） | 见左 |
| 不明确 | A 摄影写真 | 150-350 字 |

## 使用流程

1. 完整读取 `references/瑶光提示词模板_v5.0.md` 全文（一次读完，禁止只读摘要）。
2. 按模板"使用说明"：判断分支 → 选开头句式（禁止跨分支：A 电报/具备，B 营造或 `亚洲，真人，`，C 呈现画面式/电报式二选一）→ 按分支公式或 C 类三层架构组装 → 从词库取词（拿不准用"随机款/随机组合"）。
3. 九条规则全执行：复沓加权（核心词 2-3 次）、赞美词撒前段、真人+画意混搭（B 必带 `亚洲，真人，`）、声明位置灵活、糙感许可（B/C 电报）、锐度锚点（A/C 必带对焦+细节锚点）、光链三段+前景小物件（A/C）、具体事实优先（写成因不写结论）、氛围词收尾（禁止柔化指令结尾）。
4. C 类用"生成后五问"自检（开瓶器/角色锚、肤质词、光链三站、面部占比≥40%、柔化≤2、尾部氛围词）；A/B 类逐条过通用规则。
5. 输出一整段连贯中文文本，不加编号/分段标题。

## 工作流绑定

- 目标工作流：`Kook_Zimage_瑶光.json`（comfyui-control `bindings "Kook_Zimage_瑶光.json"` 查默认参数）
- 模型：z_image_bf16 底模 + Kook_Zimage_瑶光 lora + 8 步蒸馏 lora；正面提示词填节点 24，负面填节点 16
- 注意：该工作流输出是 PreviewImage（temp），无 SaveImage；产出图在 history 里取
