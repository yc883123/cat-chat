# 2D打戏手法：何时用、怎样出现、何时退出

这是导演选择库。下面是结合一手访谈、教学与本任务要求形成的制作建议，不是特定模型保证，也不是必须全部使用的清单。

每个主要Cut先确定观看目的，再选互相支持的手法。为选中手法写清：**触发事件 → 作用对象及可见变化 → 恢复／承接**。电影级张力来自动作、造型、镜头和节奏共同成立，不按特效种类或数量计分。

**必须落地到剧本和视频验收**：每段至少挑出真正服务该段事件的手法，写出观众能看见的身体变化、背景变化或运镜轨迹；成片要核对它是否出现。整场应有动作驱动的尺度、角度、视差或节奏变化。固定机位可以用于有意的角色反差、冲击停顿或结果展示，不能成为整段打斗里双方轮流挥招的默认机位。若成片只有无意义的双人固定镜头，应重做动作与摄影设计，而不是继续堆特效名词。

## 作画与运动

| 手法 | 适用及可见设计 | 限制／退出 |
| --- | --- | --- |
| 关键姿态、动作线、压缩—伸展 | 启动、猛转、发力；轮廓先收束，身体重心带动伸展，作用力穿过支撑与攻击端 | 压缩可以极短，不增加漫长蓄力；不同角色保留各自身体语法 |
| Timing／Spacing（时间与运动间距） | 突进、投掷、连击；短时间跨越大距离，接触附近短暂集中信息，结果迅速释放 | 均匀中间姿态会显得漂浮；真实速度需视频验证 |
| Smear／オバケ（过渡抹形） | 两个差异大的高速姿态之间，沿路径拉长、弯折或合并局部轮廓 | 不是柔焦或永久橡胶肢体；接续姿态恢复结构，不把整张模糊图当主体设定 |
| Multiples（复数像） | 快速摆动、轮转；少量阶段轮廓表达同一肢体的轨迹 | 会增加生图多肢风险，按需要使用；实体身体只有一个，不能增加攻击次数 |
| 大小／透视夸张 | 角色冲近、拳脚掠镜、俯冲；近端轮廓迅速扩张，远端缩短 | 变化须来自运动或观看角度；不是无因巨手；命中和结果恢复稳定归属 |
| Follow-through／Overlap／Drag | 连击接力、急停、击飞；躯干已转，拳或衣摆仍保留上一方向，再被带动 | 身体接力优先，披风摆动不能证明主体高速；不让所有部件同时启动停止 |
| 短时离模与作画省略 | 超高速衔接可简化脸和细机械线，以剪影承载速度 | 身份锚点在读点恢复；不把正常动作全程画成崩坏 |
| 掠过后的过冲／回收 | 重挥、落空、格挡反弹；上一股惯性直接进入下一拍 | 按碰撞阻力处理，不要求拳头穿过实体受击面后再回弹 |

## 冲击与短时演出

| 手法 | 何时／画什么 | 何时不该用 |
| --- | --- | --- |
| Impact frame（冲击帧） | 决定性接触／能量释放瞬间，以黑白、反色、粗轮廓或图形化剪影强调力线 | 不是每拳闪白；不是额外事件；图案不能抹掉整段因果，立即回到正常状态 |
| Hit-stop（接触瞬时停顿） | 一个值得强调的接触峰值，让力量蓄住再释放；明确结束在受力离开时 | 不能逐拳冻结或填满时长；与冲击帧、一般止め镜头不是同义词，默认允许完全不使用 |
| 色彩替换／背光剪影 | 爆发或险距处暂时减少信息，只留下主体剪影和攻击轮廓 | 属于短时表现而非永久换色，保持角色位置；不能制造人体命中火星来强调纯闪避 |
| 流背／抽象背景 | 高速飞行、拳路掠过时背景收束成有方向的线面，主体动作仍清楚 | 运动前后需可辨地理，不能用整段流背隐去路线错误 |
| 局部画面形变 | 巨力或爆压瞬间让边缘构图压缩、拉开，视觉中心跟随力线 | 暂时的观看夸张，不把地面真实扭成新场景；不全程鱼眼 |
| Harmony／绘画式止め | 情绪高潮、结束纪念性构图时的绘画化停帧 | 本用户高速打戏默认不选；不能拿海报静帧替代高潮动作 |
| 选择性主观时间 | 只有辨认、意识或决定性瞬间确实需要时才考虑，写明恢复高速的事件 | 用户没有要求时不把“电影级”理解为自动慢放；普通出拳、歪头、击飞禁用慢速展示 |

冲击帧可极短，教学中的单帧／少量帧仅说明时域尺度；不承诺H3逐帧控制。短暂静态表现画面须与前后动作相连，不能因此把整段视频拉长成停顿。

## 特效作画与摄影合成

| 手法 | 用途及运动组织 | 避免 |
| --- | --- | --- |
| 手绘爆焰／烟团 | 已有爆破：亮核展开，外层火舌破碎，烟团滚卷遮挡，随后露出结果 | 圆形光球贴图、无来源烟墙；烟应有体积与演变，不只有粒子数量 |
| 岩块／几何碎片 | 已有撞击：接触处裂开、块体剥离、前景大块穿出、后层尘团滞后 | 为“燃”新增破坏；同尺度碎石均匀撒满；并非所有大块都先于小块落地 |
| 光束／射线 | 源—路径—目标／落空—关闭完整；亮核、外晕和反光各有职责 | 从头画到尾缓慢长出；多条不相连光线；停火前角色回到射线内 |
| 刀光／弧带 | 有武器的快速挥动、旋转；轨迹附着刃路，结束后消散 | 脱离武器独立命中；亮带遮住格挡关系 |
| 冲击环／空气扰动 | 原力量规模支持时表现爆压传播，环随空间透视改变 | 普通肉拳必有魔法光环；拿环替代实际受力 |
| 残留光／动态受光／热扰动 | 能量从身旁经过，亮侧随着源移动；热扰动仅在热路径附近 | 每格同样描边发光；光源熄灭但受光不变 |
| 衣发、地尘、落屑延迟 | 急停、近失、冲击后说明惯性和风压，必要时连接下一Cut | 提前反馈、逆向风、过度延迟造成拖时；披风位置需避开仍在持续的光束 |

## 摄影与剪辑

| 手法 | 观看功能与设计 | 连续性条件 |
| --- | --- | --- |
| 侧向／纵深跟拍 | 保留行动中的关系；前景划过更快、远景变化较小，形成层次 | 有空间纵深才能声称视差；静帧只提供布局，运动交给H3 |
| 主体超越摄影机 | 摄影先跟住，角色突增速度越过近前景，摄影落后再追上 | 出画方向、下一镜目标和运动轴接得上 |
| 甩镜／鞭摇 | 由来袭转向目标或落点，过渡方向性扫掠，迅速落稳新观看关系 | 主体动作仍高速，甩镜不能掩盖落点缺失；不连续乱甩 |
| 贴身广角／近物掠镜 | 拳脚、肩背冲过画面边缘，迫近感和尺度变化 | 保留施动者与目标依据，不强求每格两人全身 |
| 背景动画／空间旋转 | 沿身体绕转或追逐转弯，背景体积随视点变化，增强空间穿行 | 不只是旋转整张图；高负荷场面优先短路径，给重建方向的落点 |
| 遮挡接力 | 身体、武器或真实尘团充满前景，运动方向把视线带到下一构图 | 遮挡是观看过渡，不授权人物瞬移、偷换装备或吞掉关键接触 |
| 动作匹配切镜 | 在力量仍持续时切至新的尺度，继续同一动作的后半段 | 攻击次数不增加；关节、动势与世界状态匹配，不强制逐像素复制 |
| 近—远尺度揭示 | 近处压力后展开受击飞行或环境尺度 | 拉远须带来信息；不把同一近失无意义重放两遍 |
| 定机位对比 | 强者从容、小幅躲避，对手／威胁高速穿过稳定构图 | 定机位不等于慢动作，也不等于全段无运动 |
| 定向后坐／短震动 | 撞击作用于观看者，沿主受力方向一次压缩／偏移后回稳 | 不是持续随机手持抖动，不覆盖每一拳 |

## 按动作选择组合

- **近失、强者从容**：稳定姿态对照 + 袭来物大间距／掠镜 + 清楚的近失关系 + 稍晚环境反馈。主角不需要大幅形变；冲击帧可不用。
- **连续贴身进攻**：短路径身体接力 + 一处高速过渡抹形 + 跟拍／前景遮挡 + 主次接触力度差。中间拳无需每次hit-stop。
- **重击击飞**：发力和受力姿态反差 + 一个决定性强调 + 运动匹配切至飞行尺度 + 撞点与延迟碎裂。若拳和撞墙都有峰值，明确后者更强。
- **刀剑交锋**：刃路与握法 + 短弧拖影 + 材质接触反馈 + 由反作用进入下一招。纯挥空无接触火星。
- **炮击／大型能量**：触发与反光 + 迅速贯通路线 + 险距／阻挡结果 + 停火与消散。避免把武器变形拍成慢速展示。
- **空战／追逐**：来向与目标空间 + 身体／摄影机相对速度差 + 背景转向／视差 + 合理的转向支点或已知能力。

以上组合仅是选型起点。复杂追逐可能无需冲击帧，克制的近失也能成为高潮。交付时说清所选组合为什么服务这一段。
