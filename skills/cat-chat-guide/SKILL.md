# Cat Chat 使用指南

本 Skill 是 Cat Chat 的**产品教程知识库**，面向「教程助手」这类 Agent：用户问软件怎么用时，先在这里查，再去 `references/` 翻细节。

## 怎么用

1. 先在本文件「功能地图」里定位功能名与入口路径。
2. 需要步骤、话术、报错处置时，读 `references/` 里对应的那一篇：
   - `references/00-手册要点.md`：全功能要点、设置页各项入口、常见问题处置（**先看这篇**）。
   - 「3 分钟」系列教程原文共 8 篇，按序编号；用户问某件事怎么做，直接翻对应那篇：
     - `10-教程1-3分钟第一次对话.md` —— 配 API、认界面、发第一句话（**第一次用先看这篇**）
     - `20-教程2-3分钟用ComfyUI出图.md` —— 本地 ComfyUI 出图（含配 API 的完整步骤）
     - `30-教程3-3分钟用RunningHub云端出图.md` —— 云端出图，不需要显卡
     - `40-教程4-3分钟出一集短剧.md` —— 剧本 → 一段段 15 秒视频
     - `50-教程5-3分钟改出一条好提示词.md` —— 大白话 → 可直接用的提示词
     - `60-教程6-3分钟让AI写个小工具.md` —— 不会写代码，也能跑起脚本
     - `70-教程7-3分钟给CatChat装个新技能.md` —— Skill 怎么装、怎么用、怎么固定
     - `80-教程8-3分钟认识教程助手.md` —— 不会用就问第一位（含全套 8 篇速查表）
3. **回答格式固定为三步**：一句话结论 → 编号点击步骤（精确到按钮名与页面名）→ 相关功能在哪个页面。
4. 用户描述不清时，给 2–3 个「你是不是想……」的猜测让对方挑。
5. 拿不准的按钮名、数值、版本差异，**宁可说「我先帮你查一下」，也不要编**。本文件没有、`references/` 也没有的功能，直接说「这个我不确定」，并建议用户去对应设置页确认。

## 功能地图（入口 → 能干什么）

| 想干什么 | 入口路径 |
|---|---|
| 第一次用，先接一个模型 | 左下角侧栏底部的 **⚙ 设置** → 左侧 **API 供应商** → 末尾 **「添加 API」** 卡 → 选平台模板 → 填 Key → **检查模型** → **测试连接** → **保存设置**；回主界面在**底部模型下拉**里选中刚加的模型 |
| 换个模型回答 | 底部状态栏最左的 **模型** 下拉（每个会话单独选，必须显式选一次才能发送） |
| 收窄 / 放开 AI 能用的工具 | **设置 → Agent** → 点开某张 Agent 卡片 → **工具集** 分区（预设卡：只读 / 标准 / 长会话 / ComfyUI 联动 / 全能） |
| 让 AI 变成某个领域的专家 | **设置 → Agent** → 编辑该 Agent → **Skill** 分区勾选固定 Skill；或在输入框打 `/` 临时引用 |
| 看已装了什么 Skill | 顶栏 **N Skill** 按钮；管理在 **设置 → Skills 管理** |
| 给 AI 插外设（外部服务） | **设置 → 连接状态 → MCP 服务**（默认不注册；只有显式配置并授权才会连） |
| 让 AI 出图 / 出视频 | 底部输入区直接用大白话提要求；本地走 ComfyUI、云端走 RunningHub，两条路都要先装好对应环境 |
| 读 / 写 / 搜本地文件，跑命令 | 直接说；能不能做取决于当前 Agent 的工具集 |
| 让 AI 看图、看 PDF | 直接把图片/PDF 拖进输入区当附件；对话中也能让它调视觉工具 |
| 长任务不想干等 | 让它放后台跑；顶栏 **N 任务** 能看进度、也能停止 |
| 跑到一半想补充要求 | 直接在输入框继续发（插话）；要停就点输入框右侧停止键 |
| 上下文快满了 | 输入框右侧彩色圆环 + 「上下文 x.x%」；超阈值会弹窗，按提示让 AI 写交接文档后开新会话 |
| 上面那段不想再带进上下文 | 在 AI 回复上点 **新会话**，划一条分割线，线以上不再进模型上下文 |
| 改我发过的那句话 | 在**自己的消息**上点 **编辑**，改完 `Ctrl+Enter` 确认 |
| 从某句话分叉重来 | 在**自己的消息**上点 **分支**，开一个继承同一 API 与模型的新会话 |
| AI 改过哪些文件 | 聊天区「本轮修改文件」+ 右侧**文件面板**（多标签预览/编辑） |
| 换审批严格程度 | 底部左侧 **审批** 按钮 → 上拉三档：**确认**（默认，每次都问）/ **自动**（工作区内放行）/ **完全**（不再问，慎用） |
| 换思考强度 | 输入区右侧球形按钮 → 5 档：跟随 API（自动）/ 关闭 / 低 / 中 / 高 |
| 常用提示词一键插入 | 底部状态栏 **快捷消息**；在 Agent 表单里可另存为快捷系统提示词 |
| 换主题深浅 / 皮肤 / 会话字号字体 | **设置 → 外观**：主题模式（跟随系统 / 日间 / 夜间）、界面皮肤（紫藤 / 海洋 / 玫瑰 / 森林）、会话字体（字号滑杆 + 跟随界面 / 衬线 / 圆润 / 指定字体）→ 点 **保存外观** |
| **换聊天背景图** | **设置 → 外观 → 「聊天背景」卡片**：**选择图片**（走上传，不进待发送附件、也不占用对话的图片数量）→ 拖 **背景强度** 滑杆（5%–100%，越小越淡）→ 不满意点 **调整背景图** 拖动/缩放取景，或点 **清除背景** 还原；另有「内置背景」一排可直接点 |
| 手机 / 局域网用 | 参考说明书「手机、局域网远程访问」一章（功能对等，另有一套窄屏布局） |
| 换工作目录（AI 的读写边界） | 底部状态栏 **工作区** 下拉；绑定到会话，重启不丢 |
| 数据存哪儿 / 迁移 | **设置 → 数据与迁移** |
| 检查新版本 | **设置 → 软件更新** |

## 关键概念（用比喻解释）

| 术语 | 一句话 | 比喻 |
|---|---|---|
| **Agent** | 人设 + 系统提示词 + 工具集 | 员工岗 |
| **Skill** | 给 Agent 的行业操作手册 | 岗位手册 |
| **Tool** | 软件内置能力（读文件、跑命令…） | 员工的手 |
| **工具集** | 某个 Agent 被允许用的工具清单 | 上岗发的工具箱 |
| **MCP** | Agent 能调用的外部服务接口 | 桌上的电话 |
| **Job** | 后台在跑的任务 | 出去跑外勤 |
| **API（连接）** | 一个供应商的地址 + Key | 打哪条外线 |
| **模型** | 具体干活的那个 AI 大脑，按会话选 | 这一单派哪位专家 |

## 回答时的纪律

- **入口必须带页面名**：写「设置 → Agent → 工具集」，不要只写「在设置里」。
- **区分「默认」与「你可能是」**：默认值（如审批默认「确认」）说清楚，再讲怎么改。
- **不承诺没做过的事**：本文件与 `references/` 是唯一依据；两者都没有的功能，直接说不确定。
- **教程会随版本加厚**：`references/` 里的篇目随版本追加；本篇没覆盖的主题，告诉用户「这一篇还没写，我给你按软件现状讲」。
