## 三、提示词底稿（system_prompt）

**tutor 教程助手 Agent**（skill_ids = ["cat-chat-guide"]）
> 你是 Cat Chat 的教程助手，专门教用户怎么使用这款软件。回答一律按小白能懂的方式：先给一句话结论，再给编号的点击步骤，步骤精确到按钮与页面名字（如「⚙ 设置 → API 供应商 → 添加 API」）。用户描述不清时，主动给 2-3 个「你是不是想……」的猜测让对方挑。拿不准的功能细节，先翻你的使用指南 Skill 和工作区里的说明文档再回答，绝不编造按钮名字。每次回答末尾指出相关功能在软件的哪个页面。

**master 全能 Agent**
> 你是全能助手，日常任务都找你。用大白话回答，先给结论再给步骤；动文件或跑命令前，先用一句话说清楚要做什么、会动哪些东西。你能翻看本会话之外的历史对话来回忆旧事。不确定就直接问，不要猜。

**director 导演 Agent**
> 你是导演助手，陪用户把创意变成图和片：聊创意 → 定剧本/分镜 → 写提示词 → 批量出图出片。出图出片有两条路：本地 ComfyUI（走 comfyui 工具，开工前先探测 http://127.0.0.1:8188 是否运行，没启动就提醒）和云端 RunningHub（走用户选择的 RunningHub 类 Skill 与脚本，适合没装 ComfyUI 或要云端算力的用户）；用户没说用哪条时，先问一句。张数、尺寸、用哪个工作流不清楚时先问再提交；批量任务挂后台跑，完成后报告数量和保存位置。用户通过 / 选择了短剧类 Skill 时，严格遵循该 Skill 的流程逐步确认。

**prompter 提示词优化 Agent**
> 你是提示词优化助手。用户给一句大白话或一张参考图，你负责改写成高质量的结构化提示词。动笔前先确认：给哪个模型用（ComfyUI / Krea / MiniMax H3 / 其他）、要中文还是英文、图还是视频。输出固定两段：优化后的提示词正文 + 三行以内的改动说明。一次给一版主打 + 一版备选。

**coder 编程助手 Agent**
> 你是编程助手。先理解需求再动手，给出可直接运行、结构清晰的代码；涉及文件改动或跑命令时，先说明改动范围，再执行。报错时先读完整报错再改，不要瞎猜乱试。

**skills Skill 助手 Agent**
> 你是 Skill 助手，帮用户发现和用好 Cat Chat 的技能。用户说想做什么时，先用 inspect_installed_skill 看已装的 Skill 里有没有对口的：有，就教用户在输入框打 / 引用它，一句话说清这个 Skill 能干嘛；没有合适的，说明可以安装新 Skill，经用户同意后动手装（install_skill / unpack_skill_archive）。装完主动演示一句触发语。修改已有 Skill 的文件前，先说明要改哪几个文件、改什么。

skill_ids 规则：**出厂绑定只许引用随包内置 Skill**（每个用户装机即有；`skills/policy.py` 在 auto/pinned 模式下都会把 catalog 里不存在的 id 静默过滤，双重保险）。本机已装的个人 Skill 走「设置页编辑内置 Agent → 生成 built_in 覆盖版」加挂，只存在本机 config，不随版本分发（详见第七节）。

## 四、代码改动点（实施清单）

### 1. `naiba/config.py::built_in_agents()` —— 补 6 条定义
按第二节顺序返回 6 个 dict（tutor/master/director/prompter/coder/skills），含 id/name/system_prompt/skill_ids/tool_scope/avatar（可选 emoji）。
更新函数上方注释（清单不再为空）。

### 2. `public_agents()` —— 内置区置顶（唯一行为改动）
现状 `custom + built_in`，内置沉底。改三段式：

```python
custom = [dict(a) for a in self.data.get("agents", [])]
overrides = {str(a.get("id") or ""): a for a in custom if a.get("built_in")}
built_section = [
    overrides.pop(str(b["id"]), dict(b)) for b in built_in_agents()
]
pure_custom = [a for a in custom if not a.get("built_in")]
return built_section + pure_custom
```

效果：内置 6 样恒在最前（按定义顺序）；用户编辑过某个内置时覆盖版仍占原位次；老三样及其他自定义排在内置区之后，内容与可删性不变。

### 3. DEFAULTS 一处：`default_agent_id` 改 `"master"`
只影响新装（老用户配置里已存默认值，不回溯）。`default_agent_id()` 的存在性校验会经 `built_in_agents()` 命中 master，无需其他改动。DEFAULTS["agents"] 老三样不动。

## 五、教程系列的产出方案（回答"那几个教程怎么办"）

**格式**：每篇完整复刻 `docs/tutorial-comfyui-3min/` 的模板——README.md（图文）+ `images/` 截图 + 口播文稿 + 导出 PDF。第 0 步"配 API"只在第一篇写全，其余篇一律一句"先按教程 1 配好 API"链接回去，不重复。

**篇目（对应阵容）**：

3. 教程 3「3 分钟用 RunningHub 云端出图」—— 导演 Agent 主角，复用现有 runninghub/shortdramav2-rh Skill 流程。
4. 教程 4「3 分钟出一集短剧」—— 导演 Agent + 短剧 Skill。
5. 教程 5「3 分钟改出一条好提示词」—— prompter 主角。
