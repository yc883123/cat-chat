# 口播文稿：3 分钟用 RunningHub 云端出图出片（小白版）

- 时长设定：**3 分钟**，中速 **240 字/分钟**
- 正文约 **665 字**（纯念约 2 分 46 秒，加停顿与画面切换刚好 3 分钟）
- 素材：**01-agent ~ 05-result 共 5 张截图**（03、04、05 内含占位产物，见制作备注 3）
- 读法提示：`RunningHub` 念「Running Hub」；`API Key` 念「A-P-I 密钥」；`/` 念「斜杠」；`webappId` 念「web-app-ID」

---

## 分镜 1｜0:00–0:15 开场钩子

**画面**：05-result.png（云端出图结果，产物区用占位卡片），大字幕「没显卡，也能出图出视频」

> 电脑没装 ComfyUI，或者显卡不够用？没关系——把算力放到云上就行。接下来三分钟，咱们用 RunningHub 出一张图，全过程不用你搭任何环境。

（约 66 字）

---

## 分镜 2｜0:15–0:49 第 1 步：切导演 Agent + 斜杠引用技能

**画面**：01-agent.png（顶栏切到导演 Agent）→ 0:33 切 02-slash-skill.png（`/` 弹出的技能列表，高亮 runninghub）

> 第一步两件事。先在顶栏的 Agent 下拉里选中「导演 Agent」。然后最关键的一下：在输入框打一个斜杠，会弹出你已经装好的技能列表，选里面那个 runninghub。这个斜杠就是「本轮临时借用一个技能」的意思，任何技能都能这么呼出来，不用跑去设置里装。

（约 120 字）

---

## 分镜 3｜0:49–1:26 第 2 步：拿 Key

**画面**：03-key.png（对话里把 Key 交给 AI 的那一句 + AI 的验证回复）

> 第二步，拿一个 Key。RunningHub 是云端服务，得先有自己的钥匙。去 runninghub.cn 注册一个账号，第一次用要充值，按量计费；然后在站内创建自己的 API Key。拿到之后不用研究怎么填，直接把 Key 发给 AI，跟它说帮我测一下能不能用，然后存下来——它会自己验证、自己保存。

（约 130 字）

---

## 分镜 4｜1:26–1:55 第 3 步：说清要什么

**画面**：04-dialog.png（输入框里的需求描述，关键词画红圈）

> 第三步，把要求说清楚。云端是按次计费的，先说清楚最省钱。至少说三件事：要什么、什么规格、有没有参考图。比如你可以说：用 RunningHub 出一张古风人物立绘，竖版一零二四乘一五三六，参考我拖进去的这张图。AI 会把参数整理好，提交到云端。

（约 124 字）

---

## 分镜 5｜1:55–2:24 第 4 步：等云端跑完

**画面**：05-result.png（产物挂回消息 + 顶栏「任务」高亮）

> 第四步，等它跑。注意这一步是在云端排队生成，不在你电脑上跑，所以你可以去干别的，只要把 Cat Chat 窗口留着。跑完的图片或视频直接挂回消息里，点开就能看；真实文件存在 data 下的 generated 目录。如果任务比较久，点顶栏的「任务」能看到进度，也能随时停。

（约 130 字）

---

## 分镜 6｜2:24–2:50 排错提示

**画面**：03-key.png 与 05-result.png 左右分屏

> 三个小贴士。提示没有 Key 或者认证失败，就是第二步没做，把 Key 发给 AI 存一下就好。提示余额不足，去站内充值。排队久是云端负载问题，建议先用一张小图把参数试对，满意了再批量出。

（约 88 字）

## 分镜 7｜2:50–3:00 收尾

**画面**：黑底字卡「注册 → 拿 Key → 说清需求」+ 项目名

> 记住这条链：注册、拿 Key、说清需求。有显卡想省钱的，去看本地 ComfyUI 那一集。

## 制作备注

1. 全片 7 个镜头，静态截图为主，建议加轻微推近。
2. `Key`、`webappId`、`1024×1536` 这类信息念出来听不清，务必上字幕。
3. **第 3、4、5 张截图里的产物需要真实的 RunningHub 账号与额度才能拍**。若暂时没有账号：把这几张截成「对话界面 + 产物占位卡片」，并在文中保留待替换位置——
   自测时用 `RUNNINGHUB_API_KEY` 未设置的状态跑，正好能拍到「它会先问你要 Key」这一步。
