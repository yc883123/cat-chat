# 高速打戏的表现力落地

适用于高速、高燃、夸张透视、强运镜请求，以及“动作清楚但像演示”的返修。安静对峙、克制表演和用户指定的固定机位不强套此模式。这里是创作与复核规则，不是 H3 的精确帧控制能力说明。

## 从事件转换成观看体验

先锁定源素材的攻击次数、路径、接触／落空、能力与结果，再设计观看方式。镜头变化、短暂运动拖形和时间压缩可强化既有事件；额外连击、传送、受伤或扩大爆炸范围不能冒充表现力。

对承担速度或冲击的主要节拍，在内部确定以下关系，再融合进对应 Shot 的自然语言，不新增六字段之外的模板字段：

- **观看目的**：这一拍突出逼近、擦身、失衡、力量反差还是尺度揭示？
- **透视变化**：哪个前景部位从多大变到多大，远端如何缩小，运动沿纵深还是横穿画面？只写“广角特写”仍是静态构图。
- **摄影机路径**：从哪个高度和主体哪一侧起步，向哪里移动，跟上、落后还是被主体越过，最后在哪个可辨状态结束？追拍期间通过前景掠过与背景视差证明位移，不能让主体和背景像整张图一起滑动。
- **速度节奏**：短暂压缩／预备后如何突然爆发，关键姿态哪里短读，主体越过后衣物、气流、碎屑如何迟到？不要让整段动作同速，也不要每拳都慢放。

每镜不必齐备所有手法。明确有效的固定机位可保留；例如摄影机不动，让拳头突然填满前景，再甩出画面。高速段整体需要具体的相对运动和快慢差，不能仅靠“fast / intense / epic”或效果名词。

先检查摄影机与攻击轴线的几何可行性，再写透视。正对发射掌心、同时看清掌后人脸的机位，通常位于攻击者前方；不能又把被瞄准的目标放到攻击者身后。需要同时展示双方时，采用侧向／越肩机位，或切镜分别展示；不强求一个构图容纳互相冲突的观看要求。

## 防止连续性规则把动作拍慢

- 将滑步落地与肩胯送拳并行，支撑脚触地即转移力量；除非源图明确强调停顿，不默认收势站稳再出招。
- 起势、经过、接触、结果是因果节点，不是四个等长镜头。保留关键证据，用动作匹配切镜或短暂遮挡压缩普通中间过程。
- 不要求全程双方全身、发射源、地面、阴影同时在画面。用建立镜头与可辨结果维持空间关系，允许靴底、拳锋、脸部或掌心占据前景。
- 接触／落空瞬间需要读得清，经过时可以抹帧、拉长运动轮廓或短暂抽象背景，随后恢复稳定结构。临时拖形不是额外肢体或攻击。
- 守方从容不等于摄影机平淡。可用极小头部位移对比高速掠过的大前景靴底；不擅自把角色改成惊慌闪躲。
- 近失威胁通过画面中的逼近、掠过和间隙表达，不靠实际命中。不要为安全可读，先完整拍守方离开再让攻击缓慢经过；若源内容明确提前闪避，则保持时序，用机位与速度表达威力。

## 能量攻击区分三个时间

发射到落点的传播、持续放射、爆炸余波是不同阶段。高速光束可在释放时迅速贯通已有攻击路径，后续镜头展示同一次持续放射和环境反馈；不能仅为逐格展示，把它写成数秒缓慢飞行。源素材指定慢速推进、扫射或延迟破坏时才照此执行。

掌心、近处沟槽、远处岩壁可以成为同一股能量的不同观看尺度，不要求发射源每镜在画内。源图的沟槽—岩壁结果顺序需可辨，但普通传播过程可以压缩。停止放射可熄灭、断流并留下余辉；除非素材明确支持，不额外规定能量像绳索一样缩回掌心。

## 时间预算与文字预算

先安排主要观看落点与实际动作负荷，再分配时间。中间姿态不按格数均分秒数，结果镜头也不自动占长时段。用户指定总时长时，在其范围内重新组织，不私自缩短。起止时间是节奏意图，不能保证模型精确执行每一帧；不要堆小数时间码伪装控制力。

每段优先写最有辨识力的主体—镜头—环境关系。身份、防串肢体、无文字等通用约束集中在相应字段，不让每镜的否定句挤掉动作指令。功能重复的技巧和相互冲突的跟拍／环绕／拉远应删减。

镜头在动不代表角色动作有爆发力。分别检查身体姿态变化和摄影机位移；不能靠放大一个定格踢腿、推近一个不变的蓄力姿势替代高速动作。给短动作分配了较长镜头时，要说明剩余时间由什么有效运动承担；“短暂定格”不能成为延长格挡或踢腿展示的含糊指令。动作已结束而模型继续保持姿势时，优先重分时间、压缩展示和简化同镜指令，不再叠加摄影术语。

## 交付前的表现力复核

与因果、空间检查分别进行：

1. 去掉“高速、强烈、震撼”等词，正文是否仍描述了可见的尺度突变、相对运动和速度反差？
2. 镜头是否有起点、运动关系及信息落点，或有明确有效的固定视点？只有“cut close / tracks / pulls back”不足以支撑主打高速的段落。
3. 是否反复出现“落地—站稳—收手—屈膝—再次启动”的不必要重置？相邻格是否被机械切成同等时长的独立动作？
4. 关键交锋能否读清，同时允许中间过程短暂出画、遮挡或拖形？是否因全程全身可见而失去强透视？
5. 主峰值是否与次级交锋有强弱和时间差？光束是否被无意拍成慢速行进？人物既有性格是否保留？

不通过就重写具体 Shot，不用增加效果词或镜头数补救。上述复核只说明提示词有明确设计，不证明生成视频已经执行成功。真实返修需对照视频查看角色位移、景别变化、背景视差、速度包络与关键姿态；记录实际模型、时长、设置和输入（可获得时），区分提示词遗漏、参考约束与模型未执行。不要把单次结果归因于唯一因素。
