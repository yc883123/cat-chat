# 验收、返修与 H3 交接

## 1. 提示词验收

交付前检查设计本身：
- 原事件、顺序、胜负、能力、伤势与破坏规模保留。
- 每次主要攻击的目标、路径、结果明确，命中／格挡／偏转／闪避／无效接触分支相容，不新增防御或反击凑模板。
- 每格一个时间点，没有肢体互斥姿态；相邻格允许省略可推断的过渡，没有无因换手、换位或复位。
- 已先展开关键姿态再合并；能说明关键格相对前格新增的可见事实，必要的重心、支点与接续证据没有被“最少格数”删掉。同状态换角度只有在提供必要证据或明确强调时保留。
- 格数、版面位置、阅读顺序一致；关键接触或避让间隙有足够空间。
- 需要展示肩胯、支撑脚或闪避落脚的格，已明确这些部位入画。画框服从动作，不因通栏、近景或规则网格裁掉关键证据。
- 参考职责与资产所有权清楚，地标、余波、光源的持续状态一致。
- 视觉峰值符合源事件，末格明确阶段结果；没有碰撞／特效时不强求主碰撞／特效生命周期。
- 有时长要求时已检查节拍容量；对白和事实没有因无字画面丢失。

这只能证明提示词自检通过，不能声称图片合格或给出模型成功率。

## 2. 返回成图验收

读取实际返回图，对照原需求及提示词，检查整页和关键格。没有图片不声称已执行图像验收；看不清时标记无法确认，不猜测通过。

硬性问题：缺格／多格或阅读歧义、关键事件缺失、身份／服装／武器串绑、无依据多人物／肢体、握法或接触对象错误、闪避变命中、胜负／伤势／能力改写、空间断裂、结果缺失、文字遮挡动作。影响事实或可读性时不得标记可交接。

次要问题：不改变事实的光效强弱、背景装饰、非关键衣纹。按用户需求处理，不为美观差异无限返工；完整无字要求仍需检查新增文字。

验收必须对照原事实，不能只看是否像提示词。出图偏差不能成为新剧情。

### 动作意图还原检查

将每格意图与实际可见状态对照；相邻格一起判断，不能只按标题或精致程度评分：
- 擦过是否能排除命中？脚／拳与脸部轮廓、间隙和避让姿态是否可辨？
- 初始发射是否仍在初始阶段，还是已画成长光束加完成闪避？连续两格是否只是同一结果的远近景？
- 借势跃起是否有接触改向、重心与支撑变化依据，还是突然变为空中造型？
- 侧闪的落脚与身体倾斜是否清楚，还是像普通行走或蹲伏？
- 连续追击是否继承上一动作，还是每招都无因站稳重置？
- 实际画布比例是否偏离要求？关键身体部位是否因过扁画框而被裁掉？有图像尺寸元数据时使用实际尺寸，不用聊天预览尺寸冒充原图。

每个问题分别记“设计意图、画面证据、影响及修法”；没有实际图不能声称已完成这些检查。

判断分三个方面：剧情／结果是否清楚、动作能否衔接、燃向视觉对比是否成立。不要把“画面精美、格数正确”直接等同于三项全通过。燃向检查见 [visual-direction.md](visual-direction.md)；静态图只能提供姿态与节奏依据，实际速度、停顿和冲击感仍需视频验证。

## 3. 返修协议

先归因再选修法：

| 问题来源 | 处理 |
| --- | --- |
| 提示词遗漏必要的动作连接或关键姿态 | 补格或重新拆解受影响事件；不靠加特效掩盖 |
| 提示词已有区别，但成图画错阶段／重复状态 | 定点改成缺失的阶段，不默认继续加格 |
| 动作内容正确，但裁切／遮挡使证据不可读 | 调整格子高度、景别、遮挡或画布尺寸，保留事件 |
| 单格身份、肢体或武器归属错误 | 局部编辑并复查相邻格 |
| 多个关键结果错误或格序混乱 | 重构相关页，不重复原提示词碰运气 |

多个问题可以并存，优先修影响事实和接续的部分。不要因一次布局偏差就规定所有任务必须用正方形，也不要把每次失败都归因于格数不足。

一条编辑词包含：
1. 核对本次实际上传顺序，重新映射待修页与必要资产参考，不沿用不对应的旧 Picture 编号。
2. 用“上排右格”等版面位置和地标定位，不给图补印格号。
3. 写出正确的当前瞬间，不只说“修好手”或堆负面词。
4. 明确保留其余格、格缝、身份、场景、持械手、剧情结果及未指定区域。若影响邻格连续性，一并检查。

例如：仅修改上排右格，甲右拳抵住乙左前臂外侧，乙左肘低于左拳，双方前臂轮廓分离且接触边缘可见；保持脸、服装、其他肢体、位置、背景和其余格不变。

返修后复查整页；局部指令不保证其他区域完全不变。同一关键错误经两轮局部返修仍存在，改用简化构图或整页重构，不再原样循环；更低的用户预算优先。本技能不自动调用生图工具。

## 4. 可带走的事实与对白

有对白、内心独白或仅由文字表达的因果时，必须在生图代码块外保留如下文字记录，不把它渲染进图：

> H3 交接信息（不渲染）
> 事实来源：原素材名称／用户描述；原阅读顺序。
> 不可改事实：事件顺序、命中结果、伤势／胜负及能力边界。
> 对白：说话者｜原文｜对应可见瞬间或前后事件｜对白／内心独白。
> 参考职责：新图负责动作／构图；人物图负责身份；原素材与本记录负责事实／对白。
> 目标时长：用户要求或未指定；仍缺失的事实。
> 动作／镜头关系（适用时）：同一连续动作对应的格组、观察角度变化、各页是否共用一段时长。

只记可核验事实，不写内部推理。对白逐字转录，模糊文字或说话者不明时标记并询问，不猜台词。无对白的文字原创用简短事实记录，不加空白对白表。

跨任务时原素材应与记录一同保留；无法携带原素材时，记录必须覆盖本段全部必要事实和对白。有遗漏不能以无字新图代替全部源内容。转录不擅自决定配音、speaker 编号或 H3 时间码。

## 5. 下游映射与回退

成图通过后向 h3-storyboard-fight 交付新图、专门资产图和原素材／记录。按下游本次实际上传顺序建立 Picture 映射，此后保持稳定。

- 用户明确修订优先；原素材／用户事实控制剧情、对白、命中、能力和伤势，原构图允许按重构需求改变。
- 新图控制已验收的动作瞬间、构图和空间路线，不覆盖事实边界。
- 相邻分镜格可属于同一连续镜头；交接关键姿态组时不强制逐格切镜或平均分配时长，也不把分页当作视频分 P。
- 专门人物／武器／场景参考控制各自外观；同职责冲突且没有用户优先级时询问，不混合猜测。
- 新图违反事实先修图，不让 H3 词偷偷修补画错的结果；同一动作可推断的中间帧未画出不构成缺陷。
- 纯闪避、突袭命中、强者静止承受只要路径、结果和空间清楚，就不应回退；下游的回应、改线、主碰撞按此分支解释。
- 缺关键事件／结果、身份错误或空间断裂时回退。用户明确接受局限并要求直转时，交付已知问题，不声称通过成图验收。

本技能不自动写 H3 六字段；用户继续视频任务时再进入下游流程。
