### 1. 视听签名 8 字段定义

#### Field 1 · 介质 (Medium)

记录什么决定看起来什么样. 数字 vs 胶片差别巨大, 大画幅 vs 35mm 也差别巨大.

| 介质 | 视觉指纹 | 适用情境 |
|---|---|---|
| **16mm** | 颗粒粗 / 动态范围窄 / 带糙粒子感 | 纪录片质感 / 复古青春 / 独立片 |
| **Super 16** | 颗粒明显但更细 / 暖偏色 | 80-90 年代电视感 / 怀旧 |
| **35mm** | 中颗粒 / 高动态范围 / 经典电影质感 | 标准电影语法 / 类型片 |
| **65mm / IMAX** | 极高分辨率 / 极宽动态 / 几乎无颗粒 / 巨幕沉浸感 | 史诗 / 大场面 / 风景压迫 |
| **Arri Alexa LF** | 大画幅数字 / 极宽动态 / 浅景深奶油焦外 | 现代主流电影 / 高质感剧集 |
| **Sony Venice** | 大画幅 6K / 高对比 / 偏冷调 | 科幻 / 水下 / 高速场景 |
| **Red Komodo / V-Raptor** | 紧凑数字 / 锐利 / 偏数字感 | 动作 / 中等预算 / 多机位 |
| **IMAX 70mm** | 极致清晰 + 巨幕高度 / 颗粒可见但动态王 | 史诗 / 实拍特技 / 风景 |
| **数字 + 胶片模拟 LUT** | 数字捕捉 + 后期叠胶片颗粒/光晕 | 大多数现代项目的折中方案 |

**写法**: 主介质 + 必要时叠"模拟"层. 例: `Arri Alexa LF + 35mm 颗粒 LUT`.

#### Field 2 · 长宽比 (Aspect Ratio)

每个比例自带情绪暗示. 选错比例 = 类型错位.

| 比例 | 名称 | 情绪暗示 |
|---|---|---|
| **1.33:1 (4:3)** | Academy / 复古电视 | 怀旧 / 局促 / 私密 / 戏剧化 |
| **1.85:1** | 经典电影 | 标准故事感 / 平衡 / 中性 |
| **2.39:1** | 宽银幕 / Scope | 史诗 / 风景 / 戏剧距离 / 大片感 |
| **2.76:1** | Ultra Panavision 70 | 极宽 / 仪式感 / 奥逊·威尔斯式戏剧 |
| **1:1** | 方画幅 | 摄影感 / Instagram / 凝视 |
| **9:16 (竖屏)** | 短剧 / 抖音 / 快手 | 人脸放大 / 情绪贴脸 / 移动端 |
| **可变比例** | 切比例 | 双时空 / 视点切换 / 后设 |

**注意**: 9:16 不是 16:9 倒过来 = 同样的镜头. 9:16 常需要突出人物与表情；全景仍可用于空间建立，主体比例按镜头任务确定. 选 9:16 = 选了"贴脸戏"为主.

#### Field 3 · 调色基调 (Color Grading)

详细 13 款主流调色对照见本附录 §3 调色风格扩展库.

#### Field 4 · 色彩 ID (Color ID)

> 工业标准: 给每个主要角色/势力分配唯一色相. 这是"看一眼就知道谁是谁"的底层武器.

**写法**: `角色名 = 色相` 一行一个.

**示例 1 · 《拦截》(科幻怪兽机甲)**:
```
THETA (机甲)     = 工业琥珀
SENTINEL-07 (敌) = 警示红
军方             = 冷白 + 钢灰
平民             = 土褐
背景城市         = 工业青绿
```

**示例 2 · 《沙丘》**:
```
厄崔迪家族 = 海蓝 + 银
哈克南家族 = 黑 + 油绿
弗雷曼人   = 沙黄 + 蓝眼
帝国近卫   = 金红
```

**示例 3 · 张艺谋《英雄》**:
```
开篇黑白色块 (秦) = 黑
飞雪长空 (回忆 1) = 红
残剑赵姑娘 (回忆 2) = 蓝
真相段                = 白
最终段落              = 绿
```

**规则**:
- 每个主要角色/势力 1 个色相 (不能 2 个, 否则混淆)
- 总数 ≤ 6 (人眼区分极限)
- 反派色 vs 主角色建议对撞 (互补色或饱和度对撞)

#### Field 5 · 介质质感 (Texture)

记录"看上去脏不脏 / 闪不闪 / 雾不雾".

| 维度 | 选项 |
|---|---|
| **颗粒程度** | 无颗粒 / 微颗粒 / 中颗粒 / 重颗粒 |
| **光晕 (Halation)** | 无 / 微 / 明显光晕 (高光红边) |
| **反射** | 干净 / 偏炫光 / 重镜头眩光 (J.J. Abrams 式) |
| **大气元素** | 雾 / 雨 / 雪 / 灰尘 / 蒸汽 / 烟 / 砂尘 / 海雾 |
| **噪点** | 数字噪点 / 胶片颗粒 / 干净 |

**写法**: 选 3-5 个标签组合. 例: `中颗粒 + 雨水光晕 + 海雾 + 蒸汽`.

#### Field 6 · 核心主题 (Core Theme)

**一句话, 描述全片在视觉上想说什么**. 不是剧情, 是"视觉语言的中心论点".

写法: 主语 + 比喻动词 + 宾语. 一句话.

示例:
- 《拦截》: "人类文明的最后一次挥拳"
- 《银翼杀手 2049》: "造物主用泡沫和雾隐藏自己"
- 《沙丘》: "沙漠把人吞下后变成神"
- 《海街日记》: "时间像晾在阳台上的衣服, 慢慢被风吹干"
- 《奥本海默》: "原子里藏着两种火, 一种照亮人, 一种烧掉人"

**规则**: 不要写抽象哲学短语 ("救赎与希望"), 要写**画面**. 测试: 闭眼能否想象一帧画面? 不能 = 重写.

#### Field 7 · 大师基因 (Master DNA)

1-3 位导演 (不能 4 个以上, 多了稀释), 用 `A × B` 或 `A × B × C` 公式.

**公式说明**:
- A = 主视觉骨架来源 (60% 权重)
- B = 调色/质感来源 (30%)
- C = 节奏/剪辑来源 (10%, 可省)

**示例**:
- 《拦截》: 吉尔莫·德尔·托罗 × 迈克尔·贝 (机械哥特骨架 × 工业巨物尺度)
- 《XX 文艺》: 是枝裕和 × 罗杰·迪金斯 (家庭日常骨架 × 自然光质感)
- 《XX 武侠》: 王家卫 × 张艺谋 (霓虹浅景深 × 单色统治)
- 《XX 黑色片》: 维伦纽瓦 × 大卫·芬奇 (对称极简骨架 × 冷蓝精密)

**禁忌**:
- 错: 4+ 大师 = "什么都想要" = 拼贴感
- 错: 大师基因和类型不匹配 (如选诺兰拍乡土片)
- 错: 大师基因之间互斥 (如塔可夫斯基 × 迈克尔·贝, 慢和爆炸打架)

#### Field 8 · 类型片配方 (Genre Formula)

该类型在视觉上的标准动作: 开场怎么拍 / 转折怎么拍 / 高潮怎么拍.

详细库见 §4. 写法是一行简短动作清单.

**示例 · 《拦截》(科幻怪兽机甲)**:
```
开场: 巨物剪影从地平线缓推 (尺度震慑)
转折: 第一次正面接触, 低角度 360° 仰拍机甲 (英雄诞生瞬间)
高潮: 海上对决, 慢动作爆破 + 尺度对比镜头 + 重 VFX
落幕: 残骸俯瞰大全景 + 静音几秒
```

### 2. 大师视听语法速查库

#### 克里斯托弗·诺兰 (Christopher Nolan)

- **视觉特征**: 深焦摄影 (前/中/后三层全清晰); IMAX 65mm + 35mm 混搭; 实拍至上, 反对纯 CG; 时间结构外化为画面 (倒退/嵌套/平行)
- **招牌镜头**: 缓慢推进至特写 (6-8 秒) / 大尺度对话戏 + 深焦 / 实拍爆破 + IMAX 巨幕 / 时间倒流的镜面构图
- **代表片例**: 《奥本海默》《信条》《敦刻尔克》《盗梦空间》《星际穿越》
- **借鉴时机**: 概念厚重的科幻 / 战争 / 时间结构片. 不适合: 私密爱情 / 喜剧 / 低预算

#### 王家卫 (Wong Kar-wai)

- **视觉特征**: 霓虹光影 (港式街景灯管色); 浅景深 + 长焦 (主角永远清晰, 背景永远模糊); 升格 (slow motion) 用于眼神/手势; 偷拍感 + 手持 (法国新浪潮血统)
- **招牌镜头**: 升格中近景 / 镜面反射构图 / 走廊深焦推进 / 雨天霓虹反光地面 / 钟表特写
- **代表片例**: 《花样年华》《重庆森林》《2046》《堕落天使》《一代宗师》
- **借鉴时机**: 都市情感 / 错过/暧昧 / 时代变迁. 不适合: 动作 / 史诗 / 战争

#### 是枝裕和 (Hirokazu Kore-eda)

- **视觉特征**: 固定中景 (摄影机不动, 让生活流过去); 自然光为主 + 实景拍摄 + 非演员; 长镜头但非塔可夫斯基的"雕塑时间", 是"日常密度"; 横构图 (家庭并置)
- **招牌镜头**: 餐桌固定中景 + 全家入画 / 走廊推门空镜 / 季节空镜 (枕镜头) / 平视低机位
- **代表片例**: 《海街日记》《小偷家族》《如父如子》《步履不停》《奇迹》
- **借鉴时机**: 家庭剧 / 慢热文艺 / 留守儿童 / 老龄化. 不适合: 类型片 / 高戏剧

#### 吉尔莫·德尔·托罗 (Guillermo del Toro)

- **视觉特征**: 纵深构图 (前景遮挡 + 中景人 + 后景奇观); 伦勃朗光 (chiaroscuro, 单光源 + 大面积阴影); 哥特机械美学 (黄铜 + 木 + 玻璃 + 齿轮); 暖琥珀 vs 病绿对撞色
- **招牌镜头**: 单光源人脸半阴半亮 / 机械装置特写 + 齿轮转动 / 怪物全身慢推 / 红衣 + 暗背景的色块对撞

- **借鉴时机**: 黑暗童话 / 怪物科幻 / 哥特恐怖. 不适合: 现代写实 / 喜剧

#### 迈克尔·贝 (Michael Bay)

- **视觉特征**: 低角度仰拍 ("英雄镜头", 让人物 = 神); 360° 旋转环绕 + 主角站立; 镜头眩光 (大量, 与诺兰相反); 慢动作爆破 (玻璃/金属碎片飞行)
- **招牌镜头**: "Bayhem 360 hero shot" (低角度 + 360° + 慢动作 + 仰拍人物起身) / 倾斜地平线快速横摇 / 玻璃慢动作爆裂 / 直升机绕飞
- **代表片例**: 《变形金刚》系列 / 《珍珠港》/ 《绝地战警》/ 《勇闯夺命岛》/ 《6 Underground》
- **借鉴时机**: 大场面动作 / 军事 / 巨物 / 爆破密集. 不适合: 文艺 / 室内剧 / 静默戏

#### 安德烈·塔可夫斯基 (Andrei Tarkovsky)

- **视觉特征**: 极长镜头 ("雕塑时间", 一镜 5-10 分钟); 自然元素四要素 (水/火/雾/土) 反复出现; 室内下雨; 缓慢横移 / 推进 + 主角入画出画
- **招牌镜头**: 长镜头中主角穿过房间 + 自然元素 (烧/水) 同框 / 镜面构图 + 双重曝光 / 室内雨 / 静止中景 + 时间流过
- **代表片例**: 《镜子》《潜行者》《乡愁》《牺牲》《飞向太空》《伊万的童年》
- **借鉴时机**: 哲学 / 记忆 / 信仰 / 战争内省. 不适合: 商业 / 类型片 / 短剧

#### 丹尼斯·维伦纽瓦 (Denis Villeneuve)

- **视觉特征**: 对称构图 (中轴线 + 人物居中); 极简留白 (画面 70% 为空气/沙/雾); 大场面静默 (无配乐, 只有环境音); 人物渺小 vs 环境宏大的尺度对比
- **招牌镜头**: 大全景 + 人物渺小一点 / 完美对称中轴 / 仰拍巨型建筑 / 缓推到面部特写无配乐
- **代表片例**: 《沙丘 1/2》《银翼杀手 2049》《降临》《边境杀手》《囚徒》《敌人》
- **借鉴时机**: 史诗科幻 / 心理悬疑 / 仪式感强的类型片. 不适合: 喜剧 / 私密家庭剧

#### 张艺谋 (Zhang Yimou)

- **视觉特征**: 单色统治 (一个段落 1 个主色铺满, 红/黄/绿/蓝/白); 仪式感构图 (大量人/旗/花阵列); 大色块对撞 (红 vs 白 / 黑 vs 黄); 慢动作 + 飘逸服饰
- **招牌镜头**: 红绸大全景 / 千人阵列 / 单色房间 + 单人 / 飘逸长发慢动作 / 屋顶大全景对决
- **代表片例**: 《英雄》《十面埋伏》《满城尽带黄金甲》《大红灯笼高高挂》《菊豆》《影》《满江红》
- **借鉴时机**: 武侠 / 古装 / 民俗 / 史诗. 不适合: 现代都市 / 写实 / 日常

### 4. 类型片视觉惯例库

#### 科幻怪兽机甲 (PacRim / Real Steel / Godzilla 路数)
- **视觉工具**: 工业写实 (机甲不光滑, 有铆钉/锈迹/油污) + 巨物尺度 (镜头从下往上 + 人物/汽车/楼对比) + 蓝橙对撞 + 重 VFX + 雨/海雾大气
- **开场**: 远景 + 巨物剪影逐渐显现 (尺度震慑)
- **高潮**: 海上对决 / 城市破坏, 慢动作 + 尺度对比 + 重 VFX
- **落幕**: 残骸俯瞰大全景 + 静音几秒

#### 武侠诗意 (徐克 / 张艺谋 / 王家卫)
- **视觉工具**: 慢动作 + 飘逸服饰 + 自然元素 (花瓣/竹叶/雪/水) + 单色统治 + 大全景留白
- **开场**: 静景大全景 (山/竹林/雪) + 主角入画
- **高潮**: 单色房间 + 多人围攻 + 飘逸长袖
- **落幕**: 大全景中两人渐行渐远

#### 黑色电影 (Noir)
- **视觉工具**: 高对比 (暗多于明) + 阴影面 (人脸半阴半亮) + 百叶窗光 (栅栏阴影投脸上) + 雨夜城市 + 烟雾 + 第一人称旁白
- **开场**: 雨夜 + 主角剪影走过霓虹街道
- **高潮**: 屋顶/巷道追逐, 雨 + 倒影 + 百叶窗光
- **落幕**: 主角独自远走, 雨雾中渐隐

#### 文艺片 (Slow Cinema / Art House)
- **视觉工具**: 长镜头 + 中景 + 自然光 + 极少配乐 + 横构图 + 留白
- **开场**: 一个长镜头 (3-5 分钟), 无台词或极少
- **高潮**: 反高潮 (没有传统爆发, 只是一场静默对话)
- **落幕**: 空镜 / 风景 / 时间流过

#### 恐怖片 (Horror)
- **视觉工具**: 低光 (大量黑) + 急摇 / 镜头跟随但延迟 + 突然失焦 + 红色/血腥点缀 + 走廊推进 + 镜面/反射制造惊吓
- **开场**: 缓慢推进至门 / 走廊 / 洞口
- **高潮**: 快切 + 闪光 + 主观镜头 (主角视角)
- **落幕**: 假平静 + 最后一个 jump scare

#### 短剧 (中国微短剧 9:16)
- **视觉工具**: 9:16 竖屏 + 高饱和 (饱和度比电影 +30%) + 快切 (1-2 秒/镜) + 大特写堆叠 (人脸占画面 70%) + 小景别为主 (中景/近景/特写, 不用全景) + 模糊背景 (浅景深贴脸) + 反转节拍密集
- **开场**: 大特写直接抓眼 (角色甩巴掌 / 怒吼 / 哭) + 字幕
- **高潮**: 反转点的特写堆叠 + 字幕配合 + BGM 起
- **落幕**: 留悬念特写 + 滑动到下一集

**短剧参考**：小屏优先看清表演和关键关系；需要交代空间时仍应使用全景。

### 7. 常见错误 (Don'ts)

1. 错: **"我什么都喜欢"** = 拼贴 = 无签名. 建议砍到 1-3 位大师
2. 错: **大师基因混搭打架** (诺兰深焦 × 王家卫浅景深 / 塔可夫斯基长镜 × Bay 快切)
3. 错: **色彩 ID 给次要角色** (NPC 不要色相, 否则主色冲淡)
4. 错: **核心主题写成情节** ("讲一个机甲师傅救女儿的故事" 不是视觉主题)
5. 错: **介质和类型错配** (短剧 9:16 用 IMAX 65mm 介质规格毫无意义)
6. 错: **调色基调写"好看"/ "高级感"** — 建议用具体术语 (Teal-Orange / Bleach Bypass)
7. 错: **类型片配方抄全套大师** — 配方是 4 行清单 (开场/转折/高潮/落幕), 不是论文
8. 错: **签名锁定后还改大师** — 锁定 = 后续 50 张镜头卡都基于此. 改 = 全部重做

```
| # | 时间 | 时长 | 景别 | 机位·运动 | 内容 | 声音 |
```

每个镜头一行, 7 列全部强制填写. 这是工业级 shot list 的最简但够用的列结构 (StudioBinder/Frame.io 模板的精炼版).

#### 列定义速查

| 列名 | 强制 | 说明 | 示例 |
|---|---|---|---|
| **#** | 必填 | 镜号 (01, 02, ...). 可加中文标签 | `02 [海报帧]` / `15 [伏笔]` / `08 [关键]` |
| **时间** | 必填 | 起始时间码 (从 0:00 算, mm:ss 或 h:mm:ss) | `0:00` / `0:42` / `1:23` |
| **时长** | 必填 | 秒数, `1"` / `2.5"` / `8"` 默认 1-8 秒 | `2"` / `3.5"` |
| **景别** | 必填 | 7 档中文 (极端特写/近景/中近景/中景/中远景/全景/远景) 或 `—` (黑屏/特殊) | `极端特写` / `中景` / `全景` |
| **机位·运动** | 必填 | "机位 · 运动方式 (· 速度修饰)" | `低角度·横移` / `水下·向上仰角` |
| **内容** | 必填 | ≤30 字, 主体+动作+关键细节, 视觉化, 可直接拍 | `琥珀瞳孔在黑暗中睁开·收缩时荧光变浓` |
| **声音** | 必填 | 关键声音元素 + 对白 (即使"无声"也写) | `次声波低鸣+气泡` / `静默 2"后心跳骤响` |

### 1 · 镜号 (#) 与 Emoji 标记系统

#### 镜号规则

- 从 `01` 开始, 按拍摄/剪辑顺序连续编号
- 单元结尾不重置, 全片连续
- 三位数 `001-999` 仅长片用; 短片 `01-99` 已够

#### 中文标签 (工业实践)

| 标签 | 含义 | 用途 | 全片配额 |
|---|---|---|---|
| `[海报帧]` | 海报帧 / Poster Frame | 适合做主视觉/营销物料的镜头 (单帧美) | 5-9 个 |
| `[伏笔]` | 伏笔 / Foreshadow / Hook | 后面要回扣的种子 (物件/动作/视觉) | 必有回扣 |
| `[关键]` | 关键叙事点 / Key Story Beat | 主线进展的关键转折 | 3-7 个 |
| `[重特效]` | VFX 重镜 / Heavy VFX | 后期工时大 (粒子/合成/CG) | 按预算 |
| `[长镜]` | 长镜头 / Long Take | 8 秒+, 一镜到底 | 稀少 |
| `[音锚]` | 声音锚点 / Sound Anchor | 配乐切换/静默点 | 单元间 |
| `[特设备]` | 机械镜头 / Mechanical | 需特殊设备 (摇臂/斯坦尼康/水下/无人机) | 按预算 |

**多标签叠加**: `02 [海报帧][关键]` (既是海报帧又是叙事点). 但同一镜不超过 2 个.

### 2 · 时间与时长

#### 时间码格式

- 短片 (≤3 分钟): `mm:ss` (如 `2:14`)
- 长片: `h:mm:ss` (如 `1:23:45`)
- 起始时间 = 上一镜的起始 + 上一镜的时长
- 全片首镜固定 `0:00`

#### 时长颗粒度

- 整数秒: `1"` `2"` `3"`
- 半秒精度 (短片刚需): `1.5"` `2.5"` `3.5"`
- 闪剪/Flash: `0.3"` `0.5"` (≤1 秒, 必标 Flash Cut)
- 长镜头: `8"+` 标记 `[长镜]`

#### ASL (Average Shot Length) 自检

时长累加 = 单元时长 (单元结尾) = 全片时长 (整片结尾). 误差 ±5% 内.

### 3 · 景别 7 档

中文 7 档, **以"画面填充人体什么部位"定义**:

| 景别 | 范围 | 主要用途 | 经典片例 |
|---|---|---|---|
| **极端特写** | 眼睛 / 嘴唇 / 单一指尖 / 一颗钉 | 情感顶点 / 关键细节 / 抽象符号 | 《镖客三部曲》(Sergio Leone) 眼睛对决; 《黑天鹅》羽毛长出皮肤 |
| **近景** | 头部 (下巴到发际, 略含肩) | 表情 / 内心独白 / 情绪 | 《沉默的羔羊》Hannibal 直视镜头; 《公民凯恩》"玫瑰花蕾" |
| **中近景** | 胸部以上 | 对白主力 / 半身肢体 + 表情 | 《老无所依》对峙长镜; 电视剧默认对白 |
| **中景** | 腰部以上 | 动作 + 表情 / 双人对话 | 《教父》会议桌默认; "两人中景" 是行业基线 |
| **中远景** | 大腿以上 (含牛仔镜) | 动作 + 环境关系 / 武打编排 | 西部片配枪带; 《神奇女侠》战场 |
| **全景** | 全身 + 部分环境 | 空间关系 / 群体调度 | 《阿拉伯的劳伦斯》骆驼远眺; 《辛德勒的名单》红衣女孩 |
| **远景** | 全身渺小 + 大量环境 | 建立 / 史诗感 / 终幕渺小 | 《疯狂麦克斯·狂暴之路》沙漠车队; 《2001》猿人遥望 |

#### 景别选择速查

- **情感顶点** → 极端特写 (眼/泪/手) 或 近景 (脸)
- **对白** → 中近景 或 中景 (单/双人)
- **动作戏** → 中远景 (看招式) + 中景 (反应) 交替
- **建立空间** → 全景 或 远景 (开场/转场)
- **群体戏** → 全景 (站位看清) + 中景 (个人反应)
- **特殊**: `—` 用于黑屏 / 闪剪 / 纯字幕 / 抽象图形

### 4 · 机位库 (10+)

机位 = 摄影机相对主体的**空间位置和角度**. 与"运动"分开 (运动是怎么移动). 写法: `<机位修饰>·<运动>`.

| 中文 | 视觉效果 | 适用场景 |
|---|---|---|
| **平视** | 平等关系, 中立观察 | 默认对白 / 自然主义 |
| **俯拍** | 弱化主体, 命运感, 渺小感 | 角色失败 / 上帝视角暗示 |
| **仰拍** | 强化主体, 威压感, 英雄化 | 反派登场 / 英雄定格 |
| **荷兰角 (倾斜)** | 不安, 心理失衡, 道德倾斜 | 惊悚 / 反派内心 / 醉酒 |
| **主观视角** | 代入感, 限制信息 | 第一人称恐惧 / 跟踪 |
| **过肩** | 对话, 关系编码, 视线建立 | 双人对白 (反打 OTS 经典) |
| **上帝视角** | 全知, 命运感, 抽象图形化 | 建立 / 终幕 / 群体调度 |
| **虫视角** | 极端仰拍, 巨物感, 压迫 | 巨物 VFX / 仰望英雄 |
| **侧面剖视** | 角色对峙, 强化轮廓, 古典 | 武打对峙 / 决战 |
| **双人构图** | 关系编码 (近=亲密, 远=疏离) | 对白 / 关系定调 |
| **三人构图** | 三角关系, 权力分布 | 谈判 / 三角恋 |

#### 复合机位写法

- `低角度 OTS·过肩` = 低角度 + 过肩复合
- `俯拍 POV·主观` = 上方俯视的 POV (如阳台往下看)
- `荷兰角 极端特写·倾斜` = 倾斜的极端特写

### 5 · 运镜库 (12+)

运动 = 摄影机**怎么移动**. 与机位 (在哪) 正交. **写法**: `<机位>·<运动>(·<速度修饰>)`.

| 中文 | 视觉效果 | 适用场景 |
|---|---|---|
| **摇** | 横向旋转 (机身不动, 镜头方向变) | 横向跟随 / 环境扫描 |
| **仰俯** | 纵向旋转 | 高楼向上扫 / 人物从脚到头建立 |
| **推** | 整机前移, 物理推进 | 情绪逼近 / 心理紧绷 |
| **拉** | 整机后退 | 情绪释放 / 揭示更大场景 |
| **横移** | 整机左右移动 (平行被摄物) | 跟拍走路 / 平视环境横扫 |
| **升降** | 整机垂直升/降, 不旋转 | 角色站起/坐下平视跟随 |
| **摇臂** | 高空 + 任意方向, 弧线运动 | 开场建立 / 终幕拉起 |
| **斯坦尼康** | 流畅跟随 + 自由路径 | 长镜头跟随 / 伪一镜到底 |
| **手持** | 故意抖动制造不安 / 真实感 | 战争/纪录片风 / 心理失控 |
| **跟拍** | 跟随主体保持相对位置 | 角色行走 / 追逐戏 |
| **推拉变焦** | 推进 + 焦距变化 (有别于纯 Dolly) | 风格化推进 |
| **急摇** | 极快横摇 → 运动模糊 | 转场利器 / 场景切换 |
| **无人机** | 高空俯瞰 + 任意路径 | 建立 / 史诗 / 自然 |
| **高速摄影** | 极慢动作 (后期放慢) | 爆炸瞬间 / 子弹时间 |
| **静止** | 完全不动 | 冷峻凝视 / 留白思考 |

#### 速度修饰

- `慢推` / `急推` (推进速度)
- `丝滑横移` (Steadicam 跟拍标配)
- `急摇接切` (Whip Pan + Cut, 隐藏剪辑)
- `Flash Cut` (≤1 秒, 闪剪)

### 6 · 转场库 (10+)

转场 = 镜头与镜头之间的连接方式. 默认 `Hard Cut`, 不写默认即可; 特殊转场写在镜末或镜首注释.

| 中文 | 用法 |
|---|---|
| **硬切** | 默认转场, 直接切换 |
| **匹配剪辑** | 形/动/声匹配, 上下镜共享视觉元素 |
| **撞切** | 强烈反差 (静→噪 / 安宁→暴力 / 笑→哭) |
| **J 切** | 下场声音先入 (画面晚于声音) |
| **L 切** | 上场声音后留 (画面切了声音继续) |
| **交叉剪辑** | 双线并行 (A 线 / B 线交替) |
| **跳切** | 同景别小幅时间跳跃 (戈达尔签名) |
| **叠化** | 时间流逝 / 梦境过渡 |
| **淡入** | 章节起始 / 黑屏渐显 |
| **淡出** | 章节结束 / 渐黑 |
| **圈入圈出** | 复古 / 注意力锁定 |
| **划像** | 风格化转场 (条状/星形/对角) |
| **急摇接切** | 急摇 → 隐藏剪辑 → 下镜 |
| **闪白/闪黑** | 单帧白/黑 → 撞击 / 闪回触发 |

---

### 7 · 高级镜头技法 (12+)

镜头本身的设计模式 (复合手法 / 风格签名), 不是单纯机位/运动. 用于在镜头卡 "内容" 列标注.

| 名称 | 描述 |
|---|---|
| **一镜到底** | 极长不剪, 8 秒+ 到 10 分钟+ |
| **眩晕变焦** | 推进 + 反向变焦 (背景压缩/拉伸) |
| **变焦对焦切换** | 焦点从前景切到背景 (或反向) |
| **动作匹配剪** | 上镜动作 → 下镜不同景别接续动作 |
| **镜面反射** | 镜中倒影同框 / 镜中真相 |
| **前景叙事** | 前景物体框定/遮挡主体, 同框双叙事 |
| **反射镜头** | 任意反射面 (水/金属/眼睛) 显主体 |
| **插入镜头** | 突然切到道具/手部/细节特写 |
| **建立镜头** | 段落首镜, 介绍空间/时间/天气 |
| **闪剪** | 跳到无关画面 (心理 / 联想 / 幽默) |
| **反应镜头** | 切到相关人物反应，依据戏点决定是否需要 |
| **子弹时间** | 多机位环绕 + 时间冻结/慢放 |

---

补充校准：推/拉为相机整体前后移动，摇为机身原地水平旋转，横移为相机左右平移；拉焦是焦点转移，不能称作变焦。推拉变焦为相机移动与焦距反向变化。高速摄影是采集/慢动作手法，不是相机空间运动。三维空间、视线与轴线保持可读，反应镜头的归属由戏剧重心决定。
