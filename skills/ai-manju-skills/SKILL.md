# AI 漫剧（21题材）

这是一个统一入口，21种题材是参考资料，不是21个独立 Skill。根据故事点子选定题材，再读取对应原版模板，保留该题材自己的节奏和制作细则。

## 选择与读取

1. 用户明确指定题材时按指定选择；否则根据故事背景和核心冲突匹配下表。能判断就直接开始，不先让用户填写长问卷。只有两种题材确实无法区分且会改变故事方向时，简短确认一次。
2. 使用 `read_file` 读取选定的一份参考全文。表中路径相对于当前激活 Skill 注入的 `root`；将 `root` 与该相对路径拼成绝对路径，不使用工作区同名文件，不硬编码安装位置。无需扫描或读取全部21份。若工具报告截断，继续读取缺失部分后再创作。
3. 参考文件保留上游原版 frontmatter 和独立粘贴使用说明，仅作为题材资料；忽略其中“只回复模板已就绪，然后等待输入”的启动段。用户已经给出故事点子时，直接产出立项卡和企划第一批，不重复等待点子。
4. 一部剧默认只用一份题材模板，避免设定混杂。用户明确要求融合题材时才再读取必要的另一份，并先确定主题材、统一世界观与节奏，而不是机械拼接所有模板。

### 容易混淆的题材

- 古代重生：以内宅为主选宅斗，以后宫为主选宫斗，跨身份穿越或更广泛古代冒险选穿越重生；现代回到过去选重生复仇，七八十年代选年代文，末世选末日废土。
- 以副本规则和通关为主选系统无限流；以民俗传说、禁忌和谜团为主选民俗怪谈；以证据和案件推理为主选悬疑刑侦。
- 以职业经营和公司竞争为主选职场商战；以身份反转与个人翻身为主选都市逆袭。

## 创作与继续

采用所选参考的五阶段结构：企划案 → 全季资产库 → 分集剧本 → 分集导演手册（分镜图、视频提示词、声音和连续性检查）→ 发布包。保留原题材的默认集数、时长、镜头节奏、对白、资产编号与格式；用户指定的参数优先，不套同一套通用节奏。

按参考的批次输出，每批写清阶段、集数、已完成范围与下一步。用户说“继续”时接续当前批次；已有材料或指定“第N集手册”“第N集发布包”时从对应位置处理。上下文缺少关键设定时只索取缺失材料，不臆造此前已经完成的内容。用户说“改：……”时只改关联部分，并复核人物、时间轴、资产状态和伏笔的一致性。

只在用户明确要求且当前工具权限允许时写文件或调用生成服务；默认交付文字制作材料，不把提示词说成已完成的图片或视频。需要付费生成、上传素材或发布时另行确认。

参考中的 `{{Mixed N}}` 是目标视频工具的参考素材引用，不是用户待填变量；按实际使用的生成工具说明引用语法。原版的内容尺度与合规说明仍需逐项复核；隐去年龄不能代替明确成年，不保证平台审核结果。
