# 口播文稿：3 分钟上手 Cat Chat × ComfyUI（小白版）

- 时长设定：**3 分钟**，中速 **240 字/分钟**
- 正文约 **670 字**（纯念约 2 分 47 秒，加停顿、画面切换刚好 3 分钟）
- 素材：主流程用 **01-home ~ 06-agent-tools 共 6 张截图**；07-mcp 为可选彩蛋镜头
- 读法提示：英文按习惯读（ComfyUI 可念「康菲 UI」，或直接念英文）；`127.0.0.1:8188` 读「本机的八一八八端口」；`cover_api.json` 读「cover-api 点 json」

## 分镜 1｜0:00–0:15 开场钩子

**画面**：04-result.png（先抛成品：消息里挂满封面图的对话截图，压暗背景 + 大标题字幕「不写代码，让 AI 用 ComfyUI 出图」）

> 不用写一行代码，让 AI 替你操作 ComfyUI 批量出图——就像这样，图片直接挂回聊天里。接下来三分钟，跟着点五下，你也能跑通。

（约 48 字）

## 分镜 2｜0:15–0:44 第 1 步：启动 ComfyUI

**画面**：无专用截图，建议 3~5 秒现场录屏（ComfyUI 控制台滚动 + 浏览器打开 8188 页面）；偷懒方案：复用 01-home.png 加字幕「先把 ComfyUI 启动起来」

> 第一步，把 ComfyUI 启动起来。Cat Chat 是指挥官，真正画图的是 ComfyUI。像平时一样启动它，浏览器能打开本机的八一八八端口，就说明它在跑了，保持开着就行。没有 ComfyUI 的，先去官网装一个。

（约 88 字）

## 分镜 3｜0:44–1:14 第 2 步：切到导演 Agent

**画面**：02-agent-switch.png（顶栏 Agent 下拉展开，高亮「导演 Agent 🎬」）

> 第二步最关键，也最容易漏：先在顶栏的 Agent 下拉里选中「导演 Agent」。为什么要先切？因为开始页那些卡片只负责发指令，不会自动帮你换 Agent——出图工具是绑在导演 Agent 身上的，不切过去，AI 手上没有工具，只会回你一句「我没有这个能力」。

（约 118 字）

## 分镜 4｜1:14–1:39 第 3 步：一键让 AI 接管

**画面**：01-home.png（开始页，高亮「通过 HTTP 调用 ComfyUI」卡）→ 1:28 左右切 03-starter-card.png（指令已发出、AI 开始思考）

> 第三步，一键让 AI 接管。新建一个会话，开始页上有一排现成卡片，点那张「通过 HTTP 调用 ComfyUI」——指令立刻发出，不用你打字，也不用回车。AI 会自己探测 ComfyUI 在不在线，接管后面的出图操作。

（约 92 字）

## 分镜 5｜1:39–2:14 第 4 步：大白话出图

**画面**：04-result.png（出图结果）；1:47 左右底部叠字幕条显示示例指令原文

> 第四步，用大白话出图。比如直接说：用 D 盘 workflows 里的 cover-api 点 json，出六张封面，seed 一到六。这个 json 是 ComfyUI 的 API 格式工作流——在 ComfyUI 网页里搭好图，点菜单、工作流、导出 API，存成一个 json 就行。发出去之后，AI 自动把任务提交给 ComfyUI，图片直接挂回消息里，点开看大图；真实文件落盘在 data 下的 generated 目录。

（约 150 字）

## 制作备注

1. 全片仅 8 个镜头，截图全是静态图，建议每张加轻微推近（Ken Burns）避免死板。
2. 字幕务必上：8188、cover_api.json 这类信息念出来听不清，靠字幕补。
3. **分镜 3 是本片的重点**（新增的一步）。它讲的是「点卡不会自动换 Agent」这个坑，剪辑上不要为了赶时间压掉它——漏了这一步，观众做完会发现出图工具不在手上。
4. 若不做进阶内容，分镜 7 砍掉 MCP 两句（约 30 字 / 8 秒），成片 2 分 46 秒，节奏更紧。
