## 三、英雄之旅 (Hero's Journey / Monomyth)

**类型：** 神话结构  
**创始人：** Joseph Campbell（神话学），Christopher Vogler（改编影视）  
**适用范围：** 史诗片、奇幻片、冒险片、超级英雄片

```
┌─────────────────────────────────────────────────────────┐
```

### 英雄vs反派双线对照

| 阶段 | 英雄之旅 | 对应反派弧线 |
|------|----------|--------------|
| 普通世界 | 平凡生活 | 表面秩序 |
| 召唤 | 回应召唤 | 阴谋浮现 |
| 跨越 | 迈出第一步 | 暴露野心 |
| 试炼 | 遭遇困难 | 扩大势力 |
| 严峻考验 | 面临死亡 | 看似胜利 |
| 获得奖赏 | 获得力量 | 获得权力 |
| 浴火重生 | 蜕变 | 受到最终选择的后果 |
| 凯旋而归 | 归来 | 其秩序或影响发生变化 |
