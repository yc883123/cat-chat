## 四、真实执行流程记录（2026-11-05 01:30–01:45，开发隔离实例 8890）

1. W1 工作流 JSON 从正式数据目录**复制**到开发实例（正式只读不动，阶段 0 §五口径）。
2. 造梦机选 W1 → steps 改 9（制造未保存调整）→ 「交给任务总管 · 批量准备」。
3. 交接弹窗：歧义裁决（W1 多文本类槽位，按阶段 0 选 `404>text`，按指纹记住）+ Q3 选「按工作流已保存的值」（试验调整不带入）→ 摘要明示「素材与提示词请在总管逐组填写」「12 个默认素材路径已忽略」。
4. 确认 → 批次页：组卡正文空、素材空、12 槽自动列出；概览「可生成 0 组 · 待补输入 1 组」。
5. 填正文 + 本组时长 5 秒 → 保存 → 「可生成 1 组」→ 逐组按钮「生成这 1 组」。
6. 确认弹窗「生成这 1 组」：预检静默通过（修正后）→ 确认 → 本机执行。
7. 执行约 4 分钟完成 → 「全部完成」→ 产物 `001_00_YZ_H3__00008-audio.mp4`（前缀与工作流 `364>filename_prefix=YZ_H3_` 一致）。
8. 服务重启 + 浏览器刷新后批次/产物完好。

**预检拦截的真实插曲**（如实记录）：首次预检报「节点 14 输入 audio 不在可用选项中」——清空默认名后，执行时会被剔除的可选装载节点的空枚举值被误校验。修正：预检按执行端同序（应用覆盖→剔除未选可选媒体→校验）构建校验图。这正是 C5「前移」要抓的问题类别，修正后静默通过并真实执行成功。
