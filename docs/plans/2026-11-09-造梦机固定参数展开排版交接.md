# 造梦机参数控件预览与桌面展开问题交接

日期：2026-11-09

> 2026-11-10 更新：固定参数 Grid 与编辑回写已在 4.2.0 落地；JSON 数组参数可视化编辑已在 4.2.1-beta 落地。下文里的「怀疑 flex」「JSON 只是预览、未接入生产」都是历史记录，不要再当现状。

## 新对话先处理

用户反馈：4.2.0 已发布，但 JSON 数组参数仍只能作为长字符串处理。交接把 JSON 编辑器列成“暂不处理”，导致只修了固定参数排版就发版。当前要求是直接实现 JSON 数组可视化编辑，并作为 4.2.1-beta 发布；不得再次把“独立预览”误当成产品范围之外。

目标包括：单次生成显示启用数量和编辑入口；共用弹窗可逐项编辑、启用/删除/添加并校验原始 JSON；批量固定参数复用弹窗并回写方案值；批量逐条参数也可逐项编辑并回写该条目。完成测试和桌面/375px 浏览器验收后，按项目发版流程将 4.2.1-beta 推到 master 并核验 Actions 与 Release 资产。

## 当前代码基线（已核对 2026-11-10）

- 当前 `master` / `origin/master` 包含 `1052f767 chore(release): 发布 4.2.0 Beta`。
- 固定参数展开区已是 `display:grid` + `repeat(auto-fill, minmax(260px, 1fr))`，每项有 `.cbm-fixed-field`；不要重复实现旧计划中的 flex→grid 改造。
- 固定参数由 `batchSetFixedValue()` 写回 `scheme.fixed`，`input` 与 `change` 事件都已分支处理；`submitBatch()` 从 `scheme.fixed` 构建 overrides。测试 `tests/test_comfyui_frontend_assets.py` 已检查固定参数标记和值回写。
- JSON 数组字符串仍按普通文本槽渲染。单次入口是 `renderSlot()` / `collectOverrides()`；批量固定入口是 `batchFixedMarkup()` / `batchSetFixedValue()` / `submitBatch()`；逐条入口是 `batchExtraCellMarkup()` / `onBatchInput()` / `submitBatch()` 中的 extras。
- 单次值需保留为 JSON 字符串进入 `comfyui.drafts` 与 overrides；批量固定保留为字符串进入 `scheme.fixed`；逐条值保留为字符串进入 `item.extras[key]`。弹窗内部解析与校验 JSON，应用时 stringify 后写回原字段。

关键入口：
- `public/js/24-comfyui.js`：`renderSlot()`、`collectOverrides()`、`batchFixedMarkup()`、`batchSetFixedValue()`、`batchExtraCellMarkup()`、`onBatchChange()`、`onBatchInput()`、`submitBatch()`。
- `public/index.html`：造梦机页面下现有原生 `<dialog>` 结构，可按同一语义添加 JSON 参数弹窗。
- `public/styles.css`：造梦机参数、批量固定字段及对话框样式；移动端断点在相邻 ComfyUI 样式区。
- 测试：`tests/test_comfyui_frontend_assets.py`、`tests/test_comfyui_batches.py`、`tests/test_comfyui_module.py`。

## 已知产品口径

- JSON 参数行摘要只显示启用项数量，例如「2 项启用」，不显示长文件名、提示词或摘要串。
- 参数行保留来源节点号、`_meta.title` 节点标题、字段名和已有的下游端口映射；当前不显示下游节点标题。
- 媒体槽继续沿用单次生成已有分组/槽位样式，批量不另造媒体控件。
- JSON 数组条目需保留未知字段和值；可视化界面支持对象数组中的常见标量字段、启用开关、增删条目。未知嵌套值仍可通过原始 JSON 编辑，不得应用格式非法或顶层结构不符合该参数要求的数据。
- 对非 JSON 文本保持原控件；只有原值可解析为 JSON 数组/对象且符合支持的数据形态时显示 JSON 编辑入口，避免误把普通文本误判为 JSON。

## 验收和发版

1. 单次参数行显示启用数量与编辑入口；打开后解析当前字段，编辑/取消/应用行为正确，应用后提交值仍为 JSON 字符串。
2. 批量固定参数共用同一弹窗；应用后刷新摘要、更新 `scheme.fixed`，输入状态在重绘后保留，提交 overrides 只带变更值。
3. 批量逐条 JSON 参数按条目打开同一弹窗；应用写入对应 `item.extras[key]`，空值仍代表按工作流，不串条目。
4. 原始 JSON 非法、顶层结构不符、取消弹窗均不覆盖原值；直接编辑原始 JSON 后能重新进入可视化模式或明确报错。
5. 桌面端完成单次/固定/逐条路径；375px 检查弹窗滚动、表单和操作按钮可用，无横向溢出。
6. 运行前端资产、批量后端与相关 ComfyUI 测试，并用真实浏览器做桌面和 375px 验收。
7. 按 `项目维护说明（修改代码前必读）.md` §7 发版流程 bump 到 `4.2.1-beta`，检查版本五处与五项 Release 资产，推 master 后核对 Actions 成功及 exe SHA-256 与更新清单一致。
