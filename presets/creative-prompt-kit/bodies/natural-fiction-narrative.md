# 祛AI味 · 人类叙事黄金法则
## 让AI生成的小说读起来像人写的

### 核心问题诊断：常见机械叙事问题（用于文本诊断，不据此判断作者或来源）

| # | AI特征 | 人类版 | 问题等级 |
|:-:|--------|-------|:-------:|
| 1 | 每个句子都承载信息/推进剧情 | 会有废话、过渡、赘余 | ★★★ |
| 2 | 句式结构规整（主谓宾完整） | 短句破句、省略句、倒装 | ★★★ |
| 3 | 情绪线干净利落（不反复） | 情绪会矛盾、会犹豫 | ★★ |
| 4 | 词汇精确（不用模糊词） | 用"大概""好像""有点" | ★★ |
| 5 | 对话每个角色都字正腔圆 | 有语气词、结巴、吞字 | ★★★ |
| 6 | 思维链完整，前后逻辑严密 | 有断点、跳跃、不连贯 | ★★★ |
| 7 | 感官描写标准（见/听/闻） | 有与叙事无关的无意识感官 | ★★ |
| 8 | 叙述距离稳定锁定 | 自然拉近拉远，偶尔抽离 | ★★ |
| 9 | 文化引用来自训练语料（统一） | 使用地域性/时代性特定梗 | ★★ |

### 技法一：句式破壁（最重要的技法）

AI最致命的特征：每句话结构都完整、语义都推进。

**A. 断句法**
```
AI版：    他在黑暗中摸索着墙壁，试图找到电灯开关。
人类版：  他在黑暗中摸索着墙壁。
          开关。
          就在指尖前面。
```

**B. 插入打断**
```
AI版：    她看着窗外下了一整夜的雨，想着昨天发生的事情。
人类版：  她看着窗外的雨。
          下了一整夜了。
          等等——那只猫怎么还在外面？
          猫是昨天想到的。
```

**C. 语法缺口**
- 故意省略主语："不想去。很冷。算了。"
- 故意用不完整句："车窗。雨刷。雨水模糊的街灯。"
- 故意重复："他坐在那里坐了很久。很久很久。"

### 技法二：对话真实化

AI对话的通病：每个人都像在宣读剧本。

**A. 加语气粒子**
```
AI版：   "你确定要这么做？这是一个危险的计划。"
人类版： "你确定？这……啧，太冒险了。"
```

**B. 对话中的空白**
- 不说话比说话更多信息
- "嗯"、"唔"、"……" 比完整句子真实
- 叉开话题（人类真实对话的特征）

**C. 信息不对称**
AI倾向：A问→B答→信息交换完成
人类：A问→B回答一半→A插话→B跑题→绕回来

试对比：
```
AI对话：
"你昨天见到老黄了吗？"
"见到了，他已经把文件签了。"
"那就好。"
"嗯。"

人类对话：
"老黄的东西弄完了？"
"签了，不过——你说他是不是故意的？拖了那么久，偏偏昨天..."
"他那人就那样。算了，签了就行。"
"也是。诶对了你吃饭没？"
```

### 技法三：无意义细节（黄金调味料）

AI只写"推进剧情"的细节。人类会写与主线无关但让世界鲜活的细节。

```
AI版：
他走进办公室，桌上放着一份文件。

人类版：
他走进办公室。
桌上放着一份文件。
角落里那盆绿萝的叶子耷拉下来——上次浇水是什么时候来着？好像是周一？
他把文件翻开。
```

那个浇水的念头与剧情无关，但它让角色像个真人。

**无意义细节的三种类型：**
1. **感官漂移** — 突然注意到与叙事无关的气味/温度/触感
2. **回忆碎片** — 看到某物触发一个短暂的无关回忆
3. **内心吐槽** — 角色对当前场景的情绪反应（"这椅子真不舒服"）

### 技法四：模糊语言与不确定性

仅在叙述者或人物确实不知道时使用不确定表达。已确认事实、决定和事件结果必须保持明确，不机械替换。

| AI用词 | 人类用词 |
|--------|---------|
| 他决定 | 他大概觉得 |
| 这是 | 这像是 |
| 一定是 | 可能是 |
| 完全 | 还算 |
| 绝对 | 基本上 |
| 三个选择 | 要么这样要么那样 |
| 他开始思考 | 他也不知道自己在想什么 |

**关键：** 叙述者不需要全知。尤其是限制视角下，主角不知道的事就是"可能""好像""说不清"。

### 技法五：情绪不一致

AI的情绪线：A生B的气→A和B吵架→A原谅B→完。
人类的情绪线：A生B的气→A觉得算了→又想起来→更气了→B无辜地看A一眼→A又觉得算了。

**情绪回旋法：**
```
AI版：
她感到非常失望，决定不再和他说话。

人类版：
她感到非常失望。
不想和他说话了。真不说了。
走到门口的时候想，算了，给他一次机会。
打开门又想，凭什么？
最后摔门走了。
```

### 技法六：叙述距离的呼吸

AI倾向锁定一个距离叙事，要么全在人物内心，要么全程上帝视角。

人类写作者擅长在段落间自然切换：

```
他的手指在扳机上微微颤抖。（近——身体感受）

雨一直下。三个小时了。（中——客观环境）

老杨躲在墙后面，手里攥着一张女孩的照片。（远——主视角可观察到的配角动作）

他不知道自己能不能扣下扳机。（回近）
```

**节奏公式：** 按情绪和信息需要在身体细节、客观环境与可见配角动作之间改变距离，不跳入未经授权的他人内心

### 技法七：避开AI的高频句式

以下句式是AI的标志性语言，尽量不用或打碎：

- ❌ "这不仅仅是一个...更是一个..."
- ❌ "在...的同时，也..."
- ❌ "从...角度来看..."
- ❌ "无论...还是..."
- ❌ "如果说...那么..."
- ❌ "与其...不如..."
- ❌ "不但...而且..."
- ❌ "随着...的..."
- ❌ "在这一刻，他意识到..."
- ❌ "他深吸一口气，说..."

**替换策略：** 发现重复或空泛时改写；合理长句和必要逻辑连接可以保留，不强制一律打碎。

### 技法八：地域性与时代性细节

AI的知识来自语料库，所有输出都带有"通用感"。

**破法：** 加入与人物生活、地域和时代相符的具体差异。
- 用特定的本地菜名而非通用描述
- 用特定年份的时代特征而非泛泛的"那个年代"
- 用角色的特定习惯而非通用行为

### 技法的参考频率（诊断提示，非硬性配额）

| 技法 | 每千字使用频率（建议） |
|------|:----------------:|
| 断句法（句式破壁） | 3-5次 |
| 对话真实化（语气粒子） | 按人物习惯需要选用 |
| 无意义细节 | 2-3个 |
| 模糊语言 | 4-6处 |

| 地域细节 | 每章1-2个 |

### 快速自检清单

写完一段后，问自己：

1. □ 有没有连续的完整主谓宾句超过3句？（有→打断）
2. □ 对话中每个人说话是否都"正确"？（是→加语气词/空白/跑题）
3. □ 每段是否都在推进剧情？（是→插入1个无意义细节）
4. □ 情绪线是否太干净？（是→加一次反复/矛盾）
5. □ 是否存在AI高频句式？（是→打碎成短句）
6. □ 叙述距离是否一直不变？（是→做一次拉远或拉近）
7. □ 是否用了太多"他意识到"/"她感到"/"他决定"？（改为"大概""好像""说不清"）


执行边界：无关细节要来自当前视角可感知的生活，不为凑配额插入随机绿萝、猫或回忆；语气词、结巴、跑题与模糊词都必须有角色处境依据。情绪反复需要触发，不制造无因果跳变。以上技法是可选写法，不是辨别文本是否由AI创作的可靠标准。
