## 0. 一页结论

本计划把两件事合并成一次版本升级，共用同一批内置 Agent、预设和工具目录改动：

1. **`show_media`**：用户明确要求展示某个已有图片/视频/音频时，把唯一匹配的文件作为当前助手回复的媒体卡呈现；不明确、零匹配、多匹配一律先问。
2. **`run_in_background` 默认开放**：标准、长会话、ComfyUI 三档预设重新带上后台创建器与完整查询闭包，任务型内置 Agent 在新会话里可以把长任务提交为后台 Job。

两条硬边界：

- **旧会话迁移只追加 `show_media`**，绝不顺带补后台工具。后台工具只对新会话生效。
- **不做「运行超时自动转后台」**。`pwsh` / `run_skill_script` 保持同步语义，由模型在启动前选择后台入口。

## 2. `show_media` 行为契约

### 2.1 两道独立门槛

工具调用必须同时通过：

1. **用户意图门**：`RunContext.show_media_intent` 为真。
   - 只从本轮用户原文计算；不取路由增强文本、Agent 提示或历史助手文本。
   - 只有承载用户原始请求的**普通主对话 Run** 可置位。
   - 辅助对话、Plan 准备、Plan 执行、子 Agent、后台 Job 一律为假。
   - 否定、假设、引用/转述、仅提及媒体不放行。
2. **目标授权门**：`RunContext.show_media_candidates` 只含两类候选：
   - (a) 当前会话已记录的媒体：`metadata.attachments` + `tool_runs[].media`；
   - (b) 本轮用户原文明确给出的工作区内路径/文件名。
   - 不扫工作区、不查其他会话、不搜索宿主全局 `generated`、不凭 basename 猜路径。

两道门任一失败都不产生媒体记录，返回结构化 `skipped` 与稳定原因。

### 2.2 参数与拒绝原因

- 参数：`paths: string[]`，**单次最多 1 个**。
- 拒绝原因枚举：
  `intent_required`、`ambiguous`、`not_found`、`not_media`、`outside_root`、`over_limit`、`too_large`、`unreadable`。
- `paths` 为空、非数组、元素非字符串、两项以上、重复项：拒绝，不做部分展示。
- 所有校验先完成，再进入采集；任一失败不得产生半张卡。

### 2.3 目标解析规则

1. 规范化后精确匹配会话候选（本地路径按 `normalized_path_key`，URL 按原串）。
2. 用户原文出现明确路径/文件名时：
   - 相对路径按**本轮冻结工作区**解析；
   - 解析后必须仍在工作区内（符号链接按真实目标判定，越界拒绝）；
   - 必须是存在文件、后缀属于 `core/media_types.py::media_kind_of` 支持的媒体类型。
3. 用户用代词/模糊指代（如「刚才那个视频」）时：
   - 从候选集合按媒体类型过滤；
   - 恰好 1 个 → 允许；
   - 0 个 → `not_found`；
   - 多个 → `ambiguous`，返回安全的候选展示名供模型追问，不挑最新、不挑第一个。
4. 仅 basename 冲突 → `ambiguous`。
5. 目录路径 → `not_media`；伪造扩展名 → `not_media`；不可访问 → `unreadable`。

### 2.4 容量与副作用

- 上限常量：`MEDIA_SHOW_MAX_BYTES = 80 * 1024 * 1024`，与 `UPLOAD_MAX_BYTES` 同源（见 §4.1）。
- 本地文件超过上限：只读 `stat`，返回 `too_large`；**不读取全文、不复制、不创建缩略图、不写 generated**。
- 允许且未超限：
  - 复用现有 `MediaCollector` 的内容哈希去重；
  - 首次未命中才复制到 `data/generated` 并生成缩略图；
  - 命中既有副本不重复写盘；
  - 复用现有 generated 清理回调。
- 消息记录只保存小型媒体元数据（`kind/name/source/thumb_path`），媒体字节不进 SQLite、不进模型上下文。

### 2.5 工具结果与脱敏

成功返回（原始结果，供采集器读取）：

```json
{"ok": true, "status": "shown", "kind": "image", "name": "a.png", "source": "<真实路径>", "thumb_path": ""}
```

模型可见结果只保留：

```json
{"status": "shown", "kind": "image", "name": "a.png"}
```

失败返回：

```json
{"ok": false, "status": "skipped", "reason": "ambiguous", "name": ""}
```

`core/tool_results.py::model_visible_result` 增加 `show_media` 分支，剥掉 `source` / `thumb_path` / 任何绝对路径。展示通道仍保留 `run.media` 供前端出卡。

## 3. `run_in_background` 默认开放契约

### 3.1 预设变化

| 预设 | 现状 | 变更后 | 新增 |
|---|---|---|---|
| 只读模式 | 6 | 6 | 无 |
| 标准模式 | 13 | **18** | `run_in_background` + `job_output` / `job_status` / `job_wait` / `job_kill` |
| 长会话模式 | 17 | **22** | 随标准模式新增同一组 |
| ComfyUI 联动 | 18 | **20** | `run_in_background` + `job_kill`（其余三个查询工具已在） |
| 全能模式 | 全部 | 全部 | 随注册表自动包含，无需手改 |

- `_DEFAULT_SELECTED_TOOLS` 必须同步为新的标准模式 18 件。
- 预设必须显式列出依赖闭包，保证「卡片显示个数 = 套用后实际个数」。
- 前端 `AGENT_TOOL_DEP_RULES` 已包含 `run_in_background`，不改。

### 3.2 内置 Agent 变化

| Agent | 预设基础 | 现状 | 变更后 | 新增 |
|---|---|---|---|---|
| `tutor` | 只读 | 6 | **7** | `show_media` |
| `master` | 长会话 | 17 | **23** | 标准新增 5 件 + `show_media` |
| `director` | ComfyUI | 18 | **21** | `run_in_background` + `job_kill` + `show_media` |
| `prompter` | 自定义只读写稿 | 7 | **8** | `show_media` |
| `coder` | 标准 | 13 | **19** | 标准新增 5 件 + `show_media` |
| `skills` | 标准 + 装拆查 | 16 | **22** | 标准新增 5 件 + `show_media` |

- `tutor` / `prompter` **不获得**后台工具。
- `director` 的 ComfyUI 工作流仍优先 `comfyui_batch`；`run_in_background` 用于其他支持的后台任务。
- 教程助手不再对外称「只读」，改称「不改源文件、不跑命令、不能编辑工作区；展示媒体时可能生成内部预览副本」。

### 3.3 提示词

1. 后台任务建议**只在创建器和查询依赖实际可用时**注入：
   ```python
   if {"run_in_background", "job_output", "job_status", "job_wait"} <= allowed:
       ...
   ```
   现有 `skills/agent.py` 里「只要 `comfyui_batch` / 子 Agent 工具在就提 `run_in_background`」的过宽条件必须收窄：只提实际可用的入口。
2. `show_media` 提示只在 `show_media in allowed_tools` 时注入：
   - 明确展示已有媒体用 `show_media`；
   - 发现目录内容仍用 `list_directory`；
   - 一次只传一个明确目标；
   - 目标有歧义先问；
   - 禁止为满足展示请求而目录扫描。
3. 提示词只负责教模型何时调用；真正防误触的是 RunContext 授权、唯一候选解析、工作区与大小校验。

## 5. 迁移设计（A+B 合并的关键）

### 5.1 配置迁移

**位置**：`naiba/config.py::ConfigStore.__init__`，在 `_migrate_legacy_tool_names()`、`_migrate_retired_factory_agents()` 之后、`save()` 之前。

**基线**：冻结「变更前出厂 scope」常量：

```
tutor     = readonly 6
master    = longsession 17
director  = comfyui 18
prompter  = 7
coder     = standard 13
skills    = standard + 装拆查 = 16
```

**新增集合**：

```
show_media = {"show_media"}
background = {"run_in_background", "job_output", "job_status", "job_wait", "job_kill"}
```

按 Agent 分配：tutor/prompter 只加 `show_media`；master/coder/skills 加 `show_media + background`；director 加 `show_media + run_in_background + job_kill`。

**判定规则**（幂等、可处理 A/B 任意先后）：

1. 只处理 `id` 属于当前 6 个内置 Agent 的已保存覆盖项。
2. `tool_scope` 为空/缺省 → 「不限制」，**保持原样**。
3. 记 `current = set(scope)`。
4. 若 `current` 含任何 **不在** `baseline ∪ additions` 里的工具 → 用户定制，保持原样。
5. 若 `baseline ⊄ current`（用户删过出厂工具）→ 用户定制，保持原样。
6. 否则 → 按目标顺序补齐缺失的 additions，写回 `tool_scope`。
7. 只改 `tool_scope`，不动名称、提示词、Skill、头像、顺序、其他工具。
8. 重复运行不重复追加。

这正好覆盖：

| 已存 scope | 结果 |
|---|---|
| 原始出厂 | 补齐 A+B 全部新增 |
| 原始 + `show_media`（B 先跑） | 只补后台工具 |
| 原始 + 后台工具（A 先跑） | 只补 `show_media` |
| 原始 + 任意其他工具 | 不动 |
| 原始少一个工具 | 不动 |
| 空/未设置 | 不动 |
| 自定义 Agent / 已退役 Agent | 不动 |

  - 重复运行稳定。
- **绝不补后台工具**：旧会话行为不变。
- 内置 Agent id 在 store 侧用冻结常量，并由测试断言等于 `built_in_agent_ids()`，避免存储层反向 import 配置层。
- 迁移在 `ChatStorage.__init__` 的 `apply_pending_migrations()` 中、任何 Run 开始前完成并持久化。

### 5.3 迁移顺序与失败恢复

- 配置迁移与数据库迁移互不依赖；两者都在应用启动期、Run 开始前完成。
- 先配置后数据库或反之都安全：配置迁移按「基线 + 新增子集」判定，数据库迁移只补 `show_media`。
- 任一步中途崩溃：
  - 配置 `save()` 是整体写；未保存则下次重跑；
  - 数据库 `user_version` 未推进则下次重跑；
  - 两个迁移都幂等。
- 新会话按新 Agent scope 固化时自然包含 `show_media` 与后台工具；已有会话只多 `show_media`。

## 7. 测试矩阵

### 7.1 `show_media` 意图与安全

- 正例：
  - 「显示这个文件」且目标唯一；
  - 「把刚生成的唯一视频放出来」；
  - 「播放刚才那段音频」。
- 反例：
  - 仅提到视频；
  - 询问视频内容但未要求展示；
  - 「不要播放视频」；
  - 「如果把视频放出来会怎样」；
  - 引用「他说‘播放视频’」；
  - 仅助手历史说过展示。
- 未授权 Run：aux、Plan 准备、Plan 执行、子 Agent、Job 均返回 `intent_required` 且无 `run.media`。
- 误调保护：构造完全匹配的路径但缺授权，仍不出卡。

### 7.2 目标与路径

- 唯一历史附件、唯一本轮路径 → 一张卡；
- 零候选 → `not_found`；
- 多候选 → `ambiguous`；
- 同 basename 多路径 → `ambiguous`；
- 绝对/相对工作区内路径通过；

- 超过 80MB → `too_large`，断言未发生全文件读取、未创建 generated 文件、未写缩略图；

- 重复展示 → 命中内容哈希，不重复复制；

## 11. 已知风险与限制

1. **自然语言意图无法数学保证**：可靠性承诺是「误判不能绕过后端授权与唯一目标校验而出卡」；模糊输入追问优先。
2. **工具定义变化会断一次前缀缓存**：六个内置 Agent 的主会话新增 `show_media`，模型工具数组字节变化一次；迁移只追加这一件，且由意图/路径/大小闸门约束。
3. **教程助手有本地写入副作用**：首次展示可能复制到应用媒体目录并生成缩略图；源文件不改；已有副本去重。对外文案必须说清，不能再称「只读」。
4. **预设工具数增加**：标准 +5、长会话 +5、ComfyUI +2，模型可见工具列表变长，可能轻微影响选择与提示词长度。
5. **后台工具仍依赖模型判断**：不是运行时保证；模型不选就仍是同步等待。
6. **旧会话能力不一致**：升级后旧主会话有 `show_media` 但没有后台工具；这是刻意选择，避免对已固化快照追溯扩权。
7. **Agent 标签是显示层增强**：不改变匹配、删除引用、覆盖保护等行为；用户点回纯预设会移除 `show_media`，这是预期结果。
