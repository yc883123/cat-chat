## 一、核心框架：三密度体系（小说版）

三密度不是三个独立指标，是一个叙事系统的三个切面：

```
信息密度（骨骼）→ 情节密度（肌肉）→ 情绪密度（皮肤）

检测逻辑：从皮肤往里查
  情绪不到位 → 查情节有没有支撑
  情节没问题 → 查信息有没有铺垫
  哪层断了修哪层
```

### 小说 vs 短剧的核心差异

| 维度 | 短剧 | 女频短篇 |
|------|------|----------|
| 信息密度 | 每10-15秒1个有效信息 | 每500字1个新信息 |
| 情节密度 | 每集2-3个拐弯 | 每1000字1个处境变化 |
| 情绪密度 | 每30秒1个情绪节点 | 每1000字1次情绪变化 |
| 检测粒度 | 秒级 | 段级（500-1000字） |
| 核心威胁 | 跳出（随时划走） | 弃读（翻页动力不足） |
| 密度逻辑 | 压缩 | 节奏（疏密交替） |
| 耦合要求 | ≥60% | ≥50% |

---

## 二、信息密度（骨骼层）

### 定义

信息密度 = 每500字内"改变读者认知状态的有效信息单元"的数量

### 有效信息单元判断标准

- **a) 认知增量**：知道了之前不知道的事实
- **b) 人物重估**：对某个角色的判断发生了修正
- **c) 悬念更新**：对后续发展的预期发生了变化
- **d) 逻辑补全**：理解了某个行为的动机

### 密度基准线

| 等级 | 标准 |
|------|------|
| 高 | 每500字≥3个 |
| 中 | 每500字2个 |
| 低 | 每500字≤1个 |

### 信息过载边界

- 每500字＞6个 = 过载
- 读者需回看 = 过载

---

## 三、情节密度（肌肉层）

### 定义

情节密度 = 每1000字内"改变主角处境的因果事件"的数量与质量的乘积

### 拐弯分级

| 级别 | 权重 | 示例 |
|------|------|------|
| 小弯 | 1分 | 获得一条线索、失去一个小优势 |
| 中弯 | 3分 | 从优势变劣势，或反过来 |
| 大弯 | 5分 | 身份暴露、关系断裂、生死转折 |

### 密度基准线（每1000字）

| 等级 | 标准 |
|------|------|
| 高 | ≥6分 |
| 中 | 4-5分 |
| 低 | ≤3分 |

### 情节因果链检测

- **强因果**：A直接导致B
- **弱因果**：A间接导致B
- **无因果**：A和B只是先后发生 → 情节堆砌，需修复

---

## 四、情绪密度（皮肤层）

### 情绪强度分级

| 级别 | 名称 | 读者反应 |
|------|------|----------|
| L1 | 微澜 | 轻微情绪反应 |
| L2 | 共振 | 明确情绪 |
| L3 | 冲击 | 强烈生理反应 |
| L4 | 失控 | 情绪溢出 |

### 密度基准线（每1000字）

| 等级 | 标准 |
|------|------|
| 高 | 切换≥2次 + 峰值L3 |
| 中 | 切换1次 + 峰值L2 |
| 低 | 无切换 或 峰值仅L1 |

### 女频核心情绪公式

```
压迫段：憋+委屈+怒（蓄力）
反击段：爽+释然（释放）
收尾段：暖+决绝（定调）
```

### 情绪过载边界

- 每1000字切换＞4次 = 过载
- 全文L4节点≤3个
- 至少触发4种不同情绪类型（愤怒、心疼、憋屈、震撼等）
- 单一情绪重复 = 脱敏

### 荒诞感检测

```
震撼 = "我没想到会这样"（可信范围内）
荒诞 = "这不可能是真的"（超出可信范围）

检测：讲给朋友听，朋友说"太过分了"还是"太假了"？
  → "太过分了" = 有效 
  → "太假了" = 出戏 
```

### 物理暴力十级量表（L1-L10）

| 等级 | 类型 | 情绪产出 |
|------|------|----------|
| L1 | 语言轻蔑 | 愤怒L2 |
| L2 | 语言羞辱（公开） | 愤怒L2+心疼L2 |
| L3 | 经济剥夺 | 愤怒L3+不公L3 |
| L4 | 社会性伤害 | 憋屈L3+愤怒L3 |
| L5 | 轻度肢体暴力 | 愤怒L3-L4 |
| L6 | 限制人身自由 | 不安L3+愤怒L3 |
| L7 | 中度肢体暴力 | 愤怒L4 |
| L8 | 严重身体伤害 | 震撼L4+愤怒L4 |
| L9 | 生命威胁 | 不安L4+愤怒L4 |
| L10 | 致死/等同于致死 | 取决于真实感 |


| 等级 | 类型 | 示例 | 情绪产出 |
|------|------|------|----------|
| PL1 | 冷淡/忽视 | 不回消息、"嗯""哦""随便" | 不安L1 |
| PL2 | 贬低/否定 | "你怎么连这点事都做不好""你太敏感了" | 憋屈L2 |
| PL3 | 道德绑架 | "我为你付出了这么多，你就不能体谅一下？" | 憋屈L3+愤怒L2 |
| PL4 | 煤气灯效应 | "你记错了""这件事根本没发生过""你是不是又犯病了" | 不安L3+愤怒L3 |
| PL5 | 联盟孤立 | 所有人都站在施虐者一边，告诉主角"是你的问题" | 憋屈L4+无力L4 |
| PL6 | 身份剥夺 | 剥夺职业、社会关系、经济来源、名誉 | 愤怒L3+心疼L3 |
| PL7 | 亲密关系武器化 | 用性、用孩子、用共同记忆作为攻击工具 | 厌恶L4+震撼L3 |

| PL9 | 存在否定 | "你活着有什么意义""没有人需要你" | 心疼L4+不安L4 |
| PL10 | 逼迫自我毁灭 | 通过系统性心理压迫，让受害者"主动"选择死亡 | 取决于过程可信度 |

### 双量表使用规则

**通用规则：**
- 起始不超过量表的30%（物理≤L3，心理≤PL3）
- 每次升级跨度不超过2级
- L5+/PL5+事件之间至少间隔800字沉淀空间
- L8+/PL7+事件全篇不超过2次
- L10/PL10只出现1次，且必须是压迫期终点

**心理操控的特殊规则：**
- 心理操控的"可信度天花板"高于物理暴力（PL8-9仍可信）
- 但过载风险不是"不可信"而是"太窒息导致读者想逃"
- 心理操控的"最致命一击"往往不是最极端的那个，而是一句轻描淡写的漫不经心的话
- 例："等她自己回来"（PL1的形式，PL10的效果）

## 六、真实感阈值系统

### 三维检测

- **维度A：行为可信度** — 角色行为是否符合身份/智力/社会地位？
- **维度B：环境可信度** — 事件在现实中的同一场所会不会被阻止？
- **维度C：后果可信度** — 事件后续是否符合现实逻辑？

### 维护规则

1. L7+/PL7+事件必须有"环境隔离"
2. 反派的权力必须有边界
3. 每1000字做一次"真实感体检"
4. **真实感一旦崩塌，无法修复** — 宁可牺牲暴力强度，也不能牺牲真实感

## 七、压迫期内部节奏模板

### 三幕式结构

**第一幕：建立（30%）** — L1-L3 / PL1-PL3，建立主角可爱点+反派初始恶
**第二幕：升级（50%）** — L3→L7 / PL3→PL7，每次升级有锚点+间隔，含虚假希望×2+意外盟友
**第三幕：极限（20%）** — L7-L8 / PL7-PL8，全篇第一个L4出现在这里

## 十、反派设计体系

### 反派行为一致性检测

对每个反派建立"身份-能力-行为"一致性表，行为必须与身份/智力/社会约束匹配。


标志性台词模式：
- **轻描淡写化**："没事，他们就是群孩子胡闹"
- **转移焦点**："霜霜被划伤，我送她去医院"
- **合理化施虐**："都快当妈的人了，怎么还这么不稳重"
- **施舍式关心**："典礼结束，我们去领证"

设计规则：
1. 他必须偶尔"好"（5%温柔+95%冷漠=最有效的情感控制）
2. 他的冷漠必须有"合理的自我叙事"（他觉得自己在平衡两边）
3. 他的"醒悟"必须付出不可逆的代价
4. "最后一击"应该是沉默——在最需要他的时刻，他什么都没做
5. **错位关心比完全不关心更有杀伤力**——他不是不爱你，他只是不知道怎么爱你


为什么双面人的情绪产出更高：同时触发三种情绪（对反派的厌恶+对旁观者的愤怒+替主角的憋屈）

设计规则：
1. "人前面具"必须有合理的成因
2. 必须给读者至少1次"看穿面具"的机会
3. 双面人的"翻车"必须是公开的（摧毁公众形象=摧毁武器）
4. "真面目"不能太早暴露给所有人（节奏：先读者→再1-2角色→最后所有人）
5. 被揭穿后的反应决定最终定位：崩溃=可悲 / 反击=纯粹 / 平静承认=复杂


核心：利用角色"不想面对真相"的心理，让谎言被主动接受。

- 最有效的欺骗不是让人相信假的，而是给人一个不面对真相的理由
- 人们不是被骗了，他们选择了被骗
- 提供者和接受者都有罪

---


### 设计规则

1. **必须在故事前30%建立情感连接**
2. **物件的状态变化 = 关系的状态变化**（戴着=还爱，摘下=放弃，碎了=毁灭）
3. **物件在高潮时刻出现 = 情感放大器**（空空的手指比任何台词都有力）
4. **每篇最多2-3个关键物件**（一个代表爱情线，一个代表亲情线）
5. **物件不能"解释"，只能"呈现"**（让读者自己理解含义）

|------|------|------|------|

合法功能：
1. **信息揭露** — 死后才能看到的信息 → 不可逆的遗憾
2. **情感审判** — 观察生者的反应 = 角色的终极真相
3. **悲凉的讽刺** — 死者旁观生者的荒唐
4. **为代理复仇铺垫** — 展示复仇动机如何形成

- 主角情绪应为"平静的悲伤"而非愤怒

### 三个层次

| 层次 | 定义 | 效果 |
|------|------|------|
| 反抗（最高） | 直接对抗压迫 | 敬佩+紧张 |
| 选择（中等） | 在两个坏选项中做出选择 | 理解处境 |
| 内心抵抗（最低） | 行为顺从但内心未屈服 | 精神未碎 |

### 使用规则

- 压迫期中至少3次能动性表现
- 其中至少1次是"反抗"
- 至少1次反抗产生"微小的胜利"
- 如果主角选择死亡：内心状态必须是"主动选择"而非"被动放弃"

四个维度：
1. **情感围猎**（亲密关系者）— 利用爱来控制
2. **社会围猎**（社会关系者）— 舆论+孤立
3. **权力围猎**（权力持有者）— 剥夺身份/资源
4. **暴力围猎**（群体执行）— 肉体+语言暴力

设计规则：
1. 四个维度不应同时出现，应逐步叠加（情感→社会→权力→暴力）
2. 每个围猎者有不同的"自我合理化"（不是一群坏人害好人，而是每个人都觉得自己在做对的事）
3. 围猎中必须有一个"缝隙"（完美围猎=不可信）
4. "收网时刻"是唯一允许四维度同时出现的节点

### 核心检测

**去掉系统后，故事是否仍然成立？** 如果成立→系统是装饰→删除

### 合法叙事功能

- **信息不对称**：系统让主角知道别人不知道的
- **选择困境**：系统制造"没有系统就不存在的困境"
- **能力赋予**：给主角力量但被束缚
- **叙事节奏控制**：倒计时节点对应情节转折

### 使用规则

1. 如果去掉系统故事仍成立→不要加系统
2. 系统必须制造"独特的困境"
3. 系统规则必须在开篇100字内交代清楚
4. 系统不能是"万能解药"（结尾不能突然提供没铺垫的能力）
5. 系统提示频率：每1500-2000字一次，每次必须携带新信息或制造新压力

---


1. 不要美化加害者的"醒悟"（醒悟≠赎罪≠被原谅）
2. 不要用死亡来"解决"道德困境（活着面对后果>死亡解脱）
3. 允许读者有复杂的感受（呈现事实，让读者自己判断）
4. 收束期不需要"治愈"（有些故事的最好结局是"她活下来了，带着伤疤"）
5. 反派的"自洽性"比"纯恶"更有力量

**规则A：压迫起始点定律**
- 压迫期第一个事件，暴力等级≤总量表的30%
- 从1楼到10楼的落差感 > 从7楼到10楼

**规则B：沉淀间隔定律**
- L5+/PL5+事件后必须≥800字沉淀空间
- 沉淀内容：主角感知变化、环境冷漠对比、微小的日常动作

**规则C：虚假希望定律**
- 压迫期至少2个虚假希望节点
- 粉碎速度>建立速度

**规则D：善意锚点定律**
- 无论压迫多严酷，必须有≥1个善意锚点
- 最低成本：路人一个善意动作（50字）

**规则E：主角能动性底线**
- 至少1次"微小的胜利"
- 证明"反抗不是完全无用的"

**规则F：反派可信度守恒**
- 可信度 = 行为逻辑 × 环境合理性
- 两者都满足=可信，任一不满足=出戏

**规则G：收束期重量守恒**
- 收束期的情绪重量必须≥压迫期
- 重量消解标志：读者觉得"还好嘛"→失败
- 重量守恒标志：读者仍然"心里堵着"→成功

**规则H：情绪类型多样性**
- 一篇故事至少触发4种不同情绪类型
- 单一情绪重复=脱敏

**规则I：物件叙事效率**
- 每篇1-3个关键物件，前30%建立连接，至少出现3次

**规则J：叙事视角承诺**
- 开篇选定视角=对读者的承诺
- 短篇中视角切换≤2次

□ 主角是否有至少1次"微小的胜利"？
□ 主角是否有"内心堡垒"？
□ 反派行为是否通过一致性检测？
□ 是否触发了至少4种不同的情绪类型？
□ 性内容是否通过了必要性检测（≤3处）？

### 【反派检查】
□ 反派是否有"合理的自我叙事"？
□ 反派智商是否与社会地位匹配？
□ 双面人反派：是否给了读者"看穿面具"的机会？
□ 漠视型反派：是否有"偶尔的好"维持关系可信度？
□ 围猎结构中，每个围猎者是否有不同的"自我合理化"？

### 【系统检查】（如有）
□ 去掉系统后故事是否仍成立？（是→删除系统）
□ 系统是否制造了"独特的困境"？
□ 系统规则是否在开篇100字内交代清楚？

□ 复仇是否由主角亲自执行？（否→爽感折扣是否可接受？）
□ 收束期情绪重量是否≥压迫期？
□ 是否有不可逆的代价/伤疤？
□ 加害者的"醒悟"是否被过度美化？
□ 结局是否尊重了伤害的重量？

### 【物件检查】
□ 是否有1-3个关键物件？
□ 物件是否在前30%篇幅建立情感连接？
□ 物件是否至少出现3次且每次含义不同？
□ 物件最后一次出现是否在高潮/收束的关键时刻？

□ 叙事视角是否全程一致？
□ 视角切换是否≤2次？
□ 切换点是否是重大事件？

### 二、钩子类型清单

开局钩子必须在前三屏（约500字）内抓住读者。常见钩子类型：

| 钩子类型 | 示例 | 情绪启动 |
|---------|------|---------|
| 当场背叛 | 婚礼上新郎吻了闺蜜 | 愤怒L3+心疼L2 |
| 孩子被害 | 孩子被夺/流产/被剜心 | 心疼L4+愤怒L3 |
| 财产被吞 | 抚恤金/嫁妆/遗产被侵吞 | 愤怒L3+不公L3 |
| 身份错位 | 真假千金/冒牌货/顶罪 | 好奇L2+不平L2 |
| 至亲背刺 | 丈夫/父亲/哥哥站在反派那边 | 心寒L3+愤怒L2 |
| 死前觉醒 | 主角死前一刻发现真相 | 震撼L4+悲凉L3 |
| 强权碾压 | 贵妃/婆婆/首长当面羞辱 | 憋屈L3+愤怒L2 |

**规则：开篇第一个事件，必须直接抛出"极不公平"——让读者第一时间站队主角。**

### 三、背叛层级排序

"亲近关系背叛"的痛感 > "陌生人害人"的痛感。具体排序：

| 层级 | 背叛关系 | 痛感 | 示例 |
|------|---------|------|------|
| L1 | 陌生人伤害 | 低 | 路人欺负主角 |
| L2 | 远亲/同事伤害 | 中低 | 姑姑帮反派说话 |
| L3 | 朋友背叛 | 中 | 闺蜜抢男友 |
| L4 | 伴侣背叛 | 高 | 丈夫出轨 |
| L5 | 父母/成年子女背刺 | 极高 | 父亲偏心私生子、儿子站队情人 |
| L6 | 最信任的人联合下刀 | 最强 | 丈夫+闺蜜+儿子三方背叛 |

**规则：核心背叛优先来自亲密关系，是否采用L4以上按本篇目标决定。低于L4的背叛做主线，痛感不够。**

### 四、反派台词库


**轻描淡写型**（漠视型反派）
- "你太敏感了"
- "你别无理取闹"
- "只是演戏而已"
- "你能不能别这么小气"

**合理化施虐型**（控制型反派）
- "我是为你好"
- "她比你更需要"
- "你要体谅大局"
- "男人都这样"

**道德绑架型**（围猎型反派）
- "我为你付出了这么多"
- "你妈一个人不容易"
- "都是一家人，至于吗"
- "你爸尸骨未寒你就想着分钱"

**羞辱型**（直接伤害）
- "你连个孩子都保不住"
- "除了我谁还会要你"
- "你这么脏，不配当妈"
- "你活着有什么意义"

**规则：反派的每句台词须符合反派自我合理化并暴露关系压力。**

### 五、隐藏优势设计规则

爆款主角必须"表面弱，实际能翻盘"。5种隐藏优势：

| 优势类型 | 示例 | 爽感来源 |
|---------|------|---------|
| 隐藏大身份 | 千年老祖、真公主、幕后大佬 | 身份碾压型 |
| 核心证据 | 录音、日记、转账记录、鉴定结果 | 证据反杀型 |
| 极强忍耐力 | 表面顺从实际在布局 | 蓄力爆发型 |
| 强决断力 | 发现真相立刻切割不回头 | 觉醒止损型 |
| 离开的能力 | 有钱/有技能/有退路 | 独立自由型 |

**规则：主角必须具备至少1种隐藏优势。没有隐藏优势的主角=被动受苦的肉，读者会从"心疼"变成"你为什么不反抗"。**

### 六、切割硬规则

反派追悔莫及时，主角必须做到以下全部：

1. **绝不回头** — 不管反派怎么哭、怎么求、怎么下跪
2. **不原谅** — "对不起"不能撤销伤害
3. **不解释** — 不需要向反派证明自己过得好
4. **不内耗** — 离开之后就是新生活，不再纠结
5. **不留悬念** — 结尾不要暗示"也许未来会复合"

**核心原则：爽文的爽，不在"报复有多狠"，而在"我不再需要你"。**

违反以上任何一条 = 爽感打折。违反两条以上 = 读者觉得"白憋屈了"。

### 七、四段式情绪推进

```
钩子期（前10%）：直接抛冲突 → 情绪L1→L2
压抑期（10%-55%）：反派持续加码 → 情绪L2→L3边缘
爆发期（55%-85%）：摊牌/证据/切割 → 情绪L3→L4
新生期（85%-100%）：新生活+旧人追悔 → 情绪L2稳定回落，保留满足感
```

**新生期 ≠ 收束期。** 收束期是"事情的结局"，新生期是"主角的重生"。新生期必须包含：
- 主角进入更好的生活（新伴侣/新事业/新身份/新自由）
- 旧人追悔但无法挽回（至少1个"追悔莫及"场景）
- 读者感到"离开烂人烂事，人生会更好"

### 八、情绪节点必须和情节强绑定

**没有事件支撑的情绪=空。** 每个情绪节点必须对应一个明确事件：

- 被打耳光 → 羞辱（不是"她觉得很屈辱"）
- 丈夫出轨 → 背叛（不是"她觉得被抛弃"）
- 法庭播放录音 → 爽点爆发（不是"她觉得很爽"）
- 离婚签字 → 切割（不是"她觉得自由了"）

**检测方法：** 删掉事件，情绪还在不在？如果在=情绪是空的，需要补事件。

### 九、选题公式

爆款 = 熟悉套路 + 新鲜设定

| 熟悉套路 | + | 新鲜设定 | = | 爆款组合 |
|---------|---|---------|---|---------|
| 婚姻出轨 | + | 丈夫是刑侦教授+隐瞒重大犯罪 | = | 《我在人间彷徨》 |
| 原生家庭压榨 | + | 女儿追查母亲遭遇+证据反击 | = | 《好孕娘》 |
| 身份打脸 | + | 千年老祖+贵妃欺辱 | = | 《皇家老祖》 |
| 婚姻消耗 | + | 去父留子+豪门清算 | = | 《怀二胎》 |

**规则：套路负责共鸣，设定负责新鲜感。只有套路=老套，只有设定=没代入感。**

### 十、人设模板

**主角5种核心优势（至少具备1种）：**
1. 隐藏大身份
2. 手握核心证据
3. 极强忍耐力+布局能力
4. 强决断力+切割能力
5. 明确的离开能力

**反派5种核心特征（至少具备2种）：**
1. 无知自大 — 不知道主角的底牌
2. 得寸进尺 — 永远不满足
3. 道德绑架 — 用"为你好"包装伤害
4. 亲情背刺 — 利用主角的软肋（孩子/父母）
5. 情感出轨 — 精神或肉体双重背叛

### 十一、事件类型梯度

剧情必须逐层加码，不能跳跃也不能停滞：

```
羞辱 → 侵占 → 背叛 → 逼迫 → 引爆 → 清算
  ↓      ↓      ↓      ↓      ↓      ↓
语言攻击 财产被夺 丈夫出轨 伪造文件 当庭翻盘 社会性死亡
当众被打 名声被毁 闺蜜抢人 被赶出门 证据曝光 反派入狱
冷暴力   孩子被夺 至亲站队 生命威胁 身份揭露 报应闭环
```

**规则：相邻两步之间必须有因果关系。不能从"被骂"直接跳到"被杀"，中间必须有升级事件。**

### 十二、复仇模式扩展

在v3.0"碾压式/逆转式"基础上，新增3种爆款复仇模式：

**模式3：法律反杀型**
- 核心：用证据/法律/制度碾压，不是用拳头
- 爽感来源："正义"的重量 > "暴力"的痛快
- 必须有：关键证据（录音/日记/转账记录/鉴定结果）
- 必须有：当庭/公开揭露场景
- 示例：《爸爸抚恤金被吞后》MP3录音当庭播放

**模式4：女性觉醒型（去父留子）**
- 核心：不把婚姻当终点，把自己和孩子的利益放第一
- 爽感来源："我不再需要你"的独立宣言
- 必须有：主角主动选择离开（不是被迫）
- 必须有：离开后生活更好（新伴侣/新事业/新自由）
- 必须有：前夫追悔但主角不回头
- 示例：《怀二胎产检时碰上丈夫情人》

**模式5：冷暴力觉醒型**
- 核心：长期慢性消耗→心死→果断止损
- 爽感来源：不是"报复你"而是"我不要你了"
- 必须有：积累过程（至少3次冷暴力事件）
- 必须有：一个"彻底死心"的关键瞬间
- 必须有：主角比反派更早走出
- 适用于男性主角也适用于女性主角
- 示例：《当爱情走到终点》

**模式6：代际复仇型**
- 核心：受害者已死/已走，由后代（女儿/儿子）代为复仇
- 爽感来源：正义的延续+血脉的传承
- 必须有：受害者的遗物/遗言作为复仇的触发器
- 必须有：复仇者的"继承性"（继承了受害者的某种特质）
- 必须有：复仇者最终"完成使命后获得自由"
- 示例：《好孕娘》女儿桃桃的复仇线

### 十三、结尾硬规则

结尾必须满足以下全部条件：

1.  反派付出代价（法律/社会/情感，至少一种）
2.  主角不再回头（不能暗示复合）
3.  新生活更好（比之前的状态有明显提升）
4.  留余韵但不留悬念（不要"未完待续"）
5.  旧人追悔莫及（至少1个"后悔但已晚"的场景）

**违反任何一条 = 结尾不够爽。违反2条以上 = 读者觉得"白看了"。**

### 十四、新增禁忌4条

21. **禁止圣母原谅** — 反派的道歉不能换来主角的回头
22. **禁止拖太久才反击** — 压迫期不能超过全文55%，超过=读者跑了
23. **禁止反派洗白** — 反派可以后悔，但不能"变好"
24. **禁止主角内耗不行动** — 主角可以犹豫，但不能一直犹豫不行动

### 十五、情绪密度的四段式检查表（补充）

在v3.0检查清单基础上，每段额外检查：

- [ ] 这一章是否至少有一次明确的情绪切换？
- [ ] 是否有一个足够强的峰值事件支撑情绪？
- [ ] 峰值是否至少达到L3？
- [ ] 读者是否能清楚感受到"主角被压制/被背叛/被误解"？
- [ ] 爆发是否和前面的压抑一一对应？
- [ ] 结尾是否完成了切割，而不是继续内耗？

### 四十七、七段式叙事结构

在四段式基础上细化，用于指导具体段落分配：

```
第1段（5-10%）强钩子开局 → 直接给冲突，前三屏必须抓住人
第2段（10-20%）表面解释埋雷 → 反派用话术安抚/否认，主角还在忍
第3段（20-40%）证据爆发 → 日记/录音/目击/鉴定，真相逐层揭开
第4段（40-55%）主角决裂 → 离婚/分手/换阵营/报警/远走
第5段（55-70%）反派追悔 → 痛哭/道歉/疯狂挽回，但主角不回头
第6段（70-85%）终极审判 → 抓捕/社会性死亡/众叛亲离/因果报应
第7段（85-100%）新生活收尾 → 新感情/新事业/经济自由/精神独立
```

**核心：第2段"表面解释埋雷"是很多新手忽略的。** 反派不是上来就翻脸，而是先用话术让主角（和读者）以为"也许没事"——这让后续真相揭露时的冲击力翻倍。

### 四十八、反派话术式埋雷机制

反派的"解释"本身就是最阴险的武器：

| 话术 | 功能 | 真相 |
|------|------|------|
| "只是演戏" | 让主角自我怀疑 | 根本不是演戏 |
| "你别多想" | 压制主角的警觉 | 事情比你想的更严重 |
| "这是为了大局" | 用集体利益压个人感受 | 大局=反派的私利 |
| "她比你更需要" | 用同情心绑架 | 反派才是最自私的 |
| "我们是朋友" | 用关系名分掩护 | 早已越界 |

**规则：埋雷话术出现后，必须在后续有"雷爆"场景——主角发现真相时，回想起这些话，每一句都变成刀。**

### 四十九、主角决裂的6种动作

主角"觉醒后"必须有明确的切割动作，不能只"想通了"：

1. **离婚** — 最经典，法律层面的彻底切割
2. **分手** — 恋爱关系中，不等结婚就跑
3. **换新郎** — 婚礼当天换人，极致打脸
4. **远走** — 离开城市/国家，物理切割
5. **辞职** — 脱离反派控制的职场/家庭
6. **报警反告** — 从被告变原告，法律反杀

**规则：决裂动作必须有一个"物理可见"的瞬间——签协议/甩文件/关门/上车——读者需要"看到"主角走出去了。**

### 五十、功能性道具清单

关键物件不能是装饰，必须推动真相落地：

| 道具类型 | 功能 | 使用时机 |
|---------|------|---------|
| 日记 | 揭露长期秘密 | 主角翻到/被发现 |
| 录音笔/MP3 | 当庭/当众播放 | 法庭/摊牌场景 |
| 转账截图 | 证明金钱关系 | 查账/质问场景 |
| 亲子鉴定材料 | 支持核实亲子关系 | 摊牌/法庭场景 |
| 病历 | 揭露身体伤害 | 法律反杀场景 |
| 旧照片 | 证明身份/关系 | 身份揭露场景 |
| 车票/机票 | 证明行踪 | 揭穿谎言场景 |
| 结婚证/离婚证 | 确认法律状态 | 打脸场景 |
| 手机/通话记录 | 还原事件真相 | 关键证据场景 |
| 小人娃娃/法器 | 证明超自然手段 | 系统设定场景 |

**规则：每个关键道具必须出现两次——第一次作为"不起眼的物品"，第二次作为"致命的证据"。中间必须有"被忽略"的过程。**

### 五十一、五大主题方向

| 方向 | 核心冲突 | 读者代入点 |
|------|---------|-----------|
| 婚恋背叛 | 丈夫出轨/闺蜜插足/前任纠缠 | 婚姻中的不安全感 |
| 家庭偏心 | 父母偏心/哥哥护假妹/兄弟争产 | 原生家庭的不公平 |
| 身份命运 | 真假千金/换脸/顶罪/替身 | 身份被剥夺的愤怒 |
| 悬疑爽文 | 彩礼失踪/资金被偷/鉴定造假/真相回溯 | 被冤枉的憋屈 |
| 时代宫廷 | 宫斗虐恋/军婚偏心/兼祧两房/生子系统/替嫁和亲 | 时代局限下的无力感 |

### 五十二、句式层面写作技巧

**句子要短，画面要狠：**
- 禁止超过30字的长句（情绪爆发段）
- 禁止连续3句以上纯心理描写
- 用动作推进，不用形容词堆砌
- 对话推进>叙述推进

**冲突密集，不要铺垫过长：**
- 每一段都要回答：发生什么？谁在欺负谁？主角怎么忍？主角如何发现？主角怎样反击？
- 连续2段没有新信息=该删

**反击要干脆：**
- 主角一旦醒悟，必须在1-2段内做出行动
- 禁止"我想了想，又想了想，最后决定……"
- 正确写法："我拿起笔，签了字。"

### 五十三、立场鲜明硬规则

爆款短篇必须让读者一眼看出：

```
 谁是坏人 — 不能模糊到"也许他也有苦衷"
 谁在装 — 伪善角色必须在3段内露出马脚
 谁该被罚 — 反派的罪必须"不可原谅"
 谁该被爱 — 主角必须"值得被心疼"
```

**规则：本模式为立场鲜明的类型爽文，需提供"我站谁"的确定性。** 如果读者在评论区说"我觉得反派也有点可怜"=你写偏了。如果读者说"这人怎么还不死"=你写对了。

### 五十四、因果报应爽点清单

| 爽点类型 | 满足的心理 | 经典场景 |
|---------|-----------|---------|
| 前夫跪求原谅 | "你现在求我也没用了" | 离婚签字后前夫跪门口 |
| 绿茶自食恶果 | "你的手段反噬了你自己" | 情人被抛弃/破产/入狱 |
| 养子站错队后悔 | "你选错人了" | 儿子发现情人的真面目后哭着找妈妈 |
| 偏心者失去一切 | "你偏爱的人毁了你" | 偏心父母被偏爱的孩子抛弃 |
| 反派在自己挖的坑里翻车 | "你设的局最终困住了你自己" | 伪造的证据被用来定反派的罪 |
| 旁观者集体倒戈 | "所有人终于看清了" | 亲戚/邻居/同事从帮反派到帮主角 |

### 五十五、创作前置输出格式

当收到"书名+主题"时，必须先生成以下8项：

```
1. 一句话简介（15字以内）
2. 故事定位（题材+受众+核心卖点）
3. 核心爆点（3-5个关键反转点）
4. 人物设定表（主角/反派/关键配角各2-3行）
5. 功能性道具清单（至少2个）
6. 章节分段大纲（7段式，每段标注字数占比+情绪级别）
7. 开篇钩子（前500字方案）
8. 结尾爽点（最后500字方案）
```

**确认以上8项后，再开始正文写作。禁止跳过。**

### 五十六、鬼魂见证子类型

死后视角的升级版——主角以鬼魂身份"见证"反派的幸福生活：

- **核心虐点**：我死了，他过得很好，和别的女人很幸福
- **必须有的场景**：鬼魂看着丈夫对新妻子做曾经对自己做过的事
- **转折点**：真相揭露时，鬼魂"在场"看着反派崩溃
- **结尾**：鬼魂释然/消散/转世，不回头

**规则：鬼魂视角不是"旁观"，而是"有情感但无能为力"——读者必须同时感到虐和憋。**

```
第一阶段：母亲受苦（压迫期）
  - 母亲被丈夫/婆婆/家族压榨
  - 母亲反复忍让，甚至自我牺牲保护女儿
  - 母亲最终死亡/被迫离开

第二阶段：女儿成长（蛰伏期）
  - 女儿在压迫环境中长大
  - 女儿表面顺从，实际在搜集证据/学习手段
  - 女儿继承了母亲的某种特质（善良/坚韧/智慧）

第三阶段：复仇启动（爆发期）
  - 女儿用母亲留下的遗物/线索/真相作为武器
  - 复仇手段：法律追责/公开证据/气运夺回
  - 关键台词："妈妈做不到的事，我替她做"

第四阶段：自由新生（收束期）
  - 复仇完成，女儿获得自由
  - 女儿以母亲的名字行走世界
  - 梦中/灵魂层面的母女重逢
```

#### A. 伤害五级体系

对小说中的伤害事件进行系统分级，用于判断开头钩子的最低门槛和后续升级路径：

| 等级 | 伤害对象 | 类型 | 情绪产出 | 开头适用性 |
|------|---------|------|---------|-----------|
| L1 | 资产 | 经济剥夺、财产被吞、工资被扣 | 愤怒L2+不公L2 |  太弱，不能做开头 |
| L2 | 身体 | 肢体暴力、健康损害、被打被推 | 愤怒L3+心疼L2 |  太弱，不能做开头 |
| L3 | 生命 | 主角自身生死威胁、重病、车祸 | 不安L3+恐惧L3 |  可做开头但不够 |
| L4 | 家庭 | 至亲死亡/被害/背叛、孩子被夺、父母被害 | 心疼L4+愤怒L3 |  **开头最低门槛** |
| L5 | 世界 | 体系性压迫、群体灾难、制度性作恶 | 震撼L4+无力L3 |  可做开头，格局更大 |

**核心规则：故事开头的事件等级不得低于L4。**

读者第一屏就知道"有人死了，而且是主角最亲的人"。低于L4的开头，钩不住人——资产损失和身体伤害需要先建立情感连接才能产生冲击，而短篇没有这个时间。

#### B. 四级开头法

**定义：开头直接抛出L4级事件（至亲被害/死亡），用"信息差"制造钩子——事件已经发生，但主角刚发现真相。**

四级开头不是"情绪从头爆到尾"，而是**事件高压+认知从零开始**的落差：

```
事件等级：L4（已经发生了，不可逆）
主角认知：L1（刚发现/刚意识到）
读者情绪：被事件冲击 → 跟着主角从"不知道"到"知道"到"反击"
```

**和"压迫起始点≤30%"的关系：不矛盾。**
- 规则A的"起始≤30%"指的是主角**正在经历**的压迫强度
- 四级开头的事件是**已经完成的**，主角是在"事后追查/事后觉醒"
- 主角的认知起点仍然是L1（不知道/刚发现），情绪仍然是从低到高升级
- 区别在于：读者的同情分已经拉满（至亲已死），所以主角每一次接近真相，情绪产出都是加倍的

#### C. 四级开头的六种经典模式

**模式1：葬礼型**
> 在XX葬礼上，我才发现XX和XX的关系。

核心机制：葬礼=信息揭露的最佳场景。所有人到齐，面具摘不下来。
- 在父亲葬礼上，我老公给另一个女人递纸巾
- 在儿子葬礼上，前妻带着新丈夫来上香，新丈夫手里拿着儿子的遗物
- 在母亲葬礼上，我才知道她改了遗嘱，把所有东西留给了照顾她的"好姐妹"

**模式2：监控/证据型**
> XX死后，我才看到那段监控/那份报告。

核心机制：证据=不可辩驳的真相。监控仍需核验时间、来源和完整上下文。
- 我妈死后，我看到了桥上的监控——我老公站在她身后，没拉
- 女儿死后，我看了她的病历——病历上的异常被忽略，家属要求核查治疗过程
- 哥哥死后，我打开他的手机——最后一条未发出的消息是"她要杀我"

**模式3：遗物/遗言型**
> 整理XX遗物时，我发现了……

核心机制：死者的秘密=不可逆的遗憾。当事人已死，真相无法当面对质。
- 整理母亲遗物，发现她藏了十年的诊断书——她没疯，她被下药了
- 翻弟弟枕头底下，找到一封写给我的信——"姐，爸不是心梗死的"
- 父亲遗物里有一张照片，背面写着：这个女人害了我，别信她

**模式4：身份揭露型**
> XX死后，我才知道他/她不是我以为的那个人。

核心机制：身份崩塌=关系崩塌。你爱的人不是你爱的人，连恨都不知道怎么恨。
- 我哥死后，有人告诉我：他不是我哥，他是替我死的那个
- 父亲死后，我翻到另一份出生证明——我还有个双胞胎姐姐，她被送走了
- 婆婆死后，我在她柜子里找到一张旧结婚证——她嫁过我公公的哥哥

**模式5：死后反转型**
> XX"死了"，但真相是……

核心机制：死亡可以是假的，但背叛是真的。
- 我参加了老公的葬礼，三年后在小城遇见他——他换了个名字，身边有个新老婆
- 儿子溺水死亡，我签了火化同意书，五年后有人发来一张照片——他活着
- 我亲手火化了我妈，但她的银行卡一直在被人取钱

**模式6：体系作恶型（L5开头）**
> 不是一个人害了我家，是整个系统。

核心机制：从L4（至亲死亡）升级到L5（体系性压迫）。反派不是一个具体的人，而是一张网。
- 回村发现七年死了一百人，全是肺癌，工厂是县里批的
- 我妈在医院去世，同层楼三年死了十二个产妇，院方说是"巧合"
- 孩子的学校出了事，不是意外——校方、教育局、施工方全知道，没人说

#### D. 四级开头与七段式的嵌套

四级开头对应段1"强钩子"，直接把事件拉到L4。但段2不能继续高压——需要用"表面解释埋雷"让情绪短暂回落：

```
段1（5-10%）L4事件直接抛出 → 读者被冲击
     ↓
段2（10-20%）表面解释/自我怀疑 → "也许不是你想的那样"
     ↓ （情绪回落，但读者知道真相，这种"我知道但主角不知道"的张力比纯压迫更强）
段3（20-40%）证据逐层揭开 → 主角从L1认知追到L4真相
     ↓
段4-7 正常执行七段式
```

**关键：段2的回落不是"事件降级"，而是"认知缓冲"。** 事件仍然是L4的，但主角（或周围人）给出一个"合理化解释"，让读者短暂动摇——"难道真的是意外？"——然后段3的真相揭露把这种动摇彻底碾碎，情绪产出翻倍。

**对比：**

| 开头等级 | 读者反应 | 段3真相揭露时 |
|---------|---------|-------------|
| L1开头（资产损失） | "哦，钱没了" | "果然是坏人" → 爽感L2 |
| L2开头（身体伤害） | "好过分" | "果然是故意的" → 爽感L2-3 |
| L3开头（主角生命威胁） | "主角会不会死？" | "她挺过来了" → 爽感L3 |
| **L4开头（至亲被害）** | **"谁干的？！"** | **"我早就知道，终于确认了"** → **爽感L4** |

#### E. 四级开头法与补丁30（钩子类型清单）的整合

补丁30的七种钩子类型中，已有三种天然是L4级：

| 钩子类型 | 伤害等级 | 四级开头匹配 |
|---------|---------|------------|
| 当场背叛 | L4（至亲背刺） |  葬礼型 |
| 孩子被害 | L4+（家庭+生命） |  监控型/遗物型 |
| 至亲背刺 | L4 |  所有类型 |
| 财产被吞 | L1 |  需升级到L4 |
| 身份错位 | L3 |  需叠加L4 |
| 死前觉醒 | L4 |  死后反转型 |
| 强权碾压 | L2-L3 |  需升级到L4 |

**整合规则：所有L1-L3级钩子，必须叠加一个L4事件才能做开头。**

示例：
- "财产被吞"（L1）→ 升级为"父亲死后财产被继母吞了，而父亲可能不是自然死亡"（L4）
- "身份错位"（L3）→ 升级为"我哥死后才知道他替我死了"（L4）
- "强权碾压"（L2）→ 升级为"全村人被工厂毒死，我家人也在其中"（L5）

#### F. 四级开头法的禁忌

1. **禁止L4事件+L4情绪同时起爆** — 事件已经是L4，情绪必须从L1（主角刚发现/刚意识到）开始。如果主角第一段就崩溃大哭，读者反而接不住。
2. **禁止L4开头后降级** — 段2可以情绪回落，但事件等级不能倒退。不能开头"母亲被害"，然后中间全在讲财产纠纷。
3. **禁止L4开头后无升级** — 既然开头就是L4，后续必须有L4+的升级点。要么事件升级（发现不止一个人被害），要么背叛升级（发现不止一个人参与），要么体系升级（L4→L5）。
4. **禁止L4开头但主角反应冷漠** — 至亲死了，主角可以冷静，但不能无感。冷漠和无感的区别：冷漠是"我忍住了"，无感是"作者忘了写"。

#### G. 四级开头法检查清单

- [ ] 开头事件等级是否≥L4？
- [ ] 主角的认知起点是否在L1（刚发现/刚意识到）？
- [ ] 段2是否有"表面解释/自我怀疑"的认知缓冲？
- [ ] 段3真相揭露时，是否和段1的L4事件形成因果闭环？
- [ ] 后续是否有L4+的升级点（更深的真相/更大的背叛/体系性作恶）？
- [ ] 主角对L4事件的反应是否有情绪过程（不是一开始就崩溃，也不是一直冷漠到底）？
- [ ] 如果钩子类型原本是L1-L3，是否已叠加L4事件？
