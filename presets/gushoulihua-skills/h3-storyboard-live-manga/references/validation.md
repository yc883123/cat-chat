# 真人改编与分段检测

## 人工语义复核

1. **改编职责一致**：谁进攻、受击、说话；脸和衣服的来源；装备覆盖；环境转换；原漫画人物和服装是否泄漏回来；表情/速度线是否改为表演；未获授权的道具变更是否出现。无实景图时确认是空间事实转实景，不是继承绘制背景。
2. **内容块完整**：对白语义闭合；攻击包含必要起势、路径、接触或掠过、结果和反应；视觉落点完整。不能把一句引导语、一次挥拳或撞壁结果拆到下一 P。
3. **P 独立**：只用本 P 上传素材能否建立人物、地点、装备状态和前提？结尾能否完成？多 P 能否直接硬切而不重复动作、不匹配姿态？
4. **时长与 P 数最少可行**：最低需求依据自然口播、动作因果与必要停顿，而非“每镜几秒”。快速切镜允许，但每个接触/结果仍须可辨。可在 15 秒内自然合并的相邻完整块不能为形式整齐拆开。多出约 2 秒以上须有源素材支持的复杂动作或必要落点。

典型原因码：`ADAPTATION_DRIFT`、`EQUIPMENT_CONFLICT`、`ENVIRONMENT_CONFLICT`、`BLOCK_SPLIT`、`UNRESOLVED_ACTION`、`DEPENDENT_OPENING`、`DUPLICATE_EVENT`、`OVERLOAD`、`DURATION_PADDING`、`UNNECESSARY_SPLIT`。

## 结构校验

Markdown 保存后运行：

```text
python scripts/validate_storyboard_output.py <file>
python scripts/validate_storyboard_output.py --self-test
```

脚本检查全局与局部素材/职责映射、六字段、真人声明、彩色/黑白开头、参考定义及 retention 覆盖、speaker/Audio/声音锚点、时间戳、对白字数、最低需求范围、固定真人尾部和检测报告一致性。

脚本不读取图片、不证明用户确认、不验证演员身份或生成效果，也不能识别所有措辞中的动画目标、装备漂移、额外攻击或歧义。它依据作者记录的最低需求检查时长，不证明该估算正确；口播阈值只是中文风险信号，其他语言需人工估算。不要把镜头数量线性换算成总时长。单镜过短提示风险，不作为固定剪辑审美规则。

结构输出有 WARN/FAIL 时先修复或说明依据，不能仍写 PASS。人工发现问题而脚本未发现时，仍以人工复核为准。

## 用户可见结果

全部通过时：

```markdown
# 分段检测

检测：PASS｜1P／12秒
P01：0字／12秒｜块完整PASS｜独立PASS｜时长PASS
真人改编：角色替换、装备覆盖、环境转换与表演处理一致。
```

有问题时只列受影响 P、原因、证据和修复建议。提示词校验与实际出片验证分开，不把前者描述成后者。
