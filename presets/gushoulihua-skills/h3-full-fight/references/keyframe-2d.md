# 阶段 2：2D 番剧关键画面标准

目标是可用作 H3 动作视频视觉锚点的**日本 2D 电视动画正片截图或高质量关键帧**，不是宣传插画、手游立绘或给原图加二次元滤镜。每次出图和返修都要明确此目标，并在看到成图后据此验收。

**适用开关**：以上目标、下文手绘／赛璐璐／材质画风约束及“提示词与返修要点”仅用于 2D 模式。用户取消 2D 后，按用户要求及指定画风参考编写图片提示词，停用这些画风标准、负面限制和“2D 材质”验收，不因写实、CG 或精细插画表现判不合格；“人物与装备”“场景与位置”“瞬间因果”三项内容检查继续执行。

无论是否采用 2D，每张新图和每张返修图都要**生成后立即实际打开、逐张检查**。未通过的图不交付为当前版，也不作为下一张的视觉基准；检查结论不能由提示词或生成器自述代替。

## 内容与画风的边界

- 已有图片作为内容参考时，保留已确认的人物身份、脸型、发型与发色、服装和配色、饰件与武器、人数、动作、位置、机位、透视、场景结构及剧情状态。按已确认剧本决定该关键瞬间，不能为了风格重设计角色、增删物体或改写事件。
- 只改变表现方式：人物以清晰且略有粗细变化的手绘轮廓线、稳定简洁的面部线稿、大中型发束及少量结构性衣褶绘制；人体和手脚准确自然。
- 采用赛璐璐上色：平整固有色、一道明确硬边暗面、必要时少量第二层阴影及极少量块状高光。皮肤、发丝、布料、皮革和金属用动画色块概括；复杂装饰保留可辨识轮廓与颜色，把细纹简化为可重复绘制的图案。
- 背景保留建筑、街道、室内、天空和植被的空间与透视，用清晰色块、手绘边缘及有限阴影概括纹理；远景减细节，近景结构清楚。雨、火、魔法、爆炸、烟尘、碎片与闪电使用手绘形状、色块、速度线和少量发光核心。水面、玻璃、湿地、金属反射只用有限色块和设计化高光。
- 夜景和环境色不吞没人物固有色；霓虹只作局部边缘色或小面积影响。雨夜是场景设定，整张图仍要服从 2D 电视动画作画逻辑。

## 逐张验收

1. **2D 材质**：看皮肤、头发、布料、皮革、金属、石地、玻璃和湿面。若出现镜面地板、连续渐变高光、塑料感、摄影反射、PBR 金属或 CG 粒子，即使脸像动漫也判不合格。
2. **人物与装备**：对照已确认角色图核对脸、肤色、发型、服装配色、饰件、手部结构；核对左右手、武器数量与长度、刀刃朝向、刀鞘当前去向。物件不得复制、凭空出现或消失。
3. **场景与位置**：对照已确认场景和相邻图核对墙、栏杆、天桥、建筑、地面等固定地标；核对人物间距离、前后左右、视线、透视、镜头轴线，以及攻击源—路径—目标。只作构图参考的图不能带入其人物、颜色或环境。
4. **瞬间因果**：这张图只表现指定的一瞬间；未发生的动作、尚未形成的云或光柱、已结束的裂缝、越过目标的冰锥等都不得提前或滞后出现。

不合格时指出哪一项与哪张已确认图冲突；直出模式从干净的已确认版本重生成或针对性编辑，提示词模式交付对应返修提示词，不调用生图工具。取得修订图后实际查看并重新执行当前模式启用的检查项。出图能力判定、返修轮次与停止条件按主文件执行：首次生成不计入返修；同一具体问题连续三轮返修没有改善时，暂停该问题的继续生成，主动建议用户提供对应动作／构图／场景参考，不自主搜索；用户提供参考或明确选择其他处理方案后再继续。参考只用于标明的职责，停止在错误图上层层叠改。

## 提示词与返修要点

不能只写“2D anime style”。在每张图的提示词中，针对实际画面写出：`2D Japanese TV animation frame, hand-drawn animation, clean line art, flat local colors, hard-edged cel shadows, limited highlights, simplified animation background, hand-drawn effects, consistent character design`。同时明确排除 3D 建模感、PBR 材质、塑料光泽、毛孔和密集发丝、真实布料纹理、摄影级湿面或镜面反射、体积光和 CG 粒子、大面积柔和渐变、Bloom、镜头光晕、景深散景、电影调色、过量锐化与厚涂笔触。按画面实际内容取舍相关项，不堆砌无关特效。

如果参考图已是精细二次元插画但不够像番剧，明确要求**降低插画完成度，提高动画作画感**：减少发丝、服装细纹、材质纹理、碎光和装饰性高光；加强轮廓线、大片平涂、硬边阴影与简化背景。若生成图有写实光影或材质，只返修表现方式，同时重申需锁定的身份、动作、构图和场景。验收时人物、背景、特效和反射都必须过关；不能只看角色脸部是否“动漫”。
