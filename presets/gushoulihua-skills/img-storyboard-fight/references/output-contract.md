# 生图提示词输出契约

## 默认交付

直接给参考图上传顺序与一条完整提示词，不先提交确认方案，不另附 negative prompt。提示词可以分段逐格写；“一条”不等于一段长句。

参考图按本次实际上传顺序声明 Picture 1...N，附角色名和可见身份锚点。没有参考图时写“参考图：无”，不虚构 Picture。映射必须在生图代码块内也写全，确保单独复制可用。Picture 是自然语言名称，不是 API 参数。

默认输出“参考图上传顺序”和一个 text 代码块。按需在代码块外补充：
- 指定模型时的建议画布与调用设置；这些要在实际界面／API 配置，不能声称在提示词中写出就已生效。
- 存在原作对白或跨任务事实时，[handoff.md](handoff.md) 规定的交接信息；对白不进入无字生图指令。

不输出内部推演、状态表、无关分析或未请求的备选版本。必要的事实澄清与约束冲突不受此输出形式限制。

## 提示词结构

1. **任务与版式**：整页方向和比例、准确格数、各行格数与跨行／跨列位置、阅读顺序、清楚的格缝；不自行增加插入格。
2. **参考与全局状态**：各图的身份／场景／事实／构图职责，角色持械手与资产所有权，稳定地标和攻防轴。专门参考覆盖其职责，原漫画保留剧情事实；同一职责冲突时不混合猜测。
3. **逐格瞬间**：按唯一阅读顺序写出位置、机位及当前可见状态，每格只有一个时间点。
4. **视觉层级**：本短段的主要视觉峰值，以及少量相容的透视、光影、运动线。无能量能力不加能量，无碰撞不加爆炸。
5. **相关防错**：只保留当前素材需要的约束。角色可跨格重复出现，同一格不得多出无剧情依据的实体副本；合法分身、额外肢体及稳定标记服从设定。
6. **无字画面**：不新增标题、格号、气泡、字幕、拟声字、Logo、水印、UI 或伪文字。参考中属于身份／剧情的纹章、符文、服装图案仍按资产保留；运动线与合法图案不属于新增文字。

## 逐格写法

> 第 N 格（版面位置；景别与机位）：明确的当前动作阶段与可见姿态。双方位置、接触端／防御面或避让间隙；说明本格必须完整入画的关键部位。一个视觉焦点，以及此刻可共存的反馈。与前格属于同一动作阶段组时保持可辨认的姿态演变。

这是字段选择顺序，不是每格必填表。建立格不需要接触点，普通拳击不需要能量光源，近景无需强塞双方全身；接触特写须显示肢体归属，并由相邻格给出重心和空间依据。

先在内部确定相邻格的状态差，再用可见事实写清区别，不把检查表抄给用户。例如“发射初期”应写短束仍靠近炮口、目标尚未完全离开弹道；下一格才写目标已经侧移、长束经过原位置。仅把相同画面命名为“开始”和“完成”不够。互斥的已完成结果不得提前出现在前格。

内部动作链保留前因后果，最终逐格词只描述当前可见事实。“出拳→格挡→弹开→转身踢击”需选择关键瞬间分格，不能用“同时”“随后”或多重残影把互斥姿态合并。尘土、衣摆、轨迹可提示此前运动，不额外复制完整人物。

“拳抵住前臂，拳套压扁，衣袖绷紧”是同一瞬间；“拳被挡后收回并再次挥出”是多个时间点。

## 布局与容量

- 先展开关键姿态并合并冗余，再落实布局。五格可写“上排两格、中排一格通栏、下排两格”，不能只写“自由不对称排版”。格号只用于提示词，不印在图中。
- 整页横向不保证单格适合横向交锋；为全身、长兵器和主要接触留足横向空间，不把其他必需格缩到不可读。
- 为关键格列出必须入画的证据：擦脸须有靴尖、脸部轮廓与间隙；托腕带起身体须有接触点、肩部与腰胯；蹬地须有支撑脚、膝盖与骨盆；侧闪须有落脚位置、躯干与弹道边缘。具体按本次动作选择，不强迫所有格都画全身。通栏可以增加高度，不能因横向宽格把必要部位裁掉。
- 输出建议画布比例时与实际界面／API 尺寸分开，能设置尺寸则需在外部配置。回来验收时比较实际比例和必要入画部位；比例偏离但内容仍清楚可接受并记录，偏离导致动作证据丢失则返修，不只重复“严格遵守比例”。
- 已知尺寸时估计扣除格缝后的单格面积，检查握法、接触与双人轮廓。没有适用于所有构图的固定最低像素／格数阈值。
- 拥挤时先删重复效果、装饰机位和非必要环境细节，再调格子面积或受支持的画布尺寸。仍装不下时按完整交锋单元拆页，每页一条独立提示词，维持资产与即时状态。拆页不等于 H3 分 P，不把同一次攻击的发射与结果拆成独立事件。
- 用户明确限定单页、尺寸或时长时，不静默拆页、删事件或扩尺寸；指出具体冲突并询问可放宽项。

复杂连续动作或多页交付时，在代码块外附简短“动作／镜头关系”说明：哪些格描述同一连续动作，哪里允许切换观察角度，多页是否属于同一段目标时长。不得平均分配每格时长，也不输出 H3 时间码或正式字段。示例：“第2–4格是同一次出拳与改线的连续姿态，不要求三次切镜；两页共同对应约15秒。”这属于交接信息，不是内部推理。
