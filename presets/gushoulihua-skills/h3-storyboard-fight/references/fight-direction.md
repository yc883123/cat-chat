# H3 动漫打戏导演规则

本规则只强化源内容已有的战斗信息。动作因果与视听表现分别设计：观众需要辨认关键攻击、接触或落空与结果，不需要观看每个中间步骤。任何技巧都不得新增剧情事实、能力、武器、攻击次数、伤势、破坏规模或胜负变化。高速／高燃请求同时执行 [表现力落地规则](performance-execution.md)，不能只从下列技巧库挑选名词。

## 1. 每个动作块先建立可见因果链

把战斗动作整理为：

```text
起势/意图 → 距离与方向 → 攻击轨迹 → 防御/闪避/反制 → 接触或落空 → 位移/破坏结果 → 关键反应
```

- 源素材没有某一环时不要虚构；用已有格或上下文能确认的最少信息连接。
- 关键交锋不能只写“双方激烈战斗”。写清主动作、对手响应、接触点和落点。
- 高速过渡可以用跳帧、抹帧、残影或镜头甩动压缩，但接触与结果必须成为清楚的画面节拍。
- 多人战斗先建立人物方位、阵营和威胁方向；每一拍只突出一个主要攻防关系，防止身份漂移和空间混乱。
- 近战强调身体重心、步法、借力、格挡面和跟随动作；远程强调发射源、弹道、遮挡、落点与环境参照；追逐强调领先/追击关系、路线和距离变化。

## 2. 单个 P 的战斗结构

每个 4–15 秒 P 选择一个主节奏和一个主冲击点。常用结构：

- **瞬发重击**：极短静止或眼神锁定 → 反向预动 → 高速突进 → 命中停顿 → 冲击与结果释放。
- **连续攻防**：建立双方位置 → 2–4 个清楚的攻防节拍 → 节奏突然中断 → 决定性交锋 → 结果落地。
- **压制与反转**：一方连续逼迫 → 防守空间收窄 → 可见破绽或决断 → 反击越过节奏 → 明确新局面。
- **必杀释放**：稳定蓄力与环境响应 → 能量/武器路径明确 → 接触 → 冲击扩散 → 延迟破坏或人物反应。
- **高速追逐**：空间与相对位置建立 → 环境参照高速掠过 → 路线变化/障碍 → 距离突变 → 截击、脱离或阶段结果。

战斗节拍要有对比。优先使用“静—动”“快—停—爆”“近景—远景”“微小表情—巨大环境反馈”。全程等速、等响、等强度会削弱高潮。

## 3. 高燃表现手法库

以下是可选导演工具，不按数量配额叠加。先确定该节拍要让观众感到逼近、速度落差、失衡或巨大尺度，再选择能在同一 Shot 中兼容执行的手法。仅写“广角、甩镜、冲击帧”不算完成；需说明作用对象、运动关系、触发瞬间及恢复的画面信息。

### A. 速度、空间与背景

- **背景速度线**：平行直线用于高速直进；放射线聚焦碰撞或爆发；弧形轨迹用于旋转、甩击与失控运动。
- **空气轨迹与运动条带**：用气流、尘粒、雨线、火星、刀光或局部拖影勾勒真实运动路径；不要生成文字状拟声图形。
- **局部空间扭曲**：在能量释放、超高速经过或巨大压力处短暂拉弯背景和空气折射；只作用于冲击邻域，不能破坏人物身份和场景结构。
- **透视夸张**：拳、脚、武器或身体前端贴近镜头时放大，远端快速缩小；用于突进、挥砍和扑击。
- **广角或鱼眼压迫**：贴身缠斗、包围、俯冲或爆炸中心可用；主方向仍须明确。
- **空间压缩/拉伸**：攻击前短暂拉长距离，爆发时迅速压缩；表现加速而不改变实际地点和人物关系。
- **背景短暂抽象化**：只在主观爆发或命中瞬间把现实背景压缩为纯色、光带、能量或运动图形，随后立刻回到可识别空间。
- **环境参照掠过**：碎石、立柱、树木、建筑边缘或地面纹理高速掠过，帮助读出速度和尺度。
- **倾斜地平线与不稳定构图**：用于局势失衡；不能连续滥用导致方位不可辨。

### B. 动作与动画

- **蓄力与反向预动**：先压低重心、收紧身体或向反方向小幅移动，再释放主动作。
- **关键姿势夸张**：优先保证剪影、力线和重心方向；只能短暂变形，随后恢复参考身份与身体结构。
- **抹帧/形体拉伸**：高速过渡时短暂拉长肢体、武器或全身；不能在接触帧和结果帧持续模糊。
- **残影与运动回声**：表达移动轨迹或连续攻击方向；残影不能被误认成新增角色或分身能力。
- **多重肢体轨迹**：仅作为一名角色的瞬时运动回声，表现高速连击；实际攻击次数服从源内容。
- **跳帧式换位**：省略非关键移动过程，让角色突然抵达新位置；前后位置与朝向必须可推断。
- **命中停顿（hit stop）**：接触瞬间极短冻结或压缩运动，随后释放冲击；停顿不能长到拖慢 P。
- **跟随动作与回弹**：命中后身体、武器继续越过接触点，再回弹或重新找平衡，建立重量。
- **次级运动延迟**：头发、衣摆、血液、碎屑和武器挂件稍晚于主体响应惯性。
- **一拍多帧密度变化**：蓄力阶段减少运动信息，爆发阶段提高动作密度；提示可描述节奏变化，无须指定技术帧率。

### C. 冲击与破坏反馈

- **冲击帧**：接触瞬间插入极短高对比、反色、黑白或剪影式闪帧，随后立即回到既定黑白/彩色模式。
- **闪白/闪黑**：用于遮断一瞬并让观众补全冲击；不得连续频闪。
- **镜头受力位移**：命中时镜头短促后坐、偏移或震动；只在冲击点使用。
- **冲击波**：用空气圆环、锥形压力波、透明折射、尘幕或云层空洞显示力量传播。
- **空气撕裂**：白色压力痕、蒸汽裂口或局部折射表现速度与压力；不能形成字形或符号。
- **地面反馈**：龟裂、下陷、碎石悬浮、尘浪和足下反作用必须符合源内容允许的破坏规模。
- **延迟破坏**：动作完成后极短停顿，环境才断裂、坍塌或爆开；仅在源素材已表现相应结果时使用。
- **多段反馈**：接触 → 人物位移 → 冲击波 → 碎裂/尘浪 → 远处环境回应，按尺度逐层释放，避免同一帧堆成噪声。

### D. 镜头、构图与尺度

- **快速推近/拉远**：推近眼神、拳脚或武器建立决断；命中后急拉远展示位移和破坏范围。
- **跟随镜头**：贴随人物、拳头、刀刃或弹道运动；接触前及时给出目标方位。
- **环绕镜头**：用于缠斗、锁定或力量对峙；旋转幅度服务空间关系，不能只为炫技。
- **主观镜头**：从攻击者或受击者视角制造临场压迫；使用前后补足客观空间信息。
- **穿越式运镜**：穿过碎屑、障碍、武器下方或双方间隙，强化纵深和速度。
- **短长镜头**：连续技术性攻防可用稳定跟随的连续镜头，减少无意义切换。
- **碎切蒙太奇**：眼神、脚步、握力、武器、接触点和结果快速切换；必须维持动作次序。
- **极近景与极远景交替**：微小决断对照巨大环境结果，建立尺度反差。
- **对角线与汇聚构图**：身体、武器、碎片和运动线共同指向主要接触点。
- **留白后爆发**：主冲击前减少背景信息，爆发时再用位移、粒子和环境反馈填满空间。
- **前景穿出**：肢体、武器或碎屑快速掠过镜头边缘，制造贴脸纵深；画面仍是无格框的全屏动画。

### E. 光、色与粒子

- **明暗对比**：攻击前压暗非关键区域，主冲击用轮廓光、爆光或剪影突出力线；已知人物和环境颜色仍服从参考图。
- **瞬时色彩压缩或对撞**：高潮一瞬减少杂色、强化参考中已有的冷暖或明暗关系；不得凭空指定新配色或画风。
- **动态光源**：火焰、雷电、能量、爆炸或刀光扫过人物和环境，受光方向必须随动作变化。
- **粒子逆流与爆散**：蓄力时尘埃、雨滴、火星向力量中心聚拢或被排开；释放后沿冲击方向爆散。
- **液体与碎屑轨迹**：雨水、汗、血液、泥水和碎片勾勒运动弧线；血量和伤势严格服从源内容。

### F. 剪辑、节奏与声音

- **静—动反差**：眼神、呼吸或稳定姿态短暂停留，随后无缝爆发。
- **快—停—快**：高速接近 → 命中停顿/极短慢化 → 冲击释放；慢化只用于读清关键关系，不用于填时长。
- **动作前切**：上一镜动作尚在起势时切入目标或路径，使能量向前推进；结果不能被剪掉。
- **反应延迟**：挥击完成后，敌人或环境稍后才出现源素材规定的结果。
- **多角度重复**：只用于决定性一击且源内容允许；同一次事件不可被写成多次命中。
- **声音抽空**：主冲击前短暂压低环境声，突出呼吸、心跳或细微摩擦。
- **破风先行**：高速物体的破风、掠过或压力声先于视觉接触极短出现。
- **低频冲击与材质叠层**：用空气闷响、金属、石材、布料、脚步和非语言人声组合重量；不要在 `overall_soundscape` 重复台词。
- **声音延迟**：远距离爆炸或巨大破坏可先见后闻，尺度和距离必须符合场景。
- **音乐缺席下的节奏**：`non_diegetic_music` 仍固定为 `N/A`；用呼吸、脚步、破风、碰撞、环境回声和短暂静默承担节拍。

## 4. 按战斗类型选择技巧

- **高速近战**：预动、透视夸张、抹帧、跟随镜头、命中停顿、次级运动；避免持续远景看不清招式。
- **兵器交锋**：武器路径、格挡面、火星、金属材质声、反作用和跟随动作；避免刀光遮住接触点。
- **重击/巨力**：留白、低机位或广角、短命中停顿、镜头后坐、地面反馈、延迟破坏。
- **能量对轰**：发射源、能量路径、受力方向、粒子逆流、空间折射、冲击波与远景尺度；不能只写满屏光效。
- **空战/高速追逐**：环境参照、相对距离、弧形轨迹、环绕或跟随镜头、音爆与路线变化。
- **群战**：先建立地理关系，再用前中后景和单一主攻防焦点分层；残影不能变成额外人物。
- **压迫性强敌**：减少强者无效动作，用稳定构图、缓慢逼近与对手快速反应形成反差。
- **必杀终结**：蓄力静默、明确释放路径、唯一主冲击点、尺度拉远、延迟结果与落地后的短呼吸空间。

## 5. 写入确认方案与正式提示词

确认阶段，每个 P 在原大纲字段之外增加：

```text
- 战斗动作链：起势 → 攻防路径 → 接触/落空 → 结果与反应
- 高燃设计：主节奏；主冲击点；选用技巧及各自功能
- 战斗可读性：人物方位、主运动方向、接触点和结尾状态如何被看清
```

正式 `detailed_description` 中：

- 开场先按原契约建立独立场景、双方位置、朝向、距离和关键道具。
- 每个 Shot 围绕一个观看关系，将动作、机位、速度变化、表演与声音同步组织；不把这些要素各自排成必须完成后才能继续的步骤。
- 战斗技巧必须落在具体 Shot 和具体动作上，不写脱离动作的效果清单。
- 高速／高燃方案的“高燃设计”应给出主节拍的具体观看变化，例如“贴地追随支撑脚，出拳超过镜头填满前景，切到红手套上拨的短读点”，不能只列“广角、跟拍、冲击帧”。正式正文必须兑现这项设计。
- Shot 2 起时间戳严格递增；主冲击点前后留出足够时间读清接触和结果，但仍选最短可行整数时长。
- `overall_soundscape` 写出环境底噪、呼吸/破风、碰撞材质、主冲击和余响层级，不写音乐。

## 6. 战斗可读性与高燃检测

正式交付前逐 P 检查：

1. **因果完整**：起势、路径/攻防、接触或落空、结果和关键反应是否完整？
2. **空间清楚**：首镜是否建立双方位置、朝向和距离？快速切镜后是否仍能判断主运动方向和目标？
3. **接触可见**：速度线、闪光、抹帧、镜头震动和粒子是否遮住接触点或让命中次数含糊？
4. **高潮分级**：是否只有一个明确主冲击点？前后是否有节奏、尺度或声响对比？
5. **强化有据**：每项破坏、能力、伤势、液体、能量和环境反馈是否由源内容支持？
6. **技巧克制**：是否只选了服务本段的少量技巧，而非把技巧库逐项堆入？
7. **结果落地**：最后一个 Shot 是否显示人物位置、姿态、受力结果、环境状态或战局变化，并可直接硬切？

高燃请求另执行 [performance-execution.md](performance-execution.md) 的表现力复核。因果完整、接触清楚、没有过量特效，均不能单独证明透视、运镜或速度张力已经设计到位。

任一答案为否就修改动作或镜头设计。不得通过增加 P、延长空镜、重复命中、长时间慢动作或全程镜头抖动来掩盖问题。
