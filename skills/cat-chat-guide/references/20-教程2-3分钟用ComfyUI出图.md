# 3 分钟上手：用 Cat Chat 调用 ComfyUI 生成图片（小白版）

> 目标：不动一行代码，让 AI 替你操作 ComfyUI 批量出图。
> 前提：**已经按教程 1 配好一个在线 API**（没配的话先看 教程 1 · 第一次对话）。
> 只需要三件事：**启动 ComfyUI**、**切到导演 Agent**、**用大白话打字**。

---

## 第 1 步：先把 ComfyUI 启动起来（约 1 分钟）

Cat Chat 是「指挥官」，真正画图的是 ComfyUI，所以它必须在运行：

1. 像平时一样启动你的 ComfyUI。
2. 浏览器能打开 `http://127.0.0.1:8188` 就说明它在跑了。**保持它开着**。

> 没装过 ComfyUI？先去 ComfyUI 官网装一个，这步不在本教程范围内。

## 第 2 步：切到「导演 Agent」（约 15 秒，**最容易漏的一步**）

打开 Cat Chat，**先在顶栏的 Agent 下拉里选中「导演 Agent」🎬**：

> **为什么必须先切？**
> 开始页那些预设卡片**只负责发送指令，不会自动帮你换 Agent**。出图工具是绑在「导演 Agent」
> 身上的——不切过去，AI 手上没有出图工具，只会回你一句「我没有这个能力」。

## 第 3 步：一键让 AI 接管 ComfyUI（约 30 秒）

点开一个**新会话**，开始页上就有现成的卡片：

点 **「通过 HTTP 调用 ComfyUI」** 这张卡——预设指令会**立即自动发送**，不用打字、也不用回车：

**AI 随即开始探测** ComfyUI 是否在线，并接管后续的出图操作。想打断随时点输入框右侧的红色停止键。

## 第 4 步：用大白话出图（约 1 分钟）

直接在输入框说你要什么，例如：

```text
用 D:\workflows\cover_api.json 出 6 张封面，seed 1-6
```

> 这个 `.json` 是 ComfyUI 的 **API 格式工作流**：在 ComfyUI 网页里搭好图后，
> 菜单 → 工作流 → **导出（API）**（旧版界面需先在设置里开启 Dev 模式，再点 "Save (API Format)"），
> 保存成一个 json 文件即可。

AI 会自动调用 `comfyui_batch` 把任务提交给 ComfyUI，**图片直接挂回消息里**，点开看大图；真实文件落盘在 `data\generated` 目录：

## 第 5 步：想看进度？开任务面板（约 10 秒）

批量出图在后台跑，**不耽误你继续聊天**。点顶栏的「任务」可以看到进度、随时停止：

## 常见问题

**Q：AI 说连不上 ComfyUI？**
A：九成是 ComfyUI 没启动，或地址不是 `http://127.0.0.1:8188`。先启动 ComfyUI；地址不同时直接告诉 AI：「ComfyUI 在 http://127.0.0.1:你的端口」。

**Q：提示没有出图工具？**
A：多半是**第 2 步漏了**——没切到导演 Agent。**导演 Agent 开箱就带「ComfyUI 联动」这套工具（18 件）**，一般不用动：

如果你换成了别的 Agent，去 **设置 → Agent** → 点开它 → **工具集**，套用 **「ComfyUI 联动」** 卡再保存。

**Q：图出到哪里了？**
A：消息里直接能看；文件在 Cat Chat 工作目录的 `data\generated` 下。

**Q：想换个模型来理解我的需求？**
A：底部输入区的「模型」下拉随时换（**注意不是顶栏那个**——顶栏那个是 API）。

## 进阶（可选）：走 MCP 通道

除了上面的 HTTP 直连，也可以让 AI 通过 MCP 调用 ComfyUI。**不用手填任何表单**——点开始页的 **「设置本地 Comfy MCP」** 卡，回车发送，AI 会按 ComfyUI 官方指南自己干完所有事：探测本机 ComfyUI 的 Python 环境 → 安装 comfy-mcp → 注册进 Cat Chat：

- 前提：第 1 步的 API 已配好（AI 得有模型才能干活）；ComfyUI 最好在运行中——AI 会优先挑正在运行的那个环境，本地有多个 ComfyUI 且都没启动时，它会停下来问你用哪个。
- 装完后按 AI 的提醒，到 **设置 → Agent → 工具集** 里勾选启用 MCP 引入的 comfy 工具（**MCP 工具不会自动开启**）。
- 已注册的服务器在 **设置 → 连接状态 → MCP 服务** 里查看和管理；那里也留着手动添加的表单，但一般用不着。

> 新手用前面的 HTTP 直连就够了，MCP 属于可选项。
