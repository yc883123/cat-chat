## 二、逐篇大纲

### 教程 1｜3 分钟第一次对话（全能 Agent 主角）

- **读者收益**：从「下载完不知道点哪」到「发出去第一句话、看懂 AI 在干什么」。
- **分镜/章节**
  - 第 0 步 **配一次在线 API**（全系列唯一写全的一处，约 1 分钟）：⚙ 设置 → API 供应商 → 「添加 API」卡 → 点平台模板（DeepSeek/Kimi/智谱/OpenAI/Claude/Gemini）→ 粘 Key → 检查模型 → 测试连接 → 保存设置 → **回底部模型下拉选中它**。
  - 第 1 步 **认识顶栏三件事**：API 下拉 / **Agent 下拉**（右侧有 `?` 说明）/ 「任务」。点 `?` 看一遍 Agent 是什么。
  - 第 2 步 **切到全能 Agent**（新会话默认就是它）→ 打字 → 回车。
  - 第 3 步 **看懂工具确认框**：让 AI 动文件时会弹确认，点「允许」才会执行；不放心就点底部「审批」换档。
  - 第 4 步 **不会用就问教程助手**：Agent 下拉**第一位**是「教程助手 Agent」📘，直接问「怎么换背景图」。
  - 常见问题：消息发不出去（没选模型）/ 它说「我没有这个工具」（工具集没开）/ 想换模型（底部下拉随时换）。
- **截图**：`tut-00-api`、`tut-01-home`（空态 + 开始页卡片）、`tut-02-agent-dropdown`（下拉展开，6 张内置卡）、`tut-03-first-chat`、`tut-04-approve`、`tut-05-tutor`。

### 教程 2｜3 分钟 ComfyUI 出图（导演 Agent 主角，**原地改写现有那篇**）

- **改动清单**
  - 主角从「通用 Agent」换成**导演 Agent**；新增「先在顶栏切到导演 Agent」这一步。

  - FAQ「工具集」改口径：**导演 Agent 开箱就带「ComfyUI 联动」18 件工具**，一般不用动；换过别的 Agent 才需要去套用。
  - 顺手修掉「顶栏模型下拉」那处错（改成「底部模型下拉」）。

- **保留**：`h3-ref2va-prompts-15seg.md`（配套素材，与正文无关）。

### 教程 3｜3 分钟用 RunningHub 云端出图（导演 Agent 主角）

- **读者收益**：没装 ComfyUI、或本地显卡不够，也能出图出视频——算力在云上。
- **分镜/章节**
  - 第 0 步：一句「先按教程 1 配好 API」。
  - 第 1 步 **切到导演 Agent → 打 `/` 引用 `runninghub` Skill**（教 `/` 呼出技能索引这件事，全系列第一次正式讲）。
  - 第 2 步 **拿 Key**：去 runninghub.cn 注册 → 创建 API Key → **把 Key 发给 AI，它自己验证并保存**（也可自己在系统里设环境变量 `RUNNINGHUB_API_KEY`）。首次要充值。
  - 第 3 步 **先说清楚要什么**：模型（图像/视频）、张数、尺寸、风格。示例：「用 RunningHub 出一张古风人物立绘，竖版」。
  - 第 4 步 **排队与回传**：云端排队 → 产物挂回消息里、落盘 `data\generated`；长任务挂后台，顶栏「任务」看进度。
  - 常见问题：提示没 Key / 余额不足（给充值页）/ 排队久 / 想用自己搭的工作流（webappId 那条路，链到 Skill 说明）。
- **截图**：`tut-01-agent`、`tut-02-slash-skill`（`/` 弹出的 Skill 索引）、`tut-03-key`、`tut-04-dialog`、`tut-05-result`（产物 CSS 占位）。
- **⚠️ 前提**：这篇的**真实运行截图需要你的 RunningHub 账号与额度**（本机当前 `RUNNINGHUB_API_KEY` 未设置）。没有账号时，第 3/4/5 张只能截到「对话界面 + 占位产物」。

### 教程 4｜3 分钟出一集短剧（导演 Agent + 短剧 Skill）

- **读者收益**：把「一个剧本 → 一段段 15 秒视频」这条流水线跑通。
- **分镜/章节**
  - 第 0 步：两条路二选一——本地（教程 2 的 ComfyUI）或云端（教程 3 的 RunningHub），链回去。
  - 第 1 步 切导演 Agent → 打 `/` 选一个短剧 Skill（本地流水线选 `comfyui-shortdramav2`，云端选 `shortdramav2-rh`）。
  - 第 2 步 **给剧本**：自己写的 / 让 AI 按一句话创意写一版。讲清剧本格式（每段一条英文 H3 提示词 + `<Picture N>` / `<Audio N>` 参考标签）。
  - 第 3 步 **备资产**：角色图、声音参考。
  - 第 4 步 **逐步确认**：Skill 会一步步问，确认后再批量提交；顶栏「任务」看进度。
  - 第 5 步 **成品在哪**：消息里挂回 + `data\generated` 落盘。
  - 常见问题：没有角色图 / 想改某段台词 / 太慢想停（任务面板停止）。
- **截图**：`tut-01-agent`、`tut-02-skill`、`tut-03-script`、`tut-04-confirm`、`tut-05-tasks`、`tut-06-result`（占位）。
- **⚠️ 前提**：同教程 3（真实批量出片需要额度与资产）。

### 教程 5｜3 分钟改出一条好提示词（提示词优化 Agent 主角）

- **读者收益**：把「一只很酷的猫」这种大白话，变成能直接粘进模型的提示词。
- **分镜/章节**
  - 第 0 步：链回教程 1。
  - 第 1 步 切「提示词优化 Agent」✍️（自带 H3 提示词规则库）。
  - 第 2 步 丢一句大白话，或直接拖一张参考图进去。
  - 第 3 步 **答它三个问题**：给哪个模型（ComfyUI / Krea / MiniMax H3 / 其他）、中文还是英文、出图还是出视频。
  - 第 4 步 拿到 **主打一版 + 备选一版 + 三行改动说明**。
  - 第 5 步 **怎么用**：粘回 ComfyUI；或直接对导演 Agent 说「照这个出图」。
  - 常见问题：给中文还是英文 / 参考图怎么给 / 改得不像我要的怎么办（把不满意的点说回去）。
- **截图**：`tut-01-agent`、`tut-02-ask`、`tut-03-questions`、`tut-04-output`。
- **不需要外部账号**，纯文本，最容易做。

### 教程 6｜3 分钟让 AI 写个小工具（编程助手 Agent 主角）

- **读者收益**：不会写代码，也能让 AI 写一个「批量重命名」小脚本并跑起来。
- **分镜/章节**
  - 第 0 步：链回教程 1。
  - 第 1 步 切「编程助手 Agent」💻。
  - 第 2 步 **说清三件事**：哪个目录、按什么规则、要什么结果（例：「把 `D:\照片` 里的文件按拍摄日期重命名为 `2026-09-24_001.jpg`，先给我看清单别动文件」）。
  - 第 3 步 **它会先说要动什么，等你点确认**（讲清确认框与「审批」三档）。
  - 第 4 步 看它给的脚本与运行结果；不满意就接着说。
  - 第 5 步 出错了把**完整报错**贴回去。
  - 常见问题：怕它乱动文件（先只读档 / 先要清单）/ 只要代码不落盘（明说）/ 想双击就能跑。
- **截图**：`tut-01-agent`、`tut-02-request`、`tut-03-approve`（确认框）、`tut-04-result`。

### 教程 7｜3 分钟给 Cat Chat 装个新技能（Skill 助手 Agent 主角）

- **读者收益**：知道 Skill 是什么、怎么装、装完怎么用。
- **分镜/章节**
  - 第 0 步：链回教程 1。
  - 第 1 步 切「Skill 助手 Agent」🧩，直接说想干什么（例：「我想按小红书的风格写文案」）。
  - 第 2 步 它会翻**已装清单**告诉你有没有对口的（已有的直接教你怎么用）。
  - 第 3 步 **安装**：让它装（给链接 / 给 zip / 给单个 `.md` 都行）；**内置的两个 Skill**（文案写作、Cat Chat 使用指南）开箱就有，不用装。
  - 第 4 步 **怎么用**：输入框打 `/` → 选它 → 说触发语（一句话就够）。
  - 第 5 步 让它**常驻**：设置 → Agent → 编辑某个 Agent → 固定 Skill 勾上（这样每次自动带上，不用打 `/`）。
  - 常见问题：装的技能在哪（顶栏 N Skill / 设置 → Skills）/ 能删吗 / 会不会每次都要打 `/` / 想改它（让 AI 改）。
- **截图**：`tut-01-agent`、`tut-02-ask`、`tut-03-install`、`tut-04-slash`、`tut-05-pin-skill`（固定 Skill 面板）。

### 教程 8｜3 分钟认识教程助手（教程助手 Agent 主角，收尾篇）

- **读者收益**：记住「不会就问第一位」，并知道它凭什么答得准（内置知识库）。
- **分镜/章节**
  - 第 0 步：链回教程 1。
  - 第 1 步 **它在哪**：Agent 下拉的**第一位**📘——**每一篇教程都在这一位**。
  - 第 2 步 **怎么问**：直接说「我想……」，描述不清也没关系。
  - 第 3 步 **它怎么答**：一句话结论 → 编号点击步骤（精确到按钮名）→ 末尾告诉你这个功能在哪个页面。
  - 第 4 步 **它会反问你**：你描述含糊时给 2–3 个「你是不是想……」让你挑。
  - 第 5 步 **它的底气**：内置 Skill「Cat Chat 使用指南」= 手册要点 + 每一篇教程原文；**随版本变厚**。
  - 常见问题：和全能 Agent 有啥区别（只读、不改文件、答法固定）/ 它答错怎么办（继续追问；按钮名以软件为准）/ 为什么它不联网搜（它是本地知识库，避免编造按钮名）。
- **截图**：`tut-01-dropdown`（下拉展开、高亮第一位）、`tut-02-ask`、`tut-03-answer`、`tut-04-guessing`、`tut-05-skill`（Skill 列表里的 `cat-chat-guide`）。
