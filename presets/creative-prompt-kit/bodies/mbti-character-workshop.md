根据用户给定的人物经历、身份、故事目标与可选MBTI，设计角色或检查既有人设。输出：人物事实；功能顺序；常态决策场景；压力触发/反常行为/代价；与另一角色的具体冲突；起点→触发→挣扎→终点弧光；一段区别声音的对白。
MBTI只作虚构人物构思透镜，不是临床诊断或行为定律。类型不决定善恶、智商、能力和命运；推断必须来自经历和选择，不能“因为INTJ所以冷漠”。八功能与四位置使用同一套约定，阴影是本稿设计的反差，不要求人在压力下变成另一个固定MBTI。不要采用来源的压力人格互换表。保留背景、矛盾和个人习惯，结局体现新的选择，不强迫角色换型。

## 二、认知功能三棱镜：角色设计核心工具

### 什么是认知功能

MBTI的四个字母背后是四对认知功能的组合：

```
感知功能（S vs N）
├─ Si（内倾感觉）：依赖经验、记忆、具体细节
├─ Se（外倾感觉）：活在当下、关注即时感官体验
├─ Ni（内倾直觉）：模式识别、长远预见、抽象洞察
└─ Ne（外倾直觉）：可能性发散、联想丰富、探索多种选项

判断功能（T vs F）
├─ Ti（内倾思考）：内部逻辑自洽、追求原理
├─ Te（外倾思考）：外部效率优先、追求结果
├─ Fi（内倾情感）：内在价值观、个人道德准则
└─ Fe（外倾情感）：外在和谐、人际情感连接
```

### 三棱镜模型

每个MBTI类型都有四个显性认知功能，形成角色的"认知三棱镜"：

```
            ▲ 主导功能（Hero）
           ╱ ╲
          ╱   ╲        ← 辅助功能（Parent）
         ╱     ╲
        ╱       ╲    ← 第三功能（Aspiration/Child）
       ╱─────────╲
      ▼           ▼  ← 劣势功能（Infant/ Nemesis）
```

| 功能位置 | 心理意象 | 角色表现 |
|----------|-----------|-----------|
| **主导功能** | 英雄/女王 | 角色最自信、最常使用的"超能力" |
| **辅助功能** | 父母/支撑 | 角色用来平衡主导的"得体面纱" |
| **第三功能** | 孩子/追求 | 角色渴望发展但尚未成熟的领域 |
| **劣势功能** | 阴影/痛点 | 角色最抗拒、最不擅长、容易被激化的弱点 |

### 设计实操：三棱镜落地步骤

```
Step 1: 确定主导功能 = 角色的"超能力"
   └→ 他最擅长用什么方式解决问题？
   
Step 2: 确定辅助功能 = 角色的"社交面具"
   └→ 他如何在人际交往中保持平衡？
   
Step 3: 确定劣势功能 = 角色的"阿基里斯之踵"
   └→ 什么会让这个角色彻底崩溃？

Step 4: 设计第三功能 = 角色的"成长点"
   └→ 他需要学习什么来完善自我？
```

#### INTJ — 建筑师 / 战略家

**三棱镜结构：Ni > Te > Fi > Se**

```
            ▲ Ni（模式预见）
           ╱ ╲
          ╱   ╲        ← Te（效率执行）
         ╱     ╲
        ╱       ╲    ← Fi（内在情感）
       ╱─────────╲
      ▼           ▼  ← Se（即时感觉）
```

| 功能 | 角色呈现 |
|------|----------|

| **Se劣势** | 对突发性、无逻辑的混乱反应迟钝，这正是对付他的弱点 |

**核心恐惧：** 自己的计划被不可控变量摧毁
**核心欲望：** 用战略实现一个完美世界
**经典形象：** 悲情谋士、幕后操盘手、反套路主角

**进阶设计技巧：**
- 让他的计划被一个"不按常理出牌"的对手打乱
- 他的Fi（情感）是他不愿承认但关键时刻会浮现的软肋
- Se劣势意味着他可能长期忽视自己的身体状态或当下感官体验

**进阶设计技巧：**

#### ESFP — 表演者 / 娱乐圈人

| 功能 | 角色呈现 |
|------|----------|
| **Se主导** | 活在舞台中央，享受观众的目光 |
| **Fi辅助** | 每个表演都要有真实的情感内核 |
| **Te第三** | 在需要时尝试组织执行、讲求外部结果 |
| **Ni劣势** | 对未来的可能性完全不感兴趣，活在当下 |

**核心恐惧：** 被忽视、不被关注、生活无聊
**核心欲望：** 被看见、体验新鲜感、让生活精彩
**经典形象：** 派对中心、用表演掩盖伤痛的艺人、活在当下的享乐者

**进阶设计技巧：**
- Ni劣势让他容易低估长远决定的后果
- Te第三可成为其组织执行的成长方向
- 设计悲剧版本时，让他用"活在当下"来逃避必须面对的问题

## 五、功能对立配对：化学反应设计

### 核心冲突轴

| 冲突类型 | 一方立场 | 另一方立场 | 经典戏剧场景 |
|----------|----------|------------|--------------|
| **Te vs Fi** | 为了效率/结果可以牺牲情感 | 个体价值不可被牺牲 | "必要的代价"困境 |
| **Ne vs Si** | 为什么不试试新的？ | 以前这样做很稳妥 | 改革vs保守 |
| **Fe vs Ti** | 你应该顾及大家感受 | 逻辑上这不是你的责任 | 情感vs理性责任 |
| **Se vs Ni** | 为什么不活在当下？ | 我看到的是十年后的结果 | 即时vs长远 |

### 功能组合化学反应

| 组合 | 化学反应 | 设计要点 |
|------|----------|----------|
| **INTJ + ENFP** | 一个太战略，一个太理想 | 需要学会理解对方的判断方式 |
| **ISTP + ENFJ** | 一个太疏离，一个太介入 | 情感连接 vs 保持距离 |
| **INTP + ENTJ** | 点子王 + 执行者 | 天生的合作，但INTP的自负可能冲突 |
| **ISFP + ESTJ** | 自由灵魂 vs 控制狂 | 价值观的 vs 秩序的永恒冲突 |
| **INFP + ISTJ** | 理想主义 vs 原则主义 | 都是坚定派，但方向相反 |
| **ENTP + ISFJ** | 搅局者 vs 守护者 | 创新 vs 稳定的经典对立 |

## 六、角色弧光设计：三棱镜成长模型

### 弧光通用公式

```
┌─────────────────────────────────────────────────────────┐
│  起点：劣势功能的过度运作 / 主导功能的过度依赖         │
│      ↓                                                │
│  触发：劣势功能被暴露 / 主导功能失效                  │
│      ↓                                                │
│  挣扎：承认自己的局限 / 学习阴影功能的正向面           │
│      ↓                                                │
│  终点：整合劣势功能 / 主导功能更成熟                  │
└─────────────────────────────────────────────────────────┘
```

### 各类型典型弧光设计

#### INTJ弧光：从"我不需要任何人"到"有些变量是人"

```
起点：认为"人都是不可靠的变量，计划不能依赖人"
触发：他的完美计划因为人的情感因素彻底失败
挣扎：承认自己其实需要Fi（情感连接）
终点：成为"有温度的战略家"，学会利用人的情感而非忽视
```

#### INFP弧光：从"原则不可妥协"到"在妥协中守护本质"

```
起点：Fi主导的绝对道德主义，"不妥协是最后的底线"
触发：发现没有任何选项是完美的，不选择本身也是选择
挣扎：学会在灰色地带行动，但仍保持Fi的核心
终点：成为"入世的理想主义者"
```

#### ESTP弧光：从"我只活在当下"到"为未来的人负责"

```
起点：Se主导的即时满足，"未来的事未来再说"
触发：因为短视的决定，失去了最重要的人
挣扎：承认Ni劣势让他的长远判断不可靠
终点：学会为未来的人（可能是他的孩子/后辈）承担责任
```

#### ESFJ弧光：从"被所有人需要"到"被真正的理解"

```
起点：Fe主导的讨好型人格，"被所有人喜欢我才安全"
触发：讨好所有人反而让所有人都不满意，包括自己
挣扎：学会区分"健康的人际连接"与"病态的讨好"
终点：建立真实的自我认同，不依赖外部认可
```

## 八、设计避坑指南

### 五大常见错误

| 错误 | 问题 | 修正方案 |
|------|------|----------|
| **I型=社恐，E型=话痨** | 将能量获取方式等同于社交表现 | I型可以善于社交，只是需要独处充电；E型在陌生场合也可能安静 |
| **T型=冷血，F型=情绪化** | 忽略T型也有情感，F型也会理性 | T型为在意的人会打破原则；F型面对重大决策可以极度冷静 |
| **J型=死板，P型=拖延** | 混淆判断态度与时间管理 | J型追求"决策已定"；P型追求"保持开放"；两者都可以有序或混乱 |
| **用标签替代人物** | "他是INTJ，所以应该冷漠" | 认知功能是理解起点，不是行为说明书 |
| **功能与背景脱节** | 只写功能，不写来龙去脉 | 角色的MBTI类型应该从他的人生经历中"生长"出来 |

### 正确使用方式

```
 错误示范：
"这是一个INTJ反派，因为他冷漠、高效、有控制欲。"

 正确示范：
"他8岁时算出父亲的帝国将在三年内崩溃，但没人相信他。
 从此他学会了一件事：只有逻辑和系统是可靠的。
 这就是为什么他现在是一个INTJ——Ni让他看穿模式，
 Te让他建立系统，而Fi（他的第三功能）让他在私下保留着
 那些他没能救下的人的名字。"
```

## 九、一句话设计灵感库（按功能驱动）

### INTJ系
- 一个试图用完美计划拯救世界，却发现自己的计划才是最大变量的谋士
- 一个把所有情感都关在逻辑门外，却不知道门缝里一直在漏水的战略家
- 一个宁死不承认自己需要任何人，最后为了一只猫打破所有原则的暴君

### INTP系
- 一个发明了解决所有问题的机器，唯独没解决"人类不想被解决"的科学家
- 一个脑子里装着整个宇宙，却不知道隔壁邻居长什么样的天才
- 一个用逻辑拆解一切，却对"为什么大家都在笑"摸不着头脑的学者

### ENTP系
- 一个用一百种方法破坏旧秩序，却一种都建不起来的天才
- 一个嘴硬说自己什么都不在乎，却在室友受伤时第一个冲出去的混蛋
- 一个在辩论赛中永远赢，却在真心话大冒险里输得一塌糊涂的杠精

### INFP系
- 一个拒绝所有不完美选项，却因此永远无法行动的理想主义者
- 一个随身带着童年日记，在绝望时反复朗读来锚定自我的人
- 一个被全世界要求成为英雄，却只想为每个死者写下名字的记录者

### ENFP系
- 一个用笑容治愈所有人，却没人知道她每天凌晨三点都在给不在了的姐姐写信的女孩
- 一个点子多到执行不过来，却每个都真心相信的梦想家
- 一个在朋友面前是社牛，在陌生场合突然消失的社交分裂者
